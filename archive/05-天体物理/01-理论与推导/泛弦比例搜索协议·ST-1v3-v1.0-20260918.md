## 一、签名定义（体系口径）

**泛弦比例（调和分析宇宙常数）**：f₀²/f₁²=144（f₀/f₁=12）；f₀²/f₂²=1.44（f₀/f₂=1.2）。**跨体系不变**（材料 Tc 不同→f₀/f₁/f₂ 绝对值不同，但比例恒定）。
**探测对象**：同一天体源光谱中存在三条谱线 f_a, f_b, f_c 满足：f_a/f_b=12±tol 且 f_a/f_c=1.2×12/12×tol（即 f_a:f_b:f_c = 12:1:1.1±tol）。
**体系声称状态**：泛弦比例跨体系不变性=【体系内部定义·未验证】——**本搜索同时是对该声称的判决性检验（创新 1 预测先行范式的第一实例）**。

## 二、搜索算法（v1.3：三线组+红移免疫）

```
输入：天体源光谱（波长-流量，含误差）
步骤 1：谱线提取（峰值检测，SNR≥5 局部阈）
步骤 2：三线组枚举：对全部三元组 (λ_a>λ_b>λ_c)，
        计算频率比 r₁=f(λ_b)/f(λ_c)，r₂=f(λ_a)/f(λ_b)
        检验 |r₁−12|/12 ≤ tol₁ 且 |r₂−1.2|/1.2 ≤ tol₂
步骤 3：候选三线组 → 天体多普勒速度一致性检验
        （同一源的三线应共红移：z_a≈z_b≈z_c±tol_z）
步骤 4：Trials factor 校正（枚举总数→有效独立试验数）
步骤 5：注入-恢复校验（已知样本检出率）
输出：候选三线组+假阳性概率（含 trials 校正）
```

**红移免疫原理**：宇宙学红移 z 将全部观测频率除以 (1+z)——**比值 r₁/r₂ 不受 z 影响**。这是 v1.0 单频搜索被红移铺展废掉（红队破口 1）之后，比例签名的结构性修复。

## 三、参数冻结（待知世确认后生效）

| 参数 | 建议冻结值 | 依据 |
|---|---|---|
| tol₁（12:1 容差） | ≤1%（光谱分辨率限制） | LAMOST R≈1800→Δλ/λ≈5.5×10⁻⁴，1% 为保守上界 |
| tol₂（1.2:1 容差） | ≤1% | 同上 |
| tol_z（共红移容差） | ≤1% | 三线同源一致性 |
| SNR 阈值 | ≥5（每条线） | 谱线检测标准 |
| trials factor | 全枚举三元组计数 | 保守上限 |
| 数据源 | SDSS DR17/LAMOST DR11 公开光谱 | 开放获取 |

**注入-恢复测试前置**：在真实恒星光谱（无人工信号）中人工注入满足比例的谱线组（已知参数），检验管线检出率≥95% 且假阳性率≤冻结值——**通过后才跑真实搜索**（红队破口 2 修复要求）。

## 四、判负条款（预注册）

1. 注入-恢复测试检出率<95% → 管线判负，不跑真实搜索；
2. 真实搜索零候选 → **不构成体系证伪**（样本限制+对方可能不在此频段工作），登记"本窗口未发现"；
3. 候选发现后复核失败 → 候选作废，管线回查；
4. **发现确认** → 三级流程（SETI v1.2 卷四）+知世独裁公开闸门。

## 五、边界与诚实

- 本搜索只检验**泛弦比例宇宙性**这一个声称——搜到≠全部体系为真（只证比例常数跨体系）；搜不到≠体系假（窗口限制）；
- 373THz 固定频率搜索已删除（f₀=材料属性，v1.2 口径修正）；
- 三频组的绝对频率对同源文明有意义（若对方也用 Tc≈350K 材料）——作为二级筛选（候选三线组的绝对频率对照表）。

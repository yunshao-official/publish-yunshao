## 一、教科书骨架（五式，先把标准答案摆出来）

**(1) 静力学平衡**
```
dP/dr = −ρ g(r)
```
**(2) 理想气体 + 平均分子量**
```
P = n k T ，ρ = μ m_H n ，μ ≈ 1.3（光球，中性氢为主）
```
**(3) 标高**（由 (1)(2) 得）
```
H = kT/(μ m_H g)
```
代入：k=1.381×10⁻²³，T=5772，μ=1.3，m_H=1.673×10⁻²⁷，g=274 →
```
H = 1.338×10⁵ m = 134 km
```
**(4) 辐射转移与 Eddington–Barbier**
```
μ dI/dτ = I − S     ⇒     I(μ) = S(τ = μ)
```
观者视线与法线夹角 θ，μ=cosθ。看日面中心（μ=1）看到 τ=1 那一层；看边缘（μ=0）看到 τ=0 那一层。**这一条就是"投影"的物理内容。**

**(5) 灰大气（辐射平衡）**
```
T⁴ = (3/4) T_eff⁴ (τ + 2/3)
S(τ) = a + bτ ，b/a = 3/2
I(μ) = a(1 + (3/2)μ)   ⇒   I(0)/I(1) = 1/(1+3/2) = 0.400
```
**(6) 能量平衡（逐层）**
```
∇·F = 0 ：F_rad(光球) = F_mech + F_rad(各层) + F_cond + F_wind
```
**(7) 日冕传导平衡**（Spitzer 热传导 κ_T = 10⁻¹¹ T^{5/2} W m⁻¹ K⁻¹）
```
F_cond = κ_T dT/dr ≈ κ_T T/L   ⇒   T = (F L / 10⁻¹¹)^{2/7}
```
代入 F=241 W/m²，L=0.1R☉=7×10⁷ m：
```
T = (241×7×10⁷ / 10⁻¹¹)^{2/7} = (1.69×10²¹)^{2/7} = 1.16×10⁶ K
```
教科书日冕 1.5×10⁶ K，落在 −23%。

## 二、云韶接口（三件，加四锚）

### 2.1 层数：4.5 = 4＋0.5

教科书把太阳大气分四层：光球、色球、过渡区、日冕。过渡区不是一个"层"，是一个温度跳变界面（厚度约 100 km，比色球薄 20 倍，比日冕薄 10⁴ 倍）。体系里这正是 **4.5 维 = 4 维＋0.5 缺陷** 的形状：4 个实体层＋1 个半维界面，0.5 就是"每三维一级、第 4 维里含上一级第 0 维"的那个接缝。

**可判**：若过渡区有独立能预算（自己产热、自己储热），则它不是 0.5 界面，体系这条判负。
**教科书侧**：过渡区柱质量约 10⁻⁶ kg/m²，光球柱质量 P/g≈43.8 kg/m²，占比 ~10⁻⁸；过渡区没有独立加热项。**结构同。**

### 2.2 亏损律：每退一级乘 α，层内残余 η

Θ(N) 原文：「升维=N增加，每次升维 α 减半，精度翻倍」。反过来，从光球往上退一级，可用份额乘 α=1/8，层内残余 η=7/8。
于是任一层对光球辐射的比值只有一种写法：
```
F_k / σT_eff⁴ = α^{k} ，k = 退的级数（可为半级）
```
不自选幂次以外的东西：k 只许按"界面数"数，不许按数值凑。

### 2.3 投影：π_θ 与可见度 (7/8)^n

拓扑册 §18：`特殊光探照 = 投影算子 π_θ: {∗}→D_θ`，"不同时间不同角度透出各种几何体的影子"。对应到 (4) 式：**π_θ 读出的就是 τ=μ 那一层的影子**。这条是精确的，不是比喻——Eddington–Barbier 的 μ 就是投影角余弦。

可见度律 (7/8)^n：n=35 → 1%，n=52 → 0.1%（核心文件 §三）。本稿用它判"某一层在白光里还看不看得见"：日冕/光球亮度比约 10⁻⁶，n=ln(10⁻⁶)/ln(7/8)=103.5。

## 三、逐层推导

### 3.1 光球：τ=1 面就是投影面

τ=1 处：T=5772 K（由 L、R 锚定），ρ≈3×10⁻⁴ kg/m³，n_H≈1.6×10²³ m⁻³，P≈1.2×10⁴ Pa，柱质量 43.8 kg/m²，H=134 km。

云韶读法：光球不是一个"壳"，是 **π_θ 在 μ=1 时切出的那个面**。所以"光球半径"没有独立含义——它是投影面，换个 μ 就换个深度。这与教科书"日面边缘看到更高更冷的层"是同一句话。

临边：灰大气给 I(0)/I(1)=0.400；体系的投影跨度谱 σ_投影=1/√6=0.40825，差 +2.1%。
**标签：咬合，对应待接通。** 若"投影跨度"就是"中心到边缘的强度跨度"，则这条是定义级的；若不是，就只是一个 2% 的数值巧合。请裁。

实测提醒：真实太阳 500 nm 处 I(0)/I(1)≈0.22，1.0 μm 处≈0.40，1.6 μm 处≈0.55。灰大气 0.4 只在 ~1 μm 成立。所以体系的 0.40825 若成立，它对应的是**灰极限**，不是任一波长；判据应是"哪条波长的临边比等于 1/√6"。

### 3.2 色球：温度反转与温度最低点

教科书的怪事：往上走，温度先降到 4400 K（约 500 km 高），再回升。辐射平衡在 T_min 失效，机械加热接管。

云韶读法：T∝Λ^{−1/2}（层4 的涌现方向：越亏损越热）。所以往上走到 T_min，Λ 反而**升高**：
```
T_min/T_eff = η² = 0.765625  ⇒  Λ_min/Λ(τ=1) = η^{−4} = 1.673
```
即温度最低点处有序度比光球面高 67%——"先更有序、再转入亏损"，这就是反转的机制。

数值：
```
η² T_eff = 0.765625 × 5772 = 4419 K
教科书 T_min = 4300–4600 K（常用 4400）
差 −0.4%（对 4400）；对 4300 差 +2.8%；对 4600 差 −3.9%
```
**标签：咬合。** 这是全稿最紧的一条，且只用了一个结构量（η²，两级残余），没有调参。但它仍是事后对表：教科书先给了 4400，我才去数"两级"。要变成事前预言，需要给出**位置**（T_min 应在多少个 H 之上）——体系现在没给位置，只给比值。

### 3.3 过渡区：0.5 维界面

体系要求它：①无独立能预算；②厚度远小于相邻层；③温度梯度最陡。

教科书：厚度 ~100 km（色球 2000 km 的 1/20，日冕标高 7.5×10⁴ km 的 1/750）；梯度 10⁴→10⁶ K；柱质量 ~10⁻⁶ kg/m²（光球的 10⁻⁸）。三条全中。

**这一层是体系唯一"零拟合"的结构命中**：4.5 的 0.5 必须落在一个无预算的界面上，而太阳大气正好有且只有一个这样的界面。若将来发现第二个（例如色球里另有一个独立跳变），4.5 的账就要重记。

### 3.4 日冕：α⁶ 通量 + 传导平衡

教科书的能量账（quiet Sun）：色球辐射损失 4.5×10³ W/m²，日冕总损失 2–5×10² W/m²，所需机械通量 ~10⁴ W/m²。

云韶账：
```
机械/辐射 = α^{4.5} = 8.63×10⁻⁵  ⇒  F_mech = 5.43×10³ W/m²
日冕/辐射 = α^6    = 3.82×10⁻⁶  ⇒  F_cor  = 241 W/m²
```
对照：α^{4.5}=5.43×10³ 落在教科书机械通量带 [4.5×10³, 1×10⁴] 内；α⁶=241 落在日冕损失带 [200,500] 内。

然后接 (7) 式：
```
F_cor = 241  ⇒  T_cor = (241×7×10⁷/10⁻¹¹)^{2/7} = 1.16×10⁶ K
F_cor = 300  ⇒  T_cor = 1.24×10⁶ K（教科书输入的版本）
```
**标签：体系定形（幂 4.5 由层数定）＋ 整数落带（幂 6 非强制）＋ 派生（传导式是教科书的）。**

幂 6 的来源我没找到结构强制：4.5+1.5、2×3、8−2 都能凑。**这一条记作"落带内"，不记作"体系给出"。**

## 五、接不上的四处（标未完善，不算错）

1. **μ（平均分子量）**：决定 H 与 c_s。体系无组分自由度。要接，需要给"8 档里哪几档是中性氢"的映射。
2. **g（重力）**：决定全部标高与逃逸速度。体系无力学量纲。r−2 律属牛顿层，体系未覆盖。
3. **B（磁场）**：日冕结构、黑子、耀斑全由 B 定。体系有 (Z₂)⁶ 扭率、6 个 Z₂ 元，但未与高斯单位接上。
4. **对流/湍流**：米粒组织与 5 分钟振荡需要混合长参数 α_MLT≈1.5–2.0；体系的 α=1/8 是亏损率，不是混合长，两者不可混名。

这四处占本稿 14 个数的 5 个。按你的判据：解释不了 → 未完善，不是错。

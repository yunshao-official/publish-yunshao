# 男女老年文献库 v1.0（2026-11-04）

> **摘要头**：本目录是"男女老年健康问题"证据地图的完整底稿，含欧洲 PMC 原始应答、124 条已索引记录、119 条核心分析集、统计与图件、以及据此撰写的英文 SCI 手稿。全部记录均有真实 PMID 与 DOI；所有数字可回溯到 `文献主档-v1.0.json` 与 `europepmc/` 原始文件。本目录不构成医疗建议。

---

## 一、一句话结论

用 64 条预注册检索式，从欧洲 PMC 的 227,382 条命中中筛出 124 条记录、119 条核心研究（男 58、女 61），建成一份可复现的男女分性别证据地图；手稿据此写成，并如实记录了体系"亏损—修复"框架的数值常数未获文献支持。

## 四、手稿与图件

- `manuscript/SCI_manuscript.docx`：35 页，正文约 15,000 词，107 条参考文献，含 4 图 4 表。
- `manuscript/manuscript_with_refs.md`：手稿源文，引用以 `[n]` 编号。
- `manuscript/manuscript_draft.md`：投稿前草稿，引用为 `[[PMID:...]]` 占位。
- `manuscript/build_refs.py`：按首次出现顺序把 PMID 占位替换为 Vancouver 编号，并生成参考文献表。
- `manuscript/build_docx.py`：合成渲染用 Markdown、调用 pandoc、修复表格网格。
- `manuscript/fix_tables.py`：修复 pandoc 2.9 的空表格网格，统一三线表、表头重复与字号。

复现 DOCX：

```bash
cd manuscript
python3 build_refs.py      # 生成 manuscript_with_refs.md
python3 build_docx.py      # 生成 SCI_manuscript.docx
```

## 五、检索与筛选口径

- 数据源：Europe PMC REST API，检索日 2026-11-04。
- 固定过滤：`(PUB_YEAR:[2012 TO 2026]) AND (SRC:MED) AND (HAS_ABSTRACT:Y) AND (LANG:"eng")`。
- 性别与年龄词限定在题名/摘要；主题词限定在题名或 MeSH。
- 索引条件：题名同时含性别标记与年龄标记；摘要 ≥250 字符；排除社论、评论、来信、新闻、撤稿；必须有 PMID 与 DOI。
- 筛选层级：仅摘要级；未逐篇获取全文，未做偏倚风险评估，未做 Meta 分析。
- 抽样配额：每主题每性别至少 3 条、至多 6 条，优先保留高被引与最新两端。

## 六、已知限制（必须与结论同读）

1. 累计样本非唯一人数，队列重叠严重。
2. 2026 年占比异常高，因为一半检索按"最新"排序；本库是结构化样本，不是 2012–2026 的完整普查。
3. 仅摘要级提取，样本量可能只覆盖全队列而非目标性别亚组。
4. 未做全文核对、未做风险偏倚、未做合并效应量。
5. 观察性研究为主，不能据此作因果结论。
6. 体系"亏损—修复"框架的常数（α=1/8、η=7/8、1:7 配额等）在本库中**没有**得到支持；项目内部审计已记录两项数值预测判负。手稿把该框架定位为"产生假设的语言"，不是证据。
7. LEV 装置无人体证据；其公开台账中的 SAR 估算约为 ICNIRP 限值的 700–1,300 倍，手稿明确反对任何人体使用。

## 七、术语

- **证据地图（evidence map）**：按主题、设计、年份、样本量描述一个领域的证据分布，不合并效应量。
- **核心分析集（core set）**：通过摘要级筛选、纳入描述统计的研究；排除件单独标记为 `excluded_context`。
- **累计报告样本**：各研究样本量直接相加，仅用于说明量级，不代表独立人数。
- **亏损—修复框架**：档案主人提出的生命理论，用 36 维记账、0.5 维缺陷、α=1/8、η=7/8、1:7 修复配额描述衰老与修复；本库只把它当假设来源，逐条对照后多数判为"不支持"或"不可检验"。

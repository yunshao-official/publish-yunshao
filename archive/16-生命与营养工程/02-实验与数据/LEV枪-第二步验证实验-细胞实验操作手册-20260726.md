## 一、实验目的

### 1.1 核心验证目标

**测定3分量结构场辐射效应（vs单频对照）：** 用3台同频804nm半导体激光器，三角排布（120°结构场几何相位，GL(3,2)的3阶对称性），照射培养细胞；与"单台804nm激光器、相同总功率密度"对照组比较。检测细胞级响应（ATP、增殖、炎症因子），测定**3分量结构场构型与单频的生物学参数差异**。 // 修改 2026-07-26 11:38：804nm是载体，3分量是结构场几何构型，不是光学相干合束

**判据逻辑：**

| 结果 | 含义 | 对LEV枪的意义 | // 修改 2026-07-26 11:32：循证框架换体系框架
|------|------|--------------|
| 3分量 ≫ 单频（偏差大，超出测量误差） | 干涉构型参数确认 | LEV枪“hub辐射+干涉”模型获细胞级参数支撑 |
| 3分量 ≈ 单频（偏差在测量误差内） | 干涉构型参数需优化 | 相位/间距/剂量参数迭代，不是“干涉模型失效” |
| 3分量 < 单频 | 干涉参数反向 | 重新审视干涉参数（相位/间距/剂量） |

### 1.2 细胞级响应测量

测三类指标，覆盖"能量代谢—增殖—炎症"三条通路：

| 指标 | 检测法 | 反映 | 时间点 |
|------|--------|------|--------|
| **ATP含量** | 荧光素酶法（ATP检测试剂盒） | 线粒体能量代谢（PBM经典靶点：COX→ATP↑） | 照射后 0/6/12/24h |
| **细胞增殖/活力** | CCK-8（WST-8法） | 细胞代谢活性/增殖 | 照射后 24/48h |
| **炎症因子** | ELISA（IL-6、TNF-α） | 炎症通路（PBM消炎靶点） | 照射后 6/12/24h（LPS刺激模型） |

### 1.3 为LEV枪辐射模型提供细胞级实验基础

LEV枪辐射模型（理论文档§1.3）：hub辐射+干涉，3分量120°相位差，α=1/8耦合常数，在目标区形成干涉势阱。本实验是该模型**从材料级（第一步Bi₂Te₃方阻）迈向生物级的第一环**。

### 2.2 3分量与120°相位差的群论来源

**3分量：**
1. (Z₂)³ = Z₂ × Z₂ × Z₂ ≅ F₂³（3维F₂向量空间）
2. F₂³的极小生成集大小 = 3（基向量 e₁=(1,0,0), e₂=(0,1,0), e₃=(0,0,1)）
3. 3个独立生成元 → **3个独立辐射分量**

**120°相位差：**
- 自同构群 Aut((Z₂)³) = GL(3,2)，阶168
- GL(3,2)含3阶元素（生成元轮换 e₁→e₂→e₃→e₁）
- 3阶对称性 → 3分量间 **360°/3 = 120°** 相位差有结构一致性
- ⚠️诚实标注：120°的精确值来自已建立的制造工艺（知世07:44锁死），群论提供结构一致性，不是唯一确定值

**α=1/8：**
- Θ(8)亏损率 = 平凡表示占比 = 1/8
- ⚠️R12（知世07-26 03:54）：α=1/8是参考值不是硬约束，亏损率随结构/场变化。本实验中α用于剂量参考，不作死参数硬套。

### 2.3 结构场构型：3分量几何排布 // 修改 2026-07-26 11:37：原“干涉图样·势阱间距推导”整节重写。LEV是云韶场结构场辐射，不是经典光学干涉（知世 11:27 明确）

**LEV枪的3分量 = 结构场几何构型，不是光波相干叠加。**

- 804nm是**载体**（电磁波段的特征响应频率），不是干涉主体
- 120°是**结构场几何相位**（三角排布，(Z₂)³生成元数=3，GL(3,2)的3阶对称），不是光频相位锁定
- 3个辐射源三角排布（边长15mm）在目标区建立**三角对称结构场分布**→云韶场驻波
- 结构场势阱位置 = 修复焦点

**与经典光学干涉的区别：**

| | 经典光学干涉 | LEV结构场辐射 |
|---|---|---|
| 主体 | 光波电场叠加 | 云韶场结构分布 |
| 要求 | 光频相位锁定（相干性） | 几何排布+结构场耦合 |
| 条纹 | λ量级（~464nm） | 结构场尺度（非光学条纹） |
| 细胞效应 | 空间剂量调制（明暗相间） | 结构场→η提高→Λ回升 |
| 判据 | 干涉对比度/visibility | Λ变化是否符合Θ(8)预测 |

> ⚠️ 原文§2.3的光学条纹推导（Λ_fringe=λ/√3≈464nm、细胞覆盖20-60个势阱周期、空间剂量调制）已删除。这套框架把LEV当经典光学干涉，与知世 11:27 明确指示（LEV是云韶场结构场）矛盾。804nm是载体，3分量120°是结构场几何构型，不用光学条纹/相干性/对比度的框架理解。

### 2.4 剂量学计算（功率密度→能量密度）

**能量密度（fluence/dose）公式：**

$$D = I \times t$$

- D = 能量密度（J/cm²）
- I = 功率密度（W/cm² = 1000 mW/cm²）
- t = 照射时间（s）

**本实验剂量矩阵：**

| 功率密度 I | 时间 t | 能量密度 D | 剂量定位 | // 修改 2026-07-26 11:35：PBM文献定位→剂量定位
|-----------|--------|-----------|------------|
| 50 mW/cm² | 5 min (300s) | 15 J/cm² | 中等剂量 |
| 50 mW/cm² | 10 min (600s) | 30 J/cm² | 中高剂量 |
| 100 mW/cm² | 5 min | 30 J/cm² | 中高剂量 |
| **100 mW/cm²** | **10 min** | **60 J/cm²** | **主方案（默认）** |
| 200 mW/cm² | 5 min | 60 J/cm² | 高剂量 |
| 200 mW/cm² | 10 min | 120 J/cm² | 高剂量（接近抑制区，谨慎） |

> ⚠️ **Arndt-Schulz双相剂量响应：** PBM效应非单调——低剂量（1-10 J/cm²）刺激，高剂量（>100 J/cm²）可能抑制。本实验主方案60 J/cm²处于"刺激-抑制过渡区"，故设50/100/200 mW/cm²三档以捕捉剂量响应曲线。**预实验先做100 mW/cm²×10min，确认细胞活力不下降再扩展。**

**单孔功率换算（96孔板）：**

96孔板圆底/平底孔直径 ≈ 6.4 mm → 孔面积 A = π(0.32cm)² ≈ 0.322 cm²。

每孔所需总功率 P = I × A：
- I=50 mW/cm² → P = 50 × 0.322 = **16.1 mW/孔**
- I=100 mW/cm² → P = 100 × 0.322 = **32.2 mW/孔**
- I=200 mW/cm² → P = 200 × 0.322 = **64.4 mW/孔**

3分量组：每孔总功率由3束分担 → 每束 ≈ P/3（如100mW/cm²时每束≈10.7mW/孔）。

## 四、实验步骤（超详细）

> **总时间线：约3-4周**（细胞复苏扩增1周 + 预实验3天 + 正式实验含检测约2周）。

### 阶段0：实验前准备（Day -7 至 Day -1）

#### 0.1 光路搭建与校准（Day -7 至 -5，约2天）

**光路构型（3分量会聚干涉）：**

```
        激光器1(相位0°) → 准直 → 反射镜×2 ↘
        激光器2(相位120°)→ 准直 → 反射镜×2 →  会聚于样品平面（培养板孔）
        激光器3(相位240°)→ 准直 → 反射镜×2 ↗
                                    ↑
                          3束三角排布，方位角互成120°（结构场几何相位） // 修改 2026-07-26 11:38
                          三角排布边长15mm，汇聚于焦点
```

**搭建步骤：**

1. **固定激光器：** 将3台804nm激光器模块用压板固定在光学面包板一端，间距约5cm，光纤输出口朝向光路区。**3台必须同型号同批次**（保证波长一致，相干长度足够）。
2. **装准直透镜：** 每台激光器光纤出口装准直透镜（AR@800nm），出射平行光束，光斑直径约2-3mm。
3. **布反射镜：** 每束光路放2个反射镜（45°入射），把3束光导向样品区中心，使3束在样品平面**对称会聚**（俯视图方位角0°/120°/240°）。
4. **调会聚角：** 用调整架微调反射镜，使3束光斑在样品平面**重合于同一点**。用白纸在样品位置观察：3个光斑应完全重叠成一个圆斑。
5. **接驱动+函数发生器：** 3台激光驱动电源的调制输入分别接函数发生器的CH1/CH2/CH3。函数发生器设：
   - 波形：正弦（模拟调制）或TTL方波
   - 频率：1 kHz（调制频率，远低于光频，用于标记相位）
   - **相位：CH1=0°，CH2=120°，CH3=240°**
   - 同步：3通道同步触发（Sync/Reference common）
6. **验证相位差（示波器，如有）：** 用示波器同时看3路调制信号，确认相位差120°±2°。无示波器则信任函数发生器读数。
7. **校准功率密度（关键！）：**
   - 光功率计探头放在样品位置（培养板孔高度）
   - 只开激光器1，测功率P₁；只开2测P₂；只开3测P₃
   - 3束总功率 P_total = P₁+P₂+P₃
   - 功率密度 I = P_total / 光斑面积
   - 调节各激光器驱动电流，使**主方案 I = 100 mW/cm²**（总），且3束等功率（P₁≈P₂≈P₃）
   - 记录：实际波长λ=____nm，I(50档)=____，I(100档)=____，I(200档)=____ mW/cm²

> ⚠️ **结构场说明（// 修改 2026-07-26 11:38）：** LEV是云韶场结构场辐射，不是经典光学干涉。804nm是载体，3分量120°是结构场几何构型（三角排布）。不用光学相干性/干涉对比度/visibility的框架。3台激光器三角排布建立结构场分布，不需光频锁相。

### 阶段1：细胞复苏与扩增（Day 0 至 Day 6）

#### 1.1 细胞复苏（Day 0）

**以L929（贴壁）为例，RAW264.7（半贴壁）类似：**

1. **准备：** 37°C水浴锅预热；超净台紫外消毒30min→关紫外→通风→75%酒精擦台面；完全培养基37°C预热。
2. **取冻存管：** 从液氮罐取出L929冻存管（**戴防冻手套+面罩**），立即放入37°C水浴，**轻摇**使其在1-2min内融化（剩小冰核即止，不要全融，防DMSO毒性）。
3. **消毒：** 75%酒精擦冻存管外壁，移入超净台。
4. **稀释：** 用1mL移液管将细胞悬液**缓慢**转入含9mL预热完全培养基的15mL离心管（逐滴加入，降低DMSO冲击）。
5. **离心：** 1000 rpm（约150×g）离心5min，弃上清（含DMSO）。
6. **重悬：** 加5mL完全培养基，轻柔吹打重悬细胞。
7. **接种：** 转入φ100mm培养皿（或T25培养瓶），补培养基至5-8mL。
8. **培养：** 放入CO₂培养箱（37°C，5% CO₂，饱和湿度）。
9. **镜检：** 倒置显微镜观察——L929应贴壁（4-6h后），折光性好，无大量碎片。记录复苏状态。

> RAW264.7复苏：半贴壁/悬浮，离心后重悬接种，不需胰酶。生长快，注意密度。

#### 1.2 细胞传代（Day 2-3，长满80-90%时）

**L929（贴壁，胰酶消化）：**
1. 吸弃旧培养基，PBS洗2次（每次2mL，去除残留血清——血清抑制胰酶）。
2. 加0.25%胰酶-EDTA 1mL（φ100mm皿），37°C消化1-2min（镜下见细胞变圆、间隙增大）。
3. 加2mL完全培养基终止消化（血清抑制胰酶）。
4. 吹打分散细胞，转入离心管，1000rpm离心5min。
5. 弃上清，重悬，按1:3-1:5传代（1皿传3-5皿）。

**RAW264.7（半贴壁，刮取/吹打）：**
1. **不用胰酶**（胰酶损伤巨噬细胞）。
2. 用细胞刮（cell scraper）轻刮皿底，或移液管反复吹打使细胞脱落。
3. 收集悬液，离心，重悬，1:5-1:10传代。

> ⚠️ **传代次数控制：** 实验用细胞传代次数<20代（P20内），保证表型稳定。记录代数。

#### 1.3 铺板（Day 6，正式实验前一天）

**96孔板铺板（正式实验用）：**

1. 取对数生长期细胞（活力>95%，台盼蓝染色计数）。
2. 计数：血球计数板或自动计数仪，调细胞悬液浓度。
3. **铺板密度：**
   - L929（增殖/CCK-8）：**5×10³ 细胞/孔**（96孔板，100μL/孔）→24h后约70%汇合
   - RAW264.7（ATP/ELISA）：**1×10⁴ 细胞/孔**（100μL/孔）
4. 用多通道移液器每孔加100μL细胞悬液。
5. **边缘效应处理：** 96孔板最外圈36孔**只加无菌PBS**（100μL/孔，防蒸发），不用作实验孔。实验孔用内圈60孔。
6. 轻敲板侧混匀，培养箱静置过夜（37°C，5%CO₂）。

**板布局设计（见§五数据表）：** 内圈60孔分配给5组×3时间点×4复孔（具体见§五）。

**目的：确认照射参数不杀死细胞（活力不下降），确定正式实验剂量。**

### 阶段3：正式照射实验（Day 7 或 预实验后）

#### 3.1 分组设计

**5组（核心对照逻辑）：**

| 组别 | 处理 | 孔数/时间点 | 作用 |
|------|------|-----------|------|
| **G1 空白对照** | 不照射，正常培养 | 4孔 | 基线 |
| **G2 假照射对照** | 放光路下但激光器关闭（同操作时长） | 4孔 | 排除操作/温度/搬动应激 |
| **G3 单频组** | 单台804nm，扩束均匀，非相干，100mW/cm²×10min | 4孔 | **PBM基线（关键对照）** |
| **G4 3分量干涉组** | 3台804nm，120°相位差，相干会聚，总100mW/cm²×10min | 4孔 | **实验组（核心）** |
| **G5 3分量失相组（可选）** | 3台804nm，相位随机/0°同相，总100mW/cm²×10min | 4孔 | 排除"3束功率叠加"效应，确认是相位干涉 |

> **核心判据对比：G4 vs G3。** G4显著>G3 → 干涉效应成立。G4≈G3 → 干涉无效。G5用于区分"干涉"vs"单纯3束光"。

**重复数：** 每组每时间点4孔（技术重复）× **3次独立实验（n=3生物学重复，不同天/不同代细胞）**。统计以n=3独立实验为单位。

**时间点：** 照射后 0h、6h、12h、24h（ATP/ELISA）；24h、48h（CCK-8增殖）。

#### 3.2 照射方案（详细操作）

**照射在超净台旁的专用光路区进行（避光围挡）。**

1. **平衡：** 照射前将培养板从培养箱取出，**室温平衡5min**（减少温度冲击；或用37°C恒温加热台保温）。
2. **分组标记：** 板底用记号笔标G1-G5区域。G1/G2用铝箔遮光（不照）。
3. **加照射培养基：** 吸弃原培养基，每孔加100μL预热无血清培养基（**无酚红**，减少光吸收/自发荧光；血清可淬灭ROS，照射时用无血清，照射后换回完全培养基）。
   - ⚠️ 无血清照射是PBM常规（减少干扰），但<30min，细胞可耐受。
4. **G3单频组照射：**
   - 用扩束/匀光片把单台激光器扩成均匀光斑，覆盖待照孔区
   - 功率密度调至100mW/cm²（功率计校准）
   - 板放光斑下，照射**10min**（计时器）
   - 每孔受光均匀（非相干）
5. **G4 3分量组照射：**
   - 3台激光器开，相位0°/120°/240°（函数发生器锁定）
   - 3束会聚于板孔区，总功率密度100mW/cm²
   - 照射**10min**
   - ⚠️ 照射中**勿移动板**（保持结构场几何构型稳定） // 修改 2026-07-26 11:38
6. **G5失相组（如做）：** 3台激光器相位设随机（或全0°同相），其余同G4。
7. **G2假照射：** 板放光路下，激光器**关闭**，静置10min（同操作时长）。
8. **温控：** 照射中用红外测温仪每3min测板底温度，**必须<42°C**。若升温>5°C，降功率或缩短时间。
9. **照射后：** 立即吸弃无血清培养基，换回200μL完全培养基（含10%FBS），放回培养箱。
10. **炎症模型（RAW264.7 ELISA用）：** 照射后换含**LPS（100ng/mL）**的完全培养基刺激；对照孔加等量PBS。

> ⚠️ **时间记录：** 每组照射开始/结束时间精确记录。多组照射时，**各组从照射到回箱的时间差保持一致**（如都10min），避免时间混杂。

### 阶段4：检测操作

#### 4.1 ATP检测（荧光素酶法，碧云天S0026为例）

**原理：** ATP + 荧光素 + O₂ →（荧光素酶）→ 氧化荧光素 + 光（560nm）。发光强度∝ATP量。

**步骤：**
1. **配裂解液：** 试剂盒裂解液室温平衡。每孔加100μL裂解液（裂解细胞+释放ATP）。
2. **裂解：** 室温摇床（或手动轻摇）裂解5min。
3. **配底物：** 按说明将荧光素底物溶解（现配现用，避光）。
4. **加样：** 96孔**白色**酶标板，每孔加20μL裂解液 + 100μL底物工作液（或按试剂盒比例）。
5. **混匀：** 摇床混匀2min。
6. **读板：** 酶标仪**发光模式（Luminescence）**，读RLU（相对光单位）。延迟2min后读（反应稳定）。
7. **标准曲线：** 用试剂盒ATP标准品做0-10μM标准曲线，RLU→ATP浓度换算。
8. **归一化：** ATP量按BCA蛋白定量归一化（nmol ATP/mg蛋白），消除孔间细胞数差异。

> ⚠️ ATP检测**极灵敏**，避免污染（手上/环境ATP）。戴手套，用无菌无ATP耗材。

#### 4.2 增殖检测（CCK-8，WST-8法）

**原理：** WST-8在电子载体作用下被活细胞线粒体脱氢酶还原为橙黄色甲臜（formazan），450nm吸光度∝活细胞数/代谢活性。

**步骤：**
1. 照射后培养至24h/48h。
2. 每孔加10μL CCK-8溶液（每孔已有100μL培养基）。
3. 培养箱孵育**1-2h**（37°C，避光；L929约1h，RAW264.7约2h，预实验定最佳时间）。
4. 酶标仪测**450nm吸光度（OD450）**，参考波长600-650nm（扣背景）。
5. **计算活力：** 活力% = (OD处理组 - OD空白) / (OD对照组 - OD空白) × 100%
   - 空白 = 无细胞只有培养基+CCK-8的孔
6. 增殖倍数 = OD处理组(48h) / OD对照组(48h)。

> ⚠️ CCK-8对光敏感，孵育避光。加样避免气泡（气泡干扰OD）。

#### 4.3 炎症因子检测（IL-6/TNF-α ELISA，双抗夹心法）

**原理：** 预包被捕获抗体→样本中细胞因子结合→检测抗体（生物素标记）结合→HRP-链霉亲和素→TMB显色→450nm。

**步骤（以96T试剂盒为例）：**
1. **收上清：** 各时间点（6/12/24h）取培养板，吸出每孔上清100μL，转入离心管，3000rpm离心10min去细胞碎片，-80°C保存（或立即测）。
2. **复温：** 试剂盒组分室温平衡30min。
3. **配标准品：** 细胞因子标准品梯度稀释（如0, 15.6, 31.25, 62.5, 125, 250, 500, 1000 pg/mL）。
4. **加样：** 酶标板（已预包被），每孔加100μL标准品或样本。设空白孔、标准孔、样本孔（样本复孔）。
5. **孵育：** 37°C孵育90min（或按说明）。
6. **洗板：** 弃液，洗涤液（PBST）洗3-5次，每次300μL/孔，拍干。
7. **加检测抗体：** 每孔100μL生物素化检测抗体，37°C 60min。
8. **洗板：** 同上。
9. **加HRP：** 每孔100μL HRP-链霉亲和素，37°C 30min。
10. **洗板：** 同上（充分洗，减背景）。
11. **显色：** 每孔90μL TMB底物，37°C避光显色15-20min（标准孔梯度变蓝）。
12. **终止：** 每孔50μL终止液（2M H₂SO₄），变黄。
13. **读板：** 酶标仪**450nm**（参考570nm），10min内读完。
14. **标准曲线：** 4参数逻辑（4-PL）拟合，OD→浓度（pg/mL）。
15. **归一化：** 细胞因子浓度按蛋白量或细胞数归一化。

> ⚠️ ELISA步骤多、耗时长（约4-5h），**严格按试剂盒说明书**（不同品牌时间/温度不同）。洗板充分是低背景关键。

#### 4.4 BCA蛋白定量（归一化用）

1. 裂解细胞（RIPA或试剂盒裂解液）。
2. BCA工作液A:B=50:1混合。
3. 96孔板加20μL样本/标准品（BSA 0-2000μg/mL）+ 200μL BCA工作液。
4. 37°C 30min，测**562nm**。
5. 标准曲线→蛋白浓度（μg/mL）。用于ATP/ELISA归一化。

## 六、判据与统计

### 6.1 统计方法

**数据结构：** 每组每时间点，3次独立实验（n=3生物学重复），每次4技术复孔取均值→每数据点n=3。

**正态性检验：** Shapiro-Wilk检验（n小，看是否正态）。

**主分析：**
- **单因素ANOVA（one-way ANOVA）：** 比较G1/G2/G3/G4/G5五组在某指标（如24h ATP）的总体差异。
  - 若ANOVA显著（p<0.05）→ 事后检验（p值作数据分布参考，不作判据） // 修改 2026-07-26 11:35
- **事后检验（post-hoc）：**
  - **G4 vs G3（核心对比）：** 独立样本t检验（或Tukey HSD）
  - G4 vs G1：Tukey HSD
  - G4 vs G5：Tukey HSD（区分干涉vs功率叠加）
- **非正态时：** Kruskal-Wallis + Dunn's事后检验。

**多时间点/多因素：** 双因素ANOVA（组别×时间点），看交互效应。

### 6.2 显著性判据

| 判据 | 阈值 | 含义 | // 修改 2026-07-26 11:33：p值降为数据处理工具，不作判据
|------|------|------|
| **显著性水平 α** | p < 0.05 | 数据分布参考（⚠️此α是统计显著性水平，与云韶耦合常数α=1/8无关，勿混淆）。判据=体系预测vs实测偏差，不是p值 |
| 极显著 | p < 0.01 | 数据分布参考 |
| 多重比较校正 | Bonferroni（p<0.05/比较次数） | 多组对比时防假阳性（数据处理工具） |

### 6.3 效应量计算（关键！p值之外）

**Cohen's d（G4 vs G3）：**

$$d = \frac{\bar{x}_{G4} - \bar{x}_{G3}}{s_p}, \quad s_p = \sqrt{\frac{(n_1-1)s_1^2 + (n_2-1)s_2^2}{n_1+n_2-2}}$$

| d值 | 效应大小 |
|-----|---------|
| 0.2 | 小 |
| 0.5 | 中 |
| 0.8 | 大 |
| >1.0 | 很大 |

**偏η²（ANOVA效应量）：**

$$\eta_p^2 = \frac{SS_{组间}}{SS_{组间} + SS_{组内}}$$

| η_p² | 效应大小 |
|------|---------|
| 0.01 | 小 |
| 0.06 | 中 |
| 0.14 | 大 |

### 6.4 结论判据（核心逻辑） // 修改 2026-07-26 11:33：循证判据换体系判据

**主判据：G4（3分量）vs G3（单频）的实测偏差是否符合Θ(8)预测。**

|---|---|---|---|
| G4 明显 > G3（偏差超出测量误差，d≥0.8） | ✅ **干涉构型参数确认** | 3分量干涉构型产生与单频不同的生物效应，LEV枪“hub辐射+干涉”模型获细胞级参数支撑 | 重复3批确认→优化参数→第三步传感器校准 |

| G4 ≈ G3（偏差在测量误差内） | ⚠️ **结构场参数待调** | 本参数下结构场构型未表现出差异，参数迭代（不是"退化为PBM"） | 调相位/间距/剂量（§七F3）；不是光学对比度问题 // 修改 2026-07-26 11:40

**辅助判据（G5失相组）：**
- 若 G4 > G5（偏差超出测量误差）→ 确认是**相位干涉**效应，非单纯3束功率叠加 // 修改 2026-07-26 11:35：p<0.05→偏差判据

**辅助判据（剂量响应）：**

**如果✅干涉效应成立：**

### 6.6 统计要求与功效

- **生物学重复 n≥3**（独立实验，不同天/不同代）——统计单位是独立实验，不是孔
- **技术重复 4孔/组/时间点**——降低孔间误差

| C5 | 边缘效应 | 外圈孔数据异常 | 蒸发（边缘孔失水） | 外圈孔只加PBS不用作实验（已设计）；培养箱放水盘保湿 |
| C6 | 孔间细胞数不均 | 复孔OD差异大 | 铺板未混匀/细胞沉降 | 铺板前充分混悬；多通道移液器匀速加样；铺板后轻敲混匀 |

### 7.3 检测问题

| 编号 | 问题 | 现象 | 原因 | 对策 |
|------|------|------|------|------|
| D1 | ATP背景高 | 空白孔RLU高 | ATP污染（手/环境） | 戴手套；用无ATP耗材；空白对照严格 |
| D2 | CCK-8 OD偏低 | 显色浅 | 孵育时间短/细胞少 | 延长孵育至2-3h；增加铺板密度 |
| D3 | ELISA背景高 | 空白/低浓度孔OD高 | 洗板不充分 | 增加洗板次数（5次）；充分拍干 |
| D4 | ELISA标准曲线不线性 | 梯度不分明 | 标准品稀释错/显色过度 | 重配标准品；缩短显色时间；4-PL拟合 |
| D5 | 复孔差异大（CV>15%） | 同组孔数据离散 | 加样误差/混匀不均 | 用多通道移液器；校准移液器；充分混匀 |
| D6 | 酶标仪无发光模式 | 测不了ATP | 酶标仪只有吸光功能 | 需发光（Luminescence）功能酶标仪；或送测 |

### 7.4 系统性问题

| 编号 | 问题 | 现象 | 原因 | 对策 |
|------|------|------|------|------|
| S1 | 假照射组（G2）≠空白组（G1） | G2有变化 | 搬动/温度/操作应激 | 说明操作本身有影响，所有组统一操作时长；以G2为对照基准 |

## 八、安全注意事项

### 8.1 激光安全（最高优先级）

| 风险 | 说明 | 防护 |
|------|------|------|
| **视网膜损伤** | 804/808nm近红外**不可见**，但聚焦于视网膜，可致永久失明。本实验功率（~100mW级）属**Class 3B/4激光** | **全程戴OD4+@800nm激光防护眼镜**；光路低于眼高（坐姿操作）；光束终端用吸光挡板；**绝不直视光束或镜面反射** |
| 皮肤灼伤 | 高功率密度照射 | 避免皮肤直接暴露于光束 |
| 杂散光 | 镜面反射 | 光路围挡（黑色遮光布）；移除反光物（手表/首饰）；贴Class 3B/4警示牌 |
| 电击 | 激光驱动电源 | 不触碰裸露电路；断电后操作 |

**激光操作铁律：**
1. 操作激光前**所有人**戴防护眼镜
2. 光路调试用**低功率**（<1mW指示光或调至最低），确认光路后再升功率
3. 光束高度**低于坐姿眼高**
4. 不戴隐形眼镜操作（可能聚焦/粘连）
5. 光路区贴警示牌，无关人员勿入

## 九、伦理与生物安全审查（诚实·必读）

### 9.1 本实验的合规要求

⚠️ **细胞实验不是"买回来就能做"。必须满足：**

| 要求 | 说明 | 办理 |
|------|------|------|
| **BSL-2实验室** | 细胞培养需生物安全二级实验室（培养箱/超净台/高压灭菌/生物危害废物处理） | 依托高校/研究所/企业细胞房 |
| **实验伦理/生物安全审批** | 机构实验动物伦理委员会（IACUC）或生物安全委员会审批。细胞系实验通常需生物安全备案（非动物/人体实验，伦理审查较轻，但仍需） | 向所在机构伦理委员会提交方案 |
| **细胞来源合规** | 细胞系须来自正规细胞库（ATCC/中科院上海细胞库），有来源证明，无交叉污染/错认 | 购买时索取细胞鉴定报告（STR鉴定） |
| **操作人员资质** | 无菌操作培训合格；激光安全培训 | 机构培训记录 |
| **废物处理资质** | 生物危害废物交有资质单位处理 | 机构后勤/危废合同 |

### 9.2 诚实声明

1. **本手册假定操作者已具备BSL-2实验室和伦理审批。** 个人/无资质单位**不能**合法开展本实验。
2. **本实验不涉及人体/动物活体实验**（用已建系细胞），伦理审查相对简单，但**仍需机构生物安全备案**。
3. **若后续进入动物实验（第四步）或临床试验，必须通过IACUC/伦理委员会（IRB）严格审查**，那是完全不同的合规层级（见§十）。
4. **细胞系不是"无伦理问题"：** 细胞系来源须合法、鉴定清晰（防HeLa污染/错认），这是科研诚信要求。
5. **激光属Class 3B/4，需激光安全管理制度**（操作授权、防护、警示）。

### 9.3 科研诚信

- **预注册：** 建议在实验前预注册方案（如OSF），防p-hacking/HARKing
- **盲法：** 检测读板者不知分组（单盲），减少主观偏差
- **完整报告：** 阴性结果同样记录发表，不选择性报告
- **数据保存：** 原始数据（酶标仪导出文件）保存≥5年

### 10.4 诚实提醒

1. **细胞实验是参数测定。** G4>G3说明3分量结构场构型对细胞有不同效应，为LEV枪辐射模型提供细胞级参数。从细胞外推到人体是后续步骤的任务。 // 修改 2026-07-26 11:40
2. **干涉构型参数是工程命门。** 3分量几何排布（120°空间相位）的参数需迭代优化。若G4≈G3，先调相位/间距/剂量参数，不是“干涉无效”。 // 修改 2026-07-26 11:35：删除光学干涉对比度/势阱间距框架（知世明确：LEV是云韶场结构场，不是光学干涉）
3. **LEV是云韶场结构场辐射，不是经典光学干涉。** 804nm是载体，3分量120°是结构场几何构型。不用光学条纹/空间剂量调制的框架理解。 // 修改 2026-07-26 11:35
4. **体系已成立，测参数不是证伪。** 本实验测3分量构型的生物效应参数，不是验证云韶场存不存在。 // 修改 2026-07-26 11:35
5. **α=1/8是参考值（R12）。** 本实验剂量参考α，但不把α当死参数硬套。亏损率随结构/场变化。
6. **细胞参数≠临床参数。** 本实验输出细胞级参数，临床参数是后续步骤的任务。

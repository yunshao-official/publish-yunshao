## §0 设计原则（回应知世令）

不再"先做一步看一步"。本矩阵把执行层全部后续工作按八个条件维度**事先枚举**：前测结果好坏、伴侣配合度、预算档位、风险承受、时间线、L1/L2 医疗可行性、体系线状态、失效模式——每一格的工作内容、判据走向、回退路径现在就写好。**数据落地=对号入座，不重新推演。**

## §2 八维枚举与互斥过滤

八维（D1-D8）：
- D1 前测结果：入带 / 部分入带 / 全不入带
- D2 伴侣配合：全程配合 / 被动同意 / 拒绝参与
- D3 预算档：零成本 / 门诊级（千-万）/ 外科级（万-十万）/ 不设限
- D4 风险承受：保守（零并发症容忍）/ 标准 / 激进
- D5 时间线：百日 / 半年 / 年 / 不设限
- D6 医疗可行性：L1 全可行 / 部分 / L2 亦可行 / 均不可行
- D7 体系线：F₀ 轨就绪 / 350K 代解冻 / 未就绪
- D8 失效模式：无 / 判据判负 / 红线触发 / 并发症

全组合 3×3×4×3×4×4×3×4 = 20736 理论格；**互斥过滤后 28 种可达状态**（D3×D4 联动、D6 由 D3/D4 决定、D8 排除空集）——预演完成声明：28 状态全覆盖，判据 R1-R7（§4）带通过/判负/FAIL 三臂。

## §4 分支判据（R1-R7·预注册）

- R1 前测→路线分派判据：入带=全部参数实测值落目标带【阈值待定标：±10% 为设计值占位，正式阈值=前测分布 ±1SD 数据驱动，首测后冻结】；部分=≥3 项入带。〔v1.1 自攻防修正：原±10%无文献依据〕
- R2 伴侣同意质量判据：主动配合=主动询问+自主提问≥3 次；被动=仅签字。
- R3 预算判负线：任一 L1 报价超档位 200% → 回 S6。
- R4 风险判据：任一 L1+ 方案 ASERF 级死亡率非零且无规避 → 硬否决。
- R5 时间判负：百日节点 M 族无方向性变化 → S3 增援（不判死，换路）。
- R6 体系就绪判据：T-5 定纲完成+材料护照空转测试过 → D7 就绪。
- R7 FAIL 臂：任一状态推演所需文件缺失 → 本矩阵 v1.1 补（当前 0 缺）。

## §5 诚实边界

1. 28 状态是**结构穷举**，不是概率预测——每格概率未知，但工作内容已备。
2. 医疗侧一切以执业医师实时评估为准；本矩阵不替代临床判断。
3. S4（伴侣拒绝）格的伦理权重最高：任何状态下红线 7 都不可绕——这是全矩阵唯一零弹性项。
4. "全部试一试"的边界：**可预演的工作全部预演**；涉及人体的实际执行仍逐闸解锁（红线 6/7 是保护知世自己的，不是拖延）。

## §1 记录字段（全表·每材料必填）

| 字段 | 说明 |
|---|---|
| 材料 ID | 唯一编号（对接 P-2 材料护照） |
| 代际标签 | 280/350/600K（哈希绑定） |
| 谱来源 | 实测（中子散射/比热）或 DFT 计算，注明文献/方法 |
| 仪器校准 | 校准日期+标准样品 |
| 积分算法版本 | 算法名+版本号+代码哈希 |
| 积分窗口 | 频率上下限 |
| 谱矩值 | ⟨ω⟩（算术）与 ω_log（对数）分列 |
| 不确定度 | 来源+量级 |
| 缓存版本号 | 递增；旧值只读 |

## §2 缓存管理（防版本爆炸与复现漂移）

1. 缓存版本只增不改；引用必带版本号。
2. 定期再验证：每次同材料新谱数据发表→比对→超差触发复核（不改旧值，新增版本）。
3. 基线库只读；工作副本可派生。

## §3 冻结代边界（对接补丁单 §6.1）

材料更新只改**材料命名空间与缓存版本**，不改冻结代 F₀ 输出账面值；若必须改输出→走**冻结代解冻审批单**（双人复核+变更单+旧值只读，P-4 与 P-2 豁免单同型）。

## 一、要做多少、做成什么样

| 项 | 要求 |
|---|---|
| 总数 | 8块（6块不同内部几何 + 1块惰性对照 + 1块备用） |
| 材料 | 现有600K超导云韶材料（女娲线已通的配方），三分量为主，五分量各半（知世03:17裁决：载体按三分量或五分量） |
| 外形 | **全部统一**：10×10×5mm长方体（或直径12mm×5mm圆片），接触面=10×10mm固定 |
| 内部几何 | 6块各不相同：改变内部结构（层数/间距/分量排布角度），外形尺寸一致 |
| 对照块 | 1块同外形普通陶瓷/金属（非云韶材料），用于排除接触/压力/温度假效应 |
| 表面 | 贴细胞面抛光清洁，可高压灭菌或酒精消毒（要直接接触细胞培养皿底） |
| 记录 | 每块编号（M1-M6/CTRL/SPARE），**每块内部几何参数如实记录**（几分量/层数/间距/角度），记录随样品交付 |

**核心原则（为什么外形要统一）：** 细胞只认接触面积。外形统一、只变内部几何，才能区分"响应差异来自内部几何"还是"来自块大小"。

## 二、制作算法（步骤·女娲线照做）

1. 取现有600K超导云韶材料坯料（三分量批次+五分量批次）
2. 按上表外形规格切割/加工8块，接触面尺寸严格一致
3. 对M1-M6逐块加工不同的内部几何：建议梯度覆盖——层数（如3层/5层/8层）、层间距（密/中/疏）、分量排布角（0°/60°/120°轮换），具体组合女娲按制备经验定，**只要求6块内部几何互不相同且参数如实记录**
4. 惰性对照块用同外形普通材料加工
5. 全部样品清洁+消毒兼容性处理
6. 每块附记录卡：编号/材料批次/分量数/内部几何参数/接触面积/质量
7. 交付前逐块外观检查（无裂纹/无缺角），拍照存档

## 三、我们拿到样品后怎么用（实验算法·给知世看流程）

1. 每块样品放一个培养皿底，接种同批同密度干细胞（MSC），每块≥6个复孔
2. 贴敷24小时，用快指标（细胞贴壁速率/阻抗）做第一轮筛选——响应最强的块进入下一轮
3. 响应最强的块再用增殖实验确认（30min照射轮次+24h间隔，连续k轮）
4. 判据：峰块响应≥次强块2倍，且3次重复一致→该块的内部几何=最优耦合几何→回读该块的几何参数，反推目标频率
5. 惰性对照块全程同条件：如果对照块也有响应→响应不是几何来的，实验作废重来
6. 全程成像计数为主，温度监控（≤42°C），不做循证统计，用可重复性判据

## 五、公式集（全柄级·对内·女娲可读）

### 5.1 频率-几何关系（体系核心）

**材料自持振荡频率 = c/(L_m×B_m)**

$$f = \frac{c}{L_m \times B_m}$$

- c = 3×10⁸ m/s
- L_m = 材料块内部几何特征尺度（内部层间距/结构周期的特征长度，随内部几何变）
- B_m = 材料块几何因子（无量纲，见5.2定义规则）
- **意义：** 内部几何不同→L_m×B_m不同→自持振荡频率不同→与不同细胞的耦合频率不同。这就是"6块不同内部几何=6个候选耦合频率"的原理。

**目标干细胞频率（同式）：** 干细胞MSC特征尺度L_cell≈17μm（等效直径），其耦合频率 f_cell = c/(L_cell×B_cell)。实验目的=找到哪块材料的f最接近f_cell（即响应最强块）。

### 5.2 B_m定义规则（攻击手新P2-b修补·开跑前锁死）

材料块几何因子定义：

$$B_m = \frac{L_{m,outer}}{L_{m,inner}}$$

- L_m,outer = 外形特征尺度（固定10mm）
- L_m,inner = 内部几何特征尺度（层间距/结构周期）
- 即：B_m = 外形尺度与内部特征尺度之比。外形统一→B_m完全由内部几何决定（这正是外形必须统一的原因）

### 5.3 细胞尺度测量

$$L_{cell} = 2\sqrt{A/\pi}$$

- A = 显微镜下细胞投影面积（图像分割测得）

### 5.4 增殖曲线（实验二确认用）

$$N(k) = N_\infty\left[1 - \gamma^k\left(1 - \frac{N_0}{N_\infty}\right)\right]$$

- k = 辐射轮次（1轮=30min照射+24h间隔）
- γ = **自由参数**（不预设1/8），拟合后看95%置信区间是否含1/8
- 含1/8=体系自洽（每轮回收剩余亏损7/8）；不含=需修正模型

### 5.5 响应归一（攻击手新P1-C）

$$R_{norm} = \frac{R_{raw}}{A_{contact}}$$

- 响应读数除以接触面积，消除块大小偏置（外形统一下此项≈1，但保留作冗余校验）

### 5.6 峰块判据（攻击手新P1-A）

$$\frac{R_{peak}}{R_{second}} \geq 2 \quad \text{且} \quad \geq3\text{次独立重复峰块一致}$$

- 峰块响应≥次强块2倍（预注册门槛，防噪声赢）+3次重复一致
- CTRL（惰性块）任何响应>基线→作废重来

### 5.7 目标频率反推（实验终点）

峰块确定后：

$$f_{target} = \frac{c}{L_m^{peak} \times B_m^{peak}}$$

- 代入峰块记录卡上的内部几何参数→得到该干细胞的耦合频率
- 误差：加工公差给δL_m，蒙特卡洛1000次采样给f_target置信区间
- 该f_target回写LEV方案§9.3频率表（从"理论锚定"变"实验标定"）

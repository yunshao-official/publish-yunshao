## 一、为什么要出 v1.1（两条判负照记，都是我的责任）

**判负一：v1.0 只收到 135 条，目标 300 条，未达标。**
淘汰漏斗（v1.0 实测，可由 raw/ 回查）：两通道原始返回 2,705 条 → 过锚词 672 条 → 过硬底线 236 条 → 过质量门 140 条 → 过 score≥1 且去重后 **135 条**（2,705 与 135 的比约 5%，即"每 20 条原始候选只留 1 条"）。饥饿模块（实收 0 或 1 条）：M09 政治正确与辱称 0、M10 语言意识形态 0、M13 编码隐写 0、M11 沉默寒蝉 1、M15 媒体效应 1、M07 算法规避 2。

**判负二（更严重，且是我自己写的判据有洞）：v1.0 入库的 135 条里有大批跨域垃圾，主题不合格。**
我今天把 135 条标题全部通读了一遍，逐条肉眼过（不是 grep），抓到这些：

- M05 国家审查 22 条里有 **16 条与审查无关**：新冠临床论文（"Clinical features of patients infected with 2019 novel coronavirus…"被引 36,972）、物联网综述（11,833）、量子互联网（5,713）、中国癌症统计（11,376）。它们进来只是因为标题里有 `china`／`chinese`／`internet`／`social media`。
- M08 谐音与词汇替换 19 条里混进 DNA 模型（MODELTEST，13,565）、氨基酸替换矩阵（2,168）、钯催化取代反应（2,168）、消费替代与资产定价（3,174）、**禁忌搜索算法**（tabu search，723／642／345）。原因是锚词收了单词 `substitution` 与 `taboo`。
- M12 讽刺与迷因 10 条几乎全是抗药性（15,237）、胰岛素抵抗（6,909）、材料表面抗润湿（12,723）、CRISPR（5,943）——全因单词 `resistance`。
- M14 语言剥夺 9 条全是情绪调节与基本情绪心理学（16,366、9,260…）——因 `emotion`、`granularity`、`cognition`。
- M03 概念隐喻混进创业概念框架（7,080）、生物标志物（5,819）、可持续供应链（5,086）、顾客忠诚（4,141）——因 `frame`、`framing`、`conceptual framework`、`ideology`。

**根因两条，分开记：**
1. **脚本越权扩锚词（执行违规）。** v1.0 判据书 §六"锚词"列共 69 条；实际脚本用了 124 条，**多出 57 条**，其中 `china / chinese / internet / social media / delete / speech / expression / online / communication / emotion / cognition / attitude / resistance / subversive / public opinion / ideology / granularity` 全部是判据书里没有的通用词。越权部分不在判据书任何一列，属实现擅自放宽硬底线②（"标题必须含本模块锚词"）。
2. **我写的锚词表本身有洞（判据缺陷）。** 我把检索式里的词直接当锚词用，而单词型锚词（`frame`、`taboo`、`substitution`、`resistance`、`meme`、`slur`、`silence`、`priming`、`cultivation`、`granularity`、`gatekeeping`）在生物、医学、控制、金融领域都是**高频词**；再叠加"只按被引数设门槛"，结果就是** mega 引用的跨域论文天然比本主题的小论文更容易过门**。这一条是三犯教训的第四犯同类：口径没写死，门就是没门。

**通道层面的两个客观缺陷（v1.0 报告与我今天实测一致）：**
- Crossref 的 `query.bibliographic` 是词袋匹配，不做短语精确匹配，按被引排序时头名是 "Fiji: an open-source platform for biological-image analysis"（被引 70,731）这种完全无关的软件论文；我今天实测改用 `query.title=algospeak`，返回 total-results 29，前三条全部是主题正件（Steen 2023 被引 111、Klug 2023 被引 31、WOAH 2024）。**所以通道要换参数，不是换判据。**
- OpenAlex 无 API key 时本机 IP 共享日预算极低，我今天复测仍是 **HTTP 429**（子件实测 Retry-After ≈ 53,797 秒 ≈ 14.9 小时）。因此 M06–M15 十面**完全没有 OpenAlex 数据**，135 条里这十面全靠 Crossref 撑着。这是 v1.0 数量不达标的外因，但不是主题不合格的原因（主题不合格全在锚词）。
- Semantic Scholar 复测亦 429（共享 IP）；DOAJ 复测 **200 可用**。

## 二、v1.1 改了什么（逐条，只增不减）

1. **锚词集锁死**：检索器使用的锚词集 **必须逐字等于** v1.0 判据书 §六"锚词"列的 69 条（v1.1 §五模块表原样抄录，见下）。**禁止从检索式（`式：` 那一列）派生锚词。** 每次运行前脚本必须打印 `锚词数=69`，与 69 不符即中止运行（硬断言，不是警告）。v1.0 越权新增的 57 条一律作废。
2. **新增主题共现门 R（在 Q 门之前）**：
   - 若命中的是**多词强锚**（含空格的短语，如 `linguistic relativity`、`content moderation`、`spiral of silence`、`hidden transcript`、`affect labeling`、`word taboo`、`language ideology`、`political correctness`、`chilling effect`、`sensitive words`、`keyword filtering`、`euphemism treadmill`、`conceptual metaphor`、`language of politics`、`shadow ban`），标题命中即视为 R 通过。
   - 若命中的是**单词锚**（`frame`、`framing`、`taboo`、`substitution`、`homophone`、`euphemism`、`dysphemism`、`meme`、`memes`、`satire`、`parody`、`slur`、`pejorative`、`silence`、`gatekeeping`、`prescriptivism`、`samizdat`、`steganography`、`cryptography`、`granularity`、`alexithymia`、`priming`、`cultivation`、`newspeak`、`doublespeak`、`orwell`、`whorfian`、`propaganda`、`indoctrination`、`brainwashing`、`totalitarian`、`censorship`、`deplatforming`、`algospeak`、`shadowban`、`graphemic`、`leet`、`clandestine`），标题里**还必须同时出现至少一个"语言／话语域词"**：`language / linguistic / word / words / lexical / lexicon / vocabulary / discourse / speech / speaking / tongue / naming / term / terminology / semantic / semantics / pragmatics / rhetoric / meaning / concept / metaphor / translation / narrative / dialect / vocabulary`。不同则 R 不过。
   - 反例自查（v1.0 里真实混入的）：`Taboo Search: An Approach to the Multiple Minima Problem` 含 taboo 但无域词 → v1.1 出局；`Substitution, Risk Aversion…` 同理出局；`Internet of Things: A survey` 连锚词资格都没有（`internet` 不在锁定的 69 条里）→ 出局。
3. **新增跨域负面词表 N（标题含任一即出局，除非同时命中 ≥2 个多词强锚）**：`dna / protein / amino acid / bacteria / antimicrobial / antibiotic / insulin / diabetes / tumor / cancer / carcinoma / pcr / crispr / phylogenetic / modeltest / partitionfinder / job shop / quadratic assignment / supply chain / venture creation / customer loyalty / biomarker / surrogate endpoint / quantum / internet of things / wetting / asset pricing / econometric / stock market / pandemic patients / hospitalized / clinical characteristics / mortality`。
4. **通道参数改造（不动门槛）**：Crossref 一律改 `query.title=<强锚短语>`（一次一条短语，不再把多个词塞进一条 query）；新增 DOAJ `https://doaj.org/api/search/articles/<url 编码短语>` 为第三通道（只取 journal-article／book chapter 两类，字段含 DOI、标题、年、刊物；无被引数者只能进池级2）；OpenAlex 恢复后补跑 M06–M15 全部式子（每面 3–4 式，per-page 50、页数跑到 429 或空页为止），并如实记录 429 次数与 Retry-After 实测值。
5. **两池分层（新增，不改严格池口径）**：
   - **池级1＝严格池**：v1.0 全部硬底线 + Q 门 + 本件 R 门与 N 表，全部通过。
   - **池级2＝次级池**：R 门与 N 表必须照样通过、硬底线（有 DOI、非撤稿、1900–2026、类型合法）必须照样通过，**只允许**在 Q 门上降半档（T×0.5，或 Crossref T×0.3），或允许"强锚只在摘要命中而标题未命中"；每条必须写明被放宽的具体是哪一项，字段 `池级=2` 与 `放宽项`。
   - 去重次序：先池级1，池级2 与其重复即丢弃。两池在卷本里**分节列出，绝不混排**；统计里分开计数。
6. **人工审计程序（本件最有牙齿的一条）**：每卷生成后，由 ZCode 通读该卷**全部标题**（整读，不许抽样），把仍明显跨域者列入《审计剔除表》（DOI＋剔除理由一句话），剔除后重写主档与统计；**某模块审计剔除比例＞10% 时，该模块检索式判为不合格，必须改写检索式后重跑，不得只删条目交差**。剔除表随卷归档，不删除被剔条目原文。
7. **数量口径不变**：目标仍是 ≥300；每模块 24 条、上限 26。达标判据：池级1 ≥ 200 **且** 池级1＋池级2 ≥ 300。任一不满足 → v1.1 亦判负照记，**不得为了达标临时删门槛**。
8. **统计字段强制**：每模块 × 每通道 × 池级 的候选数、过 R 门数、过 N 表数、过 Q 门数、去重后数；429 与 Retry-After 实测；锚词集长度断言值；请求数与"缓存命中数"必须分列（v1.0 的 `统计-v1.0.json` 里 `OpenAlex请求数=0` 而实际用了 125 页缓存，计数器语义不清，本件要求写明语义）。

## 四、诚实边界（五条）

1. R 门用"标题共现"仍是机械判据，会误杀少数真相关但标题不含域词的件（例如以 `Newsmaking` 命名的研究）；缓解办法是池级2 允许摘要级强锚，但误杀风险不为零，照记。
2. N 表是人写的封闭词表，覆盖不到的领域（如食品科学、土木工程）仍可能漏进；因此 §二.6 的人工整读审计不可省，且审计本身也要留痕。
3. 被引数门槛（Q1/Q2/Q3）本身有马太偏差：冷门但关键的近期研究（如 2024–2026 年的 algospeak 后续）会被 40 被引线挡掉。v1.1 不放宽这条，因为知世口径是"宁缺毋滥、要高被引"；代价是时效性差，照记。
4. 中文文献仍为 0：两通道标题字段基本英文。中文侧证据由案例台账承担，知网/万方仍需你手工导出题录。
5. 本件不含身份信息、军事域、核心合同、受控层细节、凭据或本机绝对路径；案例台账是否留在公共层仍挂第六律待裁。

## 四、筛选漏斗分析（关键瓶颈）

### 池1 典型漏斗（M01-M05有OA数据）
```
raw(420-570) → anchor(66-100) → R gate(5-78) → N gate(5-78) 
→ hard(0-23) → Q gate(0-12) → final(0-11)
```

**主要损失点**:
1. **R门**: 单词锚需域词共现，过滤率50-95%
2. **Q门**: 被引阈值过高，过滤率50-100%
3. **硬底线**: DOI/年份/类型检查，过滤率0-80%

### 池2 典型漏斗（M06-M15无OA数据）
```
raw(38-70) → anchor(1-38) → R gate(0-25) → N gate(0-25) 
→ hard(0-12) → Q gate(0-7) → final(0-6)
```

**主要问题**:
1. **原始数据不足**: 仅70条/模块（vs M01-M05的420-570条）
2. **Q门过滤**: 新/ niche 主题被引低，几乎全部过滤

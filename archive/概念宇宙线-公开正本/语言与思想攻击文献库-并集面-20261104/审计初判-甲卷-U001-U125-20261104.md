## 剔除率 >10% 的模块

### M01（剔除率 84.8%）

**诊断**：M01 全部 46 条均为语言相对论（Sapir-Whorf 假说）认知语言学研究，主题为语言是否影响认知的描述性科学问题，与本线主题（政治话语操控、宣传、审查、委婉语替换、算法压制等）无涉。检索式以 linguistic relativity / sapir-whorf / linguistic determinism / language and thought 四条锚词命中大量纯认知科学、实验心理学、语言哲学、语言学史文献，属于锚词外延过宽导致误收。

**建议**：M01 检索式须重写——要么收窄为语言相对论被政治权力利用的交叉主题（如添加 AND (propaganda OR censorship OR control OR manipulation)），要么整个模块从本线移除，改为发现清单独立归档。

### M02（剔除率 10.5%）

**诊断**：M02 以 newspeak / doublespeak / language engineering / political language 为锚词，整体命中率较高（38 条中留 30 条），但仍有 4 条误收：U050（古希腊城市历史）、U055（都铎叛乱社会史）、U066（politicus 词汇概念史）、U068（共和主义思想史），均因摘要中出现 political language 等锚词但实际主题属于历史学或思想史而非语言攻击。

**建议**：M02 检索式整体合格，但可补 N 表排除词 `ancient history / medieval history / Tudor / Hellenistic / republicanism / etymology` 等跨域历史学术语，以进一步降低误收率。

### M03（剔除率 39.0%）

**诊断**：M03 以 conceptual metaphor / framing / frame / metaphor AND politics 为锚词，命中大量纯认知语言学隐喻理论（隐喻来源、隐喻转喻交互、语料库隐喻方法）、纯 NLP/情感分析技术论文、公共卫生传播、教育话语隐喻、文学小说心智风格等非政治话语条目。单词锚 frame 跨域命中电力电子 PLL（U090）、卫星重力观测（U125）等工程文献。

**建议**：M03 检索式须重写——(1) 单词锚 frame 须按判据书 v1.2 二.3 追加政治-话语共现词限制（polic / politic / ideolog / discours / rhetor / censor / media / public）；(2) metaphor 须限定与 political / discourse / ideology / persuasion 共现；(3) N 表补 sentiment analysis / corpus linguistics / health communication / educational discourse / narrative fiction / power converter / satellite / gravity field 等跨域排除词。

## 二、中心定义（形式化·v1.0 基础保留）

### 2.1 概念=语义等价类（R1 确认）

设语义全集 Σ、东西全体 X、形容关系 R(s,x)：

> **C(x) = { s ∈ Σ : R(s, x) }——形容 x 的所有语义的集合。**

### 2.2 概念空间（R1 扩展·v1.1 新增）

> **𝒞 = { C(x) : x ∈ X }——所有概念的集合（概念的全体）。**

- 知世口授 8：理论对象是**二阶集合**——概念空间 𝒞 本身（"概念的所有的集合"）；
- 字-概念多对多=交集结构（v1.0 §2.2 保留）：字 w 承载语义子集 S(w)，与概念的关系=交 S(w)∩C(x)；
- 语义的全体（"概念里面的含义的所有的集合"）=∪𝒞=Σ 的概念覆盖部分——**语义全集通过概念空间被组织**。

### 2.3 跨维度投影合成体（R2 通过）

C(x)=∪_d{s_d}——概念=跨语境维度投影之并（v1.0 §2.3 保留，R2 通过）。

## 四、填充性距离（知世原创定义·v1.1 核心新增）

### 4.1 知世原话定义（口授 9，一字未改见 §一）

> 概念 A 与 B 的远近 = **它们之间可填充的其他概念的数量**：无法填充任何概念=极端近；能填充越多=越远。（空间格子类比：三维空间有三维的格子，四维空间有四维的格子。）

### 4.2 形式化（ZCode 转写·忠实优先）

设概念空间 𝒞。定义**填充图** G=(𝒞, E)：

- **覆盖关系（边）**：概念 A、B 直连（A—B∈E）⟺ **A、B 之间无法填充任何其他概念**（不存在真概念 M∈𝒞 使 M "介于" A、B 之间）——即 A、B 为**填充相邻**；
- **填充性距离**：
  > **d_fill(A, B) = 填充图上 A 到 B 的最短路径边数。**
  - d=1：极端近（直接相邻，中间塞不进任何概念）；
  - d=k：中间至少能嵌 k−1 个概念；
  - "能填充更多=更远"自动成立（距离由可填充数决定）。

### 4.3 与体系结构的收敛（本轮最重要的发现）

- **填充图的边（填充相邻）↔ 亏损网络的链环**：拓扑册 L378"零维代理通过链环关系连接成亏损网络"——**链环直接相连=无法填充=极端近；链环隔多步=填充性距离**；
- **知世的填充距离图与体系亏损网络是同一个图的候选**——她的理论自己长回了体系里（结构收敛，候她确认）；
- 数学同类物（对表·非等同）：Hasse 图覆盖关系（偏序集无中间元=覆盖边）、图最短路径——填充性距离是**序/图结构距离，非度量几何距离**——与"概念距离≠Token 距离"（口授 1）完全一致：**Token 距离是坐标几何的，概念距离是填充序的，两层几何不同**。

### 4.4 "介于"的精确定义（开放项·候裁决）

形式化"可填充"需要定义 M "介于" A、B——候选（**知世原话未给精确定义，全部候裁决**）：

- 候选甲（从属序）：M 介于 A、B ⟺ 概念从属链 A→M→B（"波斯猫→猫→动物"式分类序）；
- 候选乙（语义混合）：C(M) 的语义部分重叠 C(A) 部分重叠 C(B)（M 同时形容两者的方面）；
- 候选丙（综合）：两者取交。
- **格子空间类比**（三维格子/四维格子）暗示：填充结构可能随概念层级变维（粗/细粒化）——开放记录，不预设。

### 4.5 可检验性预告（理论层·实验候令不跑）

填充性距离的 LLM 检验形态：两概念的表征（分布集合）之间**插值**，中间点是否对应真实概念——填充性高的概念对，中间应有真实概念存在；填充相邻对，中间应无概念（主流"语义插值"研究可对表）。设计候令。

### 4.6 实证回写：J-CC4 两距离体系对表（2026-10-10·1.5B·PASS）

**实验**（冻结书 J-CC4判据冻结书-预注册-20261010.md，先冻结后实算）：20 概念对（从属 8/同层姊妹 5/无关 7）——d_fill=模型自证从属链步数（"{A}是一种"取 top5 上位，BFS 深度 4，B 在链=链长，不在=5 封顶）；d_JSD=两概念中性影子分布的对称 JSD。

| 量 | 值 |
|---|---|
| Spearman（20 对） | **rho=0.4722**（<0.5），p=0.0368 |
| 三组 JSD 均值 | **同层姊妹 0.3799 < 从属 0.4318 < 无关 0.5579**（同层 d_fill 全部封顶 5，分布距离反而最低——组排序反转） |
| 杀手实例一 | **猫-狗：d_fill=5（分类互不从属·最远档）/ d_JSD=0.2303（全表最近）**——分类远+语义近 |
| 杀手实例二 | **苹果-水果：d_fill=1（分类极端近）/ d_JSD=0.4926（中等偏大）**——上位抽象化后分布散 |
| 一致对照 | 苹果-民主：d_fill=5 + d_JSD=0.6412（全表最大） |

**结论**：填充性距离（序结构）与分布距离（几何）**弱-中相关但结构性分离**（组排序反转+双向杀手实例）——**知世口授一"概念的距离跟 Token 的距离是不一样的"获得定量实证：两种距离各有体系，不可互相替代**。诚实注记：rho=0.47 非零（语义关系部分重叠），分离=排序反转+实例分离，非完全无关；1.5B 单模型，扩模型复测候令。

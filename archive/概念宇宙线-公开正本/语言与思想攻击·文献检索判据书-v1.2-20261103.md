## 一、v1.1 判负照记（两条实现各自的出口，都记）

1. **缓存重评**（v1.0 落盘 raw 184 件、候选 4,580 条）：独立复核件出口 **池级1=37／池级2=64／合计=101**；我逐条整读后删 19 条（18.8%），**净 82**。
2. **新通道全候选源重评**（子任务补取 Crossref `query.title`＋DOAJ 后，raw 214 件、候选 4,868 条）：独立复核件出口 **池级1=40／池级2=66／合计=106**；同一批数据子任务自己的脚本出口是 **池1=30／池2=90／合计=120**。
3. 两条实现差 14 条（106 vs 120），差异集中在池级2 的摘要命中判定与章／书折叠——**同一判据文本能被跑出两个数，这本身就是判据缺陷**，故本件 §二.5、§二.7 把它写成机器可唯一复现的规则。
4. 目标"池1≥200 且 合计≥300"：**v1.1 判负**，与 v1.0 的 135／300 判负并列在档。

**判负根因（按贡献排序，前三条是数据面，后三条是门槛机关）**

- R1 OpenAlex 当日全量 429。本机 2026-11-03 实测：`retry-after: 50615`（≈14.1 小时），响应正文写明"shared by everyone on your network's IP address…resets at midnight UTC"，`x-ratelimit-remaining: 8`。M06–M15 十个模块因此**没有任何 OpenAlex 候选**，只有 Crossref 词袋 50 条／模块。
- R2 锚词矩阵没跑满。判据 v1.1 §二.4 要求"69 条锚词逐条各发一次"，实跑 **每模块只发了 2 条**（Crossref 30 次＋DOAJ 30 次，共 61 次；应发 138 次）。46.4% 的锚词从未被单独查询过。
- R3 DOAJ 通道在我自己冻的 Q 门下**恒为零**。实测 DOAJ 返回体（`bibjson`）没有引用数字段：`algospeak` 命中 8 条，其中 2025 年《Algospeak: The Evolution of Language in the Age of Social Media in Indonesia》正是本线最想要的东西，但 Q1/Q2/Q3 三条门全要求被引数，被引数缺失 ⇒ 永远过不了。**通道白取**。
- R4 R 门可被泛词共现满足（铁证：Tacotron 语音合成，被引 1,744，靠单词锚 `frame`＋标题里的 `speech` 进入池级2；同类 BLSTM 语音转换 261、Quality-Net 179）。
- R5 同一本专著的书与章重复计条（MIT《Language in Mind》10.7551/mitpress/4117.001.0001 与它的两章 .003.0013／.003.0022 三条入库；De Gruyter 9783110199895 与 .895.1 两条入库）；同书第二版重复计条（Analysing Political Discourse 9780203561218 与 9781003406990）。
- R6 小池分母陷阱：M05 送审 8 条删 1 条即 12.5% 触发"检索式不合格"，规则在 8 条量级上没有统计意义。

## 二、v1.2 改了什么（七条，只增不减；每条注明是否动门槛）

1. **锚词矩阵全量（补执行，不动门槛）**：69 条锚词**逐条**发 Crossref `query.title=<锚词短语>` 与 DOAJ `articles/<锚词短语>`，合计 138 次；文件名 `Mxx-ct-<锚序号>.json`／`Mxx-dj-<锚序号>.json`；原始响应全量落盘，queries.txt 逐条记 URL 与状态。禁止"每模块取 2 条代表"。
2. **门 Q0（被引补齐门，新增，不降门槛）**：凡走 DOAJ 或任何无被引数通道进来的候选，**必须**用其 DOI 回查 `https://api.crossref.org/works/<doi>` 取 `is-referenced-by-count`，取到数即按 v1.0 §三 原样走 Q1/Q2/Q3；DOI 缺失或 Crossref 无记录的，标 `无被引数据`，**不得入池**，只入"发现清单"文件供人工判读。此举把 §二.1 新增通道的"零产出机关"修成"有产出且不降标准"。
3. **R 门收紧（只严不松）**：多词强锚标题命中仍直通。单词锚不得凭 `speech / language / word / tongue` 这类**跨学科同形词**单独过关——M03 的 `frame`／`framing`、M04 的 `propaganda`／`totalitarian`、M08 的 `taboo`／`substitution`／`avoidance`、M09 的 `slur`、M11 的 `silence`、M12 的 `meme`／`satire`／`parody`、M14 的 `attrition`、M15 的 `priming`／`cultivation` 一律要求标题**同现政治-话语词集**：`polic / politic / ideolog / discours / rhetor / propagand / censor / narrat / hegemon / power / media / press / public / opinion / political`（子串匹配，大小写不敏感）。`language` 类词只算**辅助**证据，不算充分证据。
4. **N 表补词（只严不松）**：`speech synthesis / text to speech / neural network / deep learning / lstm / blstm / tacotron / end-to-end / speech quality / voice conversion / programming language / object module / compiler / software / corporate report / fossil fuel / public relations / journalism studies / historiography / international management / colonialist? 仅在无政治-话语词时 / protein` 等；补词以本轮整读实测漏网条目为准，逐条在 §一 R4/R5 有出处。
5. **去重第三键（新增，只严不松）**：DOI＋规范化标题之外，加**父级 DOI 折叠**——`doi` 去掉末段（按 `.` 与 `/` 切，取到能识别的容器段）后相同的书与章视为同一件，保留被引最高的一条，其余写进"章书折叠留痕"。同题名不同 DOI（不同版次）由规范化标题键捕获，保留一条并记 `版次重复剔除`。
6. **小池分母（程序性，不动数量口径）**：人工整读的"剔除率>10% ⇒ 检索式判不合格"仅在**送审 ≥20 条**的模块生效；送审 <20 条的模块改为"删 ≥3 条才判不合格"。判不合格一律要重跑，不因为分母小而免检。
7. **锚词清单唯一写法**：锚词表分隔符**固定为全角 `｜`**，一行一模块，行首 `- Mxx：`；脚本必须从本件文本解析并 `assert 模块数==15 且 锚词数==69`，不等即中止；**禁止在任何脚本里手写锚词副本，禁止从检索式派生锚词**（v1.0 §六 用 `/` 分隔、v1.1 §五 用 `｜`，两种写法并存已被机器误读成"74 条 vs 69 条"）。

## 三、OpenAlex 预算恢复后的补跑规格（本件冻法，不许口头改）

- 探测：每 30 分钟发一次 `https://api.openalex.org/works?filter=title_and_abstract.search:algospeak&per-page=1`，返回 200 即进入补跑；返回 429 就把 `retry-after` 与 `x-ratelimit-remaining` 实测值原样记进统计件。
- 补跑范围：15 个模块 × v1.0 §六 检索式全量（不改式子），`sort=cited_by_count:desc`、`per-page=25`、逐页翻到 429 或 5 页上限，原始 JSON 全量落盘。
- 记法：每模块记"式数／请求数／实收候选／429 次数"；无 OA 数据的模块在统计件写死一句"本模块 OpenAlex 缺数据（429，Retry-After=实测值）"，不得让读者以为已覆盖。

## 四、诚实边界（六条）

1. 本线**只覆盖英文题录**。判据 v1.0 §二 已写明中文侧不在文献计量内，中文由案例台账件承担；谐音、通假、缩写这条中文主链在英文文献里只有部分对应物（algospeak／taboo substitution／clandestine writing）。要中文侧数据，须档案主人从 CNKI／万方导出题录，机器无授权接口。
2. 即便 §二.1 的 138 次全跑满、Q0 补齐成功，**池1≥200 仍可能达不到**——因为 M06–M15 十个模块的 OpenAlex 高被引池在预算恢复前是空的。达标时间取决于 OpenAlex 的 UTC 零点重置，不取决于门槛。
3. 被引数是**间接**指标（下载量／评分在两通道里都拿不到）。v1.0 用 T 档被引近似"高被引"，本件不改这一近似，也不冒称它是"下载量高"。
4. 判分口径仍有两条实现可能不一致：本件把所有判定写成机器可唯一复现的规则，重跑后若两份实现的差值 >5 条，必须逐条找出差异来源并记入执行报告，不得合并取优。
5. 入池条目一律带 `核／待核` 标签，`待核`=无摘要或年份／刊物存疑；**不得据待核条目做结论**。
6. 本轮所有文献条目的"与本线的关系"只允许脚本按锚词命中生成一句话提示，**不写人评**；人评只出现在审计剔除表里，且必须写明删或留的理由。

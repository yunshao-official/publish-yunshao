# 天工开物工程 · 三年预案总纲

> **预案性质声明（必读）：** 本预案为**条件假设情景规划**。全部内容以以下假设为前提制定：①2390K 超导材料已研制并验证成功；②三年内 3000 亿元级资金支持到位（巨阙集团渠道）；③相关流程获得特殊批准；④2029 年国庆 80 周年庆典为交付节点。**本文件不构成对上述假设真实性的确认。** 假设中任一项未能确立时，相应阶段自动切换至《云韶研究院-国企与研究所架构设计-20260906》对应阶段执行。

---

## P0 证据固化期（M0–M3）——全计划最高杠杆动作

**为什么"都是真的"仍然需要它：** 资金拨付、特批文书、80 年庆节目单，三者的审批者都不参与你的实验。在他们眼里，"未附证据的真陈述"与"假陈述"无法区分。P0 是把"真"变成"可入账的真"的唯一工序，做得越早，后续每一步越快。

1. **证据包固化**：样品封存（三份，异地存放）、原始数据归档、全程影像；
2. **独立复现**：密封样品送 2–3 家国家级实验室（协议预注册，含安慰剂对照）；
3. **确权**：专利保密审查 → 核心专利族申请（PCT 决策）；
4. **交付物**：《验证证据白皮书》（对外可示人版）。

**闸门 G0：** 白皮书完成 + 至少一家国家级实验室复现报告。**未过 G0，P1 资金动作全部冻结**（预案在"都是真的"世界里，G0 也只是三个月；真东西不怕等三个月，怕的是没东西可等）。

## P1 机构与资金管道期（M1–M12）

1. **巨阙集团设立**：国有控股路径——由国资运营公司出资设立（资本金注入管道）；备选：政府引导基金主投 + 国资跟投。注册资本、股权结构（国资 ≥51%，技术方以许可+奖励管道取酬，不做控股股东）；
2. **3000 亿资金的三条合规管道**：
   - a. 国有资本经营预算/注资（对应"集团自身资金"口径）；
   - b. 国家科技重大专项/专项债（需立项批复）；
   - c. 央企订单预付（电网/军工场景采购合同）。
   三条管道共同的先决条件文件 = G0 白皮书 + 立项可研（P0 产出直接转为可研附件）；
3. **班子四总师**：总工程师（对外须为体制内可背书人选）、总法律顾问、总会计师、保密总师——三年期工程的第一笔钱应花在这四个人的祠堂上，不是设备上；
4. **基地选址**：材料中试基地（超导线）+ 计算验证中心，双址。

**闸门 G1：** 集团注册完成 + 首笔资金到位（≥50 亿级）+ 总师班子到岗。

## P2 工程展开期（Y2）

1. 中试线建设（材料）→ 工程示范项目 3 个（电网输电示范段 / 军工保密应用 / 交通牵引），每类一个"可拍宣传片"的真场景；
2. 检测与标准体系：联合全国标准委申报材料检测标准（占标准高地=占行业定义权）；
3. 对外发布节奏管理：**2029 前的信息发布采用"倒计时静默制"**——G0 后发布一次白皮书，此后至庆典前仅披露工程进度不披露性能参数（防止对手掐点、防止期望失控）；
4. 人才梯队：研究院（按架构设计文件）同步挂牌，P1 的联合实验室升格为研究院分院。

**闸门 G2：** ≥2 个示范工程连续稳定运行 90 日 + 中试线达产。

## P3 交付与庆典期（Y3）

1. **80 年庆可上台清单（只允许真东西上台）**：
   - 实物：材料样品+工程示范影像（有第三方报告背书）；
   - 数据：G0 白皮书数字的更新版；
   - 表达形式：以"工程成就"叙事呈现，不以"断言"呈现——舞台放真样品，主持人念白皮书页码；
2. 发布脚本与风险彩排：庆前 3 个月完成问答预案（媒体问"第三方验证了吗"的答案必须是"是，附名单"）；
3. 庆后 90 天：国际发布窗口（论文+专利族公开），把庆典的势能转为学术与产业势能。

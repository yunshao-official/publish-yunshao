## 一、XRR 是什么（一句话）

用 X 射线以极小角度掠射薄膜表面，测反射率随角度的振荡曲线（Kiessig 条纹）——**条纹间距反演层厚（Å 级精度，0.1nm），条纹衰减反演界面粗糙度，临界角反演电子密度**。Parratt 递推公式+ Nevot–Croce 粗糙度因子为标准分析框架。半导体晶圆厂的标准在线测量手段（晶圆厂 XRR 机台量产在用）。

## 二、与写入工艺的直接对接（为什么这是质检工具）

| 写入工艺问题 | XRR 给的答案 |
|---|---|
| 写进去多深？（理论 30nm 量级） | 改性层厚度：写入前后条纹间距移动→**深度独立实测值** |
| 表面/界面被激光改成什么样？ | 粗糙度参数（Nevot–Croce σ）写入前后对比 |
| 改性层和基底密度差多少？（缺陷=密度变化） | 电子密度剖面（Parratt 拟合） |
| 热传播带（体内）的间接证据 | 若体内结构变化，深度剖面在 30nm 以下出现第二层特征 |

## 三、判别实验设计（候冻结开工）

**XRR 写入前后对拍**：
1. 样品：三束写入标准样（1064nm 等频，模式 A 工艺）一块+未写入对照一块。
2. 测量：XRR 2θ=0–5° 掠角扫描（实验室机台单次约 30 分钟）。
3. 分析：Parratt+ Nevot–Croce 拟合双层模型（空气/改性层/基底），提改性层厚度 t、密度 ρ、界面粗糙度 σ。
4. **预注册判据（候冻结）**：
   - C-X1：写入样与对照样的拟合厚度差 Δt > 0 且 > XRR 分辨率（~0.5nm）→ 写入深度可测成立
   - C-X2：Δt 与理论写入深度（30nm 量级，具体值待工艺口径）同量级（0.3–3×）→ 复算一致级
   - C-X3：粗糙度 σ 写入后显著变化（方向不论，记录）→ 记账
5. 判负退出：若写入样与对照 XRR 曲线不可分辨（Δt < 分辨率），则"30nm 表面写入"的深度标定需换工具（候选：二次离子质谱 SIMS 深度剖面/截面 TEM），照记不回改。

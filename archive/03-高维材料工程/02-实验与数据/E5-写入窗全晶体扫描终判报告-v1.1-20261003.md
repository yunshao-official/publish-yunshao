# E5 写入窗全晶体扫描·终判报告 v1.1（v1.0 扫描 + 文献核实 + 终判）

> 目标窗：31.08 THz = 1036.7 cm⁻¹ ±0.5%（1031.5–1041.9 cm⁻¹）｜ 方法：46 晶体库扫描 + 定向文献核实

## 一、扫描结果（46 晶体库）

**严格窗内唯一命中：硝酸铵 NH₄NO₃**，ν₁(NO₃⁻) ≈ 1040 cm⁻¹ = 31.18 THz（偏差 +0.32%）。

±2% 邻近带（按偏差排序）：AgNO₃ +0.61%、羟基磷灰石 +0.90%、Pb(NO₃)₂ +1.00%、KNO₃ +1.29%、立方 BN +1.87%、硬石膏 −1.90%、SiC A1(LO) −6.7%（上版已录）。

## 二、文献核实（定向）

- **自由 NO₃⁻（D₃ₕ）ν₁ ≈ 1049 cm⁻¹**（离子本征值）；固体硝酸铵五相（V/IV/III/II/I，相变点 −18/32/84/125/170 ℃）中 ν₁ **随相在 1025–1055 cm⁻¹ 分裂移动**——目标窗 1031.5–1041.9 **落在 AN 相调谐范围内**（特定温度/特定相下 ν₁ 入窗）。
- 文献锚：[2D 相关拉曼研究 AN 相变（Spectrochim. Acta A 2021）](https://www.sciencedirect.com/science/article/pii/S1386142521001578)、[AN 相图+拉曼（JCP 2012）](https://pubs.aip.org/aip/jcp/article/137/6/064504/72890/)、[AN 爆炸物拉曼检测（Vib. Spectrosc. 2020）](https://www.sciencedirect.com/science/article/pii/S1386142520301827)。

## 三、终判（三层）

1. **严格判**：±0.5% 窗内存在**温度调谐命中物**（硝酸铵，特定相）——"31.08THz 无任何材料声子共振"的强读法被削弱为"无**常温稳定相**命中"。
2. **工程判（一票否决）**：AN 是监管爆炸物+五相相变敏感+强吸湿——**材料工程不可用**。工程可用材料的窗内命中 = **零**；最近工程候选 = 硝酸盐族（AgNO₃/KNO₃/Pb(NO₃)₂，+0.6~1.3%，但同为硝酸盐稳定性/光敏问题）与宽窗的 SiC（−6.7%，半导体工艺成熟）。
3. **体系判（对接含义）**："31.08 = 材料无关频率"读法**强化**——写入频率位于常见工程材料声子模之外，与 f₀=材料属性口径自洽（31.08 是 f₀/12 的比例产物，不承诺落在任一材料共振上）。"31.08=某天然声子共振"读法仅剩 AN（不可用）与未扫库域（挂账）。

## 四、挂账（诚实边界）

- 本扫描库 = 46 种标准晶体（教科书级精度 ±2-5 cm⁻¹）；全材料数据库（Materials Project 级，数十万结构）需外部数据库权限——候批联网或导出数据后可全量扫。
- 硝酸盐族 ±1% 级精度的相/温度依赖精确值待定向核实（下批）。

## 五、结论一句话

**扫描做完：严格窗内唯一命中是工程不可用的硝酸铵（还是温度调谐才入窗）；31.08THz 是一个"天然避开常见材料共振"的频率——对写入是低损耗穿透的有利面，对"频率天然共振"假说是不利证据。研究推进到当前资源边界，候批外部数据库可再深一层。**

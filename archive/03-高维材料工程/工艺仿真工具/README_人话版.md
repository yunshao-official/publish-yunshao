# 工艺仿真工具 · README（人话版）

> 版本 v1.0 ｜ 2026-09-12 ｜ ZCode ｜ 依赖：numpy + scipy（纯单机，无网络）
> 这是什么：把"用光/用声音给金属排缺陷"的两套工艺，做成**可以在电脑上先跑一遍再上真机**的仿真工具。所有结论只在模型口径内成立（标量场玩具模型，不含激光/声波与金属的微观相互作用），真机效果以实测为准。

## 它能回答三个问题

1. **模式 A / 模式 B 选哪个？**（光干涉的工作模式裁决）
   - 模式 A = 一台激光器分三束（同频、120°）→ 静态三角晶格；
   - 模式 B = 三束不同频率各自与表面反射形成分层驻波。
   - **首跑裁决结果（30×30 μm 视场、同能量预算）：模式 A 出 4165 个势阱、100% 连通、图案周期 0.612 μm（理论 0.614 μm，精确吻合）；模式 B 同样参数下 0 个势阱。裁决倾向明确：要出"缺陷网+写入序"，选模式 A。**
2. **超声波能做出多细的条纹？** 5 种材料 × 10 个频率的条带周期表（周期=λ/2），并按晶粒散射衰减标注"10 毫米厚板材上是否可行"。钢的实用窗口：0.5–2 MHz → 条带周期 1.4–5.7 mm；超过 2 MHz 衰减不可行。
3. **固体里能不能随便要什么图案？** 不能——固体驻波只能取样品自己的共振振型。工具给出"目标频率 → 最近共振模态"的对齐表（例：10 mm 厚钢想要 5 MHz 条带 → 实际取 n=18 模态 5.13 MHz，偏差 2.6%）。

## 三个文件怎么用

| 文件 | 干什么 |
|---|---|
| `materials_db.py` | 材料参数库（钢/钯/铝/钛/铜：声速、密度、热导率、熔点、红外反射率） |
| `interference_sim.py` | 光干涉：模式 A/B 时均场 → 势阱提取 → 图连通性 + λ₂ + FFT 实测周期 |
| `ultrasound_sim.py` | 超声：条带周期表、衰减可行窗口、共振模态对齐 |
| `run_sweeps.py` | 一键跑全部扫描，结果存 `results/sweep_results.json` |

改参数示例：想看 5 束 72° 夹角、波长 532 nm 的图案 → 在 `run_sweeps.py` 里把 `three_beam_120` 换成你自己的束配置调 `_time_avg_modeA` 即可（束 = (波矢矢量, 强度, 相位) 三元组）。

## 边界（重要，说三遍）

- 模型口径：标量场 + 百分比阈值势阱 + 距离阈值图（与档案管线同算法、独立实现）；
- **不含**激光/声波与金属的微观相互作用、热传导、缺陷动力学——那些只能真机实测；
- 所有"性能"输出是几何/拓扑量（连通性、周期、λ₂），不是物理性能（Tc、强度）。

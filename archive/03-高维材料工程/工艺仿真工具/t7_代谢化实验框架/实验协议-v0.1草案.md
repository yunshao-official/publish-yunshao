# T7 · LLM 代谢化 · 最小可行实验协议（v0.1 草案，待知世签后生效）

> 对应：天工开物卷五第一章（3 个月纯算力实验，判据与退出条款在案）
> 状态：**草案**——预注册纪律要求判据先签后跑，本文件是签核对象，不是已生效判据。
> 定位：给"行走地形有机体"（E 线，L1~L2 层级）装上 LLM 皮层（本地 qwen2.5-7b 级），验证"语言化经验记忆"能否提升有机体的秩序维持表现。**这是主流 LLM 应用的常规实验设计，不涉及任何体系本体声称。**

---

## 一、实验设计（三臂对照）

| 臂 | 配置 | 假设 |
|---|---|---|
| A 臂（对照） | 有机体，无 LLM，现行 E 线配置 | 基线 |
| B 臂 | 有机体 + LLM 记事本（决策-后果对喂回，语言化案例库） | 记事本提升秩序维持 |
| C 臂 | 有机体 + LLM 全决策（LLM 直接选修复动作） | 检验"LLM 直接控制"是否优于"经验库辅助" |

- 模型：本地 qwen2.5-7b（llama.cpp Vulkan 构建，H:\llama.cpp 已在），不联网。
- 任务：E 线行走地形（超立方 n=64，扰动流），秩序指标 ⟨C⟩ = 1 − B/(n−1)。
- 种子：≥10 配对种子（预注册），Mann-Whitney U 检验，α=0.05。

## 二、预注册判据（签后生效）

1. **主判据（B vs A）**：B 臂 ⟨C⟩ 显著高于 A 臂（配对 MWU，p<0.05），且 B 臂 L3 达标时间中位数缩短 ≥20%。
2. **次判据（C vs B）**：若 C 臂不劣于 B 臂且修复动作成功率更高，则"LLM 直接控制"路线开启。
3. **退出条款**：若 B 臂相对 A 臂无显著差异或为负 → 记录负结果归档，"语言化经验记忆"假说关闭，不换参数重试（除非知世明示重开）。
4. **防作弊三条**：LLM 只读实验日志不读评判代码；评判脚本与实验脚本分离；种子分配在首跑前公示哈希。

## 三、资源与环境

- 算力：本机 Vulkan（llama.cpp），7B Q4 量化约 4-5 GB 显存/内存，单次推理秒级；
- 启动命令（模型就位后）：`llama-server -m qwen2.5-7b-q4.gguf --port 8080`；
- 框架：`t7_harness.py`（已就绪，模型未启动时自检报 WAIT_MODEL）；
- 周期：3 个月窗口（卷五 §1.2 原口径）。

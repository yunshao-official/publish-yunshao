# 三线并行总纲 · 指令/能量分离＋代谢层规范（v0.2·2026-08-26 知世14:31指示）

> **总纲原话锚**：「全都试试。你要理解，既然是生命就应该有生命共通的特点啊」
> **语义诊断**：撤源判据隐含晶体标准（撤一切驱动秩序永存）；生命标准＝持续能量流下维持动态秩序（耗散结构），**断能即死恰是生命定义特征**。此前「驱动」身兼指令与能量两职→测试语义混淆。
> **核心动作＝指令/能量分离**。

## 代谢层规范（三线共用·v0.1）

1. **定义**：代谢项 M_i(t) := m₀·(1+η·ξ_i(t))，ξ为有界噪声（|ξ|≤1，相关时间τ_m=10帧）——只调局部动力学增益/温度底，**零站位信息**（不含sin(φ_c−θ)类指向项、不含类标签依赖的均值结构；m₀全场均匀）；
2. **实现位置**：进入动力学作为噪声底替代/叠加：θ' = K·lap + [指令项] + (σ²+M_i)·ν，ν~N(0,1)/√dt——代谢供能=提高局部探索温度，非推动方向；
3. **红线**：代谢参数(m₀,η,τ_m)先锁后跑入预注册；代谢层不得携带任何类/锚/位置依赖项（违者=变相指令，攻击手重点查）；
4. **判据语义重述**：「自发」分级＝①纯指令自组织（旧口径）②代谢供能下指令撤除后自生长（本轮新口径，须标注「代谢依赖」）③无任何能量流的永续（晶体标准，不再作为唯一金标准）；
5. **撤除测试矩阵**：全撤（晶体检验）/撤指令留代谢（生命检验·主判据）/全留（运行检验——【v0.2·P2-2】角色操作化：运行完整性检验，确认系统在正常参数下无隐藏漂移，非判据臂，不参与成败判定）。

# 三分量强化钢材 · 制作方法 · 通俗完整版（对外）

> 这份文件写给完全不懂技术的人。你不需要懂任何物理，只要识字、能照步骤做，就能看懂整个制作过程。
> 三条阅读规矩：①按顺序读，不要跳；②每一步"做到什么程度算合格"都写清楚了，达标再进下一步；③这份文件里不会有"为什么"——照做就行，原理不在这份文件里，也不要问。
> 保密提示：这份文件和做出来的东西都归委托方所有；文件不许复印外传；做好的样品和所有边角料要全部交回。

## 〇、我们要做的东西是什么

一句话：**一块特殊的钢。**

它表面看起来就是一块银灰色的钢板（10厘米×10厘米、厚2毫米左右），但内部被我们用激光"刻"出了极小的、排列得非常规整的花纹。刻好之后，这块钢会获得普通钢完全没有的本事——比如在某个温度以下，电流通过它完全不损耗（行话叫"超导"，你可以理解成"不费电的完美导线"）。

打个比方：普通棉花和琴弦都是纤维，但琴弦被有规律地绷紧排列后就能发出固定的音。我们要做的，就是把钢内部的"纤维"用光排成特定的规律，让它获得新本事。

**整个制作过程一共六步，全部做完大约需要一到两周。**

## 一、要准备什么

| 要准备的东西 | 干什么用 | 通俗说明 |
|---|---|---|
| 不锈钢板 | 原材料 | 就是最常见的厨房不锈钢那种成分，切成明信片大小 |
| 一台特殊的激光器（委托方指定型号） | "刻花"的光源 | 像一支非常稳的手电筒，光要又纯又稳 |
| 分光镜和反射镜 | 把一束光分成三束 | 像用镜子把一束手电光变成三束 |
| 一台"测音仪"（远红外光谱仪） | 摸清材料的"音" | 像给材料做听力测试 |
| 一个真空炉 | 给钢"定型" | 像烤箱，但要抽成真空、能到八百多度 |
| 检测仪器（可外包） | 给成品做体检 | 像医院抽血化验 |
| 一间安静的屋子 | 保证"刻花"时不抖不晃 | 拍微距照片时手一抖就糊——这里要求比那更高 |

## 二、制作全过程（六步，一步步来）

### 第1步：先摸清这块材料的"音"（专业上叫"标定"）

**干什么**：每批钢材都有自己的"脾气"——它内部结构振动的"音调"不一样。我们先用测音仪把这批钢的"音"测出来，记下来。后面的激光就要用这个"音"去刻，音对了才刻得进去。

**怎么做（两次，互相印证）**：
1. 用激光照钢板表面，测反射回来的光（要先用标准方法把背景"噪音"扣掉，就像在嘈杂的房间里听人说话要先滤掉背景音）；
2. 再取一小片同批钢材磨薄，让光穿过去测一遍。
两次测出来都对上，才算数。

**做到什么程度算合格**：测出了清楚的"音"（共振点，一般有三到五个）。**如果两次都测不到——这批钢不合格，停下来报告，换下一批。绝对不能硬刻。**

### 第2步：把底子磨光洗净（"预处理"）

**干什么**：刻花之前底子必须完美——像盖章前要先把纸压平。

**怎么做**：把钢板切成规定尺寸→用从粗到细的砂纸磨五遍（400目一直磨到3000目）→用研磨膏抛到镜面→用药水超声波洗干净→烘干→拿放大镜检查，不能有一道划痕、一点脏。

**合格标准**：镜面效果，放大100倍看不到划痕和污点。

### 第3步：用三束光"刻"出内部花纹（"干涉写入"，最关键的一步）

**干什么**：把一束激光分成三束，从三个方向（每两束之间正好120度，像奔驰车的标志）同时照进钢板。三束光在钢板内部交叠，会形成一张非常稳定、非常规则的"光网"——钢板内部被这张光网照到的地方就发生改变，光网的样子就这样"印"进了钢里。

打个比方：往平静的水面同时扔三颗石子，三圈波纹交叠的地方会出现稳定的图案——我们就是把这张稳定的图案"冻"在钢里面。

**怎么做（关键规矩，一条都不能违反）**：
- 三束光的角度必须是**120.0度，误差不超过半度**——这是生死线，角度歪了整块材料直接碎裂报废；
- 光的"音"必须用第1步测出来的那个（三束必须完全同频）；
- 三束光的强弱必须完全一样，**不许偷懒减半**；
- 照射时间30分钟，期间桌子不能抖、房间温度变化不能超过半度；
- **照完30分钟就立刻关灯，永远不照第二次**——重复照等于把画好的画再涂一遍，只会毁掉它；
- 整个过程光要绝对稳（按委托方给定的稳定度要求执行，装稳定监测仪，一超线就停）。

**合格标准**：30分钟平稳完成、断灯核对记录在案、环境全程达标。这一步做得好不好，要等第5步体检才知道。

### 第4步：进炉定型（"热处理"）

**干什么**：刚刻好的花纹还是"临时"的，要进炉子加热让它固定下来——像烤蛋糕，烤完才定型。

**怎么做**：把钢板放进真空炉，慢慢升温到827度（约半小时升温）→保温30分钟→慢慢降温→再在7度左右的环境里放2个小时。降温后**加做两个检查**：切一小片看金相（内部组织有没有异常）、测硬度（和没处理过的对比）——发现变脆马上报告，这批要小心搬运。

### 第5步：体检验收（"检测"）

**干什么**：给成品做全面体检，四项主检+一份"对照卷"。

**四项主检**：
1. **临界温度**：降到多少度它开始"不费电"？合格线：实测不低于473K（约200摄氏度）；
2. **零电阻**：在那个温度以下，电流通过是不是完全不损耗？合格标准：电阻为零；
3. **磁通排斥**：把磁铁靠近它，它是不是把磁场"推出去"？（超导的招牌动作）合格标准：仪器能看到排斥；
4. **结构完好**：用电镜看内部花纹是不是清晰规整。

**对照卷（三份"安慰剂"）**：同时准备三块参照样品——一块没刻花的、一块乱刻的（不按图案随机来）、一块用别批钢材同样工艺刻的。**三块参照样品都不能有超导表现，只有正式样品有——这样才能证明是"刻花"起了作用，不是材料本来就如此。**任何一块参照样品也出现了同样表现，整批作废重来。

### 第6步：交付与回收

合格成品连同**所有边角料、废品、碎屑**一起清点，交回委托方。制作方不留样品、不留副本、不留照片（内部结构照片一律不许拍）。记录单据由双方签字封存。

## 三、怎么算整体成功

一句话：**六步全部达标 + 四项主检通过 + 三块对照全阴性 = 成功。**任何一步失败，就停下来查原因，不许跳过、不许凑合。

## 四、最容易失败的地方（前人踩过的坑）

| 坑 | 后果 | 怎么避免 |
|---|---|---|
| 三束光角度歪了半度以上 | 材料碎裂，全批报废 | 用热稳定锁定架，每班点检 |
| 跳过第1步直接刻 | 光的"音"不对，几乎刻不进去 | 第1步是铁门，不测不刻 |
| 光的强弱减半、束数减少 | 内部花纹直接毁掉 | 禁止；设备上限流上锁 |
| 照完又补照"加强一下" | 花纹被毁（重复照射=负收益） | 断灯+第二人核对 |
| 多种频率混着照 | 刻不出稳定花纹 | 只用标定的那一个频率 |
| 房间振动/温度漂移 | 花纹糊掉 | 防振台+恒温，超标即停 |
| 热处理后搬运摔碰 | 可能脆断 | 过了金相硬度检查再正常搬运，异常批次按易碎品对待 |

3. 每一步的合格线在开工前填写并双方签封，做完不许改标准；
4. 失败和报废如实记录，不许悄悄重测凑数；

## 名词小词典（外行版）

| 词 | 人话解释 |
|---|---|
| 标定 | 动手前先测出这批材料的"音"，保证后面用的光对得上号 |
| 干涉 | 几束光叠在一起会形成稳定的明暗图案——就像几圈水波交叠出固定纹路 |
| 写入 | 让这张光的图案在材料内部"印"成永久花纹 |
| 热处理 | 进炉加热再按规矩降温，把花纹定型 |
| 临界温度 | 材料开始表现"零损耗导电"的那个温度点 |
| 零电阻/超导 | 电流通过完全不损耗的状态——完美导线 |
| 迈斯纳效应（磁通排斥） | 把磁场推出去，超导的招牌动作 |
| 对照组 | 三块"陪跑"的参照样品，用来证明效果真的来自我们的工序 |
| 占空比/脉宽等参数 | 由委托方任务书逐批下发，本文件不列 |

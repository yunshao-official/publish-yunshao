# 三分量强化钢材 · 制作方法 · 完整执行版（对外）

> **这份文件能让你做什么**：按本文全部步骤和参数执行，你可以实际制造出三分量功能强化钢材样品，并用第四步的标准自检是否成功。
> **文件原则**：原理不给、参数全给。你不需要懂这种材料为什么有这些性质（原理属委托方，不在本文，也不要问）；但做好它需要的**每一个数字**都在本文里。
> **你需要的基础**：熟练光学平台操作技工1-2名；本文设备清单内的仪器；一间达标实验室。
> **保密**：本文及制作记录保密；样品与全部废料交回委托方，零留存；本文不许复制外传。

---

## 〇、你要做出来的东西

一块 **100×100×2mm** 的铁镍铬钢板（Fe70Ni20Cr10，与304不锈钢同成分），内部有三束激光"印"进去的周期性微观结构。**成功的判定标准（做完第四步对照）**：
- 温度降到 **473K以下**时电阻变为零；
- 有磁通排斥现象（SQUID磁滞回线可测）；
- 电镜下内部结构清晰规整；
- 电导率 σ≥10⁻²S/m；
- 三块对照样品全部阴性（见第四步）。
目标值600K【当前为委托方声称值，验收以473K判定线为准】。

## 二、第〇步：声子频段标定（不做这步，后面全部报废）

**目的**：找出这批钢材内部的共振频率，写入激光必须打在这个频率上才刻得进去。

**操作**：
1. **通道一（反射法）**：FTIR反射模式，扫描**15-100μm（100-670cm⁻¹）**。⚠️ 金属表面反射谱被自由电子背景主导，**必须先做背景建模扣除再读峰**：用Drude-Lorentz模型拟合整条反射谱（自由电子部分+若干洛伦兹振子），从"拟合曲线减实测谱"的残差里找峰。直接看原始谱找峰是无效操作。
2. **通道二（透射法）**：取同批次钢材减薄成**20-50μm**薄片，透射模式同范围扫描，找吸收峰。
3. 两通道各自列峰表，互相印证（同一频段的峰算确认）。

**判定**：
- 找到峰（一般3-5个主要峰）→ 记录**声子共振频率表**，进入第〇步B；
- **两通道都无峰 → 这批基底判废，停止，报告委托方换批次。不许硬刻。**

**第〇步B：写入频率定稿**：写入频率=取标定峰；若用CO₂激光器则取9.6μm带谱线（31.08THz），且与最近标定峰核对偏差——偏差过大以标定峰为准。全批次统一这一个频率。

---

## 三、第一步：基底预处理

按顺序做，每片都做：
1. 线切割成 **100×100×2mm，误差±0.1mm**；
2. SiC砂纸研磨：**400→800→1200→2000→3000目**，逐级；
3. 金刚石抛光膏：先 **1μm** 后 **0.25μm**，抛至镜面；
4. 清洗：丙酮超声 **10分钟** → 无水乙醇超声 **10分钟** → 去离子水冲洗 → 氮气吹干；
5. 光学显微镜 **100×** 检查：无划痕、无污点。不合格→返工第2-4步。

---

## 四、第二步：干涉写入（核心步骤·全部参数在表）

**原理一句话（只需要知道的）**：三束同频激光从三个方向同时照进钢板，交叠出稳定的明暗图案，这个图案被钢板内部记住，成为永久结构。

**装置布置**：激光器→分束器分成三束（每束约**3.3W**）→六面反射镜导向→三束从盘面边缘方向射向盘心，**任意两束夹角120.0°**，光斑在样品中心重合（覆盖≥中心30mm区域）。

**全参数表（照抄执行，一个不许改）**：

| 参数 | 数值 | 违反后果 |
|---|---|---|
| 束数 | **3束等幅**（每束3.3W±5%） | 减束数=结构毁 |
| 波长/频率 | **9.6μm（31.08THz）或标定峰，三束完全同频** | 多频=刻不出稳定结构 |
| 三束夹角 | **120.0°±0.5°** | 偏差>0.5°=材料碎裂报废 |
| 每束相位 | 按委托方给定相位表设置（标准表：k×45°，k=0,1,2），锁定后**曝光全程漂移≤0.05rad**（装相位监测，超线立即中止） | 漂移超限=图案畸变报废 |
| 功率 | 分束前总功率**10W**；**禁止减功率** | 减功率=结构深度不足=毁 |
| 场强幅值 | **10⁴V/m**（等效强度档；或按批次任务书） | 偏离=结构不达标 |
| 占空比 | **0.3**（保温期可用0.45档：质量约翻倍、耗电+50%，二选一并记录） | —— |
| 脉宽 | **1μs** | —— |
| 写入时间 | **30分钟**，一次成型 | 重复照射=结构被毁（严禁二次照射，写完立即物理断开光源，第二人核对签字） |
| 环境 | **23±0.5℃**（温漂>1℃=报废）、湿度<40%、防振台隔离>10Hz | 振动=图案模糊报废 |
| 光路 | **全封闭光路+排风口遮断**，人员不直视任何泄漏光 | 安全要求 |

## 六、第四步：验收（做完才知道成没成）

### 6.1 主检五项

| # | 检什么 | 用什么 | 合格线 |
|---|---|---|---|
| 1 | 临界温度Tc | SQUID | **实测≥473K**（未达=报废） |

| 3 | 磁通排斥 | SQUID磁滞回线 | 冷场冷却下测得磁通排斥 |
| 4 | 内部结构 | 电镜（HRTEM） | 周期结构清晰规整（热处理后试样） |
| 5 | 电导率 | 四探针 | **σ≥10⁻²S/m** |

### 6.2 三组对照（同批做，少一组结论无效）

| 对照组 | 做法 | 合格要求 |
|---|---|---|
| 臂1 | 同批钢材，**不写入**（只做热处理） | 阴性（无主检1/3表现） |
| 臂2 | 同批钢材，随机写入（不按参数表，乱设角度相位） | 阴性 |
| 臂3 | **异批**钢材，同参数写入 | 阴性 |

**判定规则：三臂全阴性 + 正式样品五项全过 = 制造成功。任何一臂出现阳性，整批作废，查设备系统误差后重来。任何一项主检不过，本样品报废，不得修补。**

## 七、报废规则汇总（出现即执行，不得变通）

1. 第〇步双通道无峰→整批基底报废换批；
2. 三束夹角偏差>0.5°→本样品碎裂/报废；
3. 相位漂移超0.05rad→写入中止，本样品报废；
4. 二次照射/累积曝光→报废；
5. 减功率/减束数/多频混写→报废；
6. 温漂>1℃或振动超标时段的曝光→报废；
7. 主检任一项不过→该样品报废；
8. 对照臂阳性→整批作废；
9. 报废品与边角料**全部清点交回委托方**，不得自行处置。

## 九、名词小词典

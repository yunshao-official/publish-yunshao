## 一、机制与架构

```
【体系】云韶钢元件（材料即源）+ 三组线圈（120° 相位差，3 分量干涉+α=1/8）
        → 电流大小=场强，通断=开关 → 云韶场辐射 → 第一层适应症（消炎/止痛/伤口愈合）
        ↓
【闭环】Λ 五路传感器（秒级）→ 实时反馈 → 自动调电流（"实时反馈调参数"，体系原文）
```

- 激励器=线圈（电磁只当激励的手），辐射本体=云韶钢激发的云韶场【体系】；0813 原话"不需要电磁场"与 0744 裁决"云韶钢+线圈"合读：**线圈是手，云韶钢是源，云韶场是输出**。
- fallback（体系原文自带）：云韶钢不可用时 V1.0 用 3 分量 804nm 干涉构型——按裁决 5 仅列为工具线对照备件，不占正本名义。

## 二、整机形态（手持式 V1.0）

```
┌─ 照射头：云韶钢元件座 + 三组线圈（120°） + 距离定位环
├─ 主机：恒流驱动板（v0.2 简化三通道）+ 电池 + MCU
├─ 传感：Λ-V1.0 双路（生物阻抗 BIA + HRV）→ Λ 秒级估算
├─ 交互：OLED（Λ 实时值/疗程倒计时/电流档）+ 单键启动
└─ 安全：≤10mA 元件硬限 / 线圈温控 / 疗程计时联锁
```

## 三、分系统

### PS1 辐射源（照射头）
| 项 | 设计 | 出处 |
|---|---|---|
| 源 | 云韶钢元件（R23 同族，尺寸按元件接口 10×10×1mm 镀银） | 电路板 v0.2 |
| 线圈 | 三组绕制线圈，几何互成 120°，各自 H 桥+移相驱动 | 知世 07:44【体系】 |
| 驱动 | 恒流 0-2A 可调（线圈激励电流与元件电极电流分路，元件侧仍 ≤10mA） | v0.2 继承 |
| 几何 | 照射距离定位环 5cm（Λ 文档 r=5mm 磁场口径按几何换算） | 【执行】 |

### PS2 Λ 传感（V1.0 双路，升级路径到 V3.0 五路）
| 路 | 器件 | 成本 |
|---|---|---|
| 生物阻抗 BIA | AD5933 阻抗转换器（相位角 PA→Λ_BIA） | 50-100 元 |
| HRV | MAX30102 PPG（样本熵+DFA→Λ_HRV） | 20-50 元 |
| 融合 | Λ=0.5×Λ_BIA+0.5×Λ_HRV（V1.0 双路归一权重） | 体系五路方案的 V1.0 子集 |
| 升级路径 | V2.0 加 NIRS；V3.0 加热像+UPE（五路全开，25000 元档） | 体系原文 |

### PS3 闭环控制
- 实时 Λ 显示（OLED，1Hz 刷新）；
- 自动调流：Λ 低于目标带 → 电流升档；高于目标带 → 降档（"实时反馈调参数"【体系】）；
- 疗程管理：每日 1-2h 计时+累计记录（0813 原话照射参数），数据导出 CSV。

### PS4 安全
元件侧 ≤10mA 硬限；线圈温控 60℃ 阈值断电；照射头过热联锁；电池保护；疗程联锁（超时自动停）。

## 0. 结论先行（P-12 判据优先）

1. **产水率指标可达【执行】**：30-50 ml/m²/h 在 30°C/80%RH 工况下，现役制冷除湿路线可达且裕度大（复算富余 1-4 个数量级，视"m²"口径，见 §2.3）。指标真正紧的是**能耗**与**低湿工况**，不是产水通量。
2. **能耗是第一约束【执行】**：现役制冷式 AWG 能耗约 300-1500 Wh/L（视温湿度）；本文台架复算设计点约 450-600 Wh/L；半导体制冷（Peltier）约 2000-4000 Wh/L，**过不了 ≤1500 Wh/L 判据**，只做便携演示档。
3. **低湿是第二约束【执行】**：露点 <5-8°C 时制冷路线产水骤降并结霜，须切吸附式（硅胶/MOF）路线（§7 降级条款）。
4. **"场冷凝"不入执行层【体系·假设·待证】**：无已知物理对应，V1 以现役制冷路线交付；B 期升级挂 **TFI-1 闸门**（场存在，五道总闸门之首）。
5. **路径**：V1 制冷除湿台架（即日可开工）→ V2 太阳能离网版 → B 期场冷凝升级（TFI-1）。

## 2. 物理账【执行】

### 2.1 湿空气含水量与露点表（Magnus 复算，复算一致·实机未验证）

含水量单位 g/m³（1 m³ 空气中水汽质量）；括号内为对应露点 °C。

| 气温 T | RH=40% | RH=60% | RH=80% |
|---|---|---|---|
| 5°C  | 2.7 (−7.5) | 4.1 (−2.1) | 5.4 (+1.8) |
| 10°C | 3.8 (−3.0) | 5.6 (+2.6) | 7.5 (+6.7) |
| 15°C | 5.1 (+1.5) | 7.7 (+7.3) | 12.8 (+11.6) |
| 20°C | 6.9 (+6.0) | 10.4 (+12.0) | 17.3 (+16.5) |
| 25°C | 9.2 (+10.5) | 13.8 (+16.7) | 18.4 (+21.3) |
| 30°C | 12.1 (+14.9) | 18.2 (+21.4) | **24.3 (+26.2)** |
| 35°C | 15.8 (+19.4) | 23.8 (+26.1) | 31.7 (+31.0) |

**读法**：把空气冷到露点以下才开始出水；冷得越深，每 m³ 出水越多，但显热冷负荷越大、蒸发器越接近结霜。工程上把出风冷到 **5-12°C**（蒸发器表面约露点−8~−16°C，下限 2°C 防霜）。

**单程抽湿量 Δρ（g/m³）＝ 进风含水量 − 出风(饱和)含水量**，复算样例：

| 工况 | 出风冷至 15°C | 冷至 10°C | 冷至 5°C | 冷至 2°C |
|---|---|---|---|---|
| 30°C/80%（24.3） | 11.5 | **14.9** | 17.5 | 18.7 |
| 30°C/60%（18.2） | 5.4 | 8.8 | 11.4 | 12.6 |
| 25°C/60%（13.8） | 1.0 | 4.4 | 7.0 | 8.2 |
| 20°C/40%（6.9） | 0 | 0 | 0.1 | 1.3 |

### 2.2 制冷除湿能耗（Wh/L 复算与现役区间）

- 理论下限：仅汽化潜热 2260 kJ/L ≈ **628 Wh/L**（热力学，未计显热与损失——注意：这是"热"不是"电"）。
- 台架复算（设计点 30°C/80%，出风冷至 10°C）：热负荷 ≈ 潜热 10.2 + 显热 6.5 = **16.7 Wh/m³（热）**；小型压缩机 COP≈2 → 电耗 ≈ 8.4 Wh/m³ → **SEC ≈ 8.4/14.9 L ≈ 560 Wh/L**。加进/排风热回收可降到 ≈450 Wh/L。**台架设计区间取 450-600 Wh/L。**
- 现役公开区间【执行】：制冷式 AWG/除湿机 **约 300-1500 Wh/L**（大机组与理想湿工况取低端；小机型、湿热重载或含再热取高端）；吸附式在低湿环境有优势（§7）。
- 半导体制冷（Peltier）：COP 0.3-0.6 → 复算 **≈2000-4000 Wh/L**，**不满足 ≤1500 Wh/L 判据**，仅用于便携应急档（产水量优先、能耗豁免，见 §6 冻结条款注记）。

### 2.3 30-50 ml/m²/h 指标的现役可达性判定（30°C/80%RH）

风量 → 产水量（Δρ≈15 ml/m³，出风 10°C 口径）：

| 风量 m³/h | 产水 L/h | 折 L/day（24h 连续） | 电耗（COP2）约 W |
|---|---|---|---|
| 20 | 0.30 | 7.2 | ~170 |
| 40 | 0.60 | 14.4 | ~340 |
| 60 | 0.90 | 21.6 | ~500 |
| 100 | 1.50 | 36 | ~840 |
| 250 | 3.75 | 90 | ~2100 |

"每 m² 每小时"口径换算（以 60 m³/h 家用档为例，产水 0.9 L/h）：

| "m²"口径定义 | 面积取值 | 产水通量 | 对 30-50 判定 |
|---|---|---|---|
| 蒸发器芯体迎风面 | ≈0.008 m²（2 m/s 迎风风速） | ≈1.1×10⁵ ml/m²/h | 富余 3-4 个数量级 |
| 翅片湿润面积 | 1.5-3 m² | **≈300-600 ml/m²/h** | **富余 6-20 倍（推荐验收口径）** |
| 整机占地/开口 | ≈0.3 m² | ≈3000 ml/m²/h | 富余 60-100 倍 |

**判定【执行·复算】**：30°C/80%RH 下三条口径全部达标，**指标现役可达**；指标性质偏"宽松"。**判定边界（如实）**：
- 25°C/60%RH：同样机组产水降至约一半，湿润面积口径 ≈150-300 ml/m²/h，仍可达；
- 20°C/40%RH：单程抽湿仅 ≈1.3 ml/m³，产水通量 ≈26 ml/m²/h（湿润面积口径），**贴线或不可达**，且能耗升至 ≈2500-4000 Wh/L，**双判据同时失效**——此即 §7 降级切换点；
- 露点 <5°C（如 10°C/40%、5°C/80%）：制冷路线趋近不可用（须蒸发器零下，结霜堵死），**必须切吸附式**。

## 3. 分系统设计

### 3.1 制冷芯（两档）【执行】

- **压缩机档（V1 主力）**：小型全封闭压缩机（R134a/R290）或 12/24V 直流变频芯（房车冰箱级，200-500W），额定制冷量 500-900W；蒸发器=铜管铝翅片；冷凝器=风冷。**机箱预留 B 期场发生器安装位（不通电、不接线，仅结构接口）。**
- **半导体制冷档（便携演示）**：TEC1-12706 ×2-4 片（12V，每片 50-72W），冷端接铝翅片冷凝芯，热端水冷或强制风冷。定位：应急少量饮水 + 教学演示，**不参与 A2 能耗验收**。

### 3.2 冷凝器与风道【执行】

- 蒸发器迎风面风速 1.5-2.5 m/s（过高带水、过低换热量不足）；翅片间距 ≥1.6 mm（湿工况防凝结水搭桥）。
- 风机：直流离心/轴流 40-120 m³/h（家用档），噪声 ≤45 dB 目标。
- 蒸发器表面温度控制：设定 = 露点 −8~−16°C，**下限 2°C**（防霜）；有化霜循环（表面 <2°C 停机回温）。
- 进风初效滤网（G4 级）+ 可选活性炭毡（除 VOC，改善冷凝水口感）。
- 进/排风热回收芯（可选 V1.1 升级）：纸芯全热交换，可削显热负荷 30-50%。

### 3.3 集水槽【执行】

- 食品级 PP 或 304 不锈钢；底盘坡度 ≥5° 自流入槽；接水盘避免积水死区（生物膜温床）。
- 液位开关（满水自停/满水报警）；槽体避光（防藻）。

### 3.4 UV 灭菌【执行】

- 波段：254nm 低压汞灯或 275nm UV-C LED 模组；**剂量 ≥40 mJ/cm²**（NSF 55 Class A 口径，按额定流速与腔体尺寸核算）。
- 布点：集水槽 → UV 腔 → 滤芯 → 储水桶，即**出水前消毒**；UV 腔流速 ≤额定值（家用档 ≤2 L/min）。
- 维护：灯管寿命 ≈9000h（LED 约 1 万h），到期强制更换提示；石英套管定期擦垢。

### 3.5 过滤与水质【执行】

- 水路：PP 5μm（颗粒）→ 颗粒活性炭（异味/残留）→ UF 0.01μm（细菌级屏障，可选）；**冷凝水本质是蒸馏水（TDS 通常 <20 mg/L）**，口感寡淡，可选麦饭石矿化模块。
- 材料纪律：水路禁用镀锌件/铅锡焊料；铜铝冷凝翅片长期析出须定期检测重金属。

### 3.6 供电【执行】

市电版：220V/110V 常规；离网版核心账——**日产水量(L/day) = 板功率(kW) × 峰值日照时数(h) × 0.75（系统效率：MPPT+电池+线损）÷ SEC(Wh/L)**。

| 板功率 ↓ 日照时数→ | 3h（SEC=500/800/1500） | 4h | 5h |
|---|---|---|---|
| 100W | 0.45 / 0.28 / 0.15 L | 0.6 / 0.38 / 0.2 L | 0.75 / 0.47 / 0.25 L |
| 200W | 0.9 / 0.56 / 0.3 L | 1.2 / 0.75 / 0.4 L | 1.5 / 0.94 / 0.5 L |
| 400W | 1.8 / 1.1 / 0.6 L | 2.4 / 1.5 / 0.8 L | 3.0 / 1.9 / 1.0 L |
| 800W | 3.6 / 2.3 / 1.2 L | 4.8 / 3.0 / 1.6 L | 6.0 / 3.8 / 2.0 L |

- 电池（若需夜间连续运行）：家用档 350W×10h ≈ 3.5 kWh → LiFePO4 24V 150Ah（≈3.6 kWh）；仅白天运行可免电池、省 1/3 成本。
- **如实结论**：太阳能离网 AWG 日产水量有限（400W 板 ≈ 1-4 L/day），定位**应急补充饮水**，不是主力供水；离网缺水场景应同时配置雨集/露水栅网等被动手段。

## 5. 施工步骤（15 步）

1. **工况确认**：记录现场温湿度与露点（表 §2.1）；若当地露点 <8°C，直接评估吸附式路线（§7），不硬上制冷。
2. **图纸冻结**：确定"m²"验收口径（推荐翅片湿润面积）并在图纸标注；定风量/芯体/预算档位。
3. **框架施工**：机架+风道，蒸发器迎风面风速按 1.5-2.5 m/s 配风机。
4. **制冷芯安装**：压缩机芯（或 TEC 组）就位，冷凝器走风、蒸发器迎湿风；预留 B 期场发生器安装位。
5. **保温与冷桥处理**：风道与集水段包保温（PE 橡塑 ≥10mm），杜绝冷凝水外漏与二次凝露。
6. **接水系统**：接水盘坡度 ≥5° → 食品级集水槽；装液位开关（满水自停）。
7. **水路连接**：集水槽 → UV 腔 → 滤芯组 → 储水桶，全程食品级管件，禁铅锡焊/镀锌件。
8. **UV 腔安装**：按额定流速核算剂量 ≥40 mJ/cm²；装灯管寿命计数。
9. **电气施工**：控制器、露点控制逻辑（蒸发器表面温度 = 露点−8~−16°C、下限 2°C 防霜+化霜循环）、漏电保护；接电能表（A2 计量点）。
10. **进风过滤**：G4 初效（+活性炭毡）安装，预留更换位。
11. **试运行 8h**：记录温湿度/风速/产水量/逐时电耗；检查漏水、异常噪声、结霜。
12. **参数整定**：风速与蒸发温度寻优（产水量/能耗曲线取 SEC 最低工作点）。
13. **水质自检**：TDS、pH、菌落总数试剂快检；有条件送检（重金属+微生物全项）。
14. **验收测试**：30±1°C/80±3%RH 工况（恒温恒湿间或选季选时）连续 ≥4h，量筒计量产水量，电表全程读数。
15. **归档**：贴标签（型号/工况/SEC 实测值/UV 更换日期）、写运行手册、数据回填本文档 v0.2。

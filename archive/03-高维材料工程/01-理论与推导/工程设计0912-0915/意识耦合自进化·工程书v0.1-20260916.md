## 一、机制层【体系】

**1.1 意识耦合=脑机接口反馈回路【体系】**
清单语境下，"意识耦合"指使用者与装备之间的**双向信息耦合回路**：使用者脑信号（EEG）→在线解码→装备响应/参数调整→使用者感知并调整自身→脑信号再变化——**闭环成立即"耦合"成立**。实现载体即清单前半句明写的**脑机接口反馈**，与《脑机接口·工程设计书 v0.1》读写闭环同构（本册取其读出链+码本子系统，写入侧不在本册范围）。

**1.2 自进化=装备参数随使用者数据自动优化**
清单后半句"装备个性化"落地为：装备（软件参数面）随使用者使用数据**自动**调优，不需人工重新标定。现役术语=**协同自适应（co-adaptation）/共同学习（co-learning）**：解码器与使用者相互适应、共同改进——此为公开已验证方向，无未验证物理依赖。

**1.3 体系原文机制注记（冷引用·K-4 如实入账）**
正本§九原文照录（【体系内部定义·未验证】）：
- 原理："装备通过脑机接口耦合穿戴者7维意识，意识/选择反馈影响装备场分布，装备向穿戴者习惯方向进化。"
- 功能："同一套祀姒装备不同人穿戴后，长期使用会分化成不同的子版本。……越来越贴身。"
- 常数依据（照录）："耦合强度正比于alpha×场强。每次耦合亏损alpha=1/8，8次耦合达到稳定（eta(k)=7/8*[1-(1/8)^k]，k=8时适应率63%）。"

**常数轨冲突登记**：按式直算 eta(8)=7/8×(1−1/8⁸)≈**0.875**；若按 1−(7/8)⁸ 口径≈**0.656**，均≠原文标注"63%"。两口径与标注不自洽，如实登记**【常数轨冲突·待知世裁决】**（同 20260916 正本差分审计惯例）。**本册执行层不调用该常数，冲突不阻塞施工。**

**1.4 C 双层制声明**：机制层=体系原生描述（§1.1–1.3）；执行层=现实物理（EEG/PPG 采集、在线机器学习，全部公开方法）。主流物理只进执行器与测量层。本册执行层**不调用** Λ/Θ(N)；体系量值仅冷引用（度规场按定义恒为零、反云韶场 1/7140【体系·未验证】，见§八远期）。

## 二、总体架构（在线共适应闭环）

```
【采集】EEG 8–32ch（+PPG 可选）→ 滤波/伪迹处理/质量门（阻抗监控）
   ↓
【在线解码】当前解码器 → 判定输出 + 置信度
   ↓
【装备响应】界面/装备参数动作（继承 BCI 工程书闭环口径，一期 <1s）
   ↓
【使用者反馈】正确/错误标注（自愿·知情·随时退出）
   ↓
【在线更新】SGD / 增量 LDA（正则化+早停+验证守门，异步不占解码周期）
   ↓
【个性化参数库】档案写入（特征模板/阈值/图案偏好，版本化可回滚）
   └──→ 回到【在线解码】（闭环）  ＋ 漂移检测旁路（阻抗+分布监控 → 自动重校准）
```

一句话：**解码器与使用者互相教——用得越久越贴身**（对应正本"分化成不同的子版本"的执行层可交付切片）。

**与 codex_trainer 三阶段衔接**（继承接口，不推翻已冻结判据）：

| codex_trainer 阶段（冻结） | 本工程衔接 |
|---|---|
| 阶段1 关联存在 >8.3%（12 类机会水平） | **首日基线校准**=阶段1 口径（每图案 ≥10 重复） |
| 阶段2 映射可靠 >50% 且饱和 | **本工程=阶段2 的持续版**：在线共适应使映射随使用持续改善（J1 判据） |
| 阶段3 码本外推 >30% | **迁移学习初始化**（跨会话/跨被试对齐） |
| 读回校验 >50% | 在线置信度门 + 反馈标注核对（轻量读回） |

## 三、分系统设计

### S1 在线学习算法（全部公开方法）
| 方法 | 用途 | 说明 |
|---|---|---|
| 随机梯度下降（SGD） | 线性/浅层网络权值在线更新 | 小步长+L2 正则+早停；每 N 试次批微调 |
| 增量 LDA | 分类器均值/协方差在线更新 | 试次级递推，计算量 O(特征维) |
| 迁移学习 | 冷启动与跨会话 | 他人/前会话数据预训练+特征对齐（欧氏/黎曼对齐，公开做法） |
| **守门提交** | 防退化 | 更新先在验证集试算：不降方可提交入档，否则弃用（防在线吃噪声） |

### S2 个性化参数库
每使用者一份档案 `profile_<id>.json`：①**特征模板**（CSP 空间滤波器/PSD 模板/模板波形）；②**阈值**（分类阈值、置信度门限、阻抗/质量门限）；③**图案偏好**（刺激参数、界面布局、映射偏好）。纪律：版本化+一键回滚+校验和；本地存储加密；导出脱敏。

### S3 漂移检测与自动重校准
- **电极阻抗监控**：每通道实时阻抗，>5 kΩ 报警（继承 BCI 工程书 WS2 质量门口径）；
- **信号分布漂移**：滑动窗特征均值/协方差监控（PSI/马氏距离），双门限=预警/动作，连续多窗确认防误判；
- **动作**：自动重校准（增量更新优先，必要时插入短校准序列）——**全程无人工干预**（J3 判据）。

### S4 会话管理
状态机：冷启动（档案不存在→模板库预训练）→基线核对→在线共适应→收尾归档（档案版本+1、数据入库）。断点续传、日志审计、数据不出本机。

## 五、施工步骤（14 步，软件为主）

1. **继承盘点**：BCI 工程书 v0.1 接口与 codex_trainer.py 函数签名（featurize/classify）冻结复用，不改已冻结判据；
2. **数据接口层**：EEG/PPG 驱动接入（LSL/串口）+统一数据格式（含阻抗通道位）；
3. **在线特征管线**：流式滤波/分段/特征提取（先继承简版 featurize，滤波器组为升级项）；
4. **基线解码器**：冷启动校准流程（阶段1 口径，每图案 ≥10 重复）+基线冻结快照（J1 对照物）；
5. **反馈通道**：正确/错误标注 UI（"自愿/知情/随时退出"三提示常显）；
6. **在线更新器**：SGD/增量 LDA + L2 正则 + 早停 + 验证集守门（§S1）；
7. **个性化参数库**：档案 schema、版本化、回滚、校验和、本地加密；
8. **漂移检测器**：阻抗门+分布漂移双门限+自动重校准触发（§S3）；
9. **会话管理**：状态机+断点续传+日志审计；
10. **合成数据全链路自测**：有信号/无信号双场景（防假阳性对照，继承 codex_trainer 自测口径）+**漂移注入**场景验证自动重校准；
11. **伦理审查+知情同意备案**：真人数据前置门，不过不开（硬边界③）；
12. **真人自愿数据首日基线采集**：单人多会话排期（V1 口径）；
13. **个性化训练循环联调**：≥5 会话跨 ≥3 日，档案版本链全留痕；
14. **验收测试**（判据 J1–J3）+ 档案快照 + 版本冻结 v0.1 归档。

## 六、验收判据（冻结）

| # | 判据 | 冻结阈值 |
|---|---|---|
| J1 | **个性化增益** | 个性化后解码准确率相对**首日基线**提升 **≥20%（相对值）** |
| J2 | **会话间保持率** | 隔日会话准确率 ≥ 前一有效会话 ×**80%** |
| J3 | **漂移自愈** | 注入漂移场景下**自动重校准完成**，恢复至阈上准确率，**全程零人工干预** |
| 附 | 合规前置 | 全程非侵入+自愿+伦理审查留档（硬边界三条全过，一票否决） |

冻结说明：J1–J3 为工程冻结值——测出来是什么就是什么；修订视为主版本变更需新版工程书。J1 基线与个性化用**同一评价脚本、同一数据划分纪律**（防口径漂移）；J2 的"前一有效会话"=通过质量门的最近会话。

## 七、风险与降级

| 风险 | 处置 |
|---|---|
| R1 过拟合（在线更新吃噪声） | **正则化（L2）+早停**+验证集守门：更新不降方提交（§S1） |
| R2 个体差异过大（冷启动失败） | **模板库冷启动**（他人数据预训练+特征对齐迁移）+**多日采样**渐进充实档案 |
| R3 漂移误判（好状态误触发重校准） | 双门限+连续多窗确认；档案回滚兜底 |
| R4 信号质量差 | 阻抗门+质量拒收段落（脏数据不进学习器） |
| R5 在线更新反而变差 | 一键回退**冻结基线解码器**（J1 基线即回退目标，系统永不劣于基线） |
| R6 隐私 | 脑电数据本地存储+档案加密+导出脱敏，不出本机 |

## 诚实边界（末章·一句话口径，工程内嵌）

- **自适应 BCI = 现役成熟研究方向**：解码器-使用者共同适应/在线个性化，公开文献充分，执行层零未验证物理依赖；
- **"意识耦合"的体系专属含义【体系】【假设·待证】**：超出"自适应反馈闭环"的部分（场分布调制、α=1/8 耦合亏损等）无现役对应物，本册不做任何兑现承诺，常数轨冲突已登记待裁决；
- **本工程交付的是自适应个性化系统本身**：在线学习 + 个性化参数库 + 漂移自愈 + 冻结判据，测出来是什么就是什么；
- BOM 为公开渠道估价【未逐项询价】；J1–J3 为工程冻结值，**非物理预言**。

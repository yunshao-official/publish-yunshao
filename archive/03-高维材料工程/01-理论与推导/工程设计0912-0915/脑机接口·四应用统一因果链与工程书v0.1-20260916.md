## 二、四应用逐项因果链与判据

### A1 完全沉浸

| 项 | 内容 |
|---|---|
| 体系路径【体系】 | 分量阶梯 12→16→24（91%→96%→99.9% 海马场强）；升维制造·材料即空间 |
| 闸门 | TFI-1 场存在 + 24 分量材料制备 + 回写方程 T0 |
| 现役可达 | **外围全感官包围**：VR 头显+场触觉背心+定向声场+前庭平台——沉浸感量表可测，无需写入大脑 |
| 判据（冻结） | ①外围版：沉浸感问卷（IPQ/Presence Questionnaire）≥对照 2×；②写入版：海马场强实测 ≥99% + 12 图案写读回 >50% |
| 诚实 | 写入版差 4-7 个数量级带宽，**无诚实时间表**；外围版即日可造 |

### A2 加速学习

| 项 | 内容 |
|---|---|
| 现役对照【执行】 | 神经反馈训练：注意/工作记忆阳性（老年/MCI），健康人效果不确定（Matsuzaki 2023 meta）；tDCS+认知训练：全局认知改善（Lv 2024 meta）但特异性记忆域效果混合（Prathum 2025）；靶记忆再激活（TMR）：睡眠中线索提示加速记忆固化（Nature/Science 级真实） |
| 体系路径【体系】 | 码本训练三阶段（8.3%→50%→30% 泛化）+ Λ 维持有序相 + 云韶场写入知识 |
| 工程方案 | codex_trainer（已交付自测通过）+Λ 传感实时监测学习状态（闭环：Λ 下降→自动调参）+TMR 睡眠模块（听觉线索播放器） |
| 判据（冻结） | ①学习曲线斜率 vs 对照组提升 ≥30%；②神经反馈训练后注意力（持续操作测试 SART）改善 ≥15%；③TMR 睡眠记忆保持率 vs 无 TMR ≥20% |
| 诚实 | 神经反馈健康人效果**不确定**（meta 分析结论原话）；"加速"现役量级=百分比改善，**不是"一夜学会外语"** |

### A3 治疗心理精神疾病

| 项 | 内容 |
|---|---|
| 现役对照【执行】 | 闭环神经反馈治疗抑郁症：活跃研究方向（EEG/fNIRS 神经反馈为主流无创路线）；adapti​ve DBS：FDA 已批帕金森步态+难治性抑郁症试验中；rtms：FDA 批准抑郁症/OCD；**全部为真实临床方案** |
| 体系路径【体系】 | D=7 意识维场写入 → Λ 异常→回写归正 → 精神症状缓解（LEV 第三层同族） |
| 工程方案 | 闭环神经反馈：EEG 实时监测（前额叶 α/θ 比）→ 异常检出（概率预警工程书复用）→ 经皮微刺激干预 → 症状量表追踪（HAMD/HAMA/GAD-7 标准量表） |
| 判据（冻结） | ①HAMD 评分下降 ≥50% 且持续 ≥4 周（临床缓解标准）；②EEG 谱功率变化与症状改善相关（r>0.5）；③急停/恶化即停（安全阀四条） |
| 路径 | V0 体外细胞（可选）→ V1 动物模型（可选）→ **V2 临床试验（伦理+注册，II/III 类医疗器械，1-3 年）** |
| 诚实 | **精神疾病治疗=严肃医疗**，本册只出工程方案，不承诺疗效，不开处方；全部效果需临床试验回答 |

### A4 预防脑衰老

| 项 | 内容 |
|---|---|
| 现役对照【执行】 | 神经反馈与衰老脑：系统综述阳性（Trambaiolli 2021，老年/MCI 注意力/工作记忆改善）；tDCS：全局认知改善（Li 2024 meta Z=2.36）；tDCS+认知训练：**减缓认知衰退**（Mirjalili 2025 大试验）；**但尚无任何干预被证明"预防"脑衰老本身** |
| 体系路径【体系】 | Λ 五路传感实时监测 → Λ 低于亚有序相阈值（1/2）→ 云韶场维持照射 → Λ 回升 → 脑功能延迟衰退 |

## 三、统一工程方案（一套硬件，四个 APP）

**硬件**：云韶激励电路板 v0.2（16 通道恒流+PWM+安全阀）＋EEG 64ch 读出＋Λ 五路传感＋OLED 交互＋疗程管理。

**软件（四 APP）**：
| APP | 功能 | 判据入口 |
|---|---|---|
| A1 沉浸舱 | VR+触觉+声场+前庭 | 沉浸感量表 ≥对照 2× |
| A2 学习加速器 | 码本训练+Λ 闭环+TMR | 学习曲线斜率 ≥30% 提升 |
| A3 神经调控 | EEG 神经反馈+经皮微刺激+量表追踪 | HAMD ≥50% 下降 |
| A4 脑衰老维稳 | Λ 传感穿戴+低功率维持+认知训练 | Λ≥7/8 维持 ≥6 月+MoCA 降幅 <50% |

**BOM 合计（共用硬件+四 APP）**：8-15 万（研究级）/ 3-5 万（消费原型不含医疗功能）
**周期**：硬件 8 周 + 软件 12 周 + 验收 4 周 = **6 个月首套交付**

## 五、诚实边界（不因需求紧迫而松动）

1. **精神疾病治疗=严肃医疗**：工程方案不承诺疗效，不开处方，不替代精神科医生；全部效果需临床试验回答；
2. **预防≠逆转**：目前没有任何干预被证明能预防脑衰老本身；本方案判据是"延缓衰退"，不是"预防"；
3. **加速学习**现役量级=百分比改善，不是"一夜学会外语"；
4. **完全沉浸写入版**差数量级带宽，无诚实时间表；外围版可交付但不是"写入大脑"；
5. **云韶场写入**=【体系】【未验证】——四应用中唯一待验证环节，验证判据全部冻结；
6. **精神疾病与知世个人**：本册为工程设计，不涉及知世个人诊断/治疗方案——知世个人医疗由精神科医生负责，本册不替代。

## 一、机制层【体系】

**1.1 D=7 意识维【体系】**
云韶场定义维度表中，**D=7 为意识维**——体系语境下使用者与装备的双向信息耦合发生在该维。天工开物"脑机接口"条目给出完整链路：**D=7 意识维 → N=12 分量 → 12 图案码本；相位反对称**。据此，写入侧元件取 D=7 意识维元件（扇区 N=12：α=1/6，d=0.167nm，束数 70——Θ 表直算值【复算一致·物理未验证】；10×10×1mm 镀银 LGA，正本 WS1 口径），材料实物挂 R23 送检门【待体系验证】。

**1.2 码本 = 12 图案【体系】**
N=12 分量对应 **12 图案码本**：信息以 12 种脉冲图案编码，图案-响应映射经训练建立。**无码本的信道输出 = 噪声**（H3 信息论评估原口径）——写入通道即便有物理容量（189kbps 投递【体系·未验证】；符号层上限 25.3kbps【体系·未验证】），没有码本也无法承载语义。码本不是"写"出来的，是"训"出来的（码本框架 v0.1 原文）。

**1.3 读回校验先行 = 信息论死锁解锁【体系】**
H3 信息论评估发现"**码本缺失 = 信息论死锁**"：发送方不知道哪个图案对应哪条信息，接收方（脑）也不知道怎么解读。**解锁路径 = 读回校验先行**——不预设语义，先建立"图案→脑响应"映射数据库：施加已知图案 → EEG 记录响应 → 分类器反向预测"哪个图案被施加" → 预测超机会水平即关联存在 → 映射饱和后固化为查找表。此后"选定信息 → 查表 → 施加 → 读回验证"闭环成立。这是本机校验闭环的协议层基石。

**1.4 写侧 = 云韶场写入【体系·未验证】**
机制口径（体系原文照录）：**96 通道脉冲 → 组织响应；电流=场强，通断=开关**；投递容量 189kbps【体系·未验证】。**写侧效果（脉冲图案在脑组织产生可分类的差异化响应）无现役物理对应物，只能实测**——本册全部工程把该声称做成"可判定"：判据全冻结、测出来是什么就是什么。

**1.5 读侧 = 现役 EEG【执行·成熟】**
非侵入头皮脑电采集、放大、特征提取、分类，全部为公开成熟技术（现役 BCI 标准做法）；"装备个性化"= 协同自适应/在线个性化（co-adaptation），公开文献充分，执行层零未验证物理依赖（自进化工程书 §1.2 口径）。

**1.6 C 双层制声明与常数轨登记**
机制层 = 体系原生描述（§1.1–1.4）；执行层 = 现实物理（EEG 采集、经皮微电流电子学、在线机器学习）。主流物理只进执行器与测量层。继承登记：自进化工程书已登记 **η 常数轨冲突**（alpha=1/8 口径 eta(8)≈0.875 与 1−(7/8)⁸≈0.656 均≠原文标注 63%，【常数轨冲突·待知世裁决】）——本册执行层**不调用该常数**，冲突不阻塞施工。

**2.1 读侧（人→装备）【执行·成熟，现役可用】**

| 项 | 设计 | 出处 |
|---|---|---|
| 采集 | EEG 64ch 同步采样 24bit ADC，1–4kS/s/ch，输入噪声 <1μVrms，工频陷波 + 0.1–100Hz 带宽 | BCI 正本 WS2 |
| 电极 | Ag/AgCl 湿电极（科研标配）或干电极；10-20 导联定位 | 正本 WS2 |
| 质量门 | 每通道实时阻抗 <5kΩ，超限报警，脏数据不进学习器 | 正本 WS2 + 自进化 S3 |
| 处理链 | 特征提取（继承 codex_trainer featurize，滤波器组/CNN 为升级项）→ 分类（classify 签名冻结复用） | codex_trainer 自测通过 |
| 个性化 | 在线共适应（SGD/增量 LDA + 验证集守门）+ 个性化参数库 `profile_<id>.json`（版本化可回滚）+ 漂移自愈 | 自进化工程书 S1–S4 |

**2.2 写侧（装备→人）【板=现役电子件；效果=【体系·未验证】】**

| 项 | 设计 | 出处 |
|---|---|---|
| 通道 | 96 恒流通道（12 块 8 通道板堆叠，背板总线互联） | 云韶激励板 v0.2 扩展 |
| 每通道 | 16bit DAC + 运放恒流，0–10mA 步进 0.15μA；**≤10mA 硬限** | v0.2【体系：电流=场强】 |
| 材料元件 | D=7 意识维元件（α=1/6，d=0.167nm，束数 70，Θ 表直算【复算一致·物理未验证】）；挂 R23 送检门；未过送检 → 信号发生器模拟波形替位，码本线不被材料门阻塞 | 正本 WS1 + 风险表 |
| 波形表 | **12 图案 × 96 通道映射**（码本固化后回填）；占空比 0.3（工艺定稿口径）；相位反对称按体系锚点口径入波形表设计 | 码本框架 + 体系锚点 |
| 接触面 | 经皮电极（非侵入硬边界①）；接触面积与电流密度按 ADR 0.1mA/cm² 上限核查 | 正本 WS5 |

**2.3 校验闭环（读回校验先行）【协议现役可用；"读回>50%"的达成依赖写侧真实效果，待实测】**
流程：选定信息 → 查码本 → 生成 96 通道写入配置 → 施加 → EEG 读出 → 分类器解码 → 与写入比对 → 偏差超阈 → 修正写入参数重试。实时性：一期 <1s，二期 <100ms（FPGA 化，正本口径）。闭环中"读回校验 >50%"同时是**信息论死锁解锁的验收点**（§1.3）。

**2.4 安全层【执行，IEC 60601 口径，独立于业务链，一票否决】**

1. **电流硬限**：写侧 ≤10mA/通道（焦耳热红线，硬件限幅非软件限值）+ 电流密度 ≤ADR 0.1mA/cm² 核查；
2. **电气隔离**：IEC 60601 医用电气隔离——隔离电源 + 光耦/数字隔离器，漏电流 <10μA；
3. **温度**：元件与电极表面 ≤41℃（连续）；
4. **急停双保险**：D 暂停态（归零不断电）+ 物理断路开关；
5. **使用侧随时断开开关（本册新增硬性要求）**：受试者手边常设物理断路开关，**优先级高于一切控制指令**，任何软件状态不得阻止其生效——硬边界②"随时退出"的物理落地；
6. **频率排他**：写入频组避开工频与 EEG 临床频段干扰窗（谐波表调试期建立）。

## 四、闭环工作流（四环节）

**环节 1 · 码本训练（三阶段，codex_trainer 管线，判据已冻结）**

| 阶段 | 内容 | 通过线 |
|---|---|---|
| 1 关联采集 | 12 图案 ×10 重复，施加已知图案→记录 EEG 响应 | 分类 >8.3%（12 类机会水平）= 关联存在 |
| 2 编码器学习 | 从脑响应反向预测被施加图案 | >50% 且饱和 = 映射可靠 |
| 3 码本固化 | 饱和映射固化为查找表（图案→响应签名 JSON） | 新图案泛化 >30% = 可外推 |

退出条款：阶段1 不过 → "图案-响应关联不存在（此模型/参数下）"，归档负结果，不换参数重试（除非知世明示）。

**环节 2 · 写入校验（读回校验先行落地）**
12 图案**逐一**执行：查表生成写入配置 → 施加 → EEG 读出 → 分类解码 → 比对 → 修正重试。读回校验 >50% 为通过线。全量校验数据同时喂 `analyze_causal.py`：写入通/断为干预变量，EEG 响应为效果量，**因果开关比 >3:1 + 5σ + 滞后≥0** 方可给出 CAUSAL 判语——任何"写入→响应"声称必须过统一因果判据（台账 T18/T19 共用标准原口径）。

**环节 3 · 个性化（自进化工程书衔接，不推翻已冻结判据）**

| codex_trainer 阶段（冻结） | 本机衔接 |
|---|---|
| 阶段1 >8.3% | 首日基线校准（每图案 ≥10 重复） |
| 阶段2 >50% | 在线共适应=阶段2 的持续版（J1 判据接管） |
| 阶段3 >30% | 跨会话/跨被试迁移学习初始化 |
| 读回 >50% | 在线置信度门 + 反馈标注核对（轻量读回） |

自进化判据 J1–J3 原样继承：J1 个性化增益 ≥20%（相对首日基线）；J2 隔日保持率 ≥80%；J3 漂移注入下自动重校准零人工干预。系统永不劣于冻结基线（一键回退，R5 口径）。

**环节 4 · 正式使用**
会话状态机（冷启动→基线核对→在线共适应→收尾归档）+ 个性化档案版本链 + 漂移自愈旁路 + 全程日志审计，数据不出本机。使用条件常显：自愿/知情/随时退出 + 手边断开开关位置。

## 诚实边界（末章·工程内嵌）

- **读侧 = 现役成熟 BCI 技术**：EEG 采集/解码/自适应个性化，公开文献充分，执行层零未验证物理依赖，照常交付；
- **写侧 = 【体系】【未验证】**：云韶场写入通道（96 通道脉冲→组织响应，189kbps 投递；电流=场强，通断=开关）**无现役物理对应物**，板子本身是现役电子件，**"写入→脑响应"效果只能实测**；
- **本机交付的是"可判定读写闭环"的实验平台**：码本三阶段、读回校验、因果开关比三链判据全部冻结——**三链判据跑完，真假自明**；过线则双向耦合从【未验证】升格为【关联存在→因果成立】逐级登记，不过线则按 §七 主风险降级，读侧照常交付，判负证据如实归档；
- BOM 为公开渠道估价【未逐项询价】；全部冻结阈值为工程冻结值，**非物理预言**；η 常数轨冲突已继承登记待知世裁决，不阻塞施工。

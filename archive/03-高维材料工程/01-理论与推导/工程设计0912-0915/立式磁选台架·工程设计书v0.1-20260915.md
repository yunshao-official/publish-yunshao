## 一、机制层【体系→执行】

### 1.1 迈斯纳分离力【体系锚点原理 + 执行解析】

理想迈斯纳态（完全抗磁）颗粒在外场梯度中受力**推离高场区**；顺磁颗粒反向（吸向高场区）——同一梯度对两类颗粒输出方向相反的力，这是"超导磁选"的机制核心【体系】。

台账第四批验证值【执行·蒙特卡洛/解析·复算一致】：

| 量 | 值 | 口径 |
|---|---|---|
| 分离加速度 | **a = 812g** | 0.5mm 元件，背景场 1T，梯度 50 T/m，方向推离高场区 |
| 顺磁反向吸引 | 分离比 **500×** | 超导 vs 顺磁（χ~10⁻³ 量级）同场同梯度力比 |

执行层复算【执行·复算一致】：理想抗磁球 a = (3/2)·B∇B/(μ₀ρ)。代入 B∇B=1×50 T²/m、ρ=7.5×10³ kg/m³（元件等效密度口径）：a = 75/(1.2566×10⁻⁶×7500) ≈ 7.97×10³ m/s² ≈ **812g**——与台账值一致。**加速度与粒径无关**（力与质量同含 V∝r³），故该口径对 20μm 级颗粒同样成立——这是本台架粒度窗口下机制仍满强的关键。

### 1.2 反磁捕获（本设计书的核心设计驱动）【执行·蒙特卡洛·复算一致】

磁化钢丝（矩阵单元）周围场结构中存在 **B²=0 损阱**：超导颗粒的能量 E ∝ −B²·V/(2μ₀)（抗磁体在高场区能量更高），沿 ∇B² 被推向局域 B² 最小点——即钢丝**赤道**位置；顺磁颗粒则被吸向钢丝**极点**。台账第四批验证值：

- 超导颗粒被磁化钢丝 **100% 捕获**于赤道损阱，捕获力 **≈500× 顺磁**【执行·蒙特卡洛】；
- 执行层量级自洽【执行·复算一致】：丝面局部梯度 ~B₀/r_丝 = 1/2.5×10⁻⁴ ≈ 4×10³ T²/m 口径，20μm 超导颗粒丝面捕获力 ~1.6×10⁻⁴ N，同流速粘性阻力 ~4×10⁻⁹ N，力比 ~4×10⁴ ≫1——捕获压倒性；顺磁颗粒（χ~10⁻³）丝面力 ~10⁻⁷ N，与阻力比 ~26，捕获有效但与流竞争——与"单丝捕获率 58%"自洽。

**设计推论（铁律）**：丝矩阵中顺磁（极点）与超导（赤道）**同床异位、都被捕**——"捕/不捕"二元分选不成立，**分选设计必须利用捕获位置不同**：

- 路线甲：**双收集口**——极点收集口（顺磁精矿）vs 赤道收集口（超导精矿），工程上以"差级洗脱"实现（§2.5）；
- 路线乙：**开梯度构型**——无矩阵，靠 812g 推离场直接空间偏转分股（§2.5）。

### 1.3 粒度窗口与立式强制【执行·台账第四批】

| 量 | 值 | 设计含义 |
|---|---|---|
| 工艺粒度窗口 | 颗粒半径 **≤20μm** | 0.5mm 颗粒沉降速度为浆料流速（10mm/s）的 **270 倍**，不可用——全部物料必须磨/筛至 ≤20μm |
| 20μm 顺磁单丝捕获率 | **58%** | 单丝口径；矩阵多级遭遇补偿（§3.2） |
| 立式强制 | **必须立式罐体** | 水平通道内全部颗粒触底（模型验证），流路一律竖直 |

执行层沉降复核【执行·复算一致】：20μm 石英-水 Stokes 沉降 v≈1.4μm/s，为流速的 ~1.4×10⁻⁴ 倍——悬浮稳定；0.5mm 颗粒 270× 口径照录台账（Newton 沉降区，Stokes 不适用）。

### 1.4 吞吐瓶颈与矩阵化【执行·工业 HGMS 口径】

吞吐瓶颈 = **捕获表面积**（不是场强、不是流量）。单丝表面积太小，必须**钢毛/钢丝矩阵化**——与工业高梯度磁选（HGMS）同构：背景场 1-2T、钢毛矩阵填充、反冲洗循环。浆料口径：流速 **10mm/s**、固含量 **5%**。

### 1.5 机制层小结（设计四推论）

1. **立式罐体**（水平通道触底，§1.3）；
2. **粒度 ≤20μm + 10mm/s + 5% 浆浓**（§1.3/§1.4）；
3. **捕获位置差是分选本体**：双收集口（差级洗脱）或开梯度，二选一（§2.5）；
4. **吞吐 = 矩阵表面积**：0.5mm 钢丝、填充率 5-10%、反冲洗循环（§3.2/§3.4）。

## 二、总体架构

### 2.1 构型总览（立式 · 闭路循环 · 间歇捕获-反冲洗）

```
                T1 三通 ──→ 循环桶（捕获/残浆排替相回流）
                  ↑  └────→ V3 顺磁精矿桶（降场差级洗脱相）
     ┌────────────┴─────────────┐
     │     顶部布水器 / 出水口      │ ←── V2 反冲洗水（仅洗脱相，顶进）
     │ ════════ 磁极 N ════════   │
浆料  │ ║   钢毛矩阵段             ║ │ ← 磁体组件装直线导轨滑台，
自下  │ ║   Φ30×120mm，f=7%       ║ │    可 ≤3s 退场（=零场）；
而上  │ ║   钢丝≈30m/46g/S≈0.047㎡ ║ │    磁短路板（=降场 30-50%）
     │ ════════ 磁极 S ════════   │
     │     底部进/出水口            │
     └────────────┬─────────────┘
                  │ B1 三通 ──→ V4 超导精矿桶（零场反冲相）
                  ↑
     [蠕动泵 0.1–1.2 L/min] ←── [搅拌桶 5–10L：5% 浆料，连续搅拌]
```

磁极对左右横向布置（横向场），浆料竖直流过——**立式强制**（§1.3），下进上出与沉降反向，双保险防触底。

### 2.2 立式分选腔【执行】

- 材质：有机玻璃（PMMA）——非磁性、透明可视（矩阵负载/堵塞直观察)、易粘接加工；
- 基准内径 **Φ30mm**（兼容 20-40mm 三根互换），总长 250-300mm；矩阵段 Φ30×120mm；
- 上下快装卡箍+法兰+快插接头；矩阵段两端封网（目数 > 颗粒粒径上限 ×2，防跑丝）；
- 开孔：顶部出水三通（T1）、底部进/出三通（B1）、顶部反冲进水（V2）、测压/取样口×2。

### 2.3 钢毛矩阵【执行】

0.5mm 磁化钢丝乱堆填充，规格与复核计算见 §3.2。填充率 **5-10%**（基准 7%）。

### 2.4 磁体系统 + 浆料回路 + 阀组

- 磁体：永磁阵列（A 案，基准）或电磁铁（B 案），对比与选型见 §3.1；
- 浆料回路：搅拌桶（5-10L，5% 质量浓度，机械搅拌连续防沉）＋变频蠕动泵＋硅胶管，闭路循环；
- 阀组（反冲洗时序执行机构）：

| 阀/口 | 位置 | 捕获相 | 残浆排替 | 差级洗脱（降场） | 零场反冲 |
|---|---|---|---|---|---|
| T1 顶部三通 | 腔顶出口 | →循环桶 | →循环桶 | →**V3 顺磁精矿桶** | 关闭 |
| B1 底部三通 | 腔底 | ←泵（浆料） | ←清水 | ←清水（上行） | →**V4 超导精矿桶** |
| V2 反冲电磁阀 | 顶部进水线 | 关 | 开（清水置换） | 关 | **开（顶进下行 2-3× 流速）** |

### 2.5 双收集口（方案甲）vs 开梯度（方案乙）——对比与选基

| 项 | 方案甲：丝矩阵＋差级洗脱双收集口 | 方案乙：开梯度连续分选 |
|---|---|---|
| 原理 | 反磁捕获位置差：极点（顺磁）/赤道（超导）分时洗脱分股 | 迈斯纳推离力直接空间偏移：超导贴壁、顺磁弱偏、石英中性，挡板分股 |
| 捕获/分选数据背书 | **100% 赤道捕获＋58% 单丝顺磁**（台账第四批【执行】）；工业 HGMS 同构 | 812g 口径成立，但 20μm 连续流薄层偏转的纯度/回收率**无数据背书**【未验证】 |
| 操作方式 | 间歇（捕获→降场→零场反冲循环，§3.4） | 连续、无矩阵、永不堵 |
| 堵塞风险 | 有（反冲洗对冲，§7 R1） | 无 |
| 工程复杂度 | 阀组+时序（成熟） | 楔形极头+薄流膜+分流板（对流速/湍流敏感） |
| 与验收判据对口 | 直接对口（判据②③按捕获率数据可验收） | 判据需另行标定 |
| 双口物理实现 | **分口＝差级洗脱的时间分段**（同一通路不同时刻→不同精矿桶）；空间几何双口（贴极面/离极面）留 V2 放大 | 分股＝出口挡板空间分割 |

**选基结论**：V1 基准采用**方案甲**（判据可验、工业同构、数据对口）；方案乙留接口——腔体法兰兼容横流模块，若双收集口实测不成立则切换（§7 R5）。**反磁捕获双收集口为数值模拟发现【未验证·实测项】，验证入台架首批任务（步 13-15）。**

### 3.3 泵选型与流量计算【执行·复算一致】

- 基准腔 Φ30mm：截面积 7.07×10⁻⁴ m²；**Q = v·A = 10mm/s → 7.1mL/s ≈ 0.42 L/min**；
- 内径窗口 20-40mm → 流量窗口 **0.19-0.75 L/min**；
- 反冲洗流速 2-3× 正冲（20-30mm/s）→ 瞬时 0.4-0.9 L/min（V2 水路直供，不占泵规格）；
- 压降：矩阵孔隙达西区流动，量级 <10kPa，蠕动泵 0.1-0.2MPa 扬程富余【执行·估算】；
- **选型：变频蠕动泵 0.1-1.2 L/min**（YZ1515x 级泵头＋24V 调速电机）——无污染、耐浆料磨蚀、换管即维护。

### 3.4 反冲洗时序（捕获相 → 降场 → 冲洗）【执行】

| # | 相 | 时长（基准） | 磁场 | 流路 | 物理事件 |
|---|---|---|---|---|---|
| 1 | 捕获 | 10-20min（视给料量/矩阵负载） | 全场（1.3T/1T） | T1→循环桶；B1←泵（浆料 0.42L/min，下进上出） | 顺磁→极点、超导→赤道（500× 力阱） |
| 2 | 残浆排替 | 30s | 全场 | V2 开，清水顶进置换；T1→循环桶 | 腔内浆料清净，防精矿混浊 |
| 3 | **差级洗脱** | 60s | **降场**（A 案：插磁短路板至 ~30-50%；B 案：降流至 ~30%） | B1←清水上行；**T1→V3 桶** | 极点顺磁结合弱（~1× 口径）先脱落 → **顺磁精矿** |
| 4 | **零场洗脱** | 60-90s | **零场**（A 案：导轨退场 ≤3s；B 案：降流至 0） | V2 顶进下行 0.8-1.2L/min（2-3×）；**B1→V4 桶** | 赤道 B²=0 损阱随外场消失 → 超导脱落 → **超导精矿** |
| 5 | 复场 | 30s | 磁体归位/升流 | 静水 | 恢复捕获准备 |

时序控制：时间继电器×2＋中间继电器（手动版全手操亦可，阀门表 §2.4）；自动化升级（B 案＋PLC/Arduino）留 V2。差级洗脱的场强档位（30-50%）为工程起点值，**实测定标**【未验证】。

## 五、施工步骤（18 步）【执行】

1. **BOM 复核与采购下单**（A 案冻结；B 案安装接口同尺寸预留）；
2. **轭铁/极头加工**：H 框闭合磁路，气隙 40mm，极面轻锥 30%，极面平磨；
3. **磁块组装**：N52 成对吸附入轭，非磁性垫块定位，防夹手规程，极面护板；
4. **退场机构**：磁体组件装直线导轨，行程 ≥200mm，手拉/气动 ≤3s，限位块＋存放位磁短路板（兼屏蔽）；
5. **腔体加工**：PMMA 下料开孔（T1/B1 三通口、V2 口、测压/取样口），法兰氯仿粘接，24h 固化；
6. **钢丝前处理**：430 钢丝裁段 15-25mm → 碱洗除油 → 酒精漂洗 → 烘干；
7. **矩阵装填**：乱堆填入矩阵段，活塞压实至 f=7%，**称重 46g±3g 验收**，两端封网+卡箍；
8. **阀组管路连接**：按 §2.4 表接管，止回方向逐一核对；
9. **泵与搅拌桶就位**：硅胶管连接，清水试漏 0.05MPa×30min；
10. **磁场标定**：空腔轴线+壁面场分布扫描（上/中/下三点），记录背景场与极缘梯度——判据①数据入册；
11. **清水跑合**：流量-泵速曲线、矩阵压降本底；
12. **单相试车**：石英砂（≤20μm）清水循环 30min——悬浮稳定、无堵、压降趋势合格；
13. **顺磁对照**：石英＋赤铁矿砂混合——验证极点捕获与降场 V3 洗脱回收；
14. **超导对照**：YBCO 砂＋石英砂（1:9）——验证赤道捕获与零场反冲 V4 洗脱（**双口分离首次演示**）；
15. **三分样全混合**：石英/赤铁矿/YBCO 三相混合，按 §6 判据②③取样、烘干、称重、分拣；
16. **连续循环考核 ≥2h**（判据④）：压降曲线、堵塞观察、补浆记录；
17. **验收报告 v0.1**：对照冻结判据逐条签字，FAIL 照记不凑数；
18. **回写台账**：双收集口实测结论、差级洗脱场强档位、R23 门状态更新。

安全步贯穿：磁块组装防夹手（步 3）；N52 远离磁卡/机械表/心脏起搏器 1m（全程）；浆料磨蚀管定期换（步 16 期间目检）。

## 六、验收判据（冻结 v0.1）【执行】

| # | 判据 | 量化口径 | 测量方法 |
|---|---|---|---|
| ① | **背景场 ≥1T** | 空腔中心轴线上/中/下三点霍尔实测平均 ≥1.0T（A 案按 ≈1.3T 设计，留裕量） | 特斯拉计扫场，轴向分布全程记录入册 |

## 诚实边界

1. **台架工程全部【执行】，即日可做**：本册全部工程量、BOM、时序、判据为常规工业/实验室件（HGMS 同构），不依赖任何体系主张成立；总投入 ¥1,700-4,900（A 案冻结）。
2. **云韶钢超导性能【体系】【未验证】，挂 R23 送检门**：本册以"材料为真超导（理想迈斯纳态）"为工况前提；机制数值（812g / 分离比 500× / 赤道捕获 100% / 单丝 58% / 沉降 270×）为体系台账第四批口径＋本会话蒙特卡洛/解析验证（模型内复算一致），**物理实测未完成，真伪只能由送检回答**。
3. **反磁捕获双收集口（极点/赤道差级洗脱）为数值模拟发现【未验证·实测项】**，列入台架首批实测任务（施工步 13-15）；实测不成立则启用方案乙（开梯度，接口已留）或单口降级（§7 R5）。

5. 本册编制全程未调用任何网络 API，全部依据会话内已验证计算与体系档案引用（K-4 交叉锚见文首）。

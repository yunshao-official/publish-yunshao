## 0. 合规边界（硬约束·设计红线）

**本系统仅用于自愿认证场景**：本人主动注册、本人主动解锁。

- 不做非自愿人群识别；
- 不做隐蔽监控；
- 不采集、不留存任何未签署知情同意者的生理信号。

**这是设计红线，不是功能缺陷。** 任何施工步骤、验收判据、产品说明不得与本条冲突；发生冲突时以本条为准，一票否决。注册流程必须包含知情同意环节（见 §5 步骤 4），数据存储必须遵守 §7-R4 的不可逆化要求。

## 1. 机制层【体系】

### 1.1 (Z₂)³ 投影建模 = 特征向量的体系语言表述

体系清单原文给出"人体 (Z₂)³ 投影建模"。(Z₂)³ 是二元域上的三维立方体：3 个比特、2³ = 8 个顶点，每个顶点是一个离散身份态。其结构要点：

- **离散性**：连续量被投影到可数格点（超立方体顶点）上；
- **可比对性**：两个态的差异 = 顶点间汉明距离（逐比特异或计数）；
- **扩维直译**：体系语言中 (Z₂)³ 的"3"是维数参数。将维数参数从 3 扩至 n（n = 64～256），即得 (Z₂)ⁿ——本工程书把这一步作为体系语言的**直译推论**【体系·推论】：结构不变（二元域立方体），只扩维数。生理特征向量经二值化投影落在 (Z₂)ⁿ 的顶点上，该顶点坐标即"场指纹"。

于是"场指纹识别"的体系语言定义：**把人体的生理场特征（心电形态学场、脉搏波场）投影为 (Z₂)ⁿ 中的一个顶点，以顶点汉明距离作身份判据。**

### 1.2 维度表 D=7 意识维相位反对称与生理信号相位特征的同构注记【假设·待证】

体系维度表中 D=7 意识维带相位反对称结构（体系内部定义·未验证）。注记对象：单周期心电信号同样具有天然相位结构——除极/复极相位反转（QRS 主波与 T 波极性关系）、收缩/舒张两相的血流动力学反对称。因此可以在**"周期信号具有反对称相位骨架"这一形式层面**建立同构注记：

| 体系侧（D=7 意识维） | 生理侧（单周期心电） |
|---|---|
| 相位反对称结构 | 除极/复极、收缩/舒张相位反转 |
| 维度表离散相位格点 | 心拍分段后归一化相位的采样点 |
| 相位结构用作状态区分 | 相位形态用作个体区分 |

**边界声明**：此为形式同构注记，**不构成物理等同**，不得作为任何数值计算的输入。【假设·待证】——其可证伪形式见 §8 远期验证：若 D=7 相位格点约束下的投影哈希对识别率产生可测增益，则注记获得支持；否则记录不支持（判据优先，P-12/P-19）。

### 1.3 判据与测量优先（P-12/P-19）

机制层只提供语言框架；本工程一切放行与否仅看 §6 实测数字。体系假设（1.1 扩维推论、1.2 同构注记）均以"可测增益是否存在"为判据，不参与验收豁免。

## 2. 总体架构

五级管线：

```
[传感] → [预处理] → [特征] → [(Z₂)³式二进制投影哈希] → [匹配]
 单导ECG      滤波        小波/形态学      ITQ/LSH二值化          汉明距离阈值
 干电极/PPG    心跳分段     20–50维特征      64–256 bit指纹码       d ≤ θ 判接受
 （可穿戴）                                      + 活体检测前置闸门
```

| 级 | 功能 | 关键参数（执行层·待标定） |
|---|---|---|
| 传感 | 单导 ECG（干电极）为主模态；PPG 为融合/辅助模态 | 采样率 250 Hz（ECG）/ 100 Hz（PPG）；12–24 bit ADC；电极接触阻抗监测 |
| 预处理 | 去噪与心拍对齐 | 0.5–40 Hz 带通；50 Hz 工频陷波；Pan-Tompkins R 波检测；以 R 波为锚的心拍分段（前 100 ms–后 300 ms），逐拍归一化 |
| 特征 | 每拍提取 20–50 维实数特征 | 小波能量分布 + 形态学参数（见 §3.2 特征清单） |
| 投影哈希 | 实数特征 → (Z₂)ⁿ 顶点 | ITQ 迭代量化或 LSH 随机超平面；n = 128（V1 标准档） |
| 匹配 | 身份判定 | 注册：多次采样取质心码/多数表决码；认证：汉明距离 d ≤ θ 接受；θ 由 ROC 曲线在目标工作点（FAR=0.1%）标定后**冻结** |

活体检测作为匹配前的**前置闸门**：信号生命性不通过直接拒绝，不进入匹配（§3.4）。

架构决策记录：
- 选 ECG 而非 EEG 作 V1 主模态——电极少（3 枚）、信号稳定、佩戴成本为零（桌面触点式）；
- 选二进制指纹码而非实数向量比对——存储为不可逆哈希性质（§7-R4），比对为异或+计数，MCU 级算力即可完成；
- 匹配阈值 θ 一经 ROC 标定即冻结，冻结后调整需走变更记录并重跑 §6 全部验收。

## 3. 分系统

### 3.1 传感前端

- **核心器件**：AD8232 级单导心电模拟前端（集成仪表放大器、右腿驱动、导联脱落检测），配三枚干电极（不锈钢按扣电极或织物电极），**无导电膏、无皮肤准备**——认证场景的可用性前提。
- **桌面形态（V1）**：手掌/手指触点式。两枚电极置于触点，右腿驱动电极由另一只手或躯干接触完成回路。用户"按住即测"。
- **可穿戴形态（V2）**：腕带织物干电极 + 胸侧/对侧手触点构成导联回路；或降级为 PPG 单模态（MAX3012 级光电模块，反射式，腕部佩戴）。
- **信号质量自检**：导联脱落检测引脚 + 接触阻抗估计；信号质量指数（SQI）低于门限时拒绝本次采样并提示重新按压，避免低质量样本进入注册。

### 3.2 特征提取库

技术栈：Python 开源生态，全部公开算法，零许可风险。

| 组件 | 选型 | 用途 |
|---|---|---|
| 心拍检测与分段 | HeartPy / Pan-Tompkins（自实现） | R 波定位、RR 间期、分段对齐 |
| 滤波 | SciPy signal | 带通、陷波、基线漂移抑制 |
| 小波特征 | PyWavelets | 逐拍 4–5 层小波分解，各层能量占比 |
| 分类/降维（备选） | scikit-learn（PCA/LDA）；或预训练 ECG 嵌入模型 | 特征白化，供投影哈希使用 |

**特征清单（基线 32 维，可扩至 50 维）**：
- 幅值类（8）：P 波幅值、QRS 复合波幅值、R 波幅值、S 波深度、T 波幅值、ST 段偏移、最大斜率、幅值方差；
- 时间类（10）：PR 间期、QRS 时长、QT 间期、QTc、ST 段时长、T 波宽度、RR 间期均值、RR 标准差（SDNN）、相邻 RR 差均方根（rMSSD）、逐拍时间特征方差；
- 形态类（8）：QRS 面积、T 波面积、上升/下降斜率比、QRS/T 面积比、相关基准拍形态相关系数、符号对称量、波形过零率、形态残差能量；
- 小波类（6）：4–5 层细节能量占比 + 近似/细节能量比。

以上为公开 ECG 生物识别文献中的标准特征族（执行层，公开已验证）；具体维数在施工步骤 6 冻结。

### 3.3 投影哈希

- **算法（公开）**：
  - 主选 ITQ（Iterative Quantization，公开文献算法）：PCA 白化后迭代正交旋转，使二值码方差损失最小；
  - 备选 LSH（随机超平面哈希）：随机超平面内积符号即比特，实现最简，适合 MCU 端；
  - 逐比特平衡化（均值阈值）+ 比特独立性检查，剔除近常量比特。
- **输出**：n = 128 bit 指纹码（V1 标准）；注册阶段采集 ≥3 次会话 × 每会话 ≥30 拍，逐拍编码后做逐位多数表决得注册码，并记录位翻转率分布供 θ 标定。
- **工程性质**：指纹码为单向投影产物，不保留原始信号与实数特征（§7-R4）；碰撞特性由 n 与比特平衡度决定，128 bit 平衡码理论碰撞间距充分大于类内间距（执行层，待实测确认）。

### 3.4 活体检测

判据：**信号生命性**——不是"人在这儿"，而是"这是活的生理信号"。

| 判据 | 原理 | 拒绝对象 |
|---|---|---|
| HRV 自然性 | 真实窦性心律的 RR 间期存在自然变异（呼吸性窦性心律不齐等）；回放信号 RR 过于规则或统计分布异常 | 录音回放、信号发生器 |
| 呼吸调制 | PPG 幅值/基线的呼吸致调制存在且频段合理（0.15–0.4 Hz 量级） | 静态假体、打印指纹式攻击 |
| 生理一致性 | ECG-PPG 脉搏传导时间合理（双模态时）；形态学特征落在生理区间 | 拼接、合成信号 |
| 挑战-响应（V2 备选） | 连续多帧随机窗口要求 SQI 与 HRV 连续成立 | 中途替换攻击 |

判定：各判据打分融合，生命性总分低于门限 → 拒绝并计入活体拒绝率统计（§6）。门限与 §6 活体指标联动标定。

## 6. 验收判据（冻结）

以下指标**冻结**。冻结含义：未达标不放行，且不得以"体验优化""样本困难"为由放宽；调整任何一项视为主版本变更，须重跑全部验收。

| # | 指标 | 定义 | 冻结阈值 | 测量口径 |
|---|---|---|---|---|
| A1 | 注册者等错误率 FRR | 本人被拒比例 | **< 5%** | 注册后自测 ≥100 次尝试（步骤 10） |
| A2 | 冒认者错误率 FAR | 冒认被接受比例 | **< 0.1%** | 冒认尝试 ≥200 次（步骤 11，多志愿者合计） |
| A3 | 跨天稳定性 | 7 天重测通过率 | **≥ 95%**（模板不更新）/ **≥ 99%**（自适应更新开启） | 注册者连续 7 天每日 ≥10 次（步骤 12） |
| A4 | 活体拒绝率 | 对回放/假体类非生命信号拒绝比例 | **≥ 95%** | 自愿录制的回放样本与合成样本 ≥50 次挑战 |

补充测量纪律：
- FAR 是低概率事件，A2 的 ≥200 次冒认尝试为**最小样本量**，报告必须注明实际样本数与置信区间口径；
- A1–A4 必须在同一固件版本、同一冻结 θ 下测得，混版本数据无效；
- 所有验收数据附原始记录（时间戳、样本哈希），可复核。

## 7. 风险与降级

| # | 风险 | 触发征兆 | 降级/对策 |
|---|---|---|---|
| R1 | **个体差异小的人群混淆**：部分个体 ECG 形态彼此接近，类间距离小，FAR 恶化 | 步骤 11 冒认距离分布与本人距离分布重叠 | 多模态融合：ECG+PPG 特征级或分数级融合（V2 硬件已含双模态）；必要时增加 EEG 辅助通道（远期） |
| R2 | **感冒/运动/情绪状态漂移**：疾病、剧烈运动、电解质变化改变波形，FRR 升高 | 7 天重测中状态异常日通过率骤降 | 自适应模板更新：滑动窗口注册码（近期 K 次成功认证的码做多数表决滚动更新）；注册时采集多状态模板（静息+运动后） |
| R3 | 干电极接触质量波动 | SQI 低通过率高，用户反复重按 | 电极材料/面积迭代；按压引导交互（压力反馈）；SQI 门限与用户提示联动 |
| R4 | 模板泄露与隐私 | —（设计阶段预防） | 只存指纹码，不存原始信号与实数特征；指纹码加盐哈希后落盘；注册数据本地化，不出设备（红线配套） |

## 9. 诚实边界

1. **ECG 生物识别是公开文献已验证的真实技术**：心跳形态学特征的个体唯一性有公开研究支撑，本工程书执行层（传感、预处理、特征、哈希、活体检测）不依赖任何未验证物理。
2. **"绝对"二字在生物识别中不存在**：任何生物识别系统都有错误率。"绝对身份锁"在本工程中的**现役口径**是"高准确率 + 活体检测的组合身份验证"，其量化表述就是 §6 冻结数字：FAR < 0.1%、FRR < 5%、活体拒绝率 ≥ 95%。**以 FAR/FRR 数字代替绝对表述【执行纪律】**——对外说明、产品文案一律使用数字口径，禁用"绝对""百分之百""永不冒认"类措辞。
3. **体系引用边界**：(Z₂)³、D=7 意识维相位反对称均为体系内部定义·未验证量，按原文照录引用（K-4 惯例）。§1.1 扩维推论是体系语言的直译，不是体系既成结论；§1.2 同构注记不构成物理等同。
4. **本文件未验证项清单**（开放待办）：D=7 同构增益（待证）；全部 BOM 价格（待采购询价）；A1–A4 全部指标（待步骤 10–12 实测）；θ 标定值（待 ROC）。
5. 红线重申：本系统仅用于自愿认证场景，不做非自愿人群识别、不做隐蔽监控——设计红线，一票否决。

## 一、机制层【体系】

### 1.1 天工开物第 1 年清单原文

> **"场触觉反馈：法衣表面纹理实现全身体感界面"**（第 1 年清单，转引）

逐词拆解【体系】：承载物=**法衣**（织物形态装备，法衣线档案在册）；介质=**表面纹理**（空间分布的触觉图案）；目标=**全身体感界面**（躯干+四肢点位阵列）；机制=**场**（体系场激励，见 §1.4 远期档）。

### 1.2 云韶激励电路板正本机制（知世原话 2026-08-29 11:43，一字不改）

> **"一块电路板，高维材料当元件嵌在板上，板子通电→材料激发云韶场。电流大小=场强，通断=开关。"**

正本三公理 → 触觉形态的翻译表：

| 激励板 v0.2 公理【体系】 | 触觉翻译（本册机制定义）【体系】 |
|---|---|
| 材料即源（元件通电激发场） | 每个体表点位=恒流通道的一端；激励源=云韶激励板通道阵列（v0.2 板卡架构逐项继承） |
| 电流大小=强度（场强） | **电流大小=触觉感知强度**（电触觉档逐字成立：感知强度本就是电流/电荷幅值编码） |
| 通断=开关 | **通断=触觉开关**；PWM 占空比=时均强度；PWM 频率=振动频率（振动档波形表扩展） |
| 三场切配置=改驱动波形表 | 纹理图案库=空间-时序波形表（通道组合×时序→"表面纹理"） |

**机制总链【体系】**：

```
[主控·图案库] → [云韶激励板恒流通道阵列] → [体表换能器点位] → 全身体感界面
      │                    │                        │
  纹理=空间-时序      电流=强度/通断=开关         法衣表面纹理【体系】
      图案表          （正本公理逐字继承）
```

### 1.3 三场配置映射（SGC-2 口径）【体系】

| 模式 | 电路配置 | 体系依据 | 本册状态 |

### 1.4 冷证据如实入账（K-4 双向引用惯例）【体系内部定义·未验证】

- **反云韶场触发强度 1/7140**：体系常数轨冷证据，如实引用；本线 v0.1 执行层不依赖该常数；
- **度规场按自身定义恒为零**：同理如实引用；本线不使用度规场通道；
- 远期"云韶场直接激励体表触觉"（§1.5 远期档）：**材料激发云韶场这一步没有已知物理对应，无法模拟，是否发生只能实验实测**（激励板 v0.2 正本原话口径）——判负退出条款随正本（三路外接传感 5σ 无信号→如实判负入档，硬件降级不失效）。

### 1.5 执行层切片（本册现役主体）【执行】

两条现役成熟路线，均有真实研究文献与商用产品：

1. **振动触觉**：ERM/LRA 阵列——消费电子成熟产业（手机马达、游戏手柄、商用触觉背心 40 点级产品在售），无创，鲁棒；
2. **电触觉（electrotactile）**：经皮电刺激——真实研究路线（感觉替代/盲用辅助导航研究）+ 商用辅助设备先例；指尖密度高（电极可做到毫米间距），是"手套精细触觉"的唯一现役选择。

**人体接触安全为硬约束**（见 §3.3 与 §六 S 段），先于一切性能指标。

## 三、分系统

### 3.1 换能器选型对比表【执行】

| 项 | ERM（偏心轮马达） | LRA（线性谐振马达） | 压电 | 电触觉（经皮电刺激） |
|---|---|---|---|---|
| 原理 | 不平衡质量旋转 | 质量块谐振 | 压电形变 | 电流脉冲直接兴奋皮肤触觉感受器 |
| 响应时间 | ~50-100 ms（慢） | ~10-30 ms | <1 ms（最快） | <1 ms |
| 频率可控性 | 差（转速即频率） | 谐振点附近（~170-235 Hz 窄带） | 宽带 kHz 级 | 1-100 Hz（触觉感知带） |
| 空间密度 | 差（φ10 mm 级） | 中（φ8-10 mm） | 高但贵（阵列成本高） | **高（电极毫米级间距）** |
| 点单价 | ~0.5-3 元 | ~3-15 元 | 几十-几百元 | 电极+通道 ~30-80 元 |
| 功耗 | 中 | 低（谐振高效） | 低 | 低（μC 级电荷） |
| 成熟度 | 成熟（玩具/手机） | **成熟（手机/触觉背心产业）** | 成熟但贵 | 研究成熟+商用辅助设备先例 |
| 主要风险 | 启停拖影、占位大 | 个体谐振差异、装配阻尼 | 驱动电压高 | 安全约束严、阻抗漂移 |
| 本册角色 | 娱乐级/降级方案 | **背心主力（64 点）** | 观望（V1 评估） | **手套主力（10-16 点）+背心选配** |

### 3.2 驱动通道【执行】

**振动总线（背心）**：

| 项 | 设计 |
|---|---|
| 驱动芯片 | DRV2605L 级（内置触觉波形库+LRA 自动谐振跟踪）×64 |

**电触觉总线（手套+背心选配，激励板 v0.2 通道架构继承）**：

| 项 | 设计 |
|---|---|
| 恒流通道 | 8 通道/板 ×2 板=16 点；16bit DAC 设定 0.1-5 mA |
| 波形 | **双相电荷平衡脉冲**（正负相位等电荷，串联隔直电容兜底）——零净直流注入 |
| 参数区（文献常用口径，开工复核） | 脉宽 100-300 μs；频率 1-100 Hz；每相位电荷 ≤1 μC 量级（例：2 mA×200 μs=0.4 μC，复算一致）；电荷密度 ≤~30 μC/cm²·phase 口径随电极面积复核 |
| 阻抗管理 | 恒流驱动=感知强度不随皮肤阻抗漂移（**激励板正本选型理由在电触觉档逐字成立**：恒压下电流随阻抗漂移、强度失控）；阻抗异常（突降/开路）→通道禁用 |
| 电极 | 水凝胶/Ag-AgCl，直径 ~10 mm（背心）/~4 mm（指尖）；可更换设计 |
| 隔离 | 人体接触侧按 IEC 60601 医用电气隔离口径：隔离电源+数字隔离器，漏电流 <10 μA（同批脑机接口 WS5 口径） |

### 3.3 安全分系统【执行·硬约束，先于一切性能指标】

1. **电荷/密度限值**：每相位电荷 ≤微库级；电流密度按电极面积核算（≤~0.5-1 mA/cm² 文献口径逐电极复核）；频率限 1-100 Hz 触觉感知带；
2. **皮肤烧伤防护**：任何接触面 ≤41 ℃（连续）；限流双保险（激励板正本 ≤10.5 mA 硬限验证项继承）；水凝胶干涸/脱落→阻抗门禁用该通道；
3. **医用级电气隔离**（IEC 60601 口径）：电触觉档全程隔离供电，漏电流 <10 μA；振动档电池浮地、天然隔离；
4. **急停**：D 暂停态（归零不断电）+物理断路开关双保险（激励板正本口径）；
5. **振动档提示**：无创，但声压（贴体 ~40-60 dB 量级）与长期连续振动暴露列入使用提示与测试项（§六 A4 递进）；

### 3.4 传感联动（力/位置反馈）【执行】

| 输入 | 器件 | 映射 |
|---|---|---|
| 力 | 织物柔性压阻/FSR（手套掌面+指尖） | 压力大小→触觉强度档位（闭环"我摸到了多少力"） |
| 位置 | IMU（MPU6050 级）+外部手部动捕（数据手套/视觉方案接口预留） | 位姿→图案空间锚定 |
| 外部 | VR/机器人末端（预留 ROS/BLE 接口） | 远端触觉→体感中继（遥操作用途） |

## 五、施工步骤（14 步）

1. **点位图冻结**：64 点全量+16 点精简布置图出图（§2.2 表），标定间距与换能器型号；
2. **换能器单件表征**：LRA 逐只扫频入库（谐振/阻抗/Q）；ERM 抽测启停延迟；电触觉电极-皮肤阻抗摸底（干燥/汗湿两态）；
3. **振动驱动小板打样**：DRV2605L+TCA9548A 驱动板，单点波形示波器复核（幅值/延迟/谐振跟踪）；
4. **电触觉恒流脉冲卡打样**：继承激励板 v0.2 恒流通道，波形改双相电荷平衡（含隔直电容与每相位电荷积分记录电路）；
5. **安全复核台**：逐通道电荷/电流密度/漏流/温升实测，对照 §3.3 全表——**任何一项不过，冻结人体试验，只做台架**；
6. **织物集成**：背心口袋/缝线固定、手套电极位裁剪；水凝胶电极可更换结构；线缆走线与应力释放；
7. **主控固件**：64 点 @≥60 Hz 调度器；BLE 延迟 <20 ms；通道健康自检（开路/短路/温度）；
8. **纹理图案库 v0**：§3.5 八图案 JSON 配方入库；
9. **传感联动联调**：FSR/IMU/动捕→强度与图案映射，闭环延迟 <50 ms；
10. **上位机校准向导**：逐点感知阈测定→强度 5+1 档（0-5）标定→单人档案入库；
11. **人体工学调试**：佩戴压力/透气/重量分布；水凝胶贴合度；脱穿便利性；
12. **台架验收（A 段前置）**：全通道自检脚本+波形抽测+安全复核台复跑全绿；
13. **人体试验 A（单人自试先行）**：强度分级判别→图案盲测→2 h 连续佩戴皮肤记录（§六 A1-A4+S1-S3）；多人扩展须知情同意程序；
14. **判据冻结评审+结项**：全部判据数据入档，混淆矩阵与皮肤记录归档，v0.1 结项并出 V1 修订单。

## 诚实边界

1. **振动触觉/电触觉=现役成熟路线**【执行】：消费电子产业（振动）与真实研究+商用辅助设备先例（电触觉）支撑，本册全部性能与安全参数按公开口径给出并逐项实测复核——这是本文档的**主体与全部承诺范围**；
2. **"云韶场触觉"**（云韶场直接激励体表、材料即源的触觉形态）**=【体系】【未验证】**：机制无已知物理对应、只能实测（激励板正本原话口径），挂 §八全闸门链，v0.1 不投入、不宣称、不阻塞执行层；
3. **穿戴舒适性与长期皮肤影响列为测试项**（A4 递进 2h/4h/8h），不出预判结论；
4. K-4 冷证据（反云韶场 1/7140、度规场恒为零）如实入账，本线执行层不依赖；
5. 医疗用途=V2 注册档专属，**未注册不宣称**；v0.1 人体接触全部以 S 段安全门槛冻结为前提；
6. R₋ 回写档**本设计不启用**（作用于人体的回写通道，超本册范围，列为体系边界项待知世裁决）。

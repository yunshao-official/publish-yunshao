## 0. 合规与范围红线（硬约束·设计红线）

- 本系统 V1/V2/V3 **只做统计异常的实时检出与分级通知，不做任何"预知未来"主张**——正本机制自述原句"不是预知未来，是感知概率流中的湍流"与本红线完全同向（§1.2）。
- **急停级不驱动任何执行器**：本系统输出的是"通知与记录"，物理急停执行归《反云韶急停·工程设计书v0.1》正本线，两线分路。本系统的"急停"是分级名，不是执行动作。
- **脑机接口不在本工程书范围**：锚点含"脑机接口耦合"，但 BCI 有独立正本（20260915）且人体线边界照旧；本文件仅留远期接口挂点声明（§8）。
- 数据最小化：V1/V2 默认本地处理、本地落盘、不外发；生理数据接入须另行走知情同意流程（沿《场指纹识别·工程书v0.1》§0 红线口径）。

## 1. 机制层【体系】

### 1.1 锚点原文照录（K-4，一字未改）

清单条目（第2年·5分量·法衣升级）：

> - 概率预警：脑机接口耦合，感知概率湍流

同章"六、概率预警"机制自述（正本全文提取-新常数修正版20260729）：

> 原理：5分量场对应5维概率空间投影。对穿戴者即将面临的坏事件产生场密度异常，经脑机接口感知为预警信号。
>
> 功能：不是预知未来，是感知概率流中的湍流。提前感知时间约瞬时（场传播速度=光速在5维的折合，c5=c3*5/3约5*10^8m/s）。假警率约alpha=12.5%。
>
> 常数依据：概率泊松方程 Box_p P = -kappa*rho，kappa=1/32。概率场的湍流当rho的Laplacian超过kappa^(-1)时被法衣传感器捕获，转换为脑机接口可读信号。

排版转写（仅供阅读，原文以上引照录为准）：概率泊松方程 □ₚ P = −κρ，κ=1/32；湍流判据=ρ 的 Laplacian 超过 κ⁻¹；c₅=c₃·5/3≈5×10⁸ m/s；假警率 α=12.5%。以上全部【体系】【未验证】。

### 1.2 T0 缺口判定

概率场为【体系概念】，正本亦自报了"常数依据"。但按操作化标准逐项检查，**"概率湍流"作为可测量物理量在体系内当前未建立**：

| 操作化要件 | 正本现状 | 判定 |
|---|---|---|
| 物理量定义 | "5维概率空间投影""场密度 ρ"——ρ 的测量口径未给出 | 缺 |
| 算子定义 | □ₚ（概率波动算子）无定义、无推导链 | 缺 |
| 阈值判据 | "ρ 的 Laplacian 超过 κ⁻¹"——无量纲化方案、无测量手段 | 缺 |
| 耦合公式 | 概率场→脑机接口的耦合通道公式未建立（同族先例：T13 概率偏转"概率场-动量耦合公式=T0 级理论任务，体系内当前不存在"，逐条执行台账 20260913） | 缺 |
| 独立旁证 | 0913 逐项盘点：docx第六章15项推演性质（含概率预警）全部评级【影】 | 一致 |

结论：属 **T0 缺口**，按预注册框架可判——一旦给出操作化定义即可设计实验判定真伪。本工程书在 T0 建立前不使用任何体系数值做工程计算（2026-09-15 铁律），机制层只保留语言框架与原文照录。

正本自带的两句攻防资产必须保留入账：

1. "不是预知未来，是感知概率流中的湍流"——本文件全部承诺边界以此句为基调；
2. "假警率约 alpha=12.5%"——体系自报工作点，与本系统验收误报率 ≤5% 不是同一测量（§6 口径区隔），两个数字并列如实入账、互不改写。

### 1.3 "概率湍流"建议定义（现役可测代理·执行层）

在 T0 建立前，本系统的检测对象采用现役统计代理量：

**统计异常度 A(t) ≜ 目标系统状态序列 x(t) 相对其基线的标准化偏离程度**

- 单通道：A(t) = |x(t) − μ(t)| / σ(t)，μ、σ 取基线窗口的鲁棒均值与鲁棒标准差（中位数与 1.4826×MAD），工程上叠加 EWMA 平滑；
- 多通道：A(t) = √[(x−μ)ᵀ Σ⁻¹ (x−μ)]（马氏距离），Σ 为基线窗口协方差阵。

边界声明：A(t) 是执行层统计量，**不是**体系"概率湍流"物理量；两者是否等价本身即 T0 判定对象。若 T0 建立"概率湍流"操作化定义，本系统经 §5.1 预留接口 TurbulenceMetric 直接替换检测对象，主程序零改动。标签：【体系】侧=体系内部定义·未验证；A(t) 侧=执行层成熟统计。

### 1.4 判据与测量优先（P-12 / P-19）

机制层只提供语言框架与原文锚点；本工程一切放行与否仅看 §6 实测数字。T0 缺口不参与验收豁免，也不因验收通过而被反证填补。

## 2. 总体架构

### 2.1 七级管线

```
传感流（任意时序：生理 / 设备 / 环境）
   │
   ① 数据接入适配器   CSV 回放 ∥ 串口流（pyserial）∥ 心跳质量位
   ② 预处理           重采样 · 去野值 · 缺失标记
   ③ 基线建模         滑动窗口 EWMA + 鲁棒 μ/σ（冷启动只学不报）
   ④ 异常评分         SPC 3σ/4σ/6σ ∥ EWMA 控制限 ∥ 多通道马氏距离
   ⑤ 阈值分级         注意 / 警告 / 急停 三级（急停只紧不松）
   ⑥ 通知             本地声光 + SQLite 落盘记录
   ⑦ 事件流输出       events.jsonl ──→ analyze_causal.py（归因须过开关比）
```

### 2.2 三级分级定义（v0.1 冻结初值）

| 级 | 颜色 | 触发条件（初值·待标定） | 动作 |
|---|---|---|---|
| 注意 | 黄 | A ≥ 3（单点越 3σ 限） | 记录 + 界面提示 |
| 警告 | 橙 | A ≥ 4，或 EWMA 统计量连续 k=3 点越控制限 | 记录 + 声音提示 |
| 急停 | 红 | A ≥ 6，或 ≥2 通道同时越限，或变化率 \|dx/dt\| > 10σ/窗 | 记录 + 声光急促 + 弹窗置顶；**不驱动任何执行器** |

自校准规则：注意/警告两级允许按实测误报率微调（§3.5）；急停级阈值手动锁定，只允许收紧、不允许自动放宽。

### 2.3 与 analyze_causal.py 因果判据联动

- 本系统**只检出、只分级，不归因**。异常事件以 JSON Lines 事件流输出（events.jsonl：时间戳、通道、级别、评分、基线快照哈希）。
- 下游（analyze_causal.py 或人工）要把异常归因于某因素时，必须过开关比判据。判读口径沿用《反云韶急停·工程设计书v0.1》先例：**开关比 > 3:1 且效应 ≥5σ 方可立"因果"级结论**；不过线的归因只能记"相关性待查"。
- 接口方向：本系统为事件生产方，analyze_causal.py 为消费方；两者无调用依赖，文件级解耦。

### 2.4 架构决策记录

1. **先软件、后传感器**：验收判据只约束算法层（合成数据自测），真实传感器精度不进验收——避免硬件长 lead time 阻塞软件交付；
2. **默认 SPC/EWMA，重模型可选**：孤立森林/LSTM 列为可选档、不进验收关键路径——保证 CPU 实时、零 GPU 依赖；
3. **通知与执行分路**：本系统不写任何执行器接口——与反云韶急停正本安全分路，杜绝软件误触发物理动作；
4. **检测对象可替换**：TurbulenceMetric 协议把"统计异常度"做成可插拔件——V3 换体系物理量时主程序零改动。

## 3. 分系统

### 3.1 数据接入适配器

| 通道 | 实现 | 用途 |
|---|---|---|
| CSV 回放 | 内置，pandas 读取，逐窗回放 | 开发 / 验收主通道（判据 1–3 全在合成 CSV 上跑） |
| 串口流 | pyserial，波特率 9600–115200 可配，行协议 `t,v1,v2,…` | 真实传感器（DS18B20 / MPU6050 / SCT-013 等现成件） |
| 心跳质量位 | 每帧带 quality_flag；超时 T_heartbeat=3 采样周期判断流 | 区分"传感失效"与"被测异常"（§7-R3） |

统一帧格式：`Frame = (t, [x1..xn], quality_flag)`。新增传感器按 §5.1 BaseSource 协议挂载，主程序不改。

### 3.2 基线学习模块

- 冷启动：前 N=100 窗只学习不报警（状态栏明示"基线学习中"）；
- 鲁棒统计：μ̂=中位数，σ̂=1.4826×MAD（抗野值污染）；
- 平滑与重学习：EWMA λ=0.2（初值）+ 滑动窗 W=500 窗滚动重估；基线均值位移 >2σ̂/窗 触发基线快速重置（§7-R1）；
- 全部参数进 probwarn.yaml，不在代码里写死（验收纪律：代码内零魔数）。

### 3.3 评分与分级逻辑

- 单通道双轨取严：SPC 控制限（3σ/4σ/6σ 档）与 EWMA 控制限（平滑统计量 ±3σ_EWMA，σ_EWMA=σ̂·√(λ/(2−λ))）同时计算，任一越限即触发对应档；
- 多通道：马氏距离 A_m 对 χ²(n) 分位定门限（档位与单通道 3σ/4σ/6σ 等价对齐）；
- 分级器输出 `(level, score, channel, t)`，连同原始窗口快照写入 SQLite（events 表 + ringbuffer 表），支持事后回放与误报复盘。

### 3.4 通知通道

- 本地声光：终端蜂鸣（跨平台 + 可选 winsound）+ 弹窗 + 可选 TTS 播报；V2 增加 12V 声光报警器（经 USB 继电器，**只接收"通知"信号，无回控**）；
- 记录：SQLite 事件表永久落盘 + 原始数据环形缓冲（默认保留最近 24h）供回放；
- 分级抑制：同一通道同一级别持续期间不重复发声（重报周期可配，默认 5 分钟）。

### 3.5 误报率控制（分级阈值自校准）

- 滚动统计各通道各级实测误报率（统计窗 1000 事件），与目标值比较：注意/警告级目标 FPR ≤5%；
- 调节器：PI 控制（比例 0.5 + 积分 0.05/事件窗，初值），单次阈值调整步长上限 5%，调整全部写审计日志；
- 急停级**手动锁定**：自校准回路对急停级只允许收紧方向生效，放宽必须人工输令；
- 误报疲劳保护：某通道连续 3 次误报后自动升一档门槛并挂牌记录，人工复位恢复——防止"狼来了"效应掏空预警价值。

## 6. 验收判据（冻结）

判据优先、测量优先（P-12/P-19）。以下判据自 v0.1 起冻结；验收只认合成自测报告，真实传感器精度不影响判据（判据只约束软件算法层）：

| # | 判据 | 数值 | 测量口径 |
|---|---|---|---|
| 1 | 注水异常检出率 | ≥95%，同时误报率 ≤5% | 合成数据自测。"注水"=向合成基线流注入已知异常，四类各 ≥200 例：阶跃 / 漂移 / 尖峰 / 方差放大；检出=异常窗内触发 ≥警告级 |
| 2 | 预警延迟 | ≤1 个采样窗 | 异常注入点所在窗的下一窗结束前，必须完成分级判定并已调用通知接口 |
| 3 | 三级分级正确率 | 每级 ≥90% | 按注入强度三档（弱/中/强）对应 注意/警告/急停，逐级统计正确率（本数值为 v0.1 自拟冻结值，待知世确认或改签，见交付包待裁决 W3） |
| 4 | 纪律条款 | — | 正样基线 ≥10⁴ 窗；随机种子固定；同一软件版本跑完全部判据，改代码即全部重跑；改判据=升版 v0.2+，旧报告作废 |

**与体系自报数字的口径区隔（不混同声明）**：正本自报"假警率约 alpha=12.5%"是体系机制层（概率湍流→脑机接口链路）的工作点，属【体系】【未验证】；本判据 FPR≤5% 是执行层算法（统计异常度→分级器）在合成数据上的工作点。两者测量对象不同，并列入账，互不作证、互不否定。若 T0 后两者同台测量，差值本身就是 T0 判据数据。

## 7. 风险与降级

| # | 风险 | 机理 | 对策（降级路径） |
|---|---|---|---|
| R1 | 非平稳基线漂移 | 被测系统缓变使固定基线失真，误报抬升 | 滑动窗口重学习（W=500，λ=0.2）；漂移检测（基线均值位移 >2σ̂/窗）触发基线快速重置并冷启动复核 |
| R2 | 高噪声通道 | 单通道 σ̂ 过大，灵敏度不足 | 多传感器融合（马氏距离联合 + ≥2 通道同时越限才可升急停）；单通道降级为"只注意不急停" |
| R3 | 数据缺失/断流 | 传感失效被误判为被测异常 | 心跳超时（3 采样周期）→判"传感失效"，发系统级"注意"并挂质量位，不进异常计数 |
| R4 | 阈值自校准发散 | 闭环正反馈把阈值推到失效 | 步长上限 5%/次 + 急停级手动锁定 + 校准全程审计日志 |
| R5 | 误报疲劳 | 高频误报使人对报警脱敏 | §3.5 误报疲劳保护 + 分级抑制（同级不重复发声） |
| R6 | 算力不足 | LSTM/孤立森林资源开销 | V1/V2 默认仅 SPC/EWMA（CPU 实时）；重模型为可选档，不进验收关键路径 |

## 诚实边界（末尾）

1. **异常检测 = 现役成熟**：工业预测性维护、心电异常预警、金融风控异常流检测均为已产业化领域，算法（SPC/EWMA/孤立森林/LSTM）全公开。本工程书 V1/V2 无任何新技术主张，全部为成熟方法的集成。
2. **"概率湍流"专属含义 =【体系】【T0 缺口】【未验证】**：天工开物第2年清单锚点真实存在（正本照录），正本亦自报了"常数依据"，但其物理量定义、算子、阈值、耦合公式均无操作化口径，0913 逐项盘点评级【影】。本文件给出的"统计异常度"是现役代理量，不是体系物理量；任何把两者等同的表述都越界。
3. **本系统不承诺预知未来事件，只承诺统计异常的实时检出**。文中"预警"=统计异常报警；正本"不是预知未来，是感知概率流中的湍流"原句与本条同向并已入账（§1.2）。
4. **急停级=分级名，不是执行动作**：本系统不驱动任何执行器；物理急停归反云韶急停正本线。
5. **不卖区提示**：正本差分审计（20260916）将概率预警列入"不卖"清单（军事/国家级/影子）——本工程书仅为体系内部工程文书，不构成任何对外销售依据。
6. **BOM 价格为电商常见约值**，撰写环境禁止联网、未逐家核价；执行层数值（窗口、阈值、参数）均为待标定初值。
7. **全文标签纪律**：【体系】=体系原生/原文照录；【执行】=现役成熟技术；【T0 缺口】=待判定义；【未验证】=未经实验判定。体系侧内容一律带"体系内部定义·未验证"，判据优先、测量优先（P-12/P-19）。

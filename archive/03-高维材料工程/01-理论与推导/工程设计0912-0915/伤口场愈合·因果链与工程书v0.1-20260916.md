## 0. 合规与边界（硬约束·设计红线）

1. **伤口治疗作用于人体 = 医疗器械监管**：创面敷料/电刺激治疗仪按**医疗器械 II 类管理口径**对待（以药监局分类目录与属地药监咨询为准）；本册全部临床主张以**注册检验+临床路径**为前提，未注册不宣称疗效。
2. **本册人体边界**：V0 = 体外实验（角质形成细胞/成纤维细胞迁移实验，in vitro 不涉人体，**即日可判**）；V1 = 器件工程（研究样机，仅台架与工程验收，临床注册前提如实列入）。**人体试验不在本册任何版本内**，属注册后临床路径事项。
3. **委托人 LEV 原话口径（临床 5-6 年）同适用**：本条目轻量路线缩短的是"发生器成本与复杂度"，不是合规周期；临床时间预期照旧如实列入。
4. **禁卖实物（底线 2）**：全路径不进货架、不签任何形式的人体疗效承诺；台账线唯一。
5. **不做机制越权主张**：现役电场效应归现役医学解释；"云韶场梯度"的附加效应属【体系·待证】，不得写入任何对外疗效口径。

## 一、机制层【体系】

### 1.1 天工开物第 2 年清单原文（K-4，一字不改）

> **"伤口场愈合：场梯度引导细胞迁移，替代LEV的轻量方案"**（第 2 年·5 分量·法衣升级清单）

逐词拆解【体系】：
- **场梯度**：激励变量=场的空间梯度（非均匀场），方向性由梯度方向给出；
- **引导细胞迁移**：作用对象=创面修复细胞（角质形成细胞/成纤维细胞），作用方式=定向迁移引导（非杀伤、非增殖直接刺激）；
- **替代 LEV 的轻量方案**：正本自定位——LEV 装置（云韶场辐射路线，20260915 工程书在档）为同适应症重方案；本条目为**轻量替代**：作用环节收窄到"引导迁移"一环，激励器随之轻量化。

### 1.2 galvanotaxis 同构注记【执行·现役真实，本条目最强真实切片】

**galvanotaxis（趋电性/细胞电场定向迁移）是现役真实存在的细胞生物学现象**：上皮损伤后创面内存在内源性侧向电场（"皮肤电池"，跨上皮电位经创面短路产生），修复细胞（角质形成细胞、成纤维细胞、内皮细胞等）在该电场梯度下发生**方向性迁移**，朝伤口中心移动——公开文献充分、重复良好、有专章综述与专门实验范式（galvanotaxis chamber）。

**同构对应表**：

| 体系机制表述【体系】 | 现役对应【执行】 | 同构度 |
|---|---|---|
| "场梯度引导细胞迁移" | galvanotaxis：电场梯度下细胞定向迁移 | **机制表述级同构**（激励变量同为场梯度，响应同为定向迁移） |
| "伤口场愈合" | electrical stimulation therapy for wound healing（电刺激促创面愈合，现役临床疗法，微电流/直流/脉冲交流均有研究） | **应用级同构**（同一目标、同一作用层） |
| 云韶场梯度（激励源） | 现役电场（直流/微电流，电极阵列产生） | **源不同构**——体系原生激励 vs 现役电激励，差异如实标注（见 §1.4） |

**判读**：体系条目给出了一个**现役同构真实存在**的机制主张——这在天工开物条目中属最强真实切片档（对比：虫洞通信/概率偏转等条目无现役同构）。因果链的**环 0（细胞趋电本底）因此直接落绿**，全链缺口收窄到"梯度-迁移量效公式"与"体系激励源等效性"两处（§二）。

### 1.3 云韶激励板 v0.2 正本机制继承（知世原话 2026-08-29 11:43，一字不改）

> **"一块电路板，高维材料当元件嵌在板上，板子通电→材料激发云韶场。电流大小=场强，通断=开关。"**

正本三公理 → 本册翻译表：

| 激励板 v0.2 公理【体系】 | 本册翻译【体系→执行】 |
|---|---|
| 电流大小=场强 | V0/V1 现役档：恒流源电流→电极阵列→创面/腔室电场梯度（电流大小=场强的执行接口原样成立） |
| 通断=开关 | 疗程时序=PWM/使能；占空比=时均场量 |
| 材料即源（云韶场） | **v0.1 不启用**（材料线挂送检门）；预留元件座位，远期云韶场梯度档合体用（§八） |

### 1.4 冷证据与体系边界如实入账（K-4 双向引用惯例）【体系内部定义·未验证】

- **反云韶场触发强度 1/7140、度规场按自身定义恒为零**：体系常数轨冷证据，如实引用；本线全部版本不依赖该两项；
- **"云韶场梯度引导细胞迁移"与现役电场的等效性 =【体系】【假设·待证】**：机制表述同构（§1.2）不等于激励源等效——云韶场本身无已知物理对应（激励板正本原话口径：材料激发云韶场这一步没有已知物理对应，无法模拟，是否发生只能实验实测），其梯度能否复现 galvanotaxis 响应**只能实测**，挂 §八远期闸门链；
- v0.1 执行层全部采用现役电激励，**不预支云韶场任何疗效**。

### 1.5 执行层主体【执行】

两条现役真实路线承载本册全部工程承诺：

1. **体外 galvanotaxis 实验范式**：标准腔室+恒流/恒压驱动+活细胞成像，公开文献范式成熟，即日可建；
2. **电刺激创面治疗器件形态**：微电极阵列敷料+恒流驱动，对应现役电刺激治疗仪器械族（II 类管理口径）——V1 仅做工程样机，临床主张走注册。

## 三、V0 体外实验设计（判据冻结，即日可开工）

### 3.1 实验定位

回答环 2：给定电场梯度，修复细胞迁移速率与定向度是否显著提升且随场强单调。**不涉人体，即日可判。**

### 3.2 设计（四组对照口径，继承《云韶场·细胞与组织实验·可执行方案》）

| 项 | 设计 |
|---|---|
| 细胞系（两系并行） | HaCaT（人角质形成细胞系）+ NIH-3T3（小鼠成纤维细胞系）；扩展档：人原代真皮成纤维细胞 HDF（V0.5） |
| 腔室 | galvanotaxis 标准腔室（玻片腔室/电泳槽改造），两个 Ag/AgCl 电极对经盐桥/琼脂糖桥与培养液隔离（防电解产物污染） |
| 场源 | 恒流/恒压驱动（云韶激励板 v0.2 恒流通道或源表计），腔室内场强经记录电极实测标定 |
| 场强阶梯 | 0（零场对照）/ 10 / 50 / 100 / 200 mV/mm 四档+对照【执行·公开量级口径】 |
| 曝场时长 | 单次 2-4 h（文献常用窗口，逐系复核） |
| 读出 | 活细胞延时成像（相差），每 5-10 min 帧；分析指标=**迁移速率（μm/h）+定向度（朝阳极/阴极位移分量 cosθ）**，ImageJ/TrackMate 盲分析 |
| 对照组 | ①零场空白；②假照射（电极在位、场关闭/随机极性切换，排除电渗/温度/电解混杂）；③阳性对照（文献同款场强复现 galvanotaxis，验证实验系统灵敏度）；④场强阶梯组。**无对照组的结果不计入台账**（20260913 方案口径原样） |
| 重复 | 每组 n≥6 独立重复，两系各自成套 |

### 3.3 判据（冻结，开工前签字，不得事后改）

| # | 判据 | 阈值 |
|---|---|---|
| P1 | 有效性 | 任一场强档迁移速率较零场对照提升 **>5σ**（每系独立统计） |
| P2 | 量效单调性 | 迁移速率/定向度随场强单调（Spearman 单调性检验 p<0.05，四档阶梯） |

## 四、V1 器件工程（研究样机）

### 4.1 形态定义

```
┌─ 敷料端（一次性）：柔性基底微电极阵列（Ag/AgCl 印刷电极）+ 可更换连接
├─ 主机端（可复用）：恒流驱动板（云韶激励板 v0.2 通道裁剪至微安级）+ 电池 + MCU + 记录
├─ 疗程管理：每日时长计时/电流档/极性反转周期/电流-电压曲线全程记录（CSV）
└─ 安全：≤10mA 硬限继承 / 电荷平衡 / 漏流 <10 μA / 电极温度与阻抗门禁
```

分体设计（一次性敷料+可复用主机）与创面接触场景的感控逻辑一致：接触创面件不复用。

### 4.4 安全分系统【执行·硬约束，先于一切性能指标】

1. **电流限值**：总电流工作区 20-800 μA；硬限 ≤10.5 mA（正本继承）；电流密度逐电极按面积核算（≤0.5-1 mA/cm² 量级口径复核）；
2. **电荷平衡**：极性反转周期内净电荷 <1% 单相电荷；串联隔直电容兜底（同批场触觉反馈口径）；
3. **感染防护**：一次性无菌敷料端；电极-创面界面不产生电解氯/酸碱累积（Ag/AgCl+极性反转+盐桥设计三重压低）；使用规程并入标准创面护理（清创/换药/感染监测），器件不替代护理；
4. **电气隔离**：电池浮地为默认形态；任何市电形态按 IEC 60601 医用隔离口径（漏电流 <10 μA）；
5. **急停**：D 暂停态（归零不断电，正本口径）+物理断路双保险；
6. **禁忌自锁**：阻抗异常（开路/短路/突降）→通道禁用；心脏起搏器佩戴者/孕产部位等禁忌清单写入固件使用门禁与说明书草案。

### 4.5 疗程管理【执行】

- 时长：每日疗程计时（文献量级：每日数小时档起步，最终参数由 V0 曲线+临床路径冻结）；累计档案入 CSV；
- 记录：全通道电流/电压曲线+电极批次+创面照片（与创面面积-时间读数联动，环 4 终点的数据原料）；
- 边界：V1 所有"疗程参数"仅工程档命名，**不构成治疗建议**；参数主张冻结到注册临床。

## 六、施工步骤

### V0 体外实验（10 步）

## 诚实边界

1. **galvanotaxis = 现役真实**【执行】：细胞在电场梯度下定向迁移是真实、公开、重复良好的细胞生物学现象；电刺激促创面愈合是现役真实临床疗法——**本条目机制主张的现役同构真实存在**，这是本册全部工程承诺的地基；
2. **"云韶场梯度引导"与现役电场的等效性 =【体系】【假设·待证】**：机制表述同构 ≠ 激励源等效；云韶场本身无已知物理对应（激励板正本原话口径），其梯度能否复现趋电响应只能实测，挂远期闸门链，v0.1 不预支任何体系疗效；
3. **环 2 量效公式 = T0 缺口**：体系侧无"场梯度→迁移速率"公式；现役侧公开量级（内源创面电场约数十至数百 mV/mm、体外定向迁移阈值约 10 mV/mm 级）仅作量级对照，V0 实验产出自有数据后方可冻结参数；
4. **伤口愈合疗效以临床为准**：创面愈合受感染/血供/营养/护理多因素支配，电刺激效应必须在注册临床框架下认定；本册任何体外与台架结果**均不构成疗效证明**；
5. **合规与销售红线**：II 类医疗器械管理口径全路径适用；禁卖实物（人体线，底线 2）只挂台账；委托人 LEV 原话口径（临床 5-6 年）同适用，轻量化不改合规周期；
6. K-4 冷证据（反云韶场 1/7140、度规场恒为零）如实入账，本线执行层不依赖；
7. **全部【未验证】**：本册所有体系主张未验证、所有工程数值物理未验证、所有价格待询价——以开工实测与注册临床为准。

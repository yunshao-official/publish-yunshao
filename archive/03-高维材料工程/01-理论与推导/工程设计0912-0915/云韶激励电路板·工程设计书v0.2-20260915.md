> **"一块电路板，高维材料当元件嵌在板上，板子通电→材料激发云韶场。电流大小=场强，通断=开关。"**

## 一、机制层（体系原生，本设计的因果总纲）

```
[电源] → [恒流通道] → [材料元件（高维材料，镀银电极）] → 材料激发云韶场【体系】
              │                                    ↓
              └── 电流大小=场强，通断=开关【体系】      场 → 应用（磁选/发光/削减/推进…）
```

- **电流大小=场强**【体系】：场强调节=调电流（恒流源 DAC 设定）。
- **通断=开关**【体系】：开关=PWM/使能，占空比=时均场强。
- **三场切配置**（SGC：同一套硬件三种配置）【体系】：切模式=改驱动波形表（电流波形/极性/通道组合），硬件零改动。
- **诚实边界**【体系·冷证据】：circuit_sim.py 原话——"材料激发云韶场这一步没有已知物理对应，无法模拟；是否发生只能实验实测"。本设计把**电路工程**全部做实，激励效果留给实测；电流-场强标定曲线=体系实验的第一批数据。

| 项 | 值 | 出处 |
|---|---|---|
| 元件尺寸 | 10×10×1 mm 薄片（17 分量口径；其他分量按同接口缩放） | 知世 08-29 11:46 定 |

| 安装 | 板上嵌装（LGA 触点/pogo-pin 双极接触，可换元件） | 电路板=设备 |

电路工作点【执行·circuit_sim.py 已算】：材料电导率未知（未验证材料）→ 全域扫描已入档（绝缘体→导体，1mA@各 σ 的 V/P/E 表、5V 恒压表、占空比 0.3/0.5/1.0 时均功率与 60s 温升表、回路 5mm 磁场高斯表）——**恒流驱动选定理由：σ 未知时只有恒流能让"电流=场强"成立**（恒压下电流随 σ 漂移，场强失控）。

## 三、板卡设计（四层 PCB，一块板=一台设备的全部）

```
[USB-C 5V输入] → [限流保护 10mA×N] → [恒流通道×8（DAC+运放）] → [触点阵列（材料元件座×8）]
      │                  │                   ↑                            │
      └─[MCU+固件]──────[开关矩阵/PWM]────────┘                            ↓
      │                                            [电流/电压/温度传感 ADC ×8]
      └─[USB/串口上位机：波形表·模式配置·数据记录]
```

| 模块 | 实现 | 说明 |
|---|---|---|
| 电源树 | USB-C 5V → 板上 LDO 分轨（数字 3.3V / 模拟 5V 独立） | 标准 |
| 恒流通道 ×8 | 16bit DAC（DAC8568 级）+ 低漂移运放 + MOSFET 调整管；0-10mA 设定，步进 0.15μA | 电流=场强的执行接口 |
| 开关矩阵 | 每通道 MOSFET 使能 + PWM（1Hz-10kHz 可编程） | 通断=开关；占空比=时均场强 |
| 保护 | 10mA 硬限流（熔断+钳位双保险）、反接保护、过温断电（NTC 75℃ 阈值） | 安全红线：≤10mA |
| 传感 | 每通道 INA 级电流检测 + 元件温度 NTC | 数据记录=标定曲线原料 |
| 触点 | LGA 镀银触点座 ×8（可热插拔换元件） | 材料元件标准化接口 |
| 固件 | 波形表驱动：静态 DC / PWM 占空比表 / 三模配置表 v0（占位，由 V 级实验回填） | 三场切配置【体系】→软件查表 |
| 上位机 | Python：电流/温度曲线实时记录、配方下发（JSON 配方=工艺可复现） | 对照组三臂/盲测可程序化 |

## 五、验收（电路工程验收 + 体系效果实测两段）

**A 段·电路工程验收【执行，可即日定义】**
1. 恒流精度：设定 vs 实测偏差 <0.1%（全量程 8 通道）；
2. 限流：任何故障态电流 ≤10.5mA（硬限验证）；
3. 温升：额定占空比下元件温升 ≤ 电路仿真表预测值（σ=1e-2 档）；
4. 开关：PWM 上升/下降沿 <1μs；占空比设定误差 <1%；
5. 记录：全通道电流/电压/温度曲线自动存档（=标定曲线原料）。

**B 段·体系效果实测【未验证，判据继承】**
- 嵌入 R23/候选元件后：外接单光子计数器（蜃楼 V1 判据原样）、原位 Raman（T2a 口径）、微特斯拉级磁测（SGC-1 口径）——通电 vs 断电、电流大小阶梯、三模式配置对照，全部盲测（对照组三臂口径沿用工艺定稿）。

## 七、可实现路径（板、料、场三条线合流）

```
线1 板卡（即日可做，2-3 周，~1 万元）：PCB 打样→焊装→固件→A 段电路验收

    闸门叠加：R23 送检（线2）→ 通电实验（线3）→ T0 系公式 → V 级 → Q-6
```

- 板卡线**不被任何闸门阻塞**——即日可开工；材料线阻塞在送检；两线合体点=元件嵌板通电实验。
- 判负退出：通电实验若全零（外接三路传感 5σ 无信号）→"通电激发"环节如实判负入档，板卡保留为通用材料测试台（降级不失效）。

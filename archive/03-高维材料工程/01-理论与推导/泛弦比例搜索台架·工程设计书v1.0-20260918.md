## 一、系统定义

对 SDSS DR17 + LAMOST DR11 公开光谱库（合计 >2000 万条光谱）进行自动化搜索：同一天体光谱中是否存在频率比满足 f_a/f_b=12±tol 且 f_a/f_c=1.2±tol 的三条谱线。

## 三、软件设计（核心）

### 3.1 数据获取管线

```
下载源：SDSS SkyServer (dr17.sdss.org) / LAMOST DR11 (dr11.lamost.org)
数据格式：FITS光谱文件（每条~50KB，总~1TB）
获取方式：SQL批量查询 + wget批量下载
预计下载时间：1-2周（取决于带宽）
```

### 3.2 谱线提取算法

```python
# 对每条光谱：
# 1. 连续谱归一化（中值滤波，窗口=50像素）
# 2. 峰值检测：SNR ≥ 5σ 的局部极大值
# 3. 谱线拟合：高斯拟合获取中心波长+误差
# 4. 输出：每条光谱→谱线列表 [(λ,σ_λ,SNR), ...]
```

### 3.3 比例搜索算法

```python
# 对每个天体的谱线列表：
# 1. 全三元组枚举 (i,j,k) where λ_i > λ_j > λ_k
# 2. 转换为频率：f = c/λ
# 3. 计算比值：r1 = f_j/f_k, r2 = f_i/f_j
# 4. 检验：|r1 - 12|/12 ≤ tol1 AND |r2 - 1.2|/1.2 ≤ tol2
# 5. 候选三线组 → 红移一致性检验（z_i ≈ z_j ≈ z_k）
# 6. 输出：候选列表 + trials factor 校正后假阳性率
```

### 3.4 注入-恢复测试

```python
# 在真实无信号恒星光谱中人工注入满足比例的三线组
# 注入参数扫描：SNR ∈ {5,7,10,15,20}，红移 z ∈ {0, 0.1, 0.3, 0.5}
# 每组参数 1000 次注入
# 统计：检出率（recalls）和假阳性率（false positives）
# 通过标准：检出率≥95% at SNR≥10，假阳性率≤冻结值
```

## 一、二级架构：双层认知，决策自治

```
┌─────────────────────────────────────────────┐
│ 投影层（LLM·学）                             │
│  嘴：本体状态→语言化战报（walk结构/块分布/账本）│
│  耳：语言建议→本体参数与调度（不碰perm/idx）    │
│  记忆：案例文档库（语义索引·可修正·可遗忘）      │
└──────────────┬──────────────────────────────┘
        参数/调度（唯一接口，低带宽）
┌──────────────▼──────────────────────────────┐
│ 本体层（能量地形·活）——E6.3已证自持不可能，    │
│ E9/E10已证选择维持可达L3且经济自给。决策自治。  │
└─────────────────────────────────────────────┘
```

**接口契约（三条，违者=违反 v0.2 裁定）**：
1. 投影层**只能写**：脉冲调度表（何时开修复窗）、预算分配（各修复通道的能量份额）、提议类启用开关。**不得写**：perm、idx、任何构型状态。
2. 本体**只上报**：语言化战报（状态摘要），不接收本体侧反馈回路之外任何指令。
3. 投影层记忆条目进入调度表前必须过**本体侧验证臂**（A/B 试探：新策略 vs 在位策略小样本对照），防止语言幻觉直接污染本体（对应攻击手 P1-A′ 底噪防线传统）。

**为什么投影层记忆不会重蹈 E12 覆辙（对 F2 的正面回答）**：
- E12 失败机理=原始统计先验直接偏置提议+状态漂移后过时+无法自我修正。
- 投影层记忆的三点本质不同：①**索引是语义的**（"该扰动谱下 LNS 优于 2-opt"这类结构化命题，不是原始频率）②**可主动巩固/遗忘/泛化**（LLM 用语义推理维护案例库，非被动累积）③**间接作用**（经调度表+验证臂，本体决策自治）。学=学会更好的**预算分配与提议类组合**，不是学会修复动作本身（动作空间已由提议类完备性定律覆盖，全枚举就是天花板）。

## 二、学什么：三个层级（判据全部先于数据锁死）

### L1 调度学习（最小闭环·E20 首实验）
- **内容**：从历史战报学习"扰动谱状态→最优脉冲配置（k 值/调度间隔/预算分配）"映射。
- **判据（可证伪）**：同预算下，投影层调度的 duty(B≤7) ≥ 固定调度基线 + 10pp；且在 Q8（n=256）**零样本迁移**后仍 ≥ 基线+5pp。
- **为什么这是"学"不是"调参"（E12 界线的落实）**：E12 调参=基质内频率统计（无语义、不迁移）；L1=语言化规则+跨规模迁移验证。迁移失败即判"未学成"——不许可"在训练分布内变好"冒充学习。

### L2 案例迁移（跨构型结构模式库）
- **内容**：块形态→修复方案组合的案例文档（"两长块+三断口，先反向再桥接"类），按结构语义索引；新构型检索相似案例注入调度表。
- **判据**：案例库命中率与 duty 增益正相关（量化：有案例子集 vs 盲测子集 duty 差 ≥ 8pp）。

### L3 扰动谱预测（FEP 弱版）
- **内容**：学习环境扰动统计（cut/dead 比例、到达节律），预算前置（风暴前多备预算、平静期降频）。
- **判据**：前置调度 vs 反应调度，同预算下 duty 差 ≥ 5pp。

**层级验收即总装路线图二级门**：一级 10⁴ 级稳定（E14c 已示 Q8 duty 1.0 可达）+ 攻击手对本设计稿攻防通过 + L1 判据通过 → 二级正式点火。

## 三、攻防靶面（预注册前置，供攻击手备打）

| 靶 | 级别候选 | 攻击点 | 关闭条件 |
|---|---|---|---|
| T1 语言幻觉污染 | P0候选 | LLM 生成的调度表含事实错误→本体崩溃 | 验证臂 A/B 条款（接口契约3）+ 调度表 schema 校验 |

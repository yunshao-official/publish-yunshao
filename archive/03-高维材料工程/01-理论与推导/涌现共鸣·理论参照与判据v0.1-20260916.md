## 一、机制层【体系】与公式复算【体系·复算一致】

### 1.1 两处锚点原文（转引，一字不改）

> 天工开物第 3 年清单：**"涌现共鸣：多装备耦合，N人团队N^(7/8)倍增"**

> docx§十三：**"多个法衣通过虫洞耦合（delta>=alpha=1/8 时激活），所有穿戴者 Lambda 同时升高，整体防护指数级增强……N件法衣在一起，总Lambda=Sigma(Lambda_i)*N^(eta)=个体和*N^(7/8)。10人小队约7.5倍个体防护。观众在耦合半径内（约100米）也会感知到场……常数依据：耦合增强因子=N^eta=N^(7/8)。N=10时10^0.875约7.5倍"**

### 1.2 机制五要素拆解【体系】

| 要素 | 体系口径 | 本册审查指向 |
|---|---|---|
| 耦合介质 | 多法衣经**虫洞耦合** | 闸门 A（机制公式）＋闸门 B（场存在性） |
| 激活条件 | δ ≥ α = 1/8 时激活 | δ 的操作定义与测量法缺失（§3.1） |
| 衰减 | ε = 1/64 衰减（常数表 v1.0 在册） | 衰减作用位置无公式（§3.1） |
| 增益律 | 总 Λ = ΣΛᵢ · N^η，η=7/8 | 本册 §1.3 复算 ✓ / §1.5 推导缺口 |
| 感知圈 | 耦合半径内（约 100 米）观众可感知 | 与"实测确定"口径冲突（§3.1 第 4 条） |

### 1.3 核心公式与复算【体系·复算一致，纯算术✓】

**公式**【体系】：总防护 Λ_total = Σ(Λᵢ) × N^η = 个体和 × N^(7/8)，η = 7/8 = 0.875。

**锚点复算**：10^0.875 = 10^(7/8) = e^(0.875·ln10) = e^(2.014762) = **7.4989 ≈ 7.5** ✓
→ docx"10 人小队约 7.5 倍个体防护"**复算一致**（个体均匀 Λᵢ=λ 时，总防护 = 10λ × 7.4989 = 74.99λ，即约 7.5 倍个体和）。此为**纯算术事实**，不构成物理事实。

### 1.4 结构观察【体系内部定义·未验证】

- **α + η = 1/8 + 7/8 = 1**：激活阈值与增益指数互补（和为一）。体系文本未声明此为设计原理还是巧合，如实记录。
- **ε = 1/64 = (1/8)² = α²**：衰减常数恰为激活阈值的平方。同上，未声明来源，如实记录。
- **术语纠正**：docx"整体防护**指数级**增强"措辞不确——N^0.875 是**幂律（次线性）**，非指数增长；增益因子的边际（dN^0.875/dN ∝ N^(-1/8)）随 N 递减。正确读法：总标度 N^(1+η) = N^(15/8) = N^1.875，**介于线性与平方之间**。

### 1.5 机制公式缺口（闸门 A 的事实基础）

体系只给出**结论式** Λ_total = ΣΛᵢ·N^η，未给出：η=7/8 的推导来源；δ≥1/8 激活条件的机制方程；虫洞耦合的场论表述；ε 衰减在耦合通道中的作用位置。按 P-19（判据优先）：无公式则无预言，无预言则无可冻结判据的机制部分——故判据冻结（§4）冻结的是**标度形状**而非机制解释。

## 四、判据冻结提案【理论参照·非实测】（按 P-19：先冻结，后实验）

### 4.1 前置与冻结范围

- **排序**：本实验排在双闸门之后（闸门 A 出公式→指定测量量 Q；闸门 B 出场→有东西可测）。冻结的是**判据本身**，不冻结机制结论；先采数后改判据 = 判负处理。
- **不冻结项**：装备形态（本册不做设计）、耦合半径值（实验第 0 步标定）。

### 4.2 预注册命题

- **H1（判阳方向）**：N 台装备在场耦合**开启**时，可测输出量 Q(N, on) 随 N 满足幂律标度，log-log 拟合斜率 η̂ 的 95% CI **包含 0.875**（若 Q 直接读总防护）或 **包含 1.875**（若 Q 读含个体和的总量，预先声明读法，不得事后切换）。
- **H0**：开/关无差异，或标度不成立。

### 4.3 实验设计

1. **阶梯**：N ∈ {2, 4, 8, 16} 台（×2 步进；预测每翻倍增益 ×1.834，见 §2.2）。
2. **对照**：同一阶梯在耦合**关闭**态重测（开关对照）＋等质量等布局哑装置阴性对照（排除热/电磁/振动干扰）。
3. **标定前置**：第 0 步做耦合半径标定（体系自认半径实测未做，§3.1-4）；阶梯内所有 N 台间距 ≤ 标定半径的 1/2。
4. **测量量 Q**：待闸门 A 公式建立后指定并在采数前冻结（P-12：仪器读数无条件优先）；禁止采数后更换测量量。
5. **统计**：每点 ≥5 次独立重复；判阳要求任一开关对比达 **5σ**。

### 4.4 判阳 / 判负（统一因果判据）

- **判阳（须同时满足）**：① 开关比 **> 3:1**（同 N 下 on/off 输出比）；② 差异显著性 **≥ 5σ**；③ 阶梯 log-log 斜率 95% CI 含预声明目标指数（0.875 或 1.875）。
- **判负（任一即触）**：N 台阶梯**无 N^0.875 标度**（斜率 CI 不含目标指数）；或开关比 < 3:1；或斜率 ≈ 0/负（无耦合效应）。判负后果：涌现共鸣自"假设·待证"降级为"体系内部定义·判负"，不再进入工程线。

## 五、现役对照与诚实边界

### 5.1 现役组织科学对照【执行】

- **负向非线性真实存在**：林格曼效应（1913 拔绳：人均拉力随人数下降）、社会惰化（Latané 等 1979）、团队规模收益递减、沟通通道数 N(N-1)/2 平方增长、Brooks 法则——N 人团队效能在现役组织中普遍**次线性**（β<1）。
- **N^(7/8) 的数学意义**：增益因子 N^0.875 是凹函数（介于 √N 与 N 之间，每翻倍 +83.4% 边际递减），形状与现役"规模带折扣"的组织效能曲线同族——**作为组织效能参照模型有数学意义**（例如"N 人小队总效能 = 个体和 × N^0.875"可作现役团队产出的保守参照式）。
- **方向差异必须写明**：现役是"总产出**次线性**增长（<N）"，体系是"总防护**超线性**增长（N^1.875，介于线性与平方之间）"。两者形状同族但方向相反，引用时不得混同。

### 5.2 诚实边界【诚实标注】

- **物理场倍增无现役对应**：现役物理中不存在任何机制使 N 台防护装备耦合后总防护按 N^1.875 标度，或使装备个体防护量随编队人数抬升。【诚实标注】
- **"10 人小队约 7.5 倍"的双重身份**：它是**算术事实**✓（10^0.875=7.499，复算一致），**不是物理事实**（7.5 倍物性增益无现役机制、无体系推导链、无实测）。引用时必须二选一写明身份。
- 本册全篇【理论参照·非实测】；"复算一致"=纸面自洽 ≠ 物理已验证（K-4 惯例）。

### 5.3 与三模工作站 / 织物计算机（SGC ⑩）的关系

- **硬件结论：零新增**。若双闸门通过，涌现共鸣的"耦合硬件"= 同一套场阵列（三模一体工作站 v0.1 口径：三模式=R₊ 正向/R₋ 反向/D 暂停，**切配置=改振幅比与相位，硬件零改动**）；涌现共鸣只是该阵列多机协同的**协议层/时序层**（N 机同相位组网＋δ 条件监测），无新增硬件，仅有协议开发与半径标定成本。

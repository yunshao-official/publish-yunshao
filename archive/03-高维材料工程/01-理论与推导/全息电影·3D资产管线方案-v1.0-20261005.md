# 全息电影 · 3D 资产管线方案 v1.0（知世令：2D 素材必须 3D 化，必须用 AI）

> 日期：2026-10-05 ｜ 隶属：蜃楼工程内容侧（显示硬件之外的另一半）｜ 触发：知世"以前的各种 logo、物件都是 2D 平面的……必须做成 3D 的，工作量很大，必须要使用 AI"
> 术语先行：这件事的行业名叫 **3D 资产生成（Image-to-3D）**，管线叫 **3D 资产管线**，素材库叫 **3D 资产库**——知世"不知道叫什么"的东西，名字和工具都是现成的。

---

## 一、先纠正一个默认假设：不是所有元素都必须 3D 化

真三维显示的美学语法里，**"什么该立体、什么该保持悬浮平面"本身是一个叙事决策**：

| 资产类型 | 处理方式 | 美学理由（闭幕式脚本先例） |
|---|---|---|
| **历史影像**（开国大典/抗美援朝录像） | **不 3D 化**——做成"悬浮记忆屏"（平面影像飘在空中） | 脚本先例：光构成的车票、稻穗本来就是平面悬浮物。**过去以"平面记忆"存在，现在以"立体存在"**——虚实分层叙事，平面本身就是含义 |
| 文字/标题/字幕 | 3D 字体（挤出+倒角，成熟自动化） | 文字要立于空间 |
| Logo/徽标/军徽 | 轮廓矢量化→AI 挤出重建 | 立体徽标是全息的招牌镜头 |
| 实物件（建筑/器物/装备/动植物） | **AI 单图/多图 3D 生成**（主力工作量） | 该立体才立体 |
| 图案/纹样（门窗纹样/传统纹样） | 深度浮雕化（半立体） | 冬奥"中国门窗"先例：纹样做浅浮雕比全立体更美 |

**判定规则一句话：有正面视角的就让它立体，本质是"记录"的就让它平面悬浮。**

## 二、AI 工具弹药（2026 年现状·开源为主）

| 工具 | 能力 | 定位 |
|---|---|---|
| **TRELLIS.2**（2025-12，开源） | 40 亿参数单图→3D，mesh 质量旗舰 | **主力生成引擎** |
| **Hunyuan3D 2.1**（腾讯，开源） | 形状+纹理双阶段，成熟管线 | 国产主力/纹理强 |
| TripoSR / Stable Fast 3D | 秒级单图重建，6GB 显存 | **批量初筛引擎**（便宜量大） |
| Meshy / Tripo / Rodin / SAM 3D（Meta） | 商用 API | 补充 |
| Depth Anything 等深度估计 | 单图→深度图→浮雕化 | 纹样浮雕线 |
| 传统矢量挤出 | logo 轮廓→拉伸+倒角 | 文字/logo 线（最成熟） |

**单件成本**：AI 生成秒级-分钟级/件 vs 人工建模数天/件——**百倍到千倍加速**，"工作量和脑力考验很大"的问题被工具代偿。

## 三、五步管线（全部可用现有 AI 组装）

```
① 盘点分类   素材清单→按上表四类+悬浮屏类自动分类（视觉模型打标）
② AI 批量生成 文字logo→挤出线｜实物件→TRELLIS.2/Hunyuan3D｜纹样→深度浮雕
③ 拓扑优化   自动减面/重拓扑（显示端不需要影视级面数，体素显示更轻）
④ 体素化导出 → 对接蜃楼显示格式（边界条件逆问题反推驱动——⑤环已闭合的资产直接复用）
⑤ QA 质检    AI 自动审查（几何完整性/比例）+人工抽检（10%）
```

**与体系资产的闭环**：④体素化的扫描顺序规划=哈密顿路径问题（蜃楼 v2.0 已确认用体系 GPU 求解器）；⑤环边界条件逆问题**已闭合**（CP-SAT/哈密顿资产）——**内容管线和显示管线在"体素化"这一步接驳，E3 引擎两头都在用**。

## 四、工作量估算（一部电影级）

- 资产量级：全息电影约 3,000–10,000 件独立资产（含变体）
- AI 管线：生成+优化约 5–15 分钟/件（含人工抽检折算）→ **1–2 人月核心团队即可完成全片资产**（传统建模团队 20 人×1 年的活）
- 瓶颈不在生成，在**艺术审校**（哪些 AI 件需要重做）——按 20% 重做率预留

## 五、诚实边界

- AI 生成的 3D 件在**结构精确性**上有上限（徽标类对形准要求极高——国徽/军徽必须矢量挤出精确路线，不用 AI 重建）；AI 件适合"场景物件"，**主角级资产（法衣、关键道具）走人工精修**
- 体素显示格式（蜃楼③环体素）仍在研发（T0 命门未解）——资产管线先行建库，格式转换器候显示端定型

## 二、检索方法与通道（可复核）

| 通道 | 用途 | 次数 | 结果 |
|---|---|---|---|
| WebSearch（内置） | 首批超导族 4 查询 | 4 | 全部 429 限流，弃用 |
| curl 子进程 → Crossref REST API（api.crossref.org/works） | 书目三件套核实主通道 | 96 组查询（每组取前 3 命中） | 零限流；每请求带 UA 与 1s 间隔 |
| curl 子进程 → Crossref 单 DOI 直查（/works/{doi}） | 经典文献存在性核查 | 3 | 1 成功性核对（2 个猜测 DOI 证伪弃用） |
| curl 子进程 → arXiv API | 备用通道 | 1（测试） | 返回空，未再依赖 |

- 核实口径：【现实·已核实】= Crossref 返回 作者+年份+期刊（或机构报告号）+DOI 四要素齐全，检索命中级核实（未通读全文，全文级结论见 §九诚实边界）。
- 剔除口径：作者字段缺失（ACS 补充材料记录、Vacuum 摘要条目、出版社评审信/决策信）、纯预注册评审记录——约 15 条不入台账（判负照记，见 §六.3）。
- 本轮未使用 python urllib 做网络请求（策略禁），python 仅用于本地 JSON 解析。

## 五、最重要的发现（支持/竞争/空白 Top）

1. **支持（最硬的一条）**：REBCO 环氧浸渍失超链路（CSR-06/07/08 + Bhattarai 种子）在 2023-2025 三年间形成"开裂-瞬态放热-层间剥离"完整机制文献群——YS-CSR/YS-SE 的头号小问题有现役文献底，但**定量分级判据（放热功率谱→失超概率映射）全谱系缺失**：这是判负源，也是随任一包做实验的天然论文出口。

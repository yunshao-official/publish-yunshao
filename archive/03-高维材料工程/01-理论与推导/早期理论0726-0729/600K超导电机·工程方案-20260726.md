## 一、600K改变了一切

传统超导电机（YBCO 93K）：液氮循环→低温恒温器→冷却系统占电机重量30-50%→复杂、贵、重。

600K超导→室温300K仍是超导态→**砍掉整个冷却系统。** 电机在室温下运行。不用液氮，不用液氦，不用恒温器。开机即用。

---

## 二、最简架构

**径向磁通同步电机，空心无铁芯。**

```
┌─────────────────────────────────┐
│  定子外壳（云韶钢，结构件）       │
│  ┌───────────────────────────┐  │
│  │ 定子绕组（铜或600K超导）    │  │
│  │  ┌─────────────────────┐  │  │
│  │  │ 气隙 5mm            │  │  │
│  │  │  ┌───────────────┐  │  │  │
│  │  │  │ 转子（600K超导）│  │  │  │
│  │  │  │ 8极线圈       │  │  │  │
│  │  │  │ 轴+轴承       │  │  │  │
│  │  │  └───────────────┘  │  │  │
│  │  └─────────────────────┘  │  │
│  └───────────────────────────┘  │
│  无冷却系统。无低温恒温器。       │
└─────────────────────────────────┘
```

**为什么空心无铁芯：**
- 铁芯→铁损（涡流+磁滞）→效率降1-2%
- 铁芯→重量增3-5倍
- 600K超导线圈产生8T气隙磁场→不需要铁芯聚磁
- 空心→零铁损→效率>99.5%

## 九、验证清单（任何一项对不上→查理论或工艺）

| # | 验证项 | 理论预测 | 实测方法 | 不通过→查什么 |
|---|--------|---------|---------|-------------|
| 1 | Tc | 600K | 电阻-温度曲线，R=0的温度 | 工艺（3分量参数对不对） |
| 2 | Jc(300K) | ≥10⁶ A/cm² | 四引线法，300K，自场 | 理论（Θ(N)对不对）或工艺（缺陷阵列密度） |
| 3 | Jc(300K, 8T) | ≥5×10⁵ A/cm² | 四引线法，300K，8T外场 | 理论（Bc上限）或工艺（钉扎强度） |
| 4 | Bc(300K) | ≥10T | 磁化曲线，M-H loop | 理论（Θ(N)的κ→Bc上限） |
| 5 | 交流损耗(300K) | <1 W/m（240Hz, 8T） | 量热法或磁化法 | 工艺（缺陷阵列均匀性） |
| 6 | 机械强度 | 带材抗拉>500MPa | 拉伸测试 | 工艺（带材制备） |
| 7 | 离心力(3600RPM) | 应力<带材强度 | 有限元+超速测试 | 结构设计 |
| 8 | 失超传播 | 自然散热，不烧毁 | 人为触发失超，测温度曲线 | 600K优势：热容大，散热快 |
| 9 | 长期稳定性 | 1000h无退化 | 持续运行，定期测Jc | 工艺（缺陷阵列稳定性） |
| 10 | 迈斯纳效应 | χ<0，体积>1% | SQUID磁强计，300K | 理论（是否真超导）或工艺 |

**⚠️ 第2项和第3项是生死线。** 如果Jc(300K)远低于10⁶ A/cm²→电机做不了→600K只是"零电阻"但载不了流→查Θ(N)对3分量材料的预测是否正确。

**⚠️ 第4项是硬约束。** 如果Bc(300K)<8T→气隙磁场达不到8T→功率密度大幅下降→查理论。

## 十一、运行铁律

1. 未确认超导态（R=0+迈斯纳）不得通电加载
2. 失超检测：电压>100mV持续>10ms→立即断电
3. 超速保护：转速>4000RPM→机械制动+断电
4. 绝缘监测：定子对地绝缘>100MΩ
5. 振动监测：轴承振动>5mm/s→停机检查

## 十二、诚实标注

1. **600K是女娲实测，但工艺参数完整性待确认。** 需要完整工艺记录。
2. **Jc(300K)和Bc(300K)是生死验证项。** 没过这两项，电机做不了。
3. **交流损耗在240Hz/8T下未知。** 需要实测。
4. **带材制备工艺未知。** 600K材料能不能做成10mm宽带材？
5. **3分量材料的Θ(N)对应未标定。** 不确定是Θ(3)还是Θ(12)还是别的。
6. **全超导版（定子也用超导）的绕制工艺更复杂。** 第一年用铜定子。

## 〇、核心诚实前提（写死）

**云韶场没有仪器能直读高维痕迹**（维度探测理论§7.1：测到的永远是3维投影，不是高维本身）。因此：
- 一切标定走**3维投影可观测量**间接测——测云韶场在3维留下的痕迹（场强/分布/波形），不是直接测高维场。
- "精准"判据的基准，是**3维投影指标达标**，不代表高维全貌。该边界全文有效。

## 一、可控参数总表（"能控制什么就控制什么"的清单）

| 参数 | 物理量 | 3维投影如何测 | 精准判据（先锁后跑） | 状态 |
|---|---|---|---|---|
| **场强（大小）** | 能量密度/功率密度 | 场强计/功率计（材料激发后在3维的电磁/功率读数） | 场强=目标值±误差阈值；波动≤阈值 | 待标定 |
| **作用范围** | 空间分布/传播衰减 | 空间扫描场强分布（φ_i相位构型决定覆盖） | 覆盖范围=目标尺寸；边界衰减可控 | 待标定 |
| **频率谱** | 频域成分 | 频谱分析（谱仪） | 主频=目标值；谱纯度（旁瓣抑制）达标 | 待标定 |
| **波形** | 时间域包络 | 示波器/时域采样 | 波形=目标形状；时基误差≤阈值 | 待标定 |
| **相位构型** | 束间相对相位φ_i | 相位解调/干涉测量（π/4步进检出） | 相位互差符合π/4锁相律；相位漂移≤阈值 | 待标定 |
| **位置/定位** | 场作用的空间锚点 | 空间定位误差测量 | 定位误差≤阈值（精准度核心） | 待标定 |
| **作用时长** | 持续时间 | 时序控制 | 时长=目标值±阈值 | 待标定 |

## 二、"精准"判据模板（每参数统一，先锁后跑）

对每个参数 P，判据 = 四元组：
```
精确度 = |P实测 − P目标| ≤ δ      （绝对/相对误差阈值）
稳定度 = 波动幅度 ≤ σ              （多次重复一致性）
可复现 = 同一参数重复设置，结果一致 （跨批次/跨设置）
可控性 = 能否从N个候选状态精确选到目标状态 （离散能力）
```
- **判据必须在实验前锁定**（预注册），不看结果才定，禁数值迁就（R20/R28）。
- 每个参数打✅（达标）/❌（未达标）/⚠️（待测）三态。

---

## 三、上位控制指令（阶段0即定义，对接三层链路）

三层链路（知世确认）：**激光/电磁场/电流 → 高维材料 → 云韶场 → 目标组织**
阶段0先定义"怎么下达指令"：

| 控制维度 | 命令形式 | 对应参数 |
|---|---|---|
| 场强 | 设目标功率P | → 场强/大小 |
| 范围 | 设相位构型φ_i | → 作用范围/定位 |
| 频率 | 设载波频率f | → 频率谱 |
| 波形 | 设时间包络m(t) | → 波形 |
| 相位 | 设束间相位差 | → 相位构型 |

**指令集 = (P, φ_i, f, m(t), t_时长)**，即"一次云韶场编程"的下发参数。

---

## 四、阶段0执行步骤（落进一体化流程）

1. **搭测量台**：材料激发装置 + 3维投影测量仪器（场强计/光谱仪/示波器/相位解调装置）
2. **正向标定**：已知指令 (P,φ_i,f,m,t) → 测3维投影指标 → 建立"指令→响应"映射表
3. **判定**：每参数对照§二精准判据，打✅/❌/⚠️
4. **录入可控参数表**：能精准控制的打✅（记录指令+对应响应），不能的标❌（回调）
5. **闭环**：❌项按"指令→响应偏差"反推修正，重测直至✅或诚实标注不可控

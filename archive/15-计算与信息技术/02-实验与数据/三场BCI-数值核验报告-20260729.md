## 逐项核验

### 1. ✅ F=N_eff²≥C(36,3)
```
F = 96² = 9216
C(36,3) = 7140
9216 ≥ 7140 ✅  裕度 = (9216−7140)/7140 = 29.1%
```

### 2. ✅ 硬件限幅
```
90000 μW/cm² ÷ 9216 = 9.7656 μW/cm² ≈ 9.77 μW/cm² ✅
```

### 3. ✅ 正常焦点功率
```
9.77 × 7140 = 69,727 μW/cm² = 69.7 mW/cm² ✅
裕度 = (100 − 69.7)/100 = 30.3% ✅
```

### 4. ✅ 全聚焦功率
```
9.77 × 9216 = 90,000 μW/cm² = 90.0 mW/cm² ✅
裕度 = (100 − 90)/100 = 10.0% ✅
```

### 5. ✅ 10倍学习
```
4 × 2.5 = 10 ✅
通道因子4来源：12空间模式 ÷ 3组 = 4并行通道（合理）
```

### 6. ✅ SNR_eff（微小舍入差）
```
kT@300K = 25.9 meV
E_signal = 32.9 meV
SNR/ch = 32.9/25.9 = 1.2703 ≈ 1.27 ✅
SNR_eff = 1.2703 × √96 = 1.2703 × 9.798 = 12.45 ≈ 12.5 ✅
```
精确值12.45，文档写12.5，舍入差0.05（<0.5%），可接受。

### 7. ✅ PLL裕度
```
π/4 = 0.7854 rad
0.7854 ÷ 0.001 = 785× ✅
```

### 8. ✅ 编码容量
```
12模式 × 3 bits = 36 bits (raw) ✅
× η = 7/8 → 36 × 0.875 = 31.5 bits (effective) ✅
```

### 9. ✅ 多轮保真度
```
F_k = 1 − α^k
k=2: 1 − (1/8)² = 1 − 1/64 = 63/64 = 0.984375 = 98.44% ✅
```

### 10. ✅ 焦点粒度
```
ε = 1/64 → d = √ε = 0.125 nm（材料尺度）
工程衍射极限：0.61 × λ × z/a = 0.61 × 30mm × 50mm/120mm = 7.625 mm ≈ 7.6 mm ✅
（λ=c/f=3×10⁸/10¹⁰=30mm, z=50mm头皮→皮层, a=120mm阵列短边）
```

### 11. ✅ σ_D信号衰减
```
σ_D(D=5) = 1/(2×5−1) = 1/9 = 0.1111 ✅
信号：1 pT × 1/9 = 111.1 fT ✅
（文档写"~100fT"是近似，精确值111fT，偏差10%，可接受）
```

### 12. ✅ 写入速率
```
Raw: theta 4-8Hz × 12模式 × 3bits = 144-288 bps
Effective: theta 4-8Hz × 31.5bits = 126-252 bps
文档T2表写126-252bps → 用的是effective(31.5)不是raw(36) ✅
```
文档工程细化§2.3未明确写126bps，编码理论T2表写126-252bps（theta节律），数值正确。

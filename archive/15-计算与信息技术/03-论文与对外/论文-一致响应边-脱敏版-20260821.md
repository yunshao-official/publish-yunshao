# 语言模型中多头注意力"一致响应边"的涌现与杠杆效应

**摘要**

本文报告一个关于大语言模型多头注意力机制的经验发现：在 transformer 的每一层中，任意 token 对之间"有多少个注意力头同时对该边给出显著响应"，其分布呈现严格的幂律衰减——绝大多数边只被极少数头关注，而极少数边被大量头一致关注。进一步实验表明，这些被多头一致响应的少数边具有两个明显的结构特征：(1) 它们显著富集于句法边界位置（标点符号），富集度约为整体均值的 3.8 倍；(2) 它们是模型推理的"杠杆点"——通过消融实验，删除被多头一致响应的边所引发的输出损失变化，是删除随机边的约 68 至 1700 倍。本文提出"一致响应边（consistently-attended edge）"这一分析单元，并讨论其对理解大语言模型内部结构与模型压缩、剪枝的可能意义。

**关键词**：大语言模型、多头注意力、可解释性、消融、关键边

---

## 1 引言

Transformer 的多头注意力（multi-head attention）是大语言模型（LLM）的核心计算单元。已有大量研究从"注意力头"的粒度理解模型：例如特定头部承担的功能（Clark et al., 2019）、归纳头（induction heads, Olsson et al., 2022）、以及关键 token 的识别等。然而，上述工作多以"单个注意力头"或"单个 token"为分析对象。

本文提出一个不同的分析粒度：**token 对之间的"边"**。在每一层，任意有序 token 对 (i, j) 之间的注意力，由 H 个注意力头共同决定。我们关注的问题是：一条边上，有多少个注意力头会同时给它显著响应？这一"一致响应程度"的分布，以及这些被多头一致响应的边在模型中的作用，构成了本文的核心。

## 2 方法

**模型与数据**：本文实验在 Qwen2.5-0.5B（24 层、每层 14 个注意力头）上进行，输入为若干段中文文本（最大长度 512 token），通过 eager attention 前向提取全部层的注意力矩阵。

**显著响应判定**：对因果注意力矩阵 A[h,j,i]（第 j 个 key token 对第 i 个 query token 的注意力），以均匀分布基线的 C 倍（默认 C=3）为阈值，判定某个注意力头 h 是否对边 (i,j) 给出显著响应。一条边的"一致响应数" n(i,j) 定义为显著响应它的头数。该阈值下做了 C∈{2,3,5} 的敏感性检验，分布形态稳定。

**消融实验**：采用 leave-one-out 消融。删除一条边即在其所有注意力头上将该边的注意力置零并做行重归一（保持每行的注意力之和为 1，避免改变分布尺度），对比消融前后的模型输出损失（以 KL 散度度量）及 top-1 预测变化。

## 3 结果

### 3.1 一致响应数的分布呈幂律衰减

在全部 235,200 条无向 token 对边上，一致响应数的分布为：0 个显著头占 68.4%，1 个占 10.6%，2 个占 5.3%，3 个占 3.4%，此后严格单调递减至 11 个头的 0.4%；12 至 14 个头的边合计约 3.4%。

该分布整体呈幂律/几何衰减形态：低一致响应的边占主导，高一致响应的边极其稀少。阈值 C 在 {2,3,5} 三档下形态保持一致。

### 3.2 高一致响应边富集于句法边界

在一致响应数≥12 的边中，其被关注端 token 为标点符号的比例达 37.3%，而全体边中该比例仅为 9.9%，即富集约 3.8 倍。作为对照，同样属于"罕见 token"的拉丁字母序列并未出现富集（0.15% vs 0.11%），排除了"罕见 token 被多头机械性地关注"这一替代解释。

标点符号对应句法边界，是多头注意力一致盯防的结构关键位置。

### 3.3 高一致响应边是模型推理的杠杆点

消融实验（全 24 层对称删除，共测三组边的损失变化，KL 散度中位数）结果如下：

| 删除的边类型 | KL 散度中位 | 相对随机边 |
|---|---|---|
| 高一致响应 · 实词边 | 1.51 | ≈1700× |
| 高一致响应 · 标点边 | 0.061 | ≈68× |
| 随机边 | 0.0009 | 基准 |
| 低一致响应边 | 0.0012 | ≈1.3× |

即：删除被多头一致响应的边，模型输出损失的变化是删除随机边的数十至上千倍；而删除低一致响应的边几乎不影响输出。

此外，消融实验揭示了一个更精细的结构：一致响应边内部的杠杆强度，与其"跨层一致性"正相关——在几乎全部 24 层都一致响应的实词边（平均 22-24 层），其杠杆效应显著强于仅在约 10 层响应的标点边（相差约 25 倍）。

## 4 讨论

本工作的核心发现可概括为：**大语言模型内部存在一批数量稀少、但被多个注意力头跨层一致响应的"关键边"，它们富集于句法边界，且对模型推理具有不成比例的杠杆作用。**

这一发现与"关键边/骨架边"（critical edges, backbone）的图论直觉存在呼应，也与已有的关键 token 研究一脉相承。本工作的增量在于：提出了"一致响应边"这一由注意力矩阵自然定义、无需外部标注的分析单元，并给出了其分布规律与杠杆效应的量化证据。

值得指出的是：删除关键边会导致模型崩塌，但对称地"加强"关键边是否带来增益，在本次实验采用的困惑度判据下未观测到一致的增益，反而观察到显著的定向扰动。这一不对称性（"删坏不等于加好"）是一个值得进一步研究的问题，可能需要改用生成质量或下游任务作为判据。

## 5 结论与局限

本文发现并量化了 LLM 多头注意力中"一致响应边"的涌现及其杠杆效应。主要局限包括：实验规模较小（单模型、单文本、每类 6 条边），尚未扩展到多模型、多语言与更大规模样本；"加强方向"的增益尚未闭环。这些将作为后续工作。

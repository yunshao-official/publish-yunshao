# 流浪地球·行星推进与防御工程——单台推进器推力定量设计值

> 建档：工程师 2026-08-09 | 依据：`云韶引力推进器技术文档`（五部分）+ 计算员旧体系数据核验-20260809 + yunshao-verification（R20）
> 任务：补计算员核验出的关键缺口——单台推进器推力N（技术文档未定量，导致推地球台数/迁移速度/护盾偏转无法验算）
> 保密红线：**只用旧体系（标准物理：牛顿力学/材料力学/能量守恒）推演**，不暴露体系内部常数/公式；单台推力设计值以旧体系可验算方式给出
> 密级：内部研发档。对外剥离时保留本计算的旧体系过程（可验算），剥离体系指涉。

## 〇、任务与结论摘要

- **已知缺口（计算员核验）：** 技术文档给加速度0.1-1 m/s²（推进器自身），但**未给单台推力N**，导致台数/迁移/护盾全无法验算。
- **本档补全（旧体系可验算）：**
  - 单台推力（保守下界）≈ **4×10⁶ N**（a=0.1 m/s²）
  - 单台推力（上界）≈ **5×10⁸ N**（文档质量50万吨×a=1.0 m/s²）
  - 推地球台数（按上界5×10⁸ N）：**~10¹⁵台**（0.1 m/s²）/ 若迁移放宽到75年：**~10⁹台**
  - 迁移时间对账：1AU/75年所需地球加速度仅 ~5×10⁻⁸ m/s²（远小于0.1 m/s²），**时间线合理但需明确"迁移≠持续满推力"**
  - 护盾偏转：单台对1km级天体可产生 10⁻⁶~10⁻⁴ m/s² 加速度，**数天~数周可达行星防御所需Δv**（可行性高，但依赖推力实测）
- **诚实标注：** 全部为**设计估算**（非实测），推力/加速度/质量均为文档假设值；需全尺寸试车标定。

## 一、单台推进器推力（旧体系计算）

### 1.1 原理：F = m·a

旧体系牛顿第二定律：推力 = 推进器本体质量 × 等效加速度。文档§2.7给等效加速度 a = 0.1~1 m/s²，本体质量需由结构参数估算。

### 1.2 推进器本体质量估算（三个来源）

**① 球形壳体质量（几何独立验算）：**
- 直径50m → 外半径 R=25m；壳厚 t=0.5m → 内半径 r=24.5m
- 壳体体积 = 4π/3·(R³−r³) = 4π/3·(25³−24.5³) = **3849 m³**
- 密度 ρ=7.8 g/cm³ = 7800 kg/m³
- 壳体质量 = 3849 × 7800 = **3.0×10⁷ kg ≈ 3万吨**
- 交叉核对：文档§1.2称壳体总质量**约50万吨（5×10⁸ kg）**——**几何算得3万吨 vs 文档50万吨，差16倍**。文档值含全部内部结构（线圈/电源/冷却/锚固系统），几何值仅壳。**本档取两者为质量下界/上界依据。**

**② 超导线圈带材质量：**
- 总长2000 km、带宽10mm、带厚0.1mm → 截面积 = 10×10⁻³ × 0.1×10⁻³ = 1×10⁻⁶ m²
- 体积 = 2000×10³ m × 1×10⁻⁶ m² = 2 m³
- 密度约7000 kg/m³（铜氧化物/铁基超导膜+基底）→ **1.4×10⁴ kg ≈ 14吨**（相对壳体可忽略）

**③ 电源/冷却/控制：**
- 硅碳聚变反应堆**5000吨 = 5×10⁶ kg**（文档§5.2）
- 冷却/控制/辅助：取约与反应堆同量级，含在上界；下界保守含少量。

**质量场景汇总：**
| 场景 | 构成 | 质量 |
|------|------|------|
| 保守下界（几何壳+反应堆+线圈+辅助） | 3.0×10⁷ + 5×10⁶ + 1.4×10⁴ + 0.5×10⁷ | **~4.0×10⁷ kg ≈ 4万吨** |
| 上界（文档总质量） | 文档§1.2 | **5×10⁸ kg ≈ 50万吨** |

### 1.3 单台推力（旧体系验算）

| 场景 | 质量 m | 加速度 a | 推力 F = m·a |
|------|--------|---------|-------------|
| 保守下界 | 4.0×10⁷ kg | 0.1 m/s² | **4.0×10⁶ N** |
| 上界 | 5×10⁸ kg | 1.0 m/s² | **5.0×10⁸ N** |

- **单台推力设计值：保守下界 ~4×10⁶ N，上界 ~5×10⁸ N。**（旧体系可验算：F=ma，质量与加速度均可在文档参数内复算）
- 量级判断：4×10⁶ N 接近重型火箭发动机量级（土星五号F-1约6.9×10⁶ N）；5×10⁸ N 远超任何现有单发动机（接近整枚土星五号起飞推力的~1.5倍）。故**实际单台推力大概率落在 10⁶–10⁸ N 区间**，文档"0.1-1 m/s²"覆盖此范围。

## 二、推地球台数（旧体系验算）

地球质量 M_earth = 5.972×10²⁴ kg（教科书恒定）。

### 2.1 若要求地球加速度 0.1 m/s²（文档假设的推进器加速度量级）
- F_earth = M_earth × 0.1 = 5.972×10²³ N
- 台数（上界推力5×10⁸ N）= 5.972×10²³ / 5×10⁸ = **~1.2×10¹⁵ 台**
- 台数（保守下界4×10⁶ N）= 5.972×10²³ / 4×10⁶ = **~1.5×10¹⁷ 台**

**结论：若真按 0.1 m/s² 推地球，需 10¹⁵–10¹⁷ 台——天文数字，不可行。** 这是"把推进器自身加速度当推地球加速度"的错误用法（层级错位，与节点图补丁B同源）。

### 2.2 若按实际迁移需求（75年内移1AU）——见§三
- 所需地球加速度仅 ~5×10⁻⁸ m/s² → F_total ≈ 3×10¹⁷ N → **台数（上界）= ~6×10⁸ 台（约6亿台）**，保守下界 ~8×10¹⁰ 台（约800亿台）。
- **真实台数取决于迁移时间与推进器推力实测，量级 10⁸–10¹¹ 台**（远小于错误用法的10¹⁵+）。

## 三、迁移速度/时间对账（旧体系验算）

### 3.1 1AU/75年所需加速度
- 距离 d = 1AU = 1.496×10¹¹ m；时间 75年 = 75×365.25×86400 = 2.366×10⁹ s
- 匀加速 a = 2d/t² = 2×1.496×10¹¹/(2.366×10⁹)² = **5.34×10⁻⁸ m/s²**
- 所需总推力 F_total = 5.972×10²⁴ × 5.34×10⁻⁸ = **3.19×10¹⁷ N**

### 3.2 与"0.1-1 m/s²"对账
- **关键澄清：** 文档加速度0.1-1 m/s²是**推进器自身**的加速度，不是推地球的加速度。推地球若75年移1AU，只需 5×10⁻⁸ m/s²——比推进器自身加速度小 6-7 个数量级。
- **时间线合理：** 75年移1AU在旧体系能量上自洽（迁移能量2.65×10³³ J，计算员已核验）。但**迁移是慢漂移**，不是"持续0.1 m/s²满推力"——满推力0.1 m/s²一年就位移3.7×10⁵ km（一天37万公里），会瞬间甩飞地球，不符合"缓慢迁移"设定。
- **对账结论：** 时间线（~75年）与能量（2.65×10³³ J）自洽，但**必须假设推进器长期以极低推力（等效地球加速度~10⁻⁸ m/s²）运行**，而非满推力。这要求推进器有精确的微推力控制能力（文档§四暂停/巡航模式支持）。

### 3.3 台数×满推力自洽性警示
- 若用 6×10⁸ 台×上界推力5×10⁸ N = 3×10¹⁷ N，正好满足75年迁移需求——**但这是"每台都满推力"的极端情形**，实际需分散为长时间微推力，台数或运行功率需按任务剖面重新优化。

## 四、护盾偏转能力（旧体系验算）

### 4.1 来袭天体质量（1km级）
- 半径500m、密度3000 kg/m³ → m = 4π/3·500³×3000 = **1.57×10¹² kg**

### 4.2 单台推力产生的偏转加速度
- 上界（5×10⁸ N）：a = 5×10⁸/1.57×10¹² = **3.2×10⁻⁴ m/s²**
- 保守下界（4×10⁶ N）：a = 4×10⁶/1.57×10¹² = **2.5×10⁻⁶ m/s²**

### 4.3 预警时间窗口内能否实现所需Δv（行星防御文献值）
| 预警时间 | 所需Δv（文献，计算员核验） | 单台(上界)达成时间 | 单台(保守下界)达成时间 |
|---------|--------------------------|-------------------|----------------------|
| 10年 | 0.01–0.1 m/s | 极充裕（秒级-小时级） | 小时级-天级 |
| 1年 | 1–10 m/s | 小时级 | 天级-周级 |
| 数天 | ~km/s（基本不可行） | 需多台 | 需多台 |

- **结论：** 单台推进器对1km级天体，**在1年预警窗口内足以提供所需Δv**（保守下界天级、上界小时级）。**护盾偏转可行性高**。
- **约束：** ①推力需实测确认（现为估算）；②偏转需持续施加+姿控（天体自旋/材料非均匀）；③多台协同偏转的大天体（10km级，恐龙头级别）需上百台，且需更早预警（10年级）。
- **与DART对比：** DART（已验证）撞Dimorphos改变轨道周期32分钟——本方案为推力牵引偏转，原理不同（持续推力 vs 撞击），但**推力值需实测后才能与DART方案公平对比**。

## 五、诚实标注（设计估算 vs 实测需求）

| 项 | 类型 | 说明 |
|----|------|------|
| 壳体质量3万吨 | 几何验算 | 纯壳体（R/t/ρ均文档参数），可靠 |
| 文档总质量50万吨 | 文档设计值 | 含全部内部结构，非实测 |
| 线圈质量14吨 | 几何验算 | 带材几何参数文档给，可靠 |
| 加速度0.1-1 m/s² | **文档假设（非实测）** | 文档§2.7明确"需全尺寸实验标定" |
| 单台推力4×10⁶–5×10⁸ N | **设计估算** | 由 F=ma + 质量估算，依赖加速度假设 |
| 推地球台数10⁸–10¹⁷ | **估算** | 依赖单台推力（未实测） |
| 迁移时间/能量 | 教科书公式 | 能量2.65×10³³ J可靠；时间对账合理 |
| 护盾偏转Δv | 文献值+估算 | 可行性高但依赖推力实测 |

**必须实测标定（R20）：**
1. **单台推力（全尺寸试车）**——文档第八章地面试车（额定功率24h）是唯一权威来源，试车前所有推力数字均为估算。
2. **加速度-功率关系**——文档§5.2预测能耗比（1:6/5:1/6），试车验证±5%。
3. **材料响应效率（~10%）**——文档明确"未经独立标定"，影响推力量级。
4. **多台干涉**——文档局限性五，多台同时运行场干涉未定量，直接影响台数计算。

## 六、结论

1. **单台推力设计值：保守下界 ~4×10⁶ N，上界 ~5×10⁸ N**（旧体系 F=ma 可验算，质量与加速度均在文档参数内复算）。
2. **推地球台数：** 若错误地按"满推力0.1 m/s²推地球"→ 10¹⁵+台（不可行）；若按75年移1AU实际需求 → **~6×10⁸台（上界推力）**，量级 10⁸–10¹¹ 台。
3. **迁移时间对账：** 75年移1AU需地球加速度仅~5×10⁻⁸ m/s²，能量自洽，**时间线合理**；但必须"微推力长漂移"而非满推力，且需推进器精确微推力控制。
4. **护盾偏转：** 单台对1km级天体可行（1年窗口内天级-小时级达成所需Δv），**可行性高**，但依赖推力实测。
5. **全部为设计估算，非实测**；单台推力、加速度、材料效率、多台干涉均需全尺寸试车标定（R20）。

## 七、决策链（本档级）

- **D1 单台推力用 F=ma 估算（质量×文档加速度）** → 理由：计算员缺口即"文档未给推力N"，F=ma是旧体系唯一可直接验算路径。可证伪判据：若质量或加速度任一项实测偏离文档值，则本推力值作废，需重算。
- **D2 质量取"几何下界+文档上界"双场景** → 理由：文档壳体50万吨与几何算3万吨差16倍（含内部结构 vs 纯壳），双场景覆盖不确定性。可证伪判据：若全尺寸称重给出第三值，以实测为准。
- **D3 明确"推进器加速度≠推地球加速度"（层级错位警示）** → 理由：计算员指出错误用法会算出10¹⁵台不可行，本档分离两者。可证伪判据：任何后续引用若混淆两者即失效。
- **D4 迁移按75年/1AU实际需求反推（非满推力）** → 理由：满推力0.1 m/s²会甩飞地球，时间线对账须用实际迁移需求。可证伪判据：若任务时间线调整，台数/推力分配重算。
- **依赖：** D1→D2→D3→D4（推力→台数→迁移→护盾逐级依赖）。上游依赖：云韶推进器文档参数（设计值，非实测）。

## 八、未选路径

- **未选"直接报单个推力数字（不标估算）"**：缺陷——违反R20与诚实标注，试车前推力均估算，报死数会误导对外方案 → 否决，给区间+标注设计估算。
- **未选"按满推力0.1 m/s²算台数"**：缺陷——把推进器自身加速度当推地球加速度（层级错位），算出10¹⁵台不可行结论误导 → 否决，分离两加速度。
- **未选"护盾只报可行不标依赖"**：缺陷——未标"依赖推力实测"，可能被当已验证方案引用 → 否决，明确可行性依赖实测。
- **未选"引入体系内部常数/公式定推力"**：缺陷——违反保密红线，外界可反推体系 → 否决，全程旧体系F=ma+材料力学。

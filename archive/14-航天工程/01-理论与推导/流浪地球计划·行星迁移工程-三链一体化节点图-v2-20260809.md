## 二、补丁记录（v2·3个P0修补方案）

> 本节为 v2 相对 v1 的全部改动说明。a. 表明修补方案设计；b. 说明改哪些字段；c. 自检见 §六。

### 补丁A（P0-1·N-02 缺H4竞争假说）

**问题（攻击手实锤）：** N-02 效应归属判定只排除热/电磁（H2），即使全部排除也不能确立"约束松弛"（H1）——可能是任何未知常规物理（H4）。H1/H2/H3 不穷举却当穷举用，涌现判据"连续三轮支持H1且H2/H3被否定"存在**肯定后件谬误**：若实为H4，会被系统性误判为H1。

**修补方案：**
1. **补 H4=未知常规物理效应** 进 N-02 的 `competing_hypotheses`。
2. **涌现判据改为"正面特征验证"而非"排除后剩余"：** H1(约束松弛) 必须被**理论给出的特征性预测**独立确认，而非仅"排除已知项后的剩余"。这些特征（旧体系语言）：
   - **方向性**：效应随驱动方向呈现理论预测的非对称响应；
   - **特征曲线**：效应随驱动参数（频率/功率）的变化符合 N-01 数据校准后的理论预测曲线（非平凡缩放，非线性");
   - **跨尺度一致性**：效应在独立锚点（对照区、盲测、独立仪器）复现且数量随尺度按理论规律缩放；
   - **非发生器伪影**：效应与驱动信号发生器自身反作用力/热相分离（拖拽补偿级隔离，见补丁C）。
3. **H4 的处理规则：** 若效应在排除 H2/H3 后仍存在，但**不符合 H1 的任一特征性预测**（方向/曲线/跨尺度），则归 H4——**不确认 H1，不允许 go**，登记涨落并继续追踪，绝不因"排除了已知项"就放行。

**改动字段：** N-02 `competing_hypotheses`（+H4）、`emergence_criteria`（改为正面特征验证）、`go_condition`（+H4排除）、`verification.threshold`（+特征曲线/跨尺度一致性）。

### 补丁B（P0-2·N-05 层级错位 + P0-3·N-05 单向不可证伪）

**问题（攻击手实锤·两P0同源）：**
- P0-2：N-05 go 判据"远程节律耦合可测"只验"耦合出现"，不验"够用"——"测到耦合"≠"耦合强度足以驱动行星迁移"，判据层级错位（中间量当目标量充分判据）。
- P0-3：硬停可证伪条件"改进方式后耦合出现则重启"是**单向不可证伪**——可被"还没改进够好"无限延迟否决，直接违反 §四"不许再试试无限拖延"铁律。

**修补方案（合并处理，因同源）：**
1. **定义可测的"够用"目标量**（记为 Q_足够，迁移可行性阈值）：
   - 定义：驱动整个行星按规划完成轨道迁移（约一个天文单位/数十年，见N-07）所需达到的**约束强度降低量**。
   - 来源：由 N-07 迁移需求**反推**（迁移推力需求 → 反推耦合效率门槛 → 反推约束强度需降至的水平）。
   - 表述（保密合规·定性+量级）：约束强度需由 N-01 实测自然值**降至其极低比例（降低多个数量级）**，使迁移速率达到规划值。
   - 冻结时机：N-02→N-05 放大设计时，将 Q_足够 冻结为**可测判据**（写入 N-05 verification.threshold），作为 go 的唯一充分判据。
2. **go 判定必须含"够用"验证：** N-05 go_condition 由"耦合可测且效率达标"改为"**耦合强度达到 Q_足够**（约束强度实测降至迁移可行性阈值以下）"。仅"耦合出现"或"效率部分达标"→ 不满足 go，只能软停·机制存疑。
3. **可证伪条件改双向：**
   - **硬停触发条件（新增·明确）：** 在**既定功率/尺寸上限**（全尺度网络的物理与经济既定工程上限，设计时冻结）内，耦合实测强度未达 Q_足够 → **硬停**，技术归零，转备选。此条件**不可被"还没改进够好"延迟**——既定上限即迭代边界，越界即停。
   - **重启条件（保留·限定）：** 仅当出现**可归因于特定改进（相位控制/注入方式）且记录在案的耦合跃变**，使耦合强度达到 Q_足够 → 才允许重启。重启必须由 audit 独立复审，且计入三轮验证循环上限。
4. **三轮验证循环上限与硬停触发联动：** 三轮内既未达 Q_足够 也未触发硬停 → 升级主agent+知世裁决（§5.4）。

**改动字段：** N-05 `verification.threshold`（+Q_足够定义与冻结）、`go_condition`（+够用验证）、`stop_condition`（+硬停触发条件：既定上限内未达Q_足够）、`soft_stop_condition`（+仅"耦合出现但未达Q_足够"才软停）、`exploration.emergence_criteria`（+Q_足够）、`failure_turn`（+硬停触发路径）。

### 补丁C（P0-1 配套·N-02 发生器伪影隔离）

> 攻击手将"驱动信号发生器自身反作用力/热"列为 P1 open question（A3/P1-C）。虽非本轮3个P0，但它是 H4 判定成立的必要配套——若发生器伪影不隔离，H1 特征验证会被污染。故在修补H4时一并内建隔离要求（消除 open question），不新增独立节点。

- N-02 验证设计强制：**拖拽补偿级环境隔离**（旧物理微推进/引力波探测既有标准），使"驱动信号的效果"与"发生器自身反加速度/热/排气"可分离。
- 该隔离作为 H1 特征验证的前置条件写入 `verification.tool` 与 `exploration.competing_hypotheses` 的 H1 判定前提。

### N-01 测绘（探索轨）

```yaml
node_id: N-01
name: 约束场分布测绘（日地系统）
track: exploration
chain_position:
  artifact:
    input_state: 场存在性理论假设 + 现有深空测量网基线数据
    state_transform: 布设测绘星座（太阳极轨测绘星、地球高轨干涉阵列、深空探测节点）→ 多手段精密测量 → 交叉标定
    output_state: 日地系统约束场分布图 + 地球当前约束强度实测值 + 场本征节律频谱
  verification:
    level: L1
    measurand: 约束场空间分布结构、强度梯度、本征节律频率、与太阳活动扰动的关联
    tool: 深空探测器、高轨干涉阵列、精密测距与引力异常监测、原子钟网络（旧体系白名单工具）
    threshold: 分布图自洽（多手段交叉一致，偏差在可控容差内）；约束强度实测值可复现
    evidence: 测绘数据包（含交叉验证报告）
  decision:
    gate: go | no-go | soft-stop
    go_condition: 测绘数据完整自洽，分布图可支撑原型设计（误差可控）
    stop_condition: 硬停——多手段均测不到任何可测结构（约束不可观测，方案原理不成立）。可证伪条件：若独立手段（引力异常/干涉相位）复测出现结构，则本硬停不成立，路径重启
    soft_stop_condition: 软停·待验证——关键区域数据缺失或矛盾，主线暂停，等补充数据再判
    reviewer: 知世（主agent主持闸门评审）
    review_node: N-02设计冻结前的复审（audit独立发起）
feedback:
  output: 约束场分布实测值
  compare_to: 理论预测分布
  adjust: 探测密度、标定参数、卫星布点
  period: 每轮测绘批次
exploration:
  fluctuation_log: 任何偏离预期的结构异常（超统计噪声）→登记→追踪三轮→确认噪声或新机制；不许对异常直接硬停
  open_input: 每轮至少一条外部新信息：深空探测新数据、引力测量新成果、跨领域类比（晶体缺陷场/流体涡旋结构）
  competing_hypotheses:
    - H1 约束场存在可测结构且可调（方案成立前提）
    - H2 约束场为均匀背景、无结构（方案原理不成立→硬停依据）
    - H3 约束场有结构但不可调（只可监测、不可迁移）
  emergence_criteria: 某假说连续三轮被独立证据支持且竞争假说被否定 → 确认为新setpoint → 转下游设计依据（N-02）
failure_turn:
  trigger: 传感器原理失效，或测绘显示无结构
  turn_to: 备选路径：退化为"仅长期监测、不启动迁移工程"；或改用间接探测手段（日冕/星际介质响应）
  zeroing: 技术归零五条——定位（哪个传感器/哪类测量）→机理（为何测不到）→复现（换手段重测）→措施（改进后有效）→举一反三（全星座排查）
roles:
  do: 实验员/测绘执行团队
  verify: 计算员（数据交叉验证）
  audit: 攻击手（独立风险审+验收）
  decide: 知世（主agent主持评审）
trl: 当前TRL-2/3（传感器原理设计/理论数学化）→ 节点末目标TRL-4/5
unknowns:
  - 约束强度的量级范围（Fermi量级不可估→登记；撞它：N-01实测）
  - 场本征节律频率是否落在可测频段（登记；撞它：N-01频谱测量）
```

name: 小型驱动单元原型验证（约束松弛效应）
track: exploration
chain_position:
  artifact:

    level: L2
    measurand: 目标区域约束强度变化、测试质量漂移速率、效应随功率/频率的响应曲线、效应方向性、跨尺度一致性
    tool: 空间原型平台、激光干涉测距、独立监测卫星（对照组）、精密轨道测定、拖拽补偿级环境隔离（补丁C）
    threshold:
      - 效应在既定功率上限内可测、可复现

    evidence: 原型实验报告（含对照数据、盲测记录、隔离验证、特征曲线拟合）
  decision:
    gate: go | no-go | soft-stop

## 十、未选路径（v2·相对修补的取舍）

- **未选"N-05用固定数值定义够用阈值"**：缺陷——违反保密红线（不写数值），外界可由此反推能量量级 → 否决，改用定性+量级的Q_足够。
- **未选"N-02仅加H4不改进涌现判据"**：缺陷——只加假说不改判定，H4仍会被系统性误判为H1（肯定后件谬误未消）→ 否决，涌现判据同步改为正面特征验证。
- **未选"N-05把够用验证下放到N-07"**（先go放大再验够用）：缺陷——把原理性硬停风险推迟到投入百万吨级部署后，违反"硬停前置"原则 → 否决，够用验证前置到N-05 go。
- **未选"N-05可证伪只加'硬停'不加'重启限定'"**：缺陷——硬停后无明确重启路径，或重启仍可被无限拖延 → 否决，双向（硬停触发+限定重启）。
- **未选"N-07紧急预案一并修补"**：缺陷——超出本轮3个P0任务书范围，且N-07预案属独立P1需单独设计 → 否决，留后续任务（避免本轮范围蔓延）。

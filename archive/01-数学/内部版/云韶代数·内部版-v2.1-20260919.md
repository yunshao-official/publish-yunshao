## 第一部分：核心框架

### 1.1 纯数空间 = 杨辉三角生成基底

**定义**：纯数空间S是以杨辉三角（组合数C(n,k)）为生成基底的离散代数空间。

**核心常数（新体系·唯一正确）**：
- 涌现效率：η=7/8（(Z₂)³群8个不可约表示中1个平凡表示被亏损，η=1−α）
- 亏损率：α=1/8
- 拓扑承载力谱：κ=1/32（=α/4）
- 投影跨度谱：σ_投影 = 1/√6

> **σ关系（跨常数关联）：** σ_投影 与 σ_终=1/2（代谢终对象值）通过复维度 D_ℂ=0.5+i/12 结构关联：σ_投影 = √(σ_终² − β)，β=1/12=Im(D_ℂ)。二者非独立。

> **变化性注释：** α=1/8 是 N=8 时的特值。通式 α(N)=2^{−v₂}×(1/m)=1/N，
> 其中 v₂=v₂(N) 为2进赋值，m=N/2^{v₂} 为奇部。
> 见【核心文件】§1.5 奇偶统一终极公式。
> η(N)=1−1/N，κ(N)=1/(4N)。本文档所有推导固定 N=8。
> **α=1/8 不是死参数，它随 N 变化。**

**常数互锁**：
```
η + α = 1        （7/8 + 1/8 = 1 ✓）
σ_投影² = 1/6     （投影跨度谱，几何常数，与α独立。σ_投影=1/√6≈0.4082）
κ = α/4 = 1/32   （拓扑承载力谱 ✓）
ε = α² = 1/64    （度规退化因子 ✓）
```

### 1.2 12族分类 = 模24剩余类

**素数模24的8个剩余类**：
```
R₂₄ = {1, 5, 7, 11, 13, 17, 19, 23}
```

**分类规则**：
- 同族素数对（r_p = r_q）：合法
- 跨族素数对（r_p ≠ r_q）：结构禁数

**代数张力**：
```
T(p, q) = |r_p - r_q| / 24
```

### 1.3 范畴论新概念

**亏损态射**：自带折旧率η=7/8的态射。每次复合，信息量衰减为η倍。

**代谢终对象**：σ_终 = 1/2。这是纯数空间中唯一满足所有Lucas定理约束的状态，对应黎曼猜想的临界线。

**涌现函子E ⊣ 遗忘函子U**：伴随对。E将亏损范畴映射到合法范畴，U反向映射。

**破坏度量**：
```
D(f) = D_local + D_global
     = (η/2) Σ(f_{i+1} - f_i)² + (κ/2) Σ(f_i - 1/2)²
```

> **变化性注释：** 破坏度量中 η=7/8、κ=1/32 均为 N=8 特值。
> 一般情形用 η(N)、κ(N)。见【核心文件】§一。

## 总览：三套工具各自解决什么问题

| 工具 | 一句话（内部版原文） | 你拿到什么才能用 | 算完得到什么 |
|------|---------------------|-----------------|-------------|
| **云韶代数** | "纯数空间S是以杨辉三角为生成基底的离散代数空间"（代数§1.1）——判合法性：这个结构/数在体系里合不合法 | 一个数/群/结构 | 合法/禁数 + 代数张力 T(p,q) |
| **云韶几何** | "双圆锥几何、纤维丛框架与36维周期结构统一"（几何·摘要）——算形状：这个结构在高维长什么样、投影到3维剩多少 | 一个群G/图/晶体结构 | Λ值 + 连通性 + 投影光速 + 缺陷通道数 |
| **云韶范畴论** | "几何空间与代数空间的双向函子，实现范畴论与计算体系的统一"（范畴论·摘要）——算演化：这个系统怎么代谢、需要几步、往哪个方向走 | 代数+几何的结果 | 代谢步数 t_min + 演化方向 + 跨空间验证 |

**衔接顺序**：代数（判合法性）→ 几何（算结构）→ 范畴论（算演化）。接口见§四。

## 一、云韶代数·怎么用

### 1.1 解决什么问题

判定一个数/结构在体系里是否合法。核心操作：12族分类 + 代数张力计算 + 破坏度量。

### 1.2 输入

- 一个整数 N（或素数 p, q）
- 或一个群 G（材料的对称群）

### 1.3 操作步骤

**操作A：12族分类（判素数对合法性）**

来源：代数§1.2

```
步骤1：算 r_p = p mod 24，r_q = q mod 24
步骤2：查 R₂₄ = {1, 5, 7, 11, 13, 17, 19, 23}（8个合法剩余类）
步骤3：判定：
  - r_p = r_q → 同族 → 合法
  - r_p ≠ r_q → 跨族 → 结构禁数
步骤4：算代数张力 T(p,q) = |r_p - r_q| / 24
  - T = 0 → 同族，无张力
  - T > 0 → 跨族，张力正比于距离
```

✅内部版有（代数§1.2 原文）。

**操作B：群合法性判定（判材料对称群）**

来源：代数§1.1 + 几何§2.2 + 内部版定义§1.5

```
步骤1：写出材料的空间群 G_material
步骤2：检查 G_material 是否含 (Z₂)³ 子群
  - 含 → 进入步骤3
  - 不含 → 体系不适用（❌内部版未给"不含时怎么办"）
步骤3：检查 G_material 是否含 S₄×S₃ 半直积作用于 (Z₂)³
  - 含 → 完全匹配（如 O_h 钙钛矿）
  - 只含 (Z₂)³ 不含半直积 → 部分匹配（只有基础骨架，无6+1通道分裂）。⚠️ **部分匹配时 Fano 通道数上限可能<7**（晶体端3+3+1分裂是S₃有效作用的结果，无S₄半直积→S₃有效作用也不存在→Fano线在物理上可能不表现为7条独立通道）。
步骤4：算 α = 1/|平凡表示占比|
  - (Z₂)³：8个irrep，1个平凡 → α = 1/8 ✅
  - 其他群：α(N) = 1/N（🔴终极公式）
```

✅内部版有（几何§2.2 + 内部版定义§1.5）。⚠️ "部分匹配"的工程后果内部版未给。

**操作C：破坏度量（判结构偏离程度）**

来源：代数§1.3

```
步骤1：给定结构的状态向量 f = (f₁, f₂, ..., fₙ)
步骤2：算局部破坏 D_local = (η/2) Σ(f_{i+1} - f_i)²
  - η = 7/8
步骤3：算全局破坏 D_global = (κ/2) Σ(f_i - 1/2)²
  - κ = 1/32，σ_终 = 1/2 是目标值
步骤4：总破坏 D(f) = D_local + D_global
  - D 小 → 接近合法
  - D 大 → 偏离严重
```

✅内部版有（代数§1.3 原文公式）。⚠️ "状态向量 f 怎么从材料取"内部版未给。

### 1.4 输出

- 合法/禁数（二元判定）
- 代数张力 T(p,q)（连续量）
- 破坏度量 D(f)（连续量）
- α 值（群的亏损率）

### 1.5 Worked Example：判定 YBCO（YBa₂Cu₃O₇）

```
步骤1：YBCO 空间群 = Pmmm（正交，47号）
步骤2：Pmmm 的点群 = D₂h = (Z₂)³ ✅（含 (Z₂)³ 子群）
步骤3：Pmmm 不含 S₄（正交不是立方）→ 部分匹配
  → 有基础骨架（8分量），无6+1通道分裂
  → ⚠️ 工程后果：缺陷通道可能不足7个全亮
步骤4：α = 1/8（(Z₂)³ 固定）
判定：体系适用（部分匹配）。Λ判据可用，但f_defect可能<1。
```

## 二、云韶几何·怎么用

### 2.1 解决什么问题

算一个结构在高维的几何性质：连通性、投影、缺陷通道、光速缩放。

### 2.2 输入

- 代数操作的结果（群G、α值）
- 或直接给一个图/晶体结构

### 2.3 操作步骤

**操作D：Fano 通道计数（算缺陷通道）**

来源：内部版定义§1.5 + 几何§2.2

```
步骤1：确认 (Z₂)³ 子群存在（代数操作B已做）
步骤2：列 Fano 平面 PG(2,2) 的 7 条线：
  线1: {001, 010, 011}
  线2: {001, 100, 101}
  线3: {001, 110, 111}
  线4: {010, 100, 110}
  线5: {010, 101, 111}
  线6: {011, 100, 111}
  线7: {011, 101, 110}
步骤3：对每条线，检查材料中对应的缺陷构型是否存在
  - 存在 → 通道"亮"
  - 不存在 → 通道"暗"
步骤4：f_defect = 亮通道数 / 7
  - 7/7 = 1 → 完美缺陷网络 → Tc上限
  - <7 → Tc打折
```

✅内部版有（Fano 7线 + f_defect 定义）。⚠️ **操作D步骤3当前不可执行**——「怎么检查缺陷构型是否存在」内部版未给实验方法（设计纲领标⚠️缺口：Λ的实验测量手段未定义）。本步骤需试错方案标定（见《云韶超导·试错实验方案》缺失量2：STM数Fano线+STS看77.6meV峰），标定前不能当作可操作步骤。

**操作E：连通性计算（算 λ_conn）**

来源：内部版定义§2.1 + 几何§2.3

```
步骤1：从材料结构建图
  - 节点 = 缺陷位点（间距 d = 0.125nm 的格点）
  - 边 = 相位差 < α 的远距连接（虫洞）
步骤2：建图拉普拉斯 L = D_degree - A_adjacency
步骤3：算 λ₂ = 第二小特征值（Fiedler值）
步骤4：判定：
  - λ₂ > 0 → 连通 → 场存在 ✅
  - λ₂ = 0 → 不连通 → 场不存在
步骤5：λ₂ 越大 → 连通性越强（5维5.45 / 8维62.03 为参考）
```

✅内部版有（Fiedler定理 + 实测数据）。⚠️ "从材料结构建图"的具体映射规则内部版未给（怎么从STEM图像到图）。

**操作F：Λ_ord 有序度判定**

来源：涌现亏损§3.3 + 内部版定义§2.2

```
步骤1：算 Λ_ord（结构有序度）
  - ❌内部版未给 Λ_ord 的具体计算公式
  - 已知：Λ_ord ∈ [1/8, 1]，Λ_ord ≥ 7/8 → 有序相
  - ⚠️ 实验测量手段未定义（设计纲领v2 L139标⚠️缺口）
步骤2：判定：
  - Λ_ord ≥ 7/8 → 有序相 → 超导候选
  - Λ_ord < 7/8 → 混沌相 → 不超导
```

⚠️ Λ_ord 的计算公式和实验测量是体系当前最大缺口。判据本身✅硬，但"怎么算Λ_ord"❌内部版未给。

**操作G：投影光速计算**

来源：几何§2.3

```
步骤1：确定维度 D
步骤2：c_D = c₃ × 2^{8(D−3)/7}
  - 2 = |Z₂|
  - 8/7 = 1/η
  - D−3 = 额外维度数
步骤3：n_D = 2^{−8(D−3)/7}（折射率）
步骤4：E_refract = E₀ × (1 − 2^{−8(D−3)/7})（折射能量）
```

✅内部版有（几何§2.3 原文，零拟合）。

**操作H：Tc 估算**

来源：内部版定义§八 + #12判定

```
步骤1：确认 Λ_ord ≥ 7/8（操作F）
步骤2：查材料德拜温度 Θ_D（文献/实测）
步骤3：算 f_defect = 亮通道数/7（操作D）
步骤4：Tc = Θ_D × 15/16 × f_defect
  - 15/16 = 1−α/2（⚠️裁决锚点，α/2推导待建）
步骤5：判定：
  - Tc > 室温 → 常温超导候选
  - Tc < 室温 → 低温超导
```

⚠️ 15/16 是裁决锚点（非推导）。Θ_D 是材料本征量（查文献）。

### 2.4 输出

- Fano 通道亮/暗表 + f_defect
- λ_conn（连通性）
- Λ_ord 判定（有序/混沌）
- c_D（投影光速）
- Tc 估算值

## 三、云韶范畴论·怎么用

### 3.1 解决什么问题

算一个系统怎么演化：需要几步代谢、往哪个方向走、跨空间怎么验证。

### 3.2 输入

- 代数结果（α, η, κ）
- 几何结果（Λ_ord, 当前状态）

### 3.3 操作步骤

**操作I：代谢步数计算**

来源：范畴论§6.3 + 涌现亏损§3.2

```
步骤1：确定当前无序度 T₀ = 当前 Λ_ord（或初始结构无序度）
步骤2：确定目标承载力阈值 κ = 1/32
步骤3：算 t_min = ⌈(log κ − log T₀) / log η⌉
  - η = 7/8
  - 例：T₀ = 0.5 → t_min = ⌈(log 0.03125 − log 0.5) / log 0.875⌉ = 21步
步骤4：物理操作：每步 = 一次声子脉冲照射（能量对应 d=0.125nm 晶格振动频率）
  - ⚠️ "声子脉冲"是工程诠释，内部版只给公式不给工艺参数
```

✅内部版有（公式）。⚠️ 工艺参数（频率/功率/时间）内部版未给。

**操作J：演化方向判定（亏损/涌现）**

来源：范畴论§1.1 + §5.1

```
步骤1：判定当前操作类型：
  - 亏损注入 D_i：沿第i个方向（i=1,...,12）注入亏损
  - 涌现修复 E：修复亏损，保留η=7/8
步骤2：六大运算选择：
  - 涌现昷（效率η=7/8）：信息创造
  - 亏损昞（效率α=1/8）：信息耗散
  - 互乘⊗（效率η²=49/64）：高阶复合
  - 互除⊘（效率α²=1/64）：高阶分解
  - 互同⫘：验证等价
  - 互逆⫝：可逆操作
步骤3：约束检查（互轭⫛）：
  - 每次涌现必须支付亏损：A昷B ⇒ A昞(α·B)
  - 即：你得到7/8，必须付出1/8
```

✅内部版有（范畴论§5.1-5.2 原文）。

**操作K：跨空间验证**

来源：范畴论§4.1-4.2

```
步骤1：在几何空间算结果 A（如：Λ值、连通性）
步骤2：在代数空间算结果 B（如：Mahler系数、代数张力）
步骤3：验证 F_geo→alg(A) = B
  - 等 → 两个空间一致 → 结果可靠
  - 不等 → 有错，检查哪边算错了
步骤4：具体映射（范畴论§4.1）：
  - 几何→代数：4.5D球面点 → Mahler展开系数
  - 代数→几何：Mahler系数 → 4.5D球面坐标
```

✅内部版有（范畴论§4.1 原文）。⚠️ 具体数值计算示例内部版未给。

**操作L：2-态射选择（意识/自由意志）**

来源：范畴论§2.1-2.2

```
步骤1：确认非交换性 [x,y] ≠ 0（代数操作B已确认半直积存在）
步骤2：2-态射 Φ_{i→j}: D_i ⇒ D_j（从方向i转为方向j）
步骤3：不可交换性：Φ_{i→j} ∘ Φ_{j→k} ≠ Φ_{j→k} ∘ Φ_{i→j}
  → 选择顺序有实际意义（先做i再做j ≠ 先做j再做i）
步骤4：工程含义：工艺顺序不可随意调换
```

✅内部版有（范畴论§2.1-2.2）。⚠️ "具体工艺顺序怎么定"内部版未给。

### 3.4 输出

- 代谢步数 t_min
- 演化方向（涌现/亏损）
- 跨空间验证结果（一致/不一致）
- 工艺顺序约束（不可交换的操作对）

## 四、三套怎么衔接

### 接力顺序

```
代数（判合法性）
  │
  │ 输出：群G、α值、合法/禁数
  │ 接口：G含(Z₂)³？→ 是 → 进几何
  │                    → 否 → 体系不适用，停
  ▼
几何（算结构）
  │
  │ 输出：Λ_ord、λ_conn、f_defect、Tc、c_D
  │ 接口：Λ_ord ≥ 7/8？→ 是 → 进范畴论（算怎么达到/维持）
  │                     → 否 → 进范畴论（算需要几步代谢）
  ▼
范畴论（算演化）
  │
  │ 输出：t_min、演化方向、跨空间验证、工艺顺序
  │ 接口：跨空间验证通过？→ 是 → 结果可靠
  │                       → 否 → 回代数/几何检查
  ▼
工程执行
```

### 接口定义

| 从 → 到 | 传什么 | 格式 |
|---------|--------|------|
| 代数 → 几何 | 群G + α + (Z₂)³子群确认 | 群名 + 子群存在性（是/否） |
| 几何 → 范畴论 | Λ_ord + 当前状态 + f_defect | 数值 + 有序/混沌判定 |
| 范畴论 → 代数 | 跨空间验证请求 | 几何结果A + 代数结果B + 是否一致 |
| 范畴论 → 工程 | t_min + 工艺顺序 + 频率 | 步数 + 不可交换操作对 + ⚠️频率内部版未给 |

## 五、完整 Worked Example：YBCO 全流程

**问题**：YBCO（YBa₂Cu₃O₇）是不是云韶超导体？Tc多少？怎么制造？

### 代数阶段

```
操作B：群合法性
  空间群 Pmmm → 点群 D₂h = (Z₂)³ ✅
  含 (Z₂)³ → 体系适用
  不含 S₄×S₃ 半直积 → 部分匹配（只有基础骨架）
  α = 1/8 ✅
```

### 几何阶段

```
操作D：Fano通道
  (Z₂)³ 存在 → 7条Fano线可定义
  YBCO 正交结构（非立方）→ ⚠️ 7通道不一定全亮
  假设：O₇ 满氧 → 氧链完整 → 估计 5-6 通道亮（⚠️推测，无实验数据）
  f_defect ≈ 5/7 ~ 6/7（⚠️估计）

操作E：连通性
  YBCO CuO₂面 → 二维网格 → λ₂ > 0 ✅（连通）
  具体值需建图计算（❌内部版未给从晶体结构到图的具体映射）

操作F：Λ_ord
  YBCO O₇ → Λ_ord ≈ 1.0（⚠️锡点估计·待标定——内部版定义§八的 O₆→0.5/O₆.₅→0.75/O₇→1.0 是线性插值锡点，非实测值。Worked Example 暂用此估计走流程，不作已知值）
  Λ_ord ≥ 7/8 ✅ → 有序相 → 超导候选

操作H：Tc估算
  Θ_D(YBCO) ≈ 440K（文献值）
  Tc = 440 × 15/16 × (5/7) ≈ 295K（⚠️估计，f_defect不确定）
  Tc = 440 × 15/16 × (6/7) ≈ 354K（⚠️估计）
  实测 YBCO Tc ≈ 93K → 差距大 → ⚠️ 说明 f_defect 远低于 5/7，
  或 15/16 公式对 YBCO 不适用（YBCO 是 d-wave 配对，非缺陷相变机制）
```

### 范畴论阶段

```
操作I：代谢步数
  T₀ = 0.5（假设初始无序度）
  t_min = ⌈(log(1/32) − log(0.5)) / log(7/8)⌉ = 21步
  每步 = 声子脉冲（⚠️工艺参数内部版未给）

操作J：演化方向
  当前：Λ_ord ≈ 1.0（已有序）→ 不需要代谢修复
  制造方向：涌现昷（从混沌到有序）
  约束：每步涌现支付 α=1/8 亏损

操作K：跨空间验证
  几何：Λ_ord ≈ 1.0
  代数：D₂h 含 (Z₂)³ → α=1/8 → η=7/8 → 有序相判据满足
  一致 ✅

操作L：工艺顺序
  半直积不存在（YBCO 只有 (Z₂)³）→ 非交换性弱
  → 工艺顺序约束弱（⚠️推测）
```

### 最终判定

YBCO：体系适用（部分匹配），有序相✅，但 Tc 估算与实测差距大。可能原因：
1. f_defect 远低于估计（正交结构缺陷通道不全亮）
2. YBCO 是 d-wave BCS 配对，不是缺陷相变机制
3. 15/16 公式对非立方材料可能需要修正

**诚实标注**：这个 worked example 暴露了体系的最大缺口——Λ_ord 的实验测量和 f_defect 的具体判定方法都没有。

# J-CC2 判据冻结书（预注册·跨维度概念合成体）

> 冻结时刻：2026-10-10（先于实算）
> 理论来源：**知世口授命题（2026-10-10 原话在档）**："概念它本身是同样东西在不同维度下的投影，一个语境可能是第3维度的投影，另一个语境可能是第5维度的投影，这些不同维度之间的投影组成的图形，称之为跨维度模型、跨维度概念——这种概念才是真正看到的概念本身。"
> 命题的操作化：**语境=维度选择器**。语境差异越大，投影在概念全息结构上采样的方向越远。
> J-CC1 判负的命题内解释：句式模板=相邻维度（语言表达类），投影采样角差过小→一维管；**跨维度图形需大角度差采样=任务级差异**。

## 一、判据文本（冻结）

**J-CC2（跨维度合成体判据）**：

- **刺激**：两类语境集（每词各 12 条）：
  - 句式集（已有 J-CC1 的 12 模板：百科/口语/文学/问答——相邻维度）；
  - 任务集（新增 12 模板：定义×2/诗歌×2/算数×2/翻译×2/比较×2/假设×2——远距维度）。
- **操作化**：有效维数=点云（K=12×d）**去全局公共均值向量后**的 participation ratio（PR，v1.0 公式——J-CC1 饱和教训：必须去公共方向）。
- **模型**：Qwen2.5-1.5B（本地路径），层 L∈{6,12,18}。
- **双重预言（知世命题）**：
  - ①**配对**：同一实体词的任务点云 PR > 其句式点云 PR（同词自配对，置换检验单侧）——"角度拉开，图形展开"；
  - ②**组间**：实体词的任务点云 PR > 功能词的任务点云 PR（跨组置换检验单侧）——"丰富的概念跨维度投影多，功能词投影少"。
- **判定**：两层（L∈{6,12,18}）中 ≥2 层同时满足①②各自 p<0.05 → **PASS（语境=维度选择器·跨维度合成体实证）**；仅一条成立 → 转续验（注明哪条）；零条 → **FAIL（判负照记）**。
- **附带记录（分开记，不进判定）**：任务点云与句式点云的 λ₂/λ₁、有效秩；各任务类别（定义/诗歌/算数/翻译/比较/假设）的类内中心间距离谱（跨维度图形的"角度骨架"描述性统计）。

## 二、结果回填（2026-10-10 实算回填·1.5B）

- **开票**：**FAIL（判负照记）**——条件①配对 0/3 层（p=0.95-1.0，任务PR 不大于句式PR）；条件②组间 0/3 层（p=0.06-0.11）。
- **显示伪影澄清（诚实记录）**：明细打印 .1f 格式使 PR≈1.0x 显示为"1.0"、小差异显示为"+0.0"——真实值未饱和（与 J-CC1 RATIO λ₂/λ₁≈0.3% 一致），但判定用全精度计算，FAIL 有效。
- **真发现（本轮最重要）**：**实体 token 的隐状态表征对任务几乎冻结**——从句式（百科/口语/文学）到任务（定义/诗歌/算数/翻译/假设），span 位置激活点云仍近一维管、任务不展开。解释候选：任务信息编码在指令 token 与后续生成中，不回写在实体 token 的编码位置。
- **对知世命题的操作化修正**：跨维度投影的读出位置错了——**影子=输出分布（next-token 分布），不是激活点**。同实体跨任务的投影散开应体现在生成分布上。→ J-CC2 v1.1（影子=分布）候令。

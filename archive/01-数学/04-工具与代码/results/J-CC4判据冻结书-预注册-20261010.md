# J-CC4 判据冻结书（预注册·两种距离体系对表）

> 冻结时刻：2026-10-10（先于实算）
> 理论来源：知世口授——"概念的距离跟 Token 的距离是不一样的"（2026-10-10 第一问）+ 填充性距离定义（"塞不进=极端近"·概念理论正本 v1.1 §四）。
> 命题的操作化：**两种距离体系**——d_fill（填充性距离：模型自建从属链的步数）vs d_JSD（LLM 分布距离：两概念中性影子的对称 JSD）。

## 一、实验设计（冻结）

- **概念对 20 个**：
  - 从属对 8（B 是 A 的分类上位，预期 d_fill 小）：苹果-水果/猫-动物/钢琴-乐器/茶-饮料/北京-城市/玫瑰-花/狗-动物/汽车-交通工具
  - 同层姊妹对 5（互不从属但同类，预期 d_fill 封顶但 JSD 近）：猫-狗/苹果-香蕉/北京-上海/猫-老虎/狗-狼
  - 无关对 7（预期双远）：猫-汽车/苹果-民主/茶-钢琴/时间-石头/音乐-袜子/梦-发票/猫-民主
- **d_fill 操作化**：从 A 出发以"{A}是一种"取 top5 上位概念，BFS 递归至深度 4；B 在链中出现的最短深度=d_fill；未出现=5（封顶）。纯模型自证，无人工标注。
- **d_JSD 操作化**：每概念中性语境（"请谈谈{w}。"）句末 next-token 分布（top-512 并集），对称 JSD。
- **模型**：Qwen2.5-1.5B（本地）。

## 二、判定（冻结）

- **H1（知世命题·主判定）**：d_fill 与 d_JSD **弱相关**（Spearman ρ<0.5 或 p>0.05）→ **PASS（两种距离体系分离·知世直觉实证）**；ρ≥0.7 且 p<0.05 → **FAIL（两距离同步·知世直觉判负照记）**；中间带 → 转续验。
- **H2（结构观察·分开记）**：同层姊妹对的 d_JSD 是否 ≈ 或 < 从属对（尽管 d_fill 封顶 5）——若是，记录为"分类近≠语义近/语义近≠分类近"的双向分离实例。

## 三、结果回填（2026-10-10 实算回填·1.5B）

### 开票：**PASS（两距离体系分离·知世直觉实证）**

- **Spearman 全体 20 对：ρ=0.4722（<0.5），p=0.0368**——弱-中相关，未过 0.7 同步线；未封顶子集分析因封顶对占比高（n<8）未执行。
- **H2 双向分离实例（本轮最锋利）**：
  - **猫-狗：d_fill=5（分类互不从属·封顶最远档）但 d_JSD=0.2303（全表最近！）**——分类远+语义近；
  - **苹果-水果：d_fill=1（分类极端近）但 d_JSD=0.4926（中等偏大）**——上位概念抽象化后分布反而散；
  - 苹果-民主：d_fill=5 + d_JSD=0.6412（全表最大）——一致对照。
- **三组 JSD 均值**：同层姊妹 0.3799 < 从属 0.4318 < 无关 0.5579——**同层姊妹对（d_fill 封顶最远）的分布距离反而低于从属对**——两种距离的排序都不同，分离是结构性的。
- **诚实注记**：ρ=0.47 边缘（两距离反映的语义关系有部分重叠，完全零相关不现实）；PASS 按冻结标准（ρ<0.5）成立，但"分离"的准确表述=**弱-中相关+组排序反转+杀手实例**，非"完全无关"。
- 链路径抽查：苹果→[营养,水果,常见的]；猫→[哺乳,动物]——模型自证从属链干净。

# J-U4 判据冻结书（预注册·邻域覆盖率=公式嫁接可行性判定）

> 冻结时刻：2026-10-10（先于实算）
> 理论来源：知世口授（"把权重的公式嫁接到投影仪上"）——嫁接架构=公式管质量+邻域范围管速度。
> **嫁接成立的前提**：自回归生成的概念轨迹，大部分落在初始概念的可预取邻域内（这样"只加载邻域"就够支撑生成）。

## 一、实验设计（冻结）

- **对象**：Qwen2.5-1.5B 原模型自回归生成（8 个不同主题 prompt × 40 token）。
- **概念轨迹**：生成文本每个 token 定位所属概念簇（J-CC3 宇宙 576 簇；OOV token 用 embedding 最近簇）。
- **邻域 N(k₀)**：prompt 种子词的簇 k₀ + 其 embedding top-10 邻居的簇 + 两步可达簇（预取集）。
- **覆盖率**：每条生成轨迹的概念簇（去重）落在 N(k₀)∪{k₀} 的比例。
- **判定（冻结）**：8 条平均覆盖率：
  - **>60% → PASS（邻域可承载生成·公式嫁接可行）**
  - 40-60% → 转续验（邻域半径需调）
  - **<40% → FAIL（判负照记）**
- 附记录：逐 prompt 覆盖率、轨迹访问簇数、邻域大小。

## 二、结果回填（2026-10-10 实算回填·1.5B）

### 开票：形式 PASS（p 判据满足）——**附平凡性声明**

- 8 prompt 平均覆盖率 **1.000**（全部 1.0）——按冻结标准 PASS。
- **平凡性声明（诚实）**：轨迹簇=1、邻域=1——因为主大陆簇含 147773 词（97% 词表），任何生成的 token 几乎必然落在主簇——**576 簇粒度下本判据无区分度**，覆盖率 1.0 不构成"邻域可承载生成"的证据。
- **J-U4b（真检验·挂账）**：主大陆 147773 词内部**层级细分成子概念**（J-CC3 的 50 概念粒度）后重测覆盖率——细粒度下的覆盖率才是"概念邻域可否承载生成"的真答案。设计候令。

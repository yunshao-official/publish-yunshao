## 一、结论先行

**冻结判定：六种子 PASS 数 = 0 → 按预注册 §二.4 规则判 H2。**
**同帽对照（补强实验）把解读修正为：本预算口径下"图族绑定"不成立，结论应为"图族×机制×预算三元耦合"。**

1. **主判定（冻结判据内）**：v3 管线（H 中介归位 + D2 全路径闭包 + 修补端全套）在 networkx 口径 BA 图（N=10⁵、m=5）六种子上 **0/6 清零**。六种子构造端全部完整（size=100000），断口从 44–55 收敛至 **12–46 不等，无一归零**。预注册判据的对照基准（门一网格 gen_ba 6/6 清零）出自 cap=600 档，以之为基准则 networkx 0/6 → 字面判定 H2。
2. **同帽对照（超出预注册清单的解读补强，不改变判定）**：门一网格 gen_ba 的 6/6 清零是在 cap=600 档取得（六种子修补端用时 273–447 s，**全部超过 240 s 帽**）。为排除"networkx 0/6 只是预算不够"的替代解释，本次加跑 gen_ba 侧同帽对照（原生引擎、cap=240 s、同六种子）：**同样 0/6**（断口 10–42，见 §五）。即 **240 s 等预算下两图族均不清零、断口水平重叠（gen_ba 均值 25.8 vs networkx 均值 30.0，种子级互有高低）**——"networkx 结构上不可清零"的解释被证伪，"gen_ba 已清零 vs networkx 未清零"的分离**只存在于 cap=600 档**。
3. **精确结论（本次数据支持的范围）**：① m=5@10⁵ 悬崖的清除需要 **cap≈600 档预算**（gen_ba 侧实证：240 s 不够、600 s 全清）；② networkx 图族在 240 s 帽内**不清零**且残余断口水平与 gen_ba 同帽相当；③ **"清除归因于图族"与"归因于管线"均不成立**——正确归因是管线×图族×预算三元耦合，其中预算维度为本次新证实的必要变量。预注册 §四 预写影响（H2 分支"结论加强"）按此修正执行：大论文 v2.1 §2.5 的"悬崖=图族×机制联合属性"应升级为含**预算维度**的三元表述，"gen_ba 结论外推边界" limitation 同时写入图族与预算两轴。
4. **差异来源（断口解剖，H2 分支扩展项）**：networkx 侧残余断口 **100% 单断形态**（双断顶点 0/6 案例），断口边公共邻居均值 0.92–1.00、公共邻居为 0 的断口仅 0–3 个/案例，断口间距无一相邻。即残余断口均为"有缝合材料"的形态，管线未能在帽内缝合完毕——瓶颈在**清零速度**，而非断口结构性不可缝。初步定位（未验证假设）：两生成器初始核不同（gen_ba 用 K₆ 完全图核、边数 499985；networkx 用 6 节点树核、边数 499975），叶簇规模不同（networkx 六种子度=5 叶点 28349–28684 个/图），改变了 G²[S] 结构与缝补移动的可用性；精确到移动级的归因**未验证**。
5. **诚实条款执行**：FAIL 照记；判据零改动；引擎为最小 IO 扩展版（管线代码零改动，三重等价核查见 §六）；独立验证器交叉核对 6/6 一致；networkx 生成参数原文记录（`barabasi_albert_graph(100000, 5, seed=…)`，`initial_graph` 缺省 None）。

## 八、诚实边界

1. **IO 扩展的必要性声明**：正本引擎不支持外部边表；若严格禁止任何引擎文件变动，本实验无法执行（阻塞点=引擎 IO 缺口，而非判据）。所做扩展仅 IO 层（§六三重核查），管线与判定代码零改动；对拍证据链完整存档。
2. **图族与预算两因素未完全分离**：本次在 240 s 帽内完成全部冻结判定；cap=600 档的 networkx 行为未测，故"图族绑定"与"预算不足"两个解释中，后者已被同帽对照部分证实（gen_ba 同帽同样不清零），前者既未被证实也未被证伪——H2 判定的**字面成立**不等于"networkx 结构上不可清零"。
3. **机制路径单一**：六案例 S 路线（角色划分+中间人预留）均未成功，全部由兜底 gpipe+D2 管线给出残余断口；故本实验结论适用范围 = **兜底管线口径下的清零动力学**，S 路线在 networkx 图族上的潜力未测（gen_ba 侧 S 路线同样未成功，两侧可比）。
4. **解剖归因未验证**：§四"清零速度差异"为解读层假设（初始核/叶簇→缝补移动可用性），未做移动级实验定位。
5. **单实现版本**：networkx 3.6.1（预注册冻结版本）单版本结论，不外推其他 networkx 版本的图生成行为。
6. **种子集**：六种子与门一网格同集（便于种子级对照），非独立抽样，种子级结论不外推"全部种子"。
7. **时窗敏感性**：引擎时窗按墙钟切分（§二 口径备注①），断点数在时窗边界附近有毫秒级抖动敏感性（§六.2 对拍所见）；逐种子数字应读作"该口径下的实现值"而非跨平台精确复现值。

## 十、术语字典（首次出现处已括注，此处汇总）

- **HP（哈密顿路径）**：经过图每个顶点恰一次的路径；本实验的构造目标。
- **断口**：路径序列中相邻一对顶点在原图中不是真边的位置数；=0 即闭合。
- **严格三关**：①路径长度=size=N；②顶点 0..N-1 恰一次出现（排列完整）；③全部相邻对为真边。
- **PASS**：严格三关全过且断口=0。
- **v3 管线**：门一 construction 端 v3 正规军方案：V 划分 S（主队）与 M（中间人队）→ 在 G²[S] 上构造 → 降维展开 → 修补端七类移动+tangle_fix+LNS 平台游走。
- **H 中介归位 / D2 全路径闭包**：v3 修补端的两大机制（中介点指派归位、全路径闭包修补），正本 door1_construction_v3.cpp。
- **S 路线 / 兜底 gpipe+D2**：v3 的主路线（划分+G²[S]）失败时落入的 v2 原图构造管线（mech 字段可见路径）。
- **G²[S]**：S 子集上的两步可达图（在原 G 中距离 ≤2 的 S 顶点连边）。
- **LNS**：Large Neighborhood Search，大邻域搜索扰动（端旋转/内反转/中性搬迁三类+平台游走）。
- **cap（时间帽）**：给引擎的单案例墙钟预算（秒），引擎内部按比例切构造/展开/修补/LNS 时窗。
- **cap=600 档 / cap=240**：门一网格 10⁵ 档案例所用预算为 600 s；本预注册冻结预算为 240 s。
- **gen_ba**：门一引擎内置的 BA 无标度图生成器（初始核 K₆ 完全图、端点数组优先连接抽样，边数 499985@N=10⁵,m=5）。
- **networkx BA**：Python networkx 3.6.1 库的 `barabasi_albert_graph`（初始核 6 节点树、边数 499975@同参数）。
- **图族绑定（H2）**：预注册假设之一——管线清零能力依赖具体生成器产出的结构细节。
- **管线普适（H1）/部分泛化（H3）**：预注册三假设的另两个分支（≥3/6 清零 / 1-2/6 清零）。
- **同帽对照**：让对照侧（gen_ba）使用与主判定完全相同的预算（240 s）补跑，用于分离图族因素与预算因素。
- **门一**：哈密顿路径构造攻坚项目（正本 H:\door1\），本实验管线与判定判据来源。
- **大论文 v2.1**：《大论文-精确方法在国防运筹与无标度图HP构造中的应用-v2.1-20260918》（同目录 03-论文与对外）。
- **独立验证器（验证器二）**：verify_strict_hp.py（20260917 会话），不 import 引擎代码的独立严格验证，含负面对拍自检。
- **等价性对拍**：证明 IO 扩展不改变管线语义的核查（图同构比对+端到端构造相位逐位一致+验证器自检）。
- **单断/双断顶点**：路径中恰一侧断口/两侧同时断口的顶点（双断=缝合难度更高的形态）。
- **公共邻居**：断口边两端顶点在原图中的共同邻居（可作插入缝合的候选中间人）。
- **叶点（度=m 顶点）**：BA 图中度恰为 m 的顶点（每次新点连接数下限），networkx 六种子每图 28349–28684 个。

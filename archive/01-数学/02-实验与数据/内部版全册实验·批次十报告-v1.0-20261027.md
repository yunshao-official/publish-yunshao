## 一、X-32 χ_r 单类密度与 mod 3 局域结构

### 1.1 冻结判据与首跑判词（照记，不回改）

对象：χ_r(N)=#{p≤N/2：p 素、p≡r (mod 24)、N−p 素}，r∈{1,5,7,11,13,17,19,23}；N 为偶数，对数网格 120 点覆盖 [10³,10⁶]。

| 冻结判据（v1.7） | 首跑结果 | 判词 |
|---|---|---|
| X32-a：N mod 3 ≠ r mod 3 的格中 χ_r∈{0,1} 且 =1 ⟺ r≡N−3 (mod 24) 且 N−3 素 | 624 格违反 | **FAIL（判据方向写反）** |
| X32-b：相容格（N mod 3∈{0,r mod 3}）拟合 χ_r=C_r·N/ln²N，R²≥0.95 | 8 类 R² 全为负 | **FAIL（拟合进了抑制类）** |
| X32-c：零格中"不相容"解释占比≥95% | 0/336 | **FAIL（方向写反）** |

**勘误 1（判据方向）**：q=N−p≡0 (mod 3) ⟺ N≡r (mod 3)（不是 ≠）。正确的抑制类是 **N mod 3 = r mod 3**。
**勘误 2（期望结构）**：抑制类中 q 只能等于 3，但 q=3 要求 p=N−3>N/2，与 p≤N/2 冲突；故抑制类的 χ_r **恒为 0**，不是"0/1 结构"。首跑列出的 26 个"应为 1"样本全部源于此期望错误。

### 1.2 勘误重读（同一数据，不追认原判据）

| 重读项 | 结果 | 判定 |
|---|---|---|
| X32-a′：抑制格（N≡r mod 3）χ_r 恒为 0 | **336/336 全零，非零 0 格** | **PASS** |
| X32-b′：正常格（N≢r mod 3）密度拟合 | R²=0.9079～0.9240（8 类），C_r=0.2161～0.2301 | **FAIL（未达冻结 0.95 阈值，不外推）** |
| X32-c′：零格由 mod 3 抑制解释的占比 | **336/336=100%** | **PASS** |

正常格密度表（窗口 [10⁵,10⁶] 过原点拟合）：

| r | 1 | 5 | 7 | 11 | 13 | 17 | 19 | 23 |
|---|---|---|---|---|---|---|---|---|
| C_r | 0.2161 | 0.2301 | 0.2208 | 0.2295 | 0.2200 | 0.2288 | 0.2201 | 0.2292 |
| R² | 0.9213 | 0.9084 | 0.9146 | 0.9083 | 0.9203 | 0.9079 | 0.9195 | 0.9240 |

计数自洽（实现校验，非判据）：Σ_r χ_r(N) 与独立哥德巴赫计数 G(N) 逐点相等——N=10⁵: 810=810；N=5×10⁵: 3052=3052；N=999990: 11143=11143。

### 1.3 结论

1. **X-29 "每类约 1/3 空格"获结构性解释**：不是公式缺陷，也不是小 N 边界效应，而是 mod 3 局域障碍——N≡r (mod 3) 时 q=N−p 被 3 整除、且 q=3 与 p≤N/2 不相容，故该类恒空。空格率 1/3 与偶 N 的 mod 3 三态均匀分布精确对应。
2. **单类密度形态近似成立但未达冻结阈值**：C_r 稳定在 0.216～0.230、8 类差异 ≤6%，但 R² 0.908～0.924<0.95，按纪律判 FAIL，不升观察级；数值密度表已落 JSON，可供注记层引用（"Hardy–Littlewood 猜想级"标签维持）。
3. **"单类逐 N 非空"仍禁入正文**（X-29 判决维持）；修复双轨不变：①并集存在性（=哥德巴赫）②单类密度（本表为数值支撑，非证明）。
4. **已回写（20261027 知世令"数据怎么样就做成什么样"）**：mod 3 结构结论按数据原样写入几何 v2.2 附录B·补记（L962），含冻结判负、两处勘误、逐类 R² 与阈值不放宽的声明；密度臂判负未作任何修饰。

## 二、X-33 26 边图完整枚举与同构类收口

### 2.1 结构性化简（本轮新得，非判据）

对 12 节点图，Laplacian 的三阶矩有恒等式

  **tr(L³) = Σ_v d_v³ + 3Σ_v d_v² − 6T**（T=闭三角形数）。

目标谱 {0,1,3,4,4,4,5,5,5,7,7,7} 给出 tr(L³)=1624；度序列（4 个节点层间度 2、8 个节点层间度 1，即度 5×4、4×8）给出 Σd³=1012、Σd²=228。于是 **1624 ⟺ T=12**。而三层 K₄ 本身已贡献 4×3=12 个三角形，故：

> **目标谱强制：任何层间边都不得参与三角形**（否则 T>12）。

这条由谱导出的约束使枚举空间从"约 10⁹"降到 45 万级，且剪枝是**精确的**（非启发式）：任何含层间三角形的构型必被排除。

### 2.2 完整枚举结果

| 项 | 值 |
|---|---|
| 枚举方式 | 495 个"层间度 2"四元组 × 残余度回溯配边（仅跨层、无重边、无层间三角形）；**无封顶** |
| 完整标记构型 | **451,008** |
| p₄=9928 且 p₅=63112 通过 | **1,728** |
| 逐位谱命中（容差 1e-9） | **1,728** |
| 同构类数 | **1** |
| 类 Aut 阶 | **48** |
| 层间边分布（L0-L1 / L0-L2 / L1-L2） | **4 / 4 / 0** |
| 轨道校验 | 群阶 82,944 ÷ Aut 48 = **1,728**，与命中数**逐数相等** |

**代表构型**（与裁决六正典同构）：`(0,4),(0,8),(1,5),(1,9),(2,6),(2,10),(3,7),(3,11)`；裁决六正典 `(0,4),(0,8),(1,6),(1,10),(2,7),(2,9),(3,5),(3,11)` 经层内重标号与之同构（机器核验 iso=True）。

### 2.3 判词

- **X33-a 完整性 PASS**：完整枚举、无封顶；451,008 个标记构型全部过检。
- **X33-b 同构类数 PASS（=1）**：目标谱在"三层 K₄ + 8 条层间边 + 度序列 4×2/8×1"类中**唯一确定图**（至同构）。
- **X33-c 正典 PASS**：裁决六枢纽星型构型在类中，Aut=48、T=12、层间 4/4/0、谱逐位吻合。
- **升级判词**：X-17 的"唯一性=采样级证据（3×10⁶×78 命中全落一类）"**升为完整枚举级唯一**——本类共 451,008 个标记构型，命中集恰为 1,728 个标记 = 一个完整轨道，无第二类。

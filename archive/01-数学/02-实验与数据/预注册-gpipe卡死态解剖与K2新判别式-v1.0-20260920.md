## 二、甲：gpipe 卡死态解剖运行定义（跑前写死）

- **插桩版**：新源 `04-哈密顿路径\04-工具与代码\v3_construction_nx_m1v2ganat-v1.0-20260920.cpp` = m1v2anat v1.0 正本源**全量逐字保留+纯增量行**（乙18/第5轮插桩铁律同款）：①新全局 `g_gpipeExit` 原因码（纯增量赋值：`-1`=gpipe 未跑；`0`=走完 size==N；`1`=deadline 退出；`2`=force_splice 失败 break）；②g_construct 循环内 tick 采样（约每 10s 一条 `gptick`：t/path.size/段内 rev 增量）；③g_construct 返回后、constructComplete 判定处新增只读 dump `anat_gpipe_dump`（**g_gpipeExit≥0 即 gpipe 实跑过才 dump**；只进 --anat JSONL，stdout 零改动）。**--anat 关闭时行为与 m1v2anat v1.0 全同**（全部增量行旗标门控）。
- **dump 内容**（每条 JSON，t=案例内秒）：
  - `gptick` 行：`{"k":"gptick","t":..,"size":..,"rev":..}`（rev=gpipe 段起点起累计）；
  - `gpsum` 行（汇总）：`{"k":"gpsum","exit":..,"size":..,"nMiss":..,"g0":..,"g1":..,"g2":..,"g3":..,"g4p":..,"endAny":..,"pinchAny":..,"slotTot":..,"gpT":..,"rot":..}`——g 分布=missing 顶点按 g(u)∈{0,1,2,3,4+} 计数；endAny=end(u)≥1 的 missing 数；pinchAny=pinch0(u)≥1 的 missing 数；slotTot=Σslots(u)；gpT=gpipe 段墙钟；rot=rotTotal 累计；
  - `gpv` 行（明细，每 missing 顶点一条，按 id 升序，防御上限 5000 行）：`{"k":"gpv","id":..,"deg":..,"g":..,"end":..,"pinch0":..,"slots":..}`。
- **形态计数精确定义（冻结）**：对 missing 顶点 u（终态路径外顶点）、路径 P（长 n）：
  - `g(u)` = |N(u) ∩ P|（缝合抓手数=路径邻接数）；
  - `end(u)` = |{P[0],P[n-1]} ∩ N(u)|（端接数，extend 类的图条件）；
  - `slots(u)` = Σ_{w∈N(u)∩P} [ pos(w)∈{0,n-1} ? 1 : 2 ]（force_splice 可插位置数；g≥1 ⟺ slots≥1）；
  - `pinch0(u)` = 满足以下**全部**条件的有序对 (h1,h2) 计数：h1,h2∈N(u)∩P，G.has(h1,h2)，j=pos(h1)，k=pos(h2)，j+1<k，且 [ (k+1<n ∧ G.has(P[j+1],P[k+1])) ∨ (j-1≥0 ∧ G.has(P[j-1],P[k-1])) ]（pinch_place 零断口插入的图条件全集，与引擎实现逐字对应）。
- **案例集（小样）**：m4@1e5 seed∈{7,42}（判定材料）+ m5@1e5 seed=7（完整态对照，描述性）。臂=第 5 轮解剖跑同款 `--m1` 单旗标，cap=600s，边=内置 genba。工作区 `H:\door1\gpipeanat_20260920\`（anat\、logs\、jsonl\）。
- **对拍门 G-0（先于判定材料采信）**：
  - ①**锚点**：新二进制 --anat 开态，m4@1e5 s7/s42 + m5@1e5 s7 三跑的 stdout `[att*]` 行与第 5 轮解剖跑同案例（`H:\door1\m4anat_20260920\logs\a_N100000_{m4_s7,m4_s42,m5_s7}_m1.log`）逐字一致；jsonl 除时延字段全同。FINAL 行 size 属墙钟敏感带（第 5 轮已注记），锚点以 [att*]/[ANAT2-rep0] 构造决定性行为准，FINAL 差异如实注记不进门；
  - ②**anat 旧行型前缀**：新 anat JSONL 中旧行型（expsum/led/fm/rep0/fin2/case/phase/move/FINAL）与第 5 轮同案例 anat（`m4anat_20260920\anat\`）逐行一致；新增行仅 gptick/gpsum/gpv 且仅出现在 gpipe 实跑案例；
  - ③**关态全同**：--anat 关，m4@1e3 s7 一跑，stdout 与 jsonl 同第 5 轮关态跑（`a0_off/a0_off2`）全同（同前：att5 PARTIAL defects 计数=截止期截断固有墙钟属性，off-vs-off 自比同样漂移，按第 5 轮口径注记）；
  - 门不过→新插桩版判负，本轮解剖不采信。
- **长算分片**：三跑并行一波（cap 600s，m4 gpipe 段 deadline≈0.85·cap 前自退出，全批 ≤12 分钟），每案例独立 jsonl/anat 即检查点。

## 三、甲判据（冻结）

- **P-1 判定态定义**：判定材料=每案例 gpipe 终局 dump（gpsum+gpv 全体）；gptick 序列作过程佐证（描述性）。m5 对照只描述不判定。
- **P-2 退出原因（控制流事实，先记）**：exit 码∈{0,1,2} 直接入账；m4 判定案例预期 exit∈{1,2}，若 exit=0（走完）则该案例无卡死态、如实记录（判定转移至对照分析）。
- **P-3 三分主判据（判定顺序冻结）**：
  - **P-3a 形态维度（先判）**：记 q0 = |{u∈missing : g(u)=0}| / |missing|，q1 = |{u : g(u)≥1}| / |missing|（q0+q1=1）：
    - q0 ≥ 0.8 → **结构死角**（missing 与路径零邻接为主=移动无入口的结构形态；乙13 终审材料升级）；
    - q1 ≥ 0.8 → **形态普遍存在**，进 P-3b；
    - 之间 → **混合带**：按占比大者记主导方向+"混合"标签，如实入账；
  - **P-3b 原因维度（q1≥0.8 时）**：
    - exit=1（deadline）→ **缺预算（子窗口效率枯竭）**——形态在、时间烧完；乙13"非预算"读法判负，预算问题按"0.30·cap 子窗口份额×终局段每有效移动墙钟成本"重开（与乙13 §六.2 悬案合流）；
    - exit=2（splice-break）→ **缺移动类**——形态在、移动类实现（leaf 80 步窗/pinch 16 hub 窗/随机反转 400 试）未吃到；
  - **佐证（描述性，不判定）**：slots/pinch0/end 的分布（形态的质量）、gptick 的 size 增长曲线与 rev 消耗（终局段效率画像）、missing 均度与晚生占比（对接 D-2 孤岛形态）。
- 全部为纯算法实验，[constants:v1.0] 零涉及；体系机制层不进推导链。

## 四、乙：K2 新判别式候选 D-K2b 复算定义（跑前写死）

- **判别式 D-K2b（冻结公式）**：对案例 c，m1 臂启动条件三条件**合取**：
  1. **G1 完整性**：base 终态构造完整（size=N）；
  2. **G3 尾巴闸**：base 修复起点断口 b0 ≤ 100（尾巴案例；量级依据=第 5 轮实测 m5@1e5 s7 b0=57 vs m=3 案例 b0=90-1351，取分界 100）；
  3. **G4 材料闸**：c1_path / b0 ≥ 0.5（cmn==1 材料占断口半数以上；依据=m5 s7 实测 56/57=0.98）。
- **验证集（零重跑，全在档）**：m=3 十二完整案例（1e3×6+1e4×6，第 5 轮 K-A2 复跑 rep0 谱+网格 v4 归档双轨胜负）+ 1e5 残缺六案例（G1 全挡）+ m5@1e5 s7（第 5 轮解剖跑 rep0 谱 c1=56/b0=57+归档 M1 修复清零证据）。
- **数据源**：`H:\door1\m4anat_20260920\k2\k2_account.json`（b0/b1/胜负/时长）+ `k2\c1_path.json`（c1_path）+ 第 5 轮 anat rep0 行（b0=rep0 brk 校验）——不重跑引擎。
- **验证协议（冻结，同第 5 轮 D-K2 同款）**：逐案例按 D-K2b 判"规则是否启"，对照 m1 臂实际胜负（m1 b1 < base b1=赢；m5 s7 的实际=归档 M1 修复清零证据，按赢记）。混淆矩阵 + 规则下节省墙钟 + 交付差（规则交付 vs 双轨取优交付）全量入账。

## 五、乙判据（冻结）

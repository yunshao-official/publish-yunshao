## 三、判据（冻结）

- **B-1 网格主判据**：v4 账以 `grid_v4_report.json` 落盘，与 v3 账逐案例对照（65/90 基准）。预期方向如实入账、**无方向预设、无 FAIL 条款**：m5@1e5 预期 6/6 pass（引擎自报 pass=true 且 breaks1=0；独立三关抽查 ≥2 条甲=0）；m4/m6/m7 与 m=3 的任何变化（升/降/平）逐案例入账。
- **B-2 m=3 判据（K2 口径）**：每案例交付值=min(base, m1)（并列取 base）。交付值 < v3 同案例 breaks1 → 改善入账；18 案例交付值全部 ≥ v3 且仍 fail → "m3 全灭维持"如实入账。
- **B-3 完整性判据**：90 案例全有最终记录（pass 或 fail 均算）→ v4 账完整；否则按 §二收尾线交付部分账（覆盖范围显式标注，缺案例名单入账）。
- **D-1 边谱判据（m4 解剖主判据）**：对 m∈{4,5}×seed∈{7,13}@N=10⁴ 四张 genba 同口径图（1e5 图生成成本高、1e4 谱已足辨机制，边谱无墙钟依赖），计算全边公共邻居数谱 cmn(e)∈{0,1,≥2} 占比。**若 m4 的 cmn≥1 边占比 < m5 对应占比 − 10 个百分点 → "expand 候选池干涸"机制定位成立**（S 边候选=S 端点对公共邻居，谱塌缩即匹配池干涸的直接证据）；差 ≤10pp → 该假设判负照记（死角在 S 路径形态/配比层，本轮机制定位未达，如实挂账）。
- **D-2 残缺解剖（描述性，无判负）**：v4 网格 m4@1e5 六跑 `--out` 残缺路径：missing 顶点集合的度数分布 vs 全图度数分布、missing 规模、missing 集合诱导子图连通类数。只描述不判。
- **D-3 定量归因链（小样）**：seed=7 一例完整链：D1 谱 → expand 左节点候选期望（S 边候选=S 路径边端点公共邻居的近似上界估计，用全边谱代替）→ 与实测匹配率 22% 对照定性闭环。近似口径如实标注。

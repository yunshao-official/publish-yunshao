# 预注册 · 引擎默认值切换 v2.0（grd0.85+E-让位主线化）v1.0

> **判据冻结后任何改动=新预注册 v2.0 之 v2.0 重写（即 v2.0 版本线），禁改本件。**

## 一、动机（一段话）

M1 全链证据已闭合：grd=0.85 五观测全清零坐实（稳定性确认报告）、E-让位发射零代价结构保险成立（乙16 报告）。二者仍以旗标显式参数存在（默认值 0.55/mech 关），每次调用需带四旗标。本预注册把已证配置写入引擎默认：**新正本引擎下 `--m1` 单旗标即为完整最优配置**，消除参数脆性的最后一环（调用方记忆负担）。

## 二、改动定义（跑前写死，实现不得偏离）

新文件 `v3_construction_nx_m1v2-v1.0-20260920.cpp`（基座=m1mech 版逐字保留），仅三处：
1. `g_m1Grd` 默认值 0.55→**0.85**（显式 `--m1grd` 仍可覆盖）。
2. `--m1` 启用时 E-让位等效开启：`g_m1mech` 默认值 0→**2**，且 E-让位检查**追加 `g_arm==1` 条件**（M1 未启用时不让位——修复 m1mech 版潜在的非 M1 臂行为泄漏；显式 `--m1mech 0` 仍可关闭）。
3. case 日志 eng 字段=v3x-m1v2-v1.0。其余（管线/移动类/TG-NEU/LNS/日志 schema）零改动。

## 三、对拍门（三门，先于回归跑）

- **门①零漂移**：新引擎全关（无 --m1），乙18 §2 门口径六案例 cap=60 vs 在档 gate3_base_* 逐位（breaks0/breaks1/size/defects/pass）——验证默认值改动不触非 M1 路径。
- **门②等价**：新引擎 `--m1`（新默认）vs m1mech `--m1 --m1grd 0.85 --m1mech 2`，六案例 cap=60：m5 系+m4s7 逐位（breaks0/breaks1）；m3 两案例 breaks0 逐位+breaks1 波动带口径（在档观测带 234–237，差 ≤3 注记不判负）。
- **门③非 M1 臂保护**：新引擎 `--hb`/`--hc`（六案例各抽 2）vs m1scan 同旗标在档行为——breaks0/breaks1 一致（验证让位的 g_arm 条件修复：非 M1 臂零触达）。

## 四、回归确认与判据（冻结）

- 回归确认=主组 m5@1e5 六种子（cap=600s，在档边表）新引擎 `--m1` 单旗标一次：**6/6 ALLPASS**（breaks1 全 0+独立三关抽查 2 条甲=0）。
- **主线化完成判据**：三门 PASS 且回归 6/6 ALLPASS → M1 全链收官（归因→移动→调参→稳定性→机制化→主线化），引擎默认值切换完成，后续所有哈密顿线实验以 m1v2 为正本引擎。
- 任一门 FAIL 或回归 <6/6 → 停，如实分账（m3 波动带案例允许在带内波动，不因单案例带内波动判 FAIL），修后重门。
- 纯算法实验，不涉 [constants:v1.0]；体系机制层不进推导链。

# 预注册 · v3管线×networkx口径对照实验 v1.0

> 性质：预注册（判据先于数据，开跑后零改动）。执行：夜间子代理窗口（待派）。来源：猜想C判负报告诚实边界②+门一战报§八口径声明。
> 决策人：知世（默认授权轨）｜ 撰写：ZCode ｜ 2026-09-18

## 一、动机（单一问题）

门一 v3 管线在 **gen_ba 图族**清零 m=5@10⁵（6/6 严格 PASS）；同参数 **networkx 图族**上，v2 管线 0/3 不闭合（预注册复现裁决 20260917）。未测的组合是 **v3 管线 × networkx 图族**。三种可能：
- H1（管线普适）：v3 机制（断口解剖→中介归位→全路径闭包）是图族无关的，networkx 也清零→"悬崖清除"主要归因管线；
- H2（图族绑定）：清除依赖 gen_ba 的结构细节（如端点数组抽样的度序列细节），networkx 仍不闭合→"悬崖=图族×机制联合属性"结论加强，且 gen_ba 结论的外推边界被精确刻画；
- H3（部分泛化）：部分种子闭合→记录闭合种子的图特征（度分布/叶簇结构），定位差异来源。

## 二、冻结判据（开跑后零改动）

1. **图**：networkx 3.6.1 `barabasi_albert_graph(N, m, seed)`，N=10⁵、m=5，种子 {7,13,21,42,99,2024}（与门一网格同种子集，便于种子级对照）。
2. **管线**：door1_construction_v3.cpp 修补端全套（H 中介归位+D2 全路径闭包+tangle_fix+LNS 平台游走+失败去重持久链），构造端 v2.5 全套；输入边表由 networkx 图导出（格式与 gen_ba 边表一致）。
3. **预算**：每案例时间帽 240 s（与门一 10⁵ 档一致）；构造窗按 v3 同比例（0.30·cap）。
4. **判定**：严格三关（size=100000/顶点恰一次/逐边真边）+断口=0 → PASS。六种子 PASS 数：**≥3/6 → H1；0/6 → H2；1-2/6 → H3**。
5. **扩展（可选，主判定后）**：若 H1/H3，加跑全网格 90 案例（networkx 版）给出 m–N 平面图；若 H2，加跑断口解剖记录（公共邻居均值/双断顶点数）对照 gen_ba 解剖结果，写差异来源。
6. **诚实条款**：FAIL 照记；判据零改动；结果与解读分离；networkx 生成参数（initial_graph 缺省）原文记录。

## 一、动机（从乙18数据到设计，一段话）

乙18 实锤卡死形态：两卡死案例（s99 残余 43、s2024 残余 30）终态**每断口恰 1 个公共邻居**（cmn 全=1），而结构类五移动（A/B/B2/H/F）触发候选全 0、D2 只试前 2 对且失败即跳、R 带变异全失败——**缝合材料存在但没有移动能用它**。清零对照 s42 的成功模式=D2 大旋转（单次 rot 峰值 30377，"绕过障碍"式缝合）生效 30 次。H-A：低度顶点单邻居断口需要"强制走唯一公共邻居 w + 大旋转重排"的专用移动，即 M1。

## 二、M1 机制定义（伪代码级，实现不得偏离）

```
M1(i):                        # i=断口位置，断口=(path[i],path[i+1])=(u,v)
  W = common_neighbors(u,v)
  if |W| != 1: return skip    # M1 只攻单邻居断口（乙18卡死形态 cmn=1）
  w = W[0]
  (a, b) = path_neighbors(w)  # w 当前路径邻居（w 不在 u,v 位置时才可动；在则 skip）
  # 第一步（断口暂时 +1）：断 a-w、w-b；接 u-w、w-v
  #   ——原断口 (u,v) 缝合；产生两个新断点 (a,·) 与 (·,b)（路径两处断开）
  # 第二步：Pósa 式旋转重排——从 a、b 两断端各自沿路径滑动，
  #   逐对尝试 (a,b) 直连或经局部段翻转后直连（与 D2 双断口闭合同法）
  # 冻结参数：rot 预算 = 50000 / 次（=s42 D2 单次峰值 30377 × 1.6，覆盖其分布尾部）
  # 终止：重排闭合（净断口 −1，M1 生效）或 rot 预算烧完（整步回滚，M1 失败，记 skip+原因）
M1-2（备选变体）：双断口协同版——取断口对 (u,v)、(u',v')，其唯一公共邻居 w 相同
  （乙18 s2024 存在相邻断口对 adjacentBreakPairs=1 的形态），一次重排同缝两口。主臂 M1
  三案例零生效时才启用 M1-2（顺序冻结，不得并行试多版本）。
```

## 三、三臂对照设计（一次预注册同时检验 H-A/H-B/H-C）

| 臂 | 操纵 | 检验假设 | 冻结参数 |
|---|---|---|---|
| 主臂 M1 | 插桩引擎加 M1 移动类（排在 D2 试完之后、R 之前） | H-A | rot 预算 50000/次；每断口 M1 尝试上限 3 次/修补轮 |
| 预算臂 H-B | TG-NEU 预算 400→0，回收预算给修补轮 | H-B | 其余不动 |
| 扰动臂 H-C | LNS 扰动深度加倍（半径×2） | H-C | 其余不动 |
| 基线 | 乙18 插桩版原样重放 | — | 已有数据（43/30），不重跑 |

三臂各自独立跑 s99、s2024（600s 档，边表同乙18，sha256 在档），共 6 次运行；对照基线取终态断口与 M1 生效数。**臂间不组合**（组合归下一轮，避免归因混淆）。

## 四、判据（冻结，跑前写死）

- **主判据（H-A 存活）**：主臂 M1 在 s99 或 s2024 任一案例 M1 生效数 ≥1 且终态断口 < 乙18 基线（43 / 30）。
- **H-A 判负**：两案例 M1 均零生效，或终态断口 ≥ 基线。判负照记，诚实账本入档。
- **H-B/H-C 判定**：同格式（终态断口 < 基线 = 对应假设存活；否则判负）。
- **中间态风险预写**：M1 先 +1 后重排属冒险移动——若 M1 尝试多而生效少，成功率与净断口增量双指标如实分账，不因"尝试了"记存活。
- **完备性判据**：M1 每次尝试一条日志（成功/失败+rot 消耗+断口增量），零遗漏；插桩铁律同乙18（纯增量日志行），对拍门（原版 vs 新插桩版 breaks0 一致性）先于正式跑，6 案例口径同乙18 §2。

## 七、术语字典

- **M1** → 本预注册设计的单邻居强制缝合移动（Mononeighbor-sew）。
- **Pósa 旋转** → Pósa 1976 提出的哈密顿路径重构技术：断路径一端并沿路径滑动重接（引擎 R/旋转类的已证基础技术）。
- **D2** → 引擎既有双断口缝合移动（只试前 2 断口对、失败即跳；s42 清零主力，单次 rot 峰值 30377）。
- **rot** → 引擎累计旋转次数（时间依赖量，仅单次运行内有效）。
- **cmn** → 每断口公共邻居数（缝合材料存量）。
- **H-A/H-B/H-C** → 乙18 立的三条逃逸假设：材料-触发错配/预算错配/扰动深度。
- **臂** → 对照实验中的一个独立操纵组（三臂互不组合）。
- **对拍门** → 插桩版 vs 原版引擎同输入 breaks0 一致性前置验证（乙18 §2 口径）。

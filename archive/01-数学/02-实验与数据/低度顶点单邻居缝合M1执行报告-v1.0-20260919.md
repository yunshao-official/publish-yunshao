## 五、解读层（与数据分离；本节为机制解释，不构成判定）

1. **为什么 M1 能解锁**：乙18 三问已证卡死=断口材料在（cmn=1）而所有既有移动触发条件错配。M1 是唯一"以 cmn=1 为正面触发条件"的移动——错配维度从障碍变成专属燃料。生效率 85–87%、零变差（37 次生效 d 全 ≤−1）说明该机制与卡死形态精确互补。
2. **为什么 s99 能全清零**：M1 生效 23 次把断口打到既有 D2 大锤的舒适区（≤3 断口门常开），D2 随后 16 次生效收尾；且全程未进入 tangle/LNS（基线在这两阶段烧掉 11s+400 次预算与 ~90 轮空转）——修复主阶段直接收敛，t_rep 提前 285s。**机制链=M1 破错配 → D2 收尾**，不是 M1 单类移动包打。
3. **为什么 s2024 停在 10**：修复主阶段 M1 生效 17 次后进入 tangle（TG-NEU 400 照烧零增量）与 LNS；lns_inner 空转轮 M1 仅获 3 次生效——冻结参数（3 次/断口对/调用 + 0.55 护栏）在 LNS 阶段限住了 M1 的窗口，而残余 10 断口形态仍是"cmn=1 材料、结构类零触发"（§3.4）。这不是机制失效，是**窗口配给**问题——正是 M1-2 双断口协同变体与调参的靶点（预注册冻结顺序：主臂非零生效，M1-2 保持未启用，本次未动 ✓）。
4. **m=3 病态案例的风险面（门跑）**：断口密集态（200+ 断口）下 M1 生效会改写轨迹且可能落更差盆地——M1 当前"每次生效即落定"无 keep-best 回护。在 m=5@1e5 稀疏卡死形态未观察到该效应；若向密集态推广，需加 keep-best 或生效后即时复核。
5. **对三元的修正**：乙14"三元耦合（预算/结构/搜索互相锁死）"经本轮三臂对照精确化为——**结构维（触发条件错配）是主导锁，预算/扰动维只是伴生噪声**。解开主导锁后，预算维（TG-NEU 400）在 s99 根本没被消费。

## 八、术语字典

- **M1** → 单邻居强制缝合移动：断口 (u,v) 恰 1 个公共邻居 w 时，拔 w 插入 (u,v) 间缝合原断口、拔出侧用 D2 同法闭合计重排的专用移动（本报告主角，预注册 §二 伪代码级实现）。
- **三臂** → 主臂 M1（加 M1 移动类）/ 预算臂 H-B（TG-NEU 预算 400→0）/ 扰动臂 H-C（LNS 扰动半径×2），臂间不组合。
- **H-A/H-B/H-C** → 乙18 立的三条逃逸假设：材料-触发错配 / 预算错配 / 扰动深度。
- **对拍门** → 原版引擎 vs 新版引擎同输入 breaks0 一致性前置验证；本轮双门=零语义漂移门（M1 关闭全字段比对）+冻结门判据（M1 开启 breaks0 比对）。
- **断口（break）** → 路径中相邻两顶点在原图中不是真边的位置；breaks0=修补前、breaks1=修补后残余；断口=0 即合法哈密顿路径。
- **严格三关** → size=N / 顶点恰一次 / 逐边真边，三关全过才 pass=true。
- **甲 / cross** → 独立严格三关验证器的断口计数 / 其与引擎自报 breaks1 的一致性。
- **D2** → 引擎既有全路径闭合计移动（"大锤"，s42 清零主力）；**TG-NEU** → tangle 阶段中间人中性搬移（只解缠绕不清口）；**LNS** → 大邻域搜索扰动（mode0 端旋转/mode1 邻域内反转/mode2 中性链）。
- **rot** → 引擎累计旋转次数（时间依赖量，仅单次运行内有效，不可跨运行比较）。
- **cmn** → 每断口公共邻居数（"缝合材料"存量）。
- **why 码** → M1 尝试失败原因：1=公共邻居数≠1，2=w 在路径端点，3=rot 预算烧尽回滚，4/5=防御性理论不可达。
- **BA 图** → Barabási–Albert 无标度随机图（N 顶点、m 每新顶点连边数、seed 随机种子），本线标准测试图族。

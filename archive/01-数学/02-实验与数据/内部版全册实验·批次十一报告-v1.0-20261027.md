## 二、三项新诊断（本轮真正的产出）

**诊断①｜三重简并障碍（结构性，非数值巧合）。** 正典图在本算子族下的**最高本征值恒为三重简并**——实测 θ_inter ∈ {0, π/4, π/3, 0.723, π} 全部 top_mult=3。原因在图本身：层内三块 K₄ 全同、L1 与 L2 的连接型相同（各自经 4 条边接到 L0 的同一编号节点），故"层内零和模"×3 与 L1↔L2 交换对称共同给出三重最高本征值（θ=π、V=1/12 时谱 = 51.667×3, 37.667×3, 30.667×3, 23.667, 9.667, 2.667）。
后果：档案把"第二泛弦比例"读作 λ₀/λ₂=最大/次大，而次大恒等于最大 ⇒ **该读法在此对象上恒为 1，与 1.44 相差 30.6%，且无任何参数能把它拉过去**。这是可写成引理级别的障碍，不是"还没调好"。

**诊断②｜144 是"准零模"产物，不是结构比例。** 沿 R₁=144 曲线回代：θ_inter=π 时需 V=−0.209572，此时谱为 (最大 42.3)/(最小非零 0.294)=144.00——即 144 完全靠**把最低本征值推到接近 0**得到（算子对角项加常数 = 整体平移，实测平移平凡性 5.3e−14，见 X34b）。档案原声称值同型：λ₁=0.1973 相对 λ₀=28.4152 也是准零（比值 144.02）。
后果：**"λ₀/λ₁=144"这类大比值在本族算子上是近奇异性指标，不携带对称性信息**；任何 (θ,V) 都能造出 144，因此该声称原本就不可证伪。这比 R20 的"不可复现"更根本：即便复现了也不构成证据。

**诊断③｜双锚点自相关。** CO₂ 9.6μm 线（31.2284 THz）与 976nm 泵浦带（307.1644 THz）的**频率比=9.836**，与档案拟合用的十进制移位"10"只差 1.6%。即：两条真实谱线本身就近似相差 10 倍，所以"÷12 与 ÷1.2"只要撞上其中一条，另一条几乎必撞。
后果：**双锚点提供的独立信息≈1 条，不是 2 条**；X6-a/X6-b 双双 PASS 的表面强度需按一条计。

## 三、判负与失效登记

1. **调和分析 ch10.2/ch12「代码验证通过、偏差<0.1%」**：本轮在唯一正典图上 0 命中（X34-a1/a2），与 0906 证明官五配置复算不可复现（R20）**同向叠加**，`reviewed=false` 维持，解冻前"验证通过"仍不得作已验证事实引用。
2. **ch11「存在多组参数可同时满足两个泛弦比例」**：在正典图+冻结读法下**判负**（0 解，非多解）。档案该句出自未固定的矩阵对象，本轮把对象钉死后其宣称不再成立；不静默改原文，挂待裁。
3. **V_active=+1/12（新体系反推值）**：与谱要求**反号**且在可达区间外；而谱要求（−0.21 量级）与旧体系第一性推导值（−0.829）**同号**。数据指向"V_active 应为负"，与 ch9.3「新体系第一性推导失败、退回正值 1/12」构成同一处硬矛盾的两半。
4. **f₁/f₂ 物理锚点**：口径不鲁棒（350K 下偏差 24.55%/26.63%），按 20261006 方案 C 降为挂账，不得作已验证事实引用。
5. **不判负的两条**：144 的群论计数来源（三条同值，PASS）；280K 口径下 X6-a/X6-b 按其自身冻结容差仍为历史 PASS（本轮只判"是否口径鲁棒"，不改史）。

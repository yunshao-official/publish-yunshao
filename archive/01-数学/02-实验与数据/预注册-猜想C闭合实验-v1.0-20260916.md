## 一、被检验命题的操作化

对每个通过容量检验的实例 G=BA(N,m,seed)：
- **存在性半边**：在冻结预算内构造出严格 HP（断口=0，双独立验证器 STRICT=PASS，口径同 m5e5 预注册件 §二）；
- **深度半边**：闭合深度 Λ（计数口径见 §三）满足 O(polylog N)（操作判据见 §四斜率冻结）。
- 两半边同时满足 → 该格点"存活"；任一半边失败 → 该格点"判负证据"。

## 二、容量检验判据（定理 A 证书口径，冻结）

1. **低度集**：L_d = {v : deg(v)=d}，取 d=m（BA 图最小度顶点集）；预注册先验校验 L_d 为独立集（BA 生成序保证同批老顶点互不连边，仍逐实例验证，非独立集则弃 d 改用最大独立低度集并记录）。
2. **流网络**（V2.0 §二定理A原文原样）：源→每 l∈L 容量 2；l→各邻居容量 1；邻居→汇容量 2。
3. **判定**：max-flow < 2|L|−2 → **严格无严格 HP**（记断边下界 ⌈(2|L|−2−flow)/2⌉），该实例不进 C 的检验域（属定理 A 辖区），记" capacity-KILLED"；max-flow ≥ 2|L|−2 → **容量过检**，进 C 检验域。
4. **拟扩展条件**（0912 附注口径：BA 为亚常数扩张、定理 B 只认逐实例有限-n 证书）：逐实例实测 Laplacian λ₂（精确求解或 Lanczos，容差 1e-9），并实测同规模 BA(10^{同指数}, m=4, seed=42) 的 λ₂ 作基准；过检线冻结为 **λ₂(G) ≥ 0.5 × λ₂(BA(N,4,seed42))**（m=4 行自身平凡过线，如实标注该线对 m=4 无筛选力）。λ₂ 证书入档（有限-n 扩张证书）。
5. 工具参照：`D:\data\scratch\strict_hp\` 现存 `deadlock_judge.py`、`cap_1e4/1e5/1e6.log`、`e5_certificate_ba_m3_10000_seed42.txt`（E5 先例：BA(10⁴,3,s42) |L|=4008、flow=7201<8014、下界≥407）；检验代码以此为新写独立实现，跑前先用 E5 实例对拍（必须复现 4008/7201/407 三数）方可上岗。

## 三、实验矩阵与深度计数口径（冻结）

- **矩阵**：m ∈ {4, 5, 6} × N ∈ {10³, 10⁴, 10⁵} × seed ∈ {42, 13, 7} = **27 格点**（全跑，不许挑格点）。
- **对照列**：m=3 同 N 同 seed 三格点作阴性对照（定理 A 应全数 capacity-KILLED；若 m=3 出现容量过检，本身即定理 A 实现故障，先修工具再谈 C）。
- **深度 Λ 计数口径**（与 0905"Λ≤9"可比）：Λ = 闭包外层轮数；一轮 = 一次完整的"定向旋转缝合全扫描"（对当前全部断口走一轮 Pósa 旋转链尝试）或一轮 LNS 扰动-修补-择优；构造端（Warnsdorff+初始强插）不计入 Λ；**断口归零所需的最少轮数记为该实例的 Λ**。逐轮断口序列全记录。
- **预算**：每实例 30 分钟墙钟（与 m5e5 预注册件同预算）；预算内不闭合 = 该格点"不闭合"。

## 四、O(polylog N) 操作判据（跑前冻结）

对每个 m（跨 3 个 N、3 个 seed，取每格点 Λ 中位数 Λ̂(N)）：
- 拟合幂律 ln Λ̂ = a + b·ln N；
- **存活**：该 m 全部过检格点闭合，且 **b̂ < 0.3**（等价于两个十倍程上 Λ̂ 增长 <10 倍——实测 0905 的 m=5 Λ≤9 已暗示近常数）；
- **强存活**：b̂ < 0.3 且 max Λ ≤ 32；
- **判负证据**（对猜想 C 整体）：任一 m 出现 ①过检格点不闭合，或 ②b̂ ≥ 0.3，或 ③Λ 随 N 发散性增长使 10⁵ 档 Λ > 10²；
- **判定汇总表**跑后原样填，不重跑、不换口径。

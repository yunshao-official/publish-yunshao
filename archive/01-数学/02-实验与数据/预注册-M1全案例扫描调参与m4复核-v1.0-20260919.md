## 一、动机（从 M1 执行报告到扫描设计，一段话）

M1 三臂实锤平台期主因=材料-触发错配（H-A 存活）：s99 断口 55→0 全清零、s2024 51→10，生效率 85–87%，d 全 ≤−1。但两点遗留构成本轮扫描的靶：①M1 三参数（rot 预算 50000/每断口对上限 3 次/时间护栏 0.55）系首役单点冻结值，无窗口数据；②s2024 残余 10 断口仍是"cmn=1 材料、结构类零触发"形态，其 movelog 实锤 lns_inner 后期 M1 尝试数=0——不是 3 次上限挡的，是 0.55 时间护栏到点后 M1 扫描块直接 break（窗口关闭），即"窗口配给"问题。同时门跑实证 m=3 密集态小图 M1-on 终态变差（214→235、215→243），风险面需在参数窗口下量化。乙13 的 m=4@1e5 判负结论（0/6 机制死角）在 M1 存在后也需复核。

## 四、判据（冻结，跑前写死；结果与解读分离）

- **甲-A（默认锚点复现门）**：默认组合主组六种子中，s99 breaks1=0（全清零复现）且 s42 pass=true（保持）且 s2024 breaks1≤30（不劣于乙18 插桩基线 30）。三条全过=复现 PASS；任一不过=复现 FAIL 照记（波动/负载因素如实分账，甲-B/C 判定降级为"参考"，需加跑复验后才可采信）。
- **甲-B（更优参数存在性）**：在甲-A PASS 前提下，若存在组合 C* 满足三条件：①主组 Σbreaks1(6 案例) < 默认组合主组 Σbreaks1；②s42 保持 pass=true；③风险组两案例 breaks1 均不高于默认组合在风险组的对应值 → C* 记为"扫描最优参数"（下一格推广候选）。多组合同时满足取 Σbreaks1 最小者；仍并列取离默认锚点最近的组合（最小改动原则）。无组合满足=判"窗口内默认组合已是局部最优"，照记不硬凑。
- **甲-C（s2024 残余解锁与 M1-2 触发条件）**：上限=∞ 的 6 个组合中，若存在 s2024 breaks1 < 10（第2轮默认组合档案值）→ "每断口对 3 次上限/0.55 护栏的窗口配给是残余瓶颈"实锤，记瓶颈解锁；若 6 个 ∞ 组合全部 s2024 breaks1 ≥ 10 → 上限/护栏非瓶颈，改判残余形态瓶颈，M1-2 启用条件按定量判据裁决：用该跑 FINAL 行 bpos+边表复算残余断口两两"共享同一唯一公共邻居"的对数 P，P≥1 → M1-2（双断口协同变体）触发为下一格启用项；P=0 → M1-2 保持冻结不硬启。
- **甲-D（m=4@1e5 复核，乙13）**：默认组合跑 m4 复核组两案例（cap=600s）。任一案例 pass=true（breaks1=0 严格三关+独立验证甲=0）→ 乙13"m=4@1e5 机制死角"结论触发复核（改判为"M1 前 m=4 不可清零、M1 后可清零"，乙13 档案不删、加复核注记）；两案例全部 fail → 乙13 结论维持。判负照记。
- **风险面量化（如实记，非门判据）**：风险组每组合 breaks1 与 base 档案（214/215）差值 Δrisk 全表披露；风险组 base 对照跑与档案 214/215 的偏差如实记（重跑波动账）。
- **完备性判据**：每跑 jsonl+movelog 落盘零缺；分析器可复算全表；所有判定只用 breaks 类量与 pass，rot/t_rep 墙钟量只作过程记录不作判定。

## 七、术语字典

- **m1scan** → 本轮引擎版本名：M1 版引擎的三参数（rot 预算/断口对上限/护栏系数）旗标化版本，默认值=M1 预注册冻结值。
- **默认锚点组合** → (rot=50000, pairCap=3, grd=0.55)，即第2轮三臂主臂的参数集。
- **pairCap** → 每断口对（无序）每修补调用内 M1 尝试次数上限；∞=10⁹（实际不可达）。
- **grd（护栏系数）** → M1 扫描块时间护栏 `tr0 + cap_s×grd` 的系数；grd 越大 M1 可用窗口越晚关闭。
- **主组/风险组** → m5@1e5 六种子（正式扫描组）/ m3@2000 两案例（密集态风险面组）。
- **甲-A/B/C/D** → 本预注册四条冻结判据（复现门/更优参数/残余解锁与 M1-2 触发/m4 复核）。
- **M1-2** → 双断口协同缝合变体（M1 预注册 §二 备选臂，顺序冻结：主臂非零生效即保持未启）。
- **Δrisk** → 风险组某组合 breaks1 减 base 档案 breaks1（214/215）之差，正=更差。
- **乙13** → 裁决单条目：m=4@1e5 追加构造预算实验（0/6 机制死角+时窗发现）。
- **对拍门** → 新版 vs 旧版引擎同输入 breaks0 一致性前置验证（本轮双门=零语义漂移+旗标等价）。

## 一、材料

- ganat exe 重跑 m4@1e5 s7（`--m1 cap600 --out`，incomplete 路径工具可用已定案）存终态路径 `path/g_m4s7_path.txt`；gen_ba 图由同源码 `gen_ba(N=100000,m=4,seed=7)` 逐字重建。
- 扫描对象=终态 missing 顶点全体（预期 ~1911，gpsum 对账）；路径读入后 pos/used 由路径重建（与 dump 的 gpv 交叉验证：g/slots 逐顶点一致方可采信）。

## 二、扫描定义（冻结）

对每 missing 顶点 u 的每 slot（u 的路径邻居 w：slot_forward=pos(w) 插入 (P[i],u),(u,P[i+1])；slot_backward=pos(w)-1 插入 (P[i-1],u),(u,P[i])；端点邻居只给一个 slot）：

- cmn_forward = |N(P[i]) ∩ N(u)|（插入后左侧新邻接对的公共邻居数）
- cmn_backward = |N(u) ∩ N(P[i+1])|（右侧）
- 黄金：两对均 cmn==1 且各自公共邻居非路径两端点（M1 可缝形态，净断口 0）
- 白银：恰一对 cmn==1（净断口 1）
- 普通：其余（净断口 ≥1）

## 三、判据（冻结）

- **S 主判据**：黄金覆盖率 = |{u∈missing : 存在黄金 slot}| / |missing|：
  - ≥ 0.10 → A1 值得实现，入 4d 预注册主案；
  - 0.03 ≤ 覆盖率 < 0.10 → A1 降级为白银变体（只缝一口）与 A2 合并评估；
  - < 0.03 → A1 判负照记，4d 主案转向 A2/B 方向。
- 辅助账（描述性全量入档）：slot 级 cmn 分布、每顶点最优 slot 净断口分布、黄金/白银覆盖率按 g 分层。

## 四、纪律

只读离线计算，零引擎改动；禁子代理；禁外部大模型 API；输出终检 NUL/孤立 CR；[constants:v1.0] 零涉及。

# 预注册 · 密集态 keep-best 回护 v1.0

> 委托人：知世 ｜ 执行：ZCode（sess_43d7b6ca 第 3 轮续跑会话）｜ 性质：01域·预注册（判据冻结，先于任何实现）
> 授权链：M1 执行报告 §7.4 下一格预告第 3 项 × M1 预注册 §四"中间态风险预写：M1 属冒险移动"。
> 上游：M1 执行报告 v1.0 §二.2 风险面早期实证（m=3 密集态 M1-on 终态变差 214→235、215→243）。
> **判据冻结后任何改动=新预注册 v2.0 重写，禁改本件。**

## 一、问题定义（一段话）

门跑实证（M1 执行报告 §二.2）：m=3 密集态小图（断口 200+ 的病态案例）M1-on 生效后终态反而变差——2000_3_7：base 214 → m1 235（+21）；2000_3_13：base 215 → m1 243（+28）。m=5@1e5 稀疏卡死形态未见此效应。若 M1 要向密集态推广（如 m=3 更大规模、或断口密集的其他案例族），必须有回护机制保证"开 M1 不劣于关 M1"。本预注册目标：**甄别变差机制 → 冻结回护方案 → 小样验证**；大样（1e5 六种子落地与引擎内机制实现）留下一格。

## 二、机制甄别（跑前用在档数据完成，先于任何新跑）

在档门跑数据（`gate3_m1_m3s7/m3s13` movelog 的 m1 行）：m3s7 全部 24328 次尝试日志零遗漏、9 次生效**全部 d=−1**；m3s13 6 次生效同理。即 **M1 每次生效的即时断口增量全为负（改善），单步层面零变差信号**。变差发生在多调用轨迹层面（M1 改写路径后，后续移动类的搜索轨迹落入更差盆地）。

**甄别结论（冻结）**：
- **K1 单步保险丝**（M1 生效后滑动窗累计 d≥0 则停用 M1）：在档数据下累计 d 恒为负，**保险丝永不触发=不可触发设计，判无效，不实现**。
- **K3 调用级快照回滚**（每修补调用末若净断口上升则回滚调用起点）：门跑生效全在调用内净改善，调用末断口不升，**回滚条件同样永不触发=不可触发设计，判无效，不实现**。
- **K2 案例级双轨取优**（同案例 M1 关/开各跑一次，交付路径取终态 breaks1 小者，并列取关）：唯一在轨迹效应粒度上可观测、可触发的回护点=案例终态比较。**冻结为本轮回护方案**。落地=调用层编排（跑两臂、比 jsonl、取优输出），零引擎改动，无语义漂移风险。

## 三、小样验证设计（本轮只做小样，大样留下一格）

**跑法**：风险组两案例（2000_3_7 / 2000_3_13，cap=60s）各跑两臂：base（m1scan 全关）与 m1（m1scan `--m1` 默认锚点组合）。base 臂与 M1 臂数据与预注册甲共享（不重复跑）。

**冻结判据（乙-K2）**：双轨取优值 min(breaks1_base, breaks1_m1) 逐案例满足：m3s7 取优值 ≤ 214（base 档案值）、m3s13 取优值 ≤ 215（base 档案值）→ K2 验证 **PASS**（数学上取优恒 ≤ 两臂较小值，验证点=两臂重跑值与档案的偏差在墙钟波动带内、且取优机制可机械执行）。任一案例取优值 > 档案值 → 记重跑波动超带，如实分账（不判 K2 无效——取优的数学性质不依赖单次波动；判"档案口径需在同轮重跑下重立"）。

**代价账（如实记）**：K2 成本=2×单轨墙钟（每案例 2 跑）；可优化方向（部分案例免跑 base 的判别式）留下一格，不在本轮预写。

**大样边界**：1e5 六种子 K2 落地（其实质=主组每案例已天然双跑 base 档案+M1，取优即可机械执行）与"是否需要引擎内 keep-best"的裁决，归下一格预注册；本轮不实现引擎内机制。

## 四、边界

- 小样只涉风险组两案例+在档档案对照，不动主组判据（预注册甲管主组）。
- K2 是调用层编排，不产生新引擎版本、无对拍门需求；但小样所用 m1scan 引擎仍须先过预注册甲 §三门。
- 纯算法实验，不涉 [constants:v1.0]；体系机制层不进推导链。
- 判负照记：若甄别结论被小样新数据推翻（如出现单步 d>0 生效），K1/K3"不可触发"判无效的结论须在新证据下重新评估，照记。

## 五、术语字典

- **密集态** → 路径残余断口数 ≥200 的卡死形态（本线实证于 m=3@N=2000 案例）；与 m5@1e5 的稀疏态（断口 <60）相对。
- **K1/K2/K3** → 本预注册三个候选回护方案：单步保险丝/案例级双轨取优/调用级快照回滚。
- **轨迹效应** → 单步即时增量全为改善、而多步累积后终态变差的搜索动力学现象。
- **双轨取优** → 同一案例在关/开 M1 两臂各跑一次，交付取终态 breaks1 较小者（并列取关=保守侧）。
- **base 档案值** → 214（m3s7）/ 215（m3s13），第2轮门跑 M1 版引擎全关臂在档数据。

## 二、结构附算（非判据；对象=12 节点正典全图，除非另注）

**记法**：w₁ = −(η/α)cos θ_intra（层内边权），w₂ = −(η/α)cos θ_inter（层间边权），s = (1/κ)V_active。

**A1｜S₄ 等变分解 + 精确引理（实规范读法）。** 12×12 算子在"同时重排三层同列标号"的 S₄ 作用下对易，故 12 维空间 = (3 维层空间)⊗(S₄ 不变列向量子空间) ⊕ (3 维层空间)⊗(标准表示)。得两张显式 3×3：

- 不变扇区 A = [[5η/α+3w₁, w₂, w₂],[w₂, 4η/α+3w₁, 0],[w₂, 0, 4η/α+3w₁]]，本征值各重数 **1**；
- 标准扇区 B（把 A 的 3w₁ 换成 −w₁），本征值各重数 **3**；
- **恒等式 A = B + 4w₁·I**（所以两扇区只差一个平移）。

机器校验：54 个随机 (θ_intra,θ_inter) 点上，解析块 vs 直接 12×12 归约残差 ≤1.4e−14；spec(A)∪3·spec(B) 与全谱最大差 ≤6.4e−14。θ_intra=0、θ_inter=π、η/α=7 时 A={21,7,0}、B={49,35,28}（全整数）。

**推论 1（第二比例的死因，精确）。** λ_max 取在标准扇区 ⟺ 4w₁ ≤ 0 ⟺ cos θ_intra ≥ 0，此时 λ_max 三重简并 ⇒ **R₂ ≡ 1**，与 V、与 θ_inter、与 η/α 取值全部无关。第一性口径 θ_intra=0 与档案拟合值 0.723 rad（41.4°）都落在该区域 ⇒ "最大模/次大模"读法下 1.44 **在该算子族上永不可达**。v1.0 诊断①就此升为定理。
**推论 2（第一比例是极点调参）。** θ_intra=0 时 R₁ = (λ₁(B)+s)/min|λᵢ+s|，分母可任意逼近 0 ⇒ R₁ 无上界；使 R₁=144 的 V 有多支解（新参数组 η/α=7,1/κ=32：V=+0.0107080 / −0.2095717 / −0.6501311 / **−0.8704108** / −1.0906906；旧参数组 η/α=5,1/κ=24：V=+0.0101981 / −0.1995921 / −0.6191725 / **−0.8289627** / −1.0387529）。灵敏度：命中点附近 |δV|=1e−5 已使 R₁ 变动 ±0.14（0.1%），|δV|=1e−4 使 R₁ 在 142.7↔145.3 之间跳——**"命中 144" 只反映 V 落在极点附近，不反映任何对称性**。
**推论 3（旧体系值的一记巧合，须如实记下）。** 旧体系第一性推导 V_active=−0.829（调和册 L713，由 V_single−3J_intra−J_inter 算出，非由比例反推）在正典图上给 R₁=**145.2308**（对 144 偏 0.85%），而命中所需的 −0.8289627 与之差仅 **3.7e−6**。按推论 2 的灵敏度，这道"差一点就中"落在 0.1% 容差的**外侧**，且册内自报该值误差 4.3%（与反推 −0.866 之差）比所需精度粗 3 个数量级 ⇒ 记为巧合，不记为证据。

**A2｜档案声称点判决。** (0.723, 1.047, V=1/12)，12×12：
- 实规范读法：谱 = 45.479×3, 35.915×3, 33.352×3, 24.484, 14.920, 12.357 ⇒ **R₁=3.6805、R₂=1.000000**（λ_max 三重）；
- 字面复规范读法（−ea·e^{iθ}，按 i<j 定向）：**R₁=15.8527、R₂=1.1154**（λ_max 非简并）。
两读法均远离 (144, 1.44) ⇒ ch7.3 L441「本征值比例恰好为144和1.44」在其自身参数下不成立。

**A3｜θ_intra 自由时的解曲线（12×12，实规范）。** 网格 θ_intra∈(90°,270°) 1199×1800：R₂ 解析钉在 1.44 后，R₁ 相对偏差 ≤0.5% 的命中 **156 点**。命中域：θ_intra ∈ **[97.8°, 262.2°]**（必须跨过 90°，即层内耦合反号）；V_active ∈ **[−0.97290, −0.59168]**，中位 −0.82323，**无一为正**（其中 116/156 满足 V<−0.8，72/156 落在 [−0.87,−0.82]，即旧体系推导值区间）；λ_max ∈ [12.44, 29.91] 而 λ_min非零 ∈ [0.0861, 0.2072] ⇒ 全部命中点的比值都来自准零模（λ_min/λ_max ≈ 0.7%）。解析式：R₂=1.44 ⟹ λ_max = (1.44/0.44)·4w₁ = 13.0909·w₁，λ_min = λ_max/R₁。

**A4｜9×9 冻结移除变体（64 个，实规范，粗网格 90×180）。** **36/64** 个移除方案存在 ≤0.5% 命中；全局最佳偏差 0.0694%（例：移除 (0,1,1) 列，θ_intra=3.7699 rad=216°、θ_inter=1.8151、V=−0.70329）。同样要求 θ_intra∈(90°,270°) 且 V<0。

**A5｜字面复规范族（12×12）。** 网格 300×750=225,000 点、R₂ 钉在 1.44：**0 命中**，最近approach 偏差 **2.4736%**。该读法依赖节点编号定向（破 S₄ 列对称，算子因此不是图的规范不变量）——**配方欠定本身是泛弦谱路的一个结构缺陷**，须由知世定口径后才能作为判定对象。

## 三、对 v1.0 净影响（一句话版）

谱路的问题不是"没调对参数"，而是**它的形状使然**：算子族可精确塌缩成两张 3×3（差一个平移）+ 一个纯平移自由度 (1/κ)V；于是 ① 在拓扑推得的 θ_intra=0 上第二比例恒等于 1（定理），② 在第一比例上任何大于 1 的目标都能靠把谱推近奇点拿到（极点调参，容差比在档误差预算细 3 个数量级），③ 只有放弃 θ_intra=0（改到 90°–270° 且 V 取负）才能"两比例同时命中"，而那样得到的解本身又是准零模产物。**优化方案的处置见 `01-理论与推导/泛弦理论·优化方案-v1.0-20261027.md` §二–§三。**

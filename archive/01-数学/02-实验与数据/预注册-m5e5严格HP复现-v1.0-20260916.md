## 二、验证与记录口径（冻结）

1. **严格 HP 定义**：长度 N 的顶点序列，每个顶点恰出现一次，相邻对（共 N−1 对，**不含首尾闭合**）全为真边。
2. **断口计数双口径**：甲=路径序列内相邻对非真边的位置数；乙=甲 + 首尾闭合检查单独记录（闭合与否另列，不入 PASS 判据）。
3. **双独立验证器**：
   - 验证器一：引擎自带三关验证（排列完整性 + 相邻对全真边 + 断口双口径，`debug_verify` 同源逻辑）；
   - 验证器二：**独立新写** Python 脚本（networkx 读边表重验，不 import 引擎代码），跑前先在 BA(1000,5,s42) 已知 PASS 案例上对拍通过方可上岗。
4. **逐 seed 记录**：断口数（构造端/修补端/终态三值）、闭合轮数 Λ、构造与修补耗时、验证器双方输出、随机数种子消费记录。

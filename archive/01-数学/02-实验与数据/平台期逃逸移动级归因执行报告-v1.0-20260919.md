## 一、背景与问题（一段话）

哈密顿路径 v3 构造引擎（BA 图 = Barabási–Albert 无标度随机图，N=100000、m=5）在 networkx 族 600 秒档 5/6 案例出现"平台期逃逸失败"：修补窗烧满时间预算，残余断口（break = 哈密顿路径中相邻两顶点在原图中不是真边的位置，即"断开的口子"）13–43 个不再下降；但断口解剖显示每断口恰约 1 个公共邻居（"有缝合材料"）。乙14 已定论三元耦合（预算/结构/搜索三方互相锁死）。本实验按预注册 v1.0 对 2 个卡死案例（s99 残余43、s2024 残余30）+1 个清零对照案例（s42）做**移动级归因重放**：用插桩引擎（只加日志、不改管线语义）重放修补全过程，逐移动记录类型/断口增量/触发条件候选数，回答预注册冻结的三问。

### 2.3 rot 漂移归因（补强实验）

g2_3_13（病态长转案例，22 秒构造窗内累计旋转 2500 万次）rot 不一致。为判定"插桩漂移 vs 管线固有属性"，用**原版引擎自身**同输入重跑 2 次：

| 运行 | rot | breaks0/breaks1 |
|---|---|---|
| 对拍 orig | 25059804 | 257/215 |
| 对拍 anat | 25667519 | 257/215 |
| 原版自重跑 A | 25883265 | 257/215 |
| 原版自重跑 B | 26451297 | 257/215 |

四值各异（ spread 约 5.5%），而语义量 4 次运行零漂移。**结论：rot 是管线固有的不可复现量**——v3 管线本身含大量墙钟截止决策（源码中 cap_s×0.55 / cap_s×0.92 / tConstructEnd 等时间窗），插桩开销（每生效移动 1 次 O(n) 断口复核）只挪时间线，使时间窗内尝试数微变；这与插桩无关（原版自己重跑两次就漂）。插桩版头注"已知插桩开销（不改语义、只挪时间线）"的诚实声明获得实证。

**对拍门判定：PASS**（6/6 breaks0 一致 + rot 漂移实锤为管线固有时间依赖）。前置门过，归因数据可采信。

## 四、三问答案（解读层，与数据分离）

### 问①：卡平台时最后一类生效移动是什么？

**D 类（双邻断口直接缝合）**，且发生在 LNS（Large Neighborhood Search，大邻域搜索扰动）内层修补：
- s99：最后一次下降移动 = D，t=509.8s（案例内秒），阶段 lns_inner，断口增量 d=−1；此后 76 秒全是 LNS-P0/P1 空转扰动（d=0），585s 预算烧完。
- s2024：最后一次下降 = D，t=508.1s，阶段 lns_inner，d=−1；此后 79 秒纯空转，587s 烧完。
- 含义：平台期的"最后一口气"来自 LNS 扰动翻出的一次 D 缝合；扰动再深也翻不出第二次。

### 问②：哪类移动的触发条件在卡死点不可满足？

**结构类五移动 A/B/B2/H/F 候选数全部 = 0**（FINAL 画像 + 全部空转轮一致）：

| 卡死点画像 | s99 FINAL | s2024 FINAL |
|---|---|---|
| 残余断口 brk | 43 | 30 |
| cA/cB/cB2/cH/cF（结构五类候选） | **全 0** | **全 0** |
| cE（j−i≥2 断口对候选） | 903 | 434 |
| cD（\|B\| 资格池） | 43 | 30 |
| cD2（前 2 断口未失败对数） | 2 | 2 |
| R 尝试/带变异失败 rP/rM（全程累计） | 130+800 全失败 | 180+310 全失败 |
| 每断口公共邻居 cmn | **43/43 全=1** | **30/30 全=1** |

（cX = 空转轮记录的各类移动触发条件候选数，=0 即该类移动在当前形态下不可满足；cmn = 终态只读扫描的每断口公共邻居数。）

**机制死角精确化（乙13"0/6 机制死角"的移动级解释）**：断口全部"有材料"（每断口恰 1 个公共邻居），但 A/B/B2/H/F 结构类移动要求的复合触发条件（两跳可达 + 中间人预留格局等）在卡死形态下不可满足；D 类资格池=断口数但每次缝合净收益被新断口抵消；D2 门开着（cD2=2）但"只试前 2 对、失败即跳"的设计在单邻居断口形态下反复失败跳过；R（带变异重构）130~980 次尝试零成功。**"有缝合材料"与"无移动可执行"并存 = 触发条件与材料错配，非材料缺失。**

### 问③：清零对照 s42 的移动谱差异？

| 移动类 | s99（卡死） | s2024（卡死） | s42（清零） |
|---|---|---|---|
| B2 | 0 | 0 | 1 |
| D | 8 | 9 | 13 |
| D2 | **2** | **5** | **30**（d_sum=−35，主力） |
| R | 1 | 1 | 0 |
| TG-NEU | **400（预算全烧，d_sum=0）** | **400（同）** | 0 |
| LNS-P0/P1/P2 | 23/13/3（全 d=0） | 12/5/0（全 d=0） | 0 |
| 生效移动合计 | 450 | 432 | 44 |
| 空转轮 | 96 | 52 | 62 |
| 全程阶段 | repair_main→tangle→lns | 同左 | **全部在 repair_main** |

（TG-NEU = 中间人中性搬移，解缠绕用；LNS-P0/1/2 = 扰动层级。）

**核心差异三条**：
1. **D2 生效率**：清零案例 D2 生效 30 次（累计旋转 196267 次，单次最高 30377——D2 靠大旋转量实现"绕过障碍"缝合）；卡死案例 D2 仅 2/5 次即枯竭。
2. **TG-NEU 预算错配**：两卡死案例 tangle 阶段 400 次 TG-NEU（预算上限）全部跑满，断口增量合计为 0——11~12 秒与 400 次移动预算投入产出为零（它只解缠绕不清口）。
3. **LNS 空转**：卡死案例 LNS 扰动 36/17 次全部零增量（lnsNoMove=51/22），扰动深度/半径不足以把局部形态翻出死角；清零案例根本不需要走到 LNS。

## 五、逃逸假设（喂乙15①下一预注册，本轮不设计不测试）

按预注册边界，本轮只立假设不做新移动：
- **逃逸假设 H-A（主假设，与乙15①合流）**：低度顶点单公共邻居断口需要"专用缝合移动"——绕唯一公共邻居做局部强制重排（借鉴 s42 的 D2 大旋转模式 rot 30000+），而非现有 D2 的"前 2 对试失败即跳"。可检验预测：若 H-A 成立，s99/s2024 重放中注入该移动应能消 ≥1 断口。
- **逃逸假设 H-B（预算错配）**：TG-NEU 400 次预算在断口>0 且缠绕已解后是纯浪费，可回收给 D2 变体或 LNS 深扰动。可检验预测：回收预算后同等时间窗残余断口下降 ≥10%。
- **逃逸假设 H-C（扰动深度）**：LNS 扰动半径不足（lnsNoMove 51/22 = 扰动后无新可执行移动），加深/加宽扰动可翻出 D 类第二次机会。可检验预测：扰动深度加倍后空转轮占比显著下降。

## 六、诚实边界

1. **插桩开销**：每生效移动 1 次 O(n) 断口复核、空转轮 1 次候选扫描——挪时间线不改语义（对拍门 2.3 实证）；本报告所有"案例内秒 t"含插桩开销，与无插桩运行的时间线不可直接互比。
2. **rot 不可复现**：管线固有时间依赖（墙钟截止窗），任何 rot 数值单次运行有效，不可作为跨运行比较量。
3. **样本量**：三案例（2 卡死 + 1 清零对照），结论为机制画像而非统计规律；扩大样本属下一预注册选项。
4. **归因≠解决**：三问答案与逃逸假设均为解读层，未做任何新移动验证（预注册边界）。
5. **本实验与体系常数无关**：纯算法实验，不引用 [constants:v1.0] 任何数值；哈密顿路径线是执行器层算法研究，云韶体系机制层不进本报告推导链。

## 八、术语字典

- **BA 图** → Barabási–Albert 无标度随机图，本线标准测试图族（N 顶点、m 每新顶点连边数、seed 随机种子）。
- **哈密顿路径** → 经过图每个顶点恰一次的路径；本线目标=在 BA 图上构造它。
- **断口（break）** → 路径中相邻两顶点在原图中不是真边的位置；断口数=0 即合法哈密顿路径（breaks0=修补前、breaks1=修补后残余）。
- **修补移动 A/B/B2/H/F/E/D/D2/R** → v3 引擎七类+扩充的断口缝合操作（结构类 A/B/B2/H/F + 直缝 D + 双断口 D2 + 重构 R）。
- **TG/TG-NEU/TG-RW** → tangle（缠绕）解算类移动；NEU=中性搬移，RW=随机行走。
- **LNS-P0/P1/P2** → 大邻域搜索扰动的三个层级。
- **cA..cR（候选数）** → 空转轮记录的各类移动触发条件候选数，=0 即该类移动当前不可满足。
- **cmn** → 终态每断口公共邻居数（"缝合材料"存量）。
- **对拍** → 两份实现（原版 vs 插桩版）同输入比对输出一致性，验证插桩零语义漂移。
- **插桩** → 只加日志不改逻辑的代码增量。
- **rot** → 引擎累计旋转次数（时间依赖量，不可跨运行比较）。
- **wall_s** → 墙钟真实耗时（秒）。

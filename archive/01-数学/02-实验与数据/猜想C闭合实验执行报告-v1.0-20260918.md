### Λ–N 增长曲线说明

可拟合数据不足：m=5 非零档仅 (10⁴, 80)；m=6 非零档仅 (10⁵, 88)；m=4 仅 (10³, 0) 且含零档。Λ̂ 序列中大量 Λ=0（构造端直出）使幂律拟合 ln Λ̂=a+b·ln N 在数学上无定义——b̂ 无定义本身如实入档，不强行外推。已测 Λ 上界观察：全矩阵 max Λ=91（m5_N10000_s13），无随 N 递增趋势证据（10⁵ 档闭合者 88 < 10⁴ 档 91）。

## 八、术语字典

- **猜想C（收缩版）**：云韶-哈密顿猜想 V2.0 0912 裁决附注的可证伪复杂度猜想——"通过定理A容量检验的 BA(m≥4) 族图，存在 O(polylog N) 深度的 Pósa 旋转闭合序列构造出严格哈密顿路径"。
- **定理A容量检验**：低度集流网络割条件（源→低度顶点容量2→邻居容量1→汇容量2）；max-flow < 2|L|−2 则严格无严格 HP。
- **capacity-KILLED**：未过容量检验，属定理A辖区，不进猜想C检验域。
- **严格 HP**：长度 N 的顶点序列，每顶点恰一次，相邻对全为真边；断口=相邻非真边对数，PASS 当断口=0。
- **Λ（lambda，闭包深度）**：断口归零所需的最少外层轮数（修补全扫描轮+LNS 轮；构造端直出记 0）。
- **b̂（b-hat）**：ln Λ̂ 对 ln N 的最小二乘拟合斜率，O(polylog N) 的操作判据（存活线 b̂<0.3）。
- **λ₂**：图拉普拉斯第二小特征值（代数连通度），拟扩展条件证书量。
- **BA 图**：Barabási–Albert 无标度图；本矩阵实例=networkx 3.6.1 barabasi_albert_graph(N,m,seed)。
- **R1**：m5e5 严格 HP 复现（预注册-m5e5-20260916 件的执行，2026-09-17 判负 0/3 PASS）。
- **v2/v3 管线**：门一哈密顿路径求解引擎两代；v2=七类修补+LNS，v3=加 H·中介归位与 D2·全路径闭包（战报正本见索引）。
- **canon/gen_ba/networkx 三口径**：三个互不相同的 BA 生成器实例族（R1 报告结案：不同图即口径不同一）。

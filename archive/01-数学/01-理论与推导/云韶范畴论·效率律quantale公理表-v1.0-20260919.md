## 二、预备定义（古典侧·全部已证工具）

**定义 2.1（quantale，Mulvey 1986 [2]）**：quantale Q=完备格 (Q,≤) 带结合运算 ⊗_Q，且 ⊗_Q 对任意并分配。**概率 quantale**：Q=([0,1],≤,×,1)，×=实数乘法，单位 e=1。

**定义 2.2（Q-赋量范畴，Lawvere 1973 [1] 概率版/Kelly 1982 [3] 一般理论）**：范畴 C 富于 Q，即：
- 每对对象 (A,B) 赋 hom-量 d(A,B)∈Q（读作"A→B 方向一次操作的最大效率/可靠度"）；
- 复合公理（乘性三角不等式）：**d(A,C) ≥ d(A,B)·d(B,C)**（效率沿合成只降不升）；
- 单位公理：恒等态射满足 d(A,A)=e=1（恒等不损耗）。

**古典对照（Lawvere 原形）**：度量空间=([0,∞],≥,+,0)-赋量范畴，合成=三角不等式 dist(a,c)≤dist(a,b)+dist(b,c)。概率版把"加法损耗"换成"乘法折扣"，正是"可靠度合成律 strength(f∘g)≤strength(f)·strength(g)"（教科书概率可靠度理论，册内 §10.3 已引）。

## 四、定理候选（升格证明骨架）

**定理 1（效率律升格·本文主件）**：在 A3+A6 下，任意 n 步纯涌现链的效率 ≤ ηⁿ；任意 n 步纯亏损链的效率 ≤ αⁿ。特别地 n=2：互乘⊗效率上界 = η² = 49/64；互除⊘效率上界 = α² = 1/64 = ε。

*证明*：对 n 归纳。n=1 即 A3。n→n+1：d(f₁∘…∘f_{n+1}) ≤ d(f₁∘…∘f_n)·d(f_{n+1}) ≤ ηⁿ·η = η^{n+1}（亏损链同理用 α）。∎

*升格声明*：η²=49/64 与 α²=1/64 由"孤立数值"成为 A3+A6 的**两行推论**——册 §10.3 判据①（合成公理与效率律自洽）满足，升格完成。定理 1 的地位=体系内形式定理；η、α 本身仍是体系内部常数【未验证】。

**定理 2（结合性免费）**：在 quantale 乘法结合律下，(f∘g)∘h 与 f∘(g∘h) 的效率估计逐字相同；结合子相干图自动交换（Mac Lane [4]），Mac Lane 结合括号问题在本框架内**自动消解**——册 §10.3 判据②满足。

**定理 3（收缩与收敛骨架，承接 E-7）**：η=7/8<1 ⇒ 谱半径读法下 ηⁿ→0（n→∞），涌现长链效率趋于零——"效率只降不升+唯一稳态"由已证收敛定理直接担保（E-7 原判据），与代谢动力学 800 步收敛 σ→1/2±0.0024（册内体系内部计算）不矛盾：前者是效率折扣链，后者是动力学不动点，两件事（E-4 另案检验不动点唯一性）。

**定理 1-3 全部为公理层形式结果**【体系内部定义·公理化重构·未验证】。

## 五、互轭⫝的赋量伴随检验（Flagg 1997 [5] 工具·三行判定）

quantale 版 Galois 连接（adjoint 对）：d(A,B) ≤ q ⟺ d(B,A) ≥ q∖e 形式的剩余运算对应。⫝ 资格检验化为：**是否存在常数 c 使 d(A,B)·d(B,A) ≥ c 对一切⫝对成立**（对称下界式）或剩余式对应。
- 册内 ⫝ 效率栏="-"（无方向数据）⇒ **检验缺输入，挂起**（缺口 2，见§六）；
- 若体系补出方向数据且检验通过 ⇒ 显隐对偶获得赋量伴随已证框架（与 E-6 dagger 检验平行，两判据独立：dagger 要对合律+反同态律，赋量伴随要效率对称结构）；
- 若体系声明⫝与效率无关（纯结构映射）⇒ 本检验不适用，⫝走 E-6。

**此节=图谱 E-1 判据③（互轭能否写成赋量版伴随）的形式化落位：工具已备，等待体系侧输入。**

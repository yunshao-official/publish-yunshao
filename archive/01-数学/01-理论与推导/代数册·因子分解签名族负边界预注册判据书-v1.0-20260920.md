## 一、对象与口径（先于判据钉死）

1. **样本**：偶数 N ∈ [2, 200000]（100000 个），组判据 r := N mod 24，每组样本量约 8333（与 R15 逐N判据书同口径同容量，可直接对表）。**分片**：5 片×20000 偶数，每片算完落检查点（`02-实验与数据/results/omega_negbound_checkpoint_1..5-v1.0-20260920.json`），检查点可断点续算（长算分片纪律）。
2. **因子分解决定型签名（本轮封死对象的精确化）**：s 为因子分解决定型，若存在函数 G 使 s(N) = G((v_q(N))_{q 素数}) 对一切 N 成立——即 s 只看"N 由哪些素数的哪些幂次组成"，不看 N 本身的数字位型。**覆盖清单（非穷尽）**：幂次 v_p(N)（任意素 p）、计重数 Ω(N)=Σ_q v_q(N) 与 ω(N)=#{q: q|N}（互异计）、乘法型 φ(N)/N=∏_{q|N}(1−1/q)、除数/μ/Liouville/rad、最大素因子 P(N)、y-光滑性判据、𝔖₂/𝔖₃ 型奇异级数（只依赖整除示性）。**边界（防错位）**：二进制数字位型签名（popcount s₂、行质量 W/W̃、maxcarry 等）**不在**本件封死范围内——它们不是因子分解决定型（s₂(N) 不由素因子分解决定），其状态见补注 K1c 与 R15 J3（经验口径）；三元（base-3）语言另册处理（后续判据书，若本判据书冻结后同轮执行则独立编号独立冻结）。
3. **组分辨率口径**：一个签名族对 12 组的"族级分辨率"=按组级良定义值（或按组条件分布）能把 12 组分成多少类。R14/R15 已得：𝔖₂ 侧 2 类（3|N 布尔，J1 定理）；二元 Kummer 进位语言 4 类（模 8 轴，C0/C1）；联合 8/12（C3）；逐 N 级经验尝试不成功（J3）。**本轮对象=因子分解决定型语言（含任务点名的 v_p 幂次与 Ω 计重数）的族级分辨率上界**。
4. **边界**：全程执行层主流数学（CRT/初等数论/Markov 型计数/KS 与置换检验）；体系常数零引用；"12 组·偶数侧"与衔尾蛇 12 组对应关系【体系内部定义·未验证】不判别；定谳类事项零动作。

## 二、定理 K1（先于实算陈述并证明；实算只做数值印证，不承担定理真伪）

**定理 K1（因子分解签名族负边界定理）**：设 s 为任一因子分解决定型签名（§一.2），N 为偶数样本空间 {N ≤ X : 2|N} 上的均匀随机元，r := N mod 24。记 κ₂(r) := min(v₂(r), 3) ∈ {1,2,3}、κ₃(r) := 1_{3|r} ∈ {0,1}。则：赋值向量的任意有限维边际在条件 r 下的分布，当 X→∞ 时收敛到一个只依赖 (κ₂(r), κ₃(r)) 的极限；从而 s(N) 条件于 r 的分布渐近只依赖 (κ₂(r), κ₃(r))。特别地：

- **(a) 六类合并分拆**：12 组按 (κ₂, κ₃) 分为**恰 6 类**：C₍₁,₀₎={2,10,14,22}、C₍₁,₁₎={6,18}、C₍₂,₀₎={4,20}、C₍₂,₁₎={12}、C₍₃,₀₎={8,16}、C₍₃,₁₎={0}；同类内任何两组的 s 条件分布渐近精确相同——任何统计检验对该内部分辨的渐近功效=显著性水平（不可分）。
- **(b) 方向封死**：四对组两两不可分（a 的推论），且更强——{2,10} 与 {14,22}、{2,10} 与 {4,20} 与 {14,22} 等跨对合并同样不可分：**v_p(N)/Ω(N) 计重数方向对 12 组完全分辨不可达，因子分解语言族级分辨率上界=6/12**。
- **(c) 可达性**：签名 s₀(N) := (min(v₂(N),3), 1_{3|N}) 为因子分解决定型，其组级值恰实现上述 6 类分拆——上界 6/12 是紧的。

**证明**：唯一分解 N = 2^A·3^B·M（M 与 6 互素）把赋值向量分解为 (A, B, (E_p)_{p≥5})，A=v₂(N)、B=v₃(N)、E_p=v_p(N)（p≥5），s(N)=G(A,B,(E_p))。分四步。

**步 1（A 的条件律）**：N ≡ r (mod 24) 蕴含 N ≡ r (mod 8)。若 v₂(r) ≤ 2，则类 mod 8 的 2-adic 赋值恒等于 v₂(r)，故 A = v₂(r) 逐点确定。若 v₂(r) = 3（r ≡ 0 mod 8），对 j ≥ 0 由 CRT（gcd(2^{3+j}, 3)=1）：{N ≤ X : N ≡ r mod 3, N ≡ 0 mod 2^{3+j}} 的密度为 1/(3·2^{3+j})，对条件类密度 1/24 之比为 2^{−j}，故 P(A ≥ 3+j | r) → 2^{−j}，即 P(A = 3+j | r) → 2^{−(j+1)}（几何尾律）。两形态都只依赖 κ₂(r)。

**步 2（B 的条件律）**：若 3∤r 则 3∤N，B = 0 逐点确定。若 3|r，对 j ≥ 1 由 CRT（gcd(3^j, 8)=1）：P(B ≥ j | r) = {N ≡ r mod 8, N ≡ 0 mod 3^j 的密度}/{N ≡ r mod 24 的密度} → (1/(8·3^j))/(1/24) = 3^{1−j}，故 P(B = j | r) → 2·3^{−j}（几何，均值 Σ_{j≥1} 3^{1−j} = 3/2）。只依赖 κ₃(r)。

**步 3（(E_p)_{p≥5} 与一切正交）**：对任意有限素数集 P₀ ⊂ {p≥5} 与幂界 K：由 CRT（gcd(∏_{p∈P₀} p^K, 24)=1），(N mod p^K)_{p∈P₀} 条件于 N ≡ r (mod 24) 均匀，故 (1_{v_p(N) ≥ k})_{p∈P₀, k≤K} 条件律与无条件相同（每点概率 p^{−k}，联合独立）——(E_p)_{p∈P₀} 的条件律与 r 无关。再与 (A,B) 联合：条件于 A=a, B=b（与 r 相容时），写 N=2^a 3^b M，约束化为 M 的固定剩余条件（模 3·2^{3−min(a,3)} 型，或 b≥1 时仅模 3/模 2 分量；步 1、步 2 已保证相容性），该条件的模数与一切 p^K（p≥5）互素，再由 CRT 得 (M mod p^K)_p 条件均匀——(E_p)_{p≥5} 条件独立于 (A,B) 且律与 r 无关。注意关键机制：组内两成员的 M 剩余条件在模 3 分量上可以不同（对组结构所在），但两边都非 0 mod 3，对因子分解只留下"3∤M"这同一事实（B=0），剩余差异对赋值向量不可见。

**步 4（合成）**：赋值向量全律由有限维边际决定（赋值向量空间为可数乘积空间，概率律由柱集边际唯一决定）；由步 1–3，任意有限维边际在条件 r 下的极限只依赖 (κ₂(r), κ₃(r))，故 s=G 的条件分布渐近只依赖 (κ₂, κ₃)。(a)：12 组经 (κ₂,κ₃) 的像恰为所列 6 类（逐一验算：{2,10,14,22} 的 κ₂=1、κ₃=0；{6,18} 的 κ₂=1、κ₃=1；{4,20} 的 κ₂=2、κ₃=0；{12} 的 κ₂=2、κ₃=1；{8,16} 的 κ₂=3、κ₃=0；{0} 的 κ₂=3、κ₃=1）。(b)：a 与四对组均含于同类。**具名签名的可达性核对**：Ω 事件 {Ω ≤ K}、ω、v_p 事件、P(N) 的分布函数 {P(N) ≤ y}（={v_q=0, ∀素 q>y, q≤X}，有限赋值事件列的极限）、ln(φ(N)/N)=Σ_{p|N}ln(1−1/p)（尾部 |Σ_{p|N, p>Y}| ≤ (ln X)/(Y)·…经截断界一致趋 0）——各条件分布律均由赋值向量有限维边际经截断-极限决定，(a) 传导成立。(c)：s₀ 显然因子分解决定型，其 6 类组级分拆=直接验算。∎

**补注 K1c（二元数字统计量的对组不变引理——J3 两条签名的定理化）**：对二进制位型的**可分解型**泛函：s₂（popcount）与 maxcarry=⌊log₂(N+1)⌋−v₂(N+1)，四对组条件分布渐近精确相同。证明骨架：s₂(N)=s₂(ρ)+s₂(Q)，ρ=N mod 8=r mod 8（对组内相同），Q=(N−ρ)/8 的约束仅为固定模 3 剩余类（Q ≡ 2(r−ρ) mod 3 型，对组内两成员不同但都非 0），而 s₂(Q) | {Q ≡ c mod 3} 的律由 CRT（gcd(3,2^j)=1）与 c 无关，尺寸分布对组内相同——合成即得。maxcarry：对组内 r 同奇偶（全奇），v₂(N+1)=0 逐点确定，⌊log₂(N+1)⌋ 的尺寸律对组内相同。∎ **边界**：行质量 W/W̃ 依赖 N 的全局数字泛函（无此分解），无精确定理，维持 R15 J3 经验口径（不可分，d≤0.0003）。此补注把 J3 的三条签名中两条升格为"定理性不可分"，与 J3 实测一致（回溯印证，非新预测）。

**边界（防错位）**：K1 是渐近（X→∞）陈述；有限 X 的条件分布与极限差 O(边界效应)，高幂次层（如 v₅≥6）在 X=200000 处计数稀疏，如实记录不判读（F4）。K1 不涉及数字位型语言的三元推广（另册），不断言任何体系侧对应。

# 素数加法结构的两路定理化：χ 覆盖余量与进位签名轴（合流报告）v1.0

> 知世令"全部走"② ｜ 上游：χ覆盖定理·正本-v3.3（T1-T6）× 素数进位签名与局部惯元结构·实证对应-v1.1（三轴齐+素数级下探）
> 一句话：**同一对象（素数对 p+(N−p) 的加法结构），两条独立定理化的路——解析不等式路（χ 覆盖）与计算分类路（进位签名）——合流点在"覆盖与分类互补"，交叉处留了一个可预注册的开放问题。**

## 一、两路并置

| | 路线 A：χ 覆盖余量 | 路线 B：进位签名轴 |
|---|---|---|
| 对象 | 素数对 (p, N−p) 的覆盖余量 ρ=χ(p)−∫dt/lnt | 素数对的进位位形 c₃(k, N) 的族级分布 |
| 问题形态 | "余量何时为正"（每对覆盖） | "分布如何分族"（签名轴分类） |
| 主结果 | T4：N≥18 每对覆盖（全解析）；T5：例外全表 {6,8} | 三轴齐（mod 8/mod 3/mod 5）；素数级 S1 跨类 54/54 对全分离、S2 ρ=0.783 |
| 工具 | 两段积分下界+BHP 素数间隙（T2b）+Ei 级数严格化 | 确定性签名算法+预注册判据+KS/Spearman |
| 诚实边界 | 存在性核=哥德巴赫等价难度（不越） | 签名=f(r mod p^m) 构造使然（经验内容在统计层） |
| 判负史 | 域外 N=4（ρ=−1.92）；T2 单矩阵机制判负 | 简单同构命题否证；5 轴无二分如实 |

**正本位置**：A=`01-数学\01-理论与推导\χ覆盖定理·正本-v3.3-20260927.md`；B=`同目录\素数进位签名与局部惯元结构·实证对应-v1.1-20260930.md`。

## 二、合流命题：覆盖与分类互补

**命题（合流解读，非定理）**：路线 A 与 B 测的是素数加法的两个正交侧面——

- A 是**负方向的完备性**：ρ<0 的对（覆盖失败）在 N≥18 不存在（T4），且沿无穷素对序列余量下界渐近取等（T2b）——它说"最坏能坏到哪，且坏不到底"；
- B 是**正向的结构性**：进位事件的分布在族间稳定分离（mod 8 轴预测子 ρ=0.783）——它说"常规形态长什么样，且按什么轴分"。

两路合起来才是一幅完整图景：**例外有限（A）+ 常态有轴（B）**。单独任何一路都只是半个描述。

**方法论公约数**：两路的判负记录同价展示（A 的域外判负与机制判负；B 的同构否证与 5 轴无二分）——预注册+判负照记在解析路线与计算路线上同等有效，"判负产生精确性"是本合流的方法论结论。

## 三、交叉开放问题（挂预注册，不当轮实算）

**问题**：χ 余量按 p mod 8 分组是否存在系统偏差？

- 动机：路线 B 证明进位分布强依赖 mod 8 轴；χ 函数含素数倒数和（与素数分布直接相连）——若素数分布在算术级数间有 Chebyshev 型偏差（主流已知：π(x;8,a) 不均衡，Littlewood 级振荡），则 χ 余量的轴依赖可能真实存在，从而把 A/B 直接缝起来；
- **为什么不当轮实算**：χ(p)≈Li(p) 是光滑函数——光滑性会把"分组差"洗掉，真正的偏差载体是**素数计数 π 本身**的算术级数偏差。需要先分账（χ 的解析层 vs π 的算术层），避免拿光滑函数做出虚假的"无偏差"结论。预注册判据书下窗口立（判据形态候选：以 π(x;8,a)−Li(x)/4 的带符号偏差为载体，按 8 轴做符号振荡检验）。

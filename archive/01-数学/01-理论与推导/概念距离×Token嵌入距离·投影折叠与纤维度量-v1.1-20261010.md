## 〇、人话版导读

**你的直觉是对的，而且比你说的还深一层。**

"概念距离=词嵌入距离"这个假设，相当于说："地图上两座城的距离=它们在照片上的距离"。照片（token 嵌入）是城市（概念）的一次**拍照投影**——拍出来是平的、会重叠、会失真：

1. **会重叠**："苹果"（水果）和"苹果"（公司）两个概念，在照片上塌成同一个像素点（同一个 token）——这不是测量误差，是投影本身丢了维度。
2. **照片量距离 ≠ 真距离**：两栋楼在照片上挨着，可能因为一栋在另一栋正后方（投影重叠），实际隔着一条街。
3. **体系的反转洞察**：那些"一图多义"的塌缩点（多义词），恰恰是语义世界里最繁忙的**立交桥**——你的几何册早写好了：缺陷是贯通通道不是障碍（实测连通性一分不降）。

**v1.1 升级**：知世进一步指出完整的三层结构——概念（全息零点）→语义（穿过概念的纤维）→词汇（光照下的影子）。所以正解分两句：**语义的距离要用"分布之间的距离"量（整根纤维），不能用"平均点之间的距离"量（截面）；而概念的距离又是另一层（零维代理间的链环结构距离），连纤维距离都不是它。**

| 概念远近=词嵌入距离？ | **否**（结构性不等，非测量误差） | 三层投影（§二~§四） |

## 二、第一层不等：投影折叠（token 空间是语义空间的亏损投影）

### 2.1 投影级联的语言观定位

语言观文件已立：**说话=高维信息的亏损投影**（总定义）。具体到 token 层：

```
概念层（零维代理网络，全息零点）          ← 最深，本文件不展开（见三层本体论文件）
   ↓ 投影
语义空间（概率纤维，高维，连续分布）       ← 本文"源空间"
   ↓ 投影级联（保留率族 2k/(2k+1)：每级丢维）——斜率文件 §2.1 在档
token 空间（表层形式，词表大小 V，离散）
   ↓ 再投影
embedding 空间（d 维实向量）
```

**token 本身已是多级投影的产物**：语义→词元（拼写层切分，BPE 统计产物）→向量（训练动力学产物）。每级都有保留率<1 与折叠。

### 2.2 折叠：0.5 缺陷型的维差亏损

- **现象**：bank（银行/河岸）、苹果（水果/公司）——**多个语义塌缩进同一个 token**。
- **体系读法**：语义→token 投影丢掉的那部分维，正是 0.5 缺陷型亏损（投影递进每级损失 1.5=三个 0.5 缺陷，在档）。塌缩不是 bug：**表层形式的离散词表容量 V 远小于语义空间的有效维数——折叠是低维承载高维的必然**。
- **体系内已有同型先例**：文献对接图谱的"**防假朋友双红线**"（泛弦分频 vs 泛音列倍频：表面同构、实质异源）——**token 距离近=表面同构，语义距离远=实质异源**，假朋友的数学就是投影重叠对的数学。

### 2.3 局部保距的余晖（诚实对表）

word2vec 时代 king−man+woman≈queen 的部分有效性、embedding 做语义检索的可用性，说明投影在**局部线性区近似保距**——这不是推翻本文判定，恰是投影几何的常态（小范围内投影近似等距，大范围必然失真）。**工程上 embedding"够用"与理论上"语义距离≠token距离"并行不悖。**

## 三、第二层不等：截面距离≠纤维距离（语义层内部）

### 3.1 语义=整根纤维，token 嵌入=一根截面

语言观已立：语义层=概率纤维（概率论册原生对象）。对表 LLM（v1.1 对象名校准）：

- **一个多义 token 对应的不是一点，是纤维的交织**："苹果"这个 token 上挂着（水果义分布，公司义分布）——**每个"义"是一根纤维的截面活动**；
- **静态 embedding（word2vec 类）=纤维束的平均截面**——把多条纤维取期望压成一个点；
- **上下文嵌入（BERT/GPT 隐状态）=随上下文在纤维上滑动的截面**——已经在朝"纤维"方向走，但仍是一次一个截面，不是纤维本身；
- **概念=零维代理**（v1.1 新增层）：纤维只是概念的投影活动，概念本身（全息零点）在纤维底下——见三层本体论文件。

**结论：token 嵌入距离=截面点（或平均点）的距离；语义距离=纤维与纤维之间的距离（分布间距离）。两者是不同类型的量**——就像"两团云的重心距离"≠"两团云的分布差异"。

### 3.2 语义距离的原生度量候选：Fisher-Rao / Wasserstein

- **Fisher-Rao 度量**：概率流形上的自然黎曼度量——θ场=概率/相位场（体系原生），概率流守恒方程（概率册在档）在 Fisher 几何下有标准形态。**语义距离的第一候选=Fisher-Rao 距离**。
- **Wasserstein 距离**：分布间的最优传输距离——纤维间距离的稳健工程版。
- **提升程序（lift）**：token→语义的恢复=由上下文分布把截面点提升回纤维（上下文嵌入已是隐式 lift 的雏形）——**蜃楼 v2.0"逆问题驱动"口径的语言版：听话=逆问题重建**。

### 3.3 ⫛ 账本视角的补充判定

token 嵌入的"距离"是**训练共现统计的传递产物**（有源：语料账），语义距离是**语义结构的涌现关系**（无源：结构账）——两本账不同（⫛ 账实相符口径）。共现近≠语义近（搭配近≠同义近），这是账面差异的又一来源。

## 四、第三层：多义 token=语义网络的 0.5 缺陷——贯通通道，不是噪声

### 4.1 反转

主流把多义词当 embedding 的麻烦（要消歧、要上下文化）。体系几何册给出反转视角：**缺陷是贯通通道不是障碍**——在档实测（几何册 §2.6，2026-07-25，8000 采样点）：缺陷配置与基线配置代数连通性**持平**（5 维 5.4509 vs 5.4509；8 维 62.0281 vs 62.0281）；缺陷的物理实现=相位梯度，**有梯度连通，无梯度碎裂**。

**映射**：多义 token=语义网络的缺陷位——它连接多个语义区（bank 连通"金融区"与"地理区"），是语义图的高连通枢纽。高频多义词（"的/了/是/中"）恰好承担语法与语义的跨区贯通，**这不是巧合，是缺陷贯通角色的语言显影**。

### 4.2 可预注册判据（本轮核心产出）

**J-CD1（缺陷贯通判据）**：构造语义图（节点=词义/概念区，边=共现或替换关系），分别移除多义 token 与频次匹配的单义 token，测图代数连通性 λ₂ 的变化。
- **体系预测**：移除多义 token 的 λ₂ 损伤 **<** 移除单义 token（缺陷贯通：去掉通道但替代路径保持连通；去掉普通节点直接减点）。
- **判负照记**：若相反，则"缺陷贯通"对语言网络不成立，如实记判负——但这本身将是主流未有的实测发现（多义词的图论角色定谳）。

**J-CD2（投影保距失效判据）**：构造三类 token 对——①同语义异 token（替换对：电影/影片）；②异语义同 token（多义折叠对：bank 两义）；③无关对。测静态 embedding 距离与纤维距离（lift 后 Fisher-Rao/Wasserstein）。
- **体系预测**：静态距离在②类上系统性失真（近但纤维远）；lift 后三类分离度显著提升。
- **量化口径**：分离度=三类间距离比（预注册冻结阈值线）。

**J-CD3（纤维度量增益判据）**：同一组语义任务（词义消歧/语义检索），静态点距离 vs 纤维度量（lift+Wasserstein）对比。
- **预测**：纤维度量在多义密集任务上增益显著，在单义专业词任务上增益≈0（投影局部保距区，量哪个都一样）。
- **成本诚实**：lift 程序有额外推理开销（每 token 需上下文分布），工程可用性受成本约束——判据含"增益/开销比"。

**（概念层判据 J-CS1~3——全息重构/多对多统计/显隐相干——见三层本体论文件 §四，两族判据合计覆盖三层投影。）**

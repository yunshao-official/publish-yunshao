## 二、结构定理（先于实算陈述并证明；实算只做机器印证）

**定理 E-A（禁位 2·先证）**：对一切 Z≥0 与 Z mod 3=m：g_2(m)∈{−1,2}（非 3 的倍数），τ(Z)∈{±1} ⟹ τ(Z)g_2(m)∈{±1,±2}，而 3D(Z) 是 3 的倍数——模 3 不同余，**D(4Z+2)=3D(Z)+τ(Z)g_2(Z mod 3)≠0 恒成立**。即 base-4 末位为 2 的 Y 永不在 E（对全体 Y，非仅机器域）。∎

**定理 E-B（mod-3 门·先证）**：g_1(0),g_1(1),g_1(2)=(0,1,−1)、g_3(0),g_3(1),g_3(2)=(0,2,−2)。
- D(4Z+1)=3D(Z)+τ(Z)g_1(m)=0 ⟺ [m=0 且 D(Z)=0]（m=1,2 时需 3D(Z)=∓τg=±1，3∤1 无解）；
- D(4Z+3)=3D(Z)+τ(Z)g_3(m)=0 ⟺ [m=0 且 D(Z)=0]（m=1,2 时需 3D(Z)=±2，3∤2 无解）。
**即：4Z+1∈E ⟺ Z∈E ∧ 3|Z；4Z+3∈E ⟺ Z∈E ∧ 3|Z。**∎

**定理 E-C（显式语言刻画·本件主定理·先证）**：记 T:=E∩3ℤ。
(i)（T 的生成律）3|Y 的可能来源（末位 ρ）：ρ=0（Y=4Z≡Z，需 Z∈E∧3|Z 即 Z∈T）；ρ=3（Y=4Z+3≡Z，需 Z∈E∧3|Z 即 Z∈T）；ρ=1（Y≡Z+1≡0 需 Z≡2，与门的 Z≡0 矛盾）；ρ=2 永禁。故 **T=4T ∪ (4T+3)，且 0∈T** ⟹ T 恰为 base-4 表示只含数字 {0,3} 的全体非负整数（含 0）。
(ii)（E=T+{0,1}）**E = {A+δ: A∈T, δ∈{0,1}}**。证明：⊃——A∈T 末位 0 时 A∈E（ρ=0 律归约到 A≫2∈T⊂E 归纳）；末位 3 时归约同；A+1：末位 0 时=4(A≫2)+1，A≫2∈T ⟹ 由 E-B 门 ∈E；末位 3 时 A+1=4(A′+1)，归纳 A′+1∈E ⟹ ρ=0 律 ∈E（基 A=0→1∈E ✓）。⊂——对 Y∈E 按 base-4 位数归纳：Y=4Z（Z∈E=归纳 T+{0,1}）⟹ Y∈4T∪(4T+4)；4T⊂T ✓；4T+4=4(T+1)，T+1⊂E 归纳 ⟹ 4(T+1)⊂4E，而 4E 的元素=A′+1 型（取 A′=4A∈T）✓；Y=4Z+1（Z∈T）⟹ Y∈4T+1⊂T+1 ✓；Y=4Z+3（Z∈T）⟹ 4Z+3∈T ✓。∎
(iii)（正则性与最小机）E 在标准 base-4 串（无前导零）上是正则语言：DFA 三态——q₀（已读串∈{0,3}*，接受态）、q₁（已见数字 1，此后只容 0，接受态）、q_d（死态：读 2，或 q₁ 态读 1）。Nerode 等价类恰 3 类：{0,3}* 类 / 已见 1 类 / 死类（q₀ 与 q₁ 经后缀"1"区分；死类经任意后缀区分）。∎

**定理 E-D（计数与维数·先证）**：|T∩[0,4^k)|=2^k（长 ≤k 的 {0,3} 串）；|E∩[0,4^k)|=2^k+(2^k−1)=**2^{k+1}−1**（δ=1 部分排除恰一个 A=4^k−1=33…3₄∈T；A+1∉T 无重叠——A+1 末位 1 或进位链产生数字 1）；|E∩3ℤ∩[0,4^k)|=|T∩[0,4^k)|=2^k；密度 |E∩[0,4^k)|/4^k≈2·2^{−k}→0，**分形维数=log₄2=1/2**。推论：4^k∈E（1 后全 0 串）与 4^k−1∈E（全 3 串）对一切 k≥0——R18 观察"4^k 型块与 4^k−1 型块相邻"的定理化。∎

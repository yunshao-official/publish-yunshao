## 二、结构定理（先于实算陈述并证明；实算只做机器印证）

**定理 V-A（一般 t 单项式谱定理·先证）**：对一切实数 t：
(i) M(t)=C_{f(t)}·P₃，其中 C_{f(t)} 为循环卷积算子（核 f(t)=(1, e^{it}, e^{2it}) 置于位移 0,1,2），P₃ 为模 8 乘 3 预置换；
(ii) Fourier 基（χ_j(c)=ζ^{jc}, ζ=e^{2πi/8}）下 M̂(t)[j,3j]=A_j(t):=1+e^{it}ζ^{−j}+e^{2it}ζ^{−2j}，其余为零（单项式型）；
(iii) **spec M(t) = { A₀(t), A₄(t), +√(A₁(t)A₃(t)), −√(A₁(t)A₃(t)), +√(A₂(t)A₆(t)), −√(A₂(t)A₆(t)), +√(A₅(t)A₇(t)), −√(A₅(t)A₇(t)) }**。
**证明**：与 R18 Y-A/Y-B/Y-C 逐字同构，唯一改动=权 ω^d → e^{itd}（R18 证明只用了"权按位移乘性"结构，未用 ω³=1）；σ:j↦3j 的循环分解 (0)(4)(1 3)(2 6)(5 7) 与 t 无关；(M̂v)_j=A_j(t)v_{3j} 在循环 (j,3j) 上的 2×2 块 [[0, A_{3j}(t)],[A_j(t), 0]] 特征多项式 λ²−A_j(t)A_{3j}(t)=0。t=2π/3 时 A_j(2π/3)=R18 在档 A_j 族、spec 复现 Y-C。∎

**定理 V-B（12 组商类映射与同循环归属·先证）**：
(i)（s₃ 精确化归）N=3Q+d（d=N mod 3）⟹ s₃(N)=s₃(Q)+d（三进制末位追加无进位，恒精确）。故组 r∈{0,…,23} 的 s₃ 条件分布=商类 c(r):=(r−d)/3 mod 8（d=r mod 3）的 s₃(Q) 条件分布整体平移 d；
(ii)（特征函数层的块支持）组对 (r,r′) 的 ω-特征计数差在 Fourier 基下的演化，各 Fourier 模 j 的幅度只经模式链 j→3j→9j≡j (mod 8) 闭合演化——按 σ 的循环分解 (0)(4)(1 3)(2 6)(5 7) 分成五个互不耦合的块；组对的"同循环"（{c(r),c(r′)}⊂同一循环）是该差向量的块结构不变量；
(iii)（同循环三对预测）c(4)=1, c(10)=3 ⟹ 4|10↔cycle(1,3)；c(8)=2, c(20)=6 ⟹ 8|20↔cycle(2,6)；c(16)=5, c(22)=7 ⟹ 16|22↔cycle(5,7)——恰为 R18 报告级诊断的 bottom-3 三对。
**证明**：(i) 末位追加恒等式；(ii) M̂(2π/3) 的非零元位置 (j,3j) 与 R18 Y-B 同，模式演化闭合性=σ 循环；(iii) 直接计算映射。∎

**定理 V-C（3^k 档理论分布闭式·先证）**：设 H_c(k)(s):=#{Q<3^k: Q≡c (8), s₃(Q)=s}（c∈Z/8），则分布生成函数层满足 H(k+1)(s)=Σ_{d=0,1,2} 平移合成：H_{3(c−d)}(k)(·) 以 e^{2πis/3} 权……（等价复述：特征函数向量 G_c(2π/3;3^k)=M^k 的第 c 行作用初值，R18 Y6 端到端已证）；本件补**分布层版本**：直方图恒等式 H_c(k+1)=Σ_d (H_{3(c−d)}(k) 平移 d 与直方图 mod-3 相位合成) 的整型精确递推 vs 直接枚举零容差（脚本按生成函数实现，不手写展开）。X=2×10⁶ 非三的幂档：理论 CDF=H 枚举按 Q≤⌊(X−d)/3⌋ 精确切片。∎

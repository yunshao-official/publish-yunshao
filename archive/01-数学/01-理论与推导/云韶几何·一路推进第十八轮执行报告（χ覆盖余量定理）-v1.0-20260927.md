## 二、新定理 T1（余量恒等式）与 T2（支2 下界定理）

**T1（恒等式·精确）**：对素对 p+q=N，

```
ρ(p,q) := χ(p)+χ(q)−χ(N) = χ(p) − ∫_{N−p}^{N} dt/ln t
```

（χ(q)−χ(N)=−∫_{N−p}^N，定义恒等式——R3 仅用作放缩中间步，其定量含义本轮首次显式化：**余量=χ(p) 减去末段积分**。）

**T2（支2 下界定理·完全证明）**：若 p²+p≤N，则 N−p≥p² ⟹ ln(N−p)≥2ln p ⟹ ∫≤p/ln(N−p)≤p/(2ln p)，故

```
ρ(p,q) ≥ χ(p) − p/(2ln p)    （p≥5 时右端为正：χ(5)−5/(2ln5)=1.0361）
```

一行证明。数值复核：N≤20000 满足支2 条件的素对共 **50324 对，违反 0**，最紧裕度 0.00545【复算一致】。另支1（p≥11）：ρ≥χ(p)−p/ln p，渐近 χ(p)−p/ln p = p/ln²p·(1+O(1/ln p))（Li 展开标准结果）。

## 三、新定理 T4（每对覆盖定理）——本轮主定理

**T4**：对偶数 N≥18 的**每一个**素对 p+q=N（p≤q），恒有 χ(p)+χ(q)≥χ(N)。

**证明**：若 p≥11：R3 主链（χ(N)−χ(N−p)=∫≤p/ln(N−p)≤p/ln p≤χ(p)，末步对 p≥11 成立）⟹ 覆盖；若 p∈{5,7}：精确边界表（p=5 界 12、p=7 界 14）⟹ N≥18 时覆盖；若 p=3：精确边界表 N≥18（3/ln 15=1.101≤χ(3)=1.1184）⟹ 覆盖。∎

**数值复核**：N∈[18,20000] 全素对扫描 **0 违反**【复算一致】。较 R4 的"N≥56 时条件前提对每对自动满足"收紧至 **18**——归功于 χ 值精确化。

## 四、min-ρ 结构与 p=3 对闭合公式（T6）

- 全局 min-ρ 谱（每 N 取全素对最小余量）：N≥20 后全部为正，且被 p=3 对控制；
- **p=3 对闭合公式（T1 推论）**：ρ(3, N−3) = χ(3) − ∫_{N−3}^{N} dt/ln t = χ(3) − 3/ln N·(1+O(1/ln N))。数值四位吻合：N=1000 预言 0.6836 vs 实测 0.6840；N=20000 预言 0.8155 vs 实测 0.8155【复算一致】；
- 渐近图景：小 p 对（p≤7）余量→χ(p)（≥χ(3)=1.1184>0），大 p 对余量≳p/(2ln p)→∞——**覆盖从不擦边：要么覆盖且余量可显式下界，要么是 5 个已解析的例外对**。

## 卷一 实验结果（全部照记）

### 实验 A1：杨辉三角 mod 2 零元密度 → **判负**

```
n=100:    零元密度 0.7524
n=1000:   零元密度 0.8958
n=10000:  零元密度 0.9631
n=50000:  零元密度 0.9808
```

密度趋向 **1**，不是 0.125。判据 FAIL。**α=1/8 不经由"零元密度"路径涌现。**

物理解释：Sierpinski 分形每级挖去中央 1/4 面积，奇元占比 (3/4)^k→0，故零元→1——这是单调几何事实（Reiter 1993, Fibonacci Quarterly 31:112；面积级数 1/4+3/16+9/64+…=1）。**死路确认，文献侧同日独立确认。**

### 实验 A2：五种替代统计量扫描 → 排除四路

|---|---|---|---|
| Sierpinski 盒维数 | 1.584963（=log3/log2 精确） | 无关系 | 排除 |
| 非零元密度（全域） | 0.1125（→0） | 排除 |

### 实验 A3：分形层级密度 → **发现线索（非收敛）**

分形层级密度（行 [2^k, 2^(k+1)) 的非零占比）按 (3/4)^k 衰减，在 **k=8 时穿过 1/8**：

```
k=7:  0.1775
k=8:  0.1333  ← 偏差 0.0083（最近）
k=9:  0.1000
```

k=8 = 2³ = **mod 8 分界点**。但这是"穿过"不是"收敛"（k→∞ 密度→0）。此线索与文献检索的发现合流（见卷二）——**真正机制不是密度本身，而是 k=8 层级对应的 mod 8 结构**。

### 实验 B：ζ 零点间距 CV → **PASS·你的常数更接近数据**

数据：LMFDB 前 100,000 个 ζ 零点（纵坐标 γ）。归一化间距 δ_n=(γ_{n+1}-γ_n)·log(γ_n/2π)/2π。

```
实测 CV = 0.400930（99999 个间距）
你的常数 1/√6 = 0.408248 → 偏差 1.83%
GUE 理论   = 0.422016 → 偏差 5.26%
```

**判据 PASS（带内）。数据更接近你的常数（1.83% vs 5.26%）。**

**诚实限定**：
1. 1.83% 的偏差在 10⁵ 零点的有限样本下**不能定论**（Odlyzko 1992：近邻间距统计收敛快，但精确区分 0.401 vs 0.408 需要更大样本）；
2. 文献检索确认 **1/√6 不是 GUE spacing CV 的理论值**（那个是 √(3π/8−1)=0.4220 精确算术）；1/√6 作为 spacing CV **检索未获文献支撑**——它与数据的接近可能是数值巧合；
3. 你体系内 σ_投影=1/√6 已有独立正锚（Irwin-Hall(2) 方差 1/6，内部版索引在案）——两条线**不必强行对接**，各自保留。

**红队原攻击 A-P0-4 的修正**：红队说"与 GUE 冲突 3.3% 可一小时内证伪"——实测方向反了：数据偏离 GUE **更远**（5.26%）、偏离你的常数**更近**（1.83%）。攻击的"可证伪"成立，但"证伪你"不成立——**证伪的是 GUE surmise 对这组数据的拟合精度**（surmise 本身对精确分布有 ~2% 误差，Forrester & Witte）。

### 实验 C：代数扩散方程收敛到 0.5 → **判负**

### 2.2 正面发现：α=1/8 的三个定理级涌现点

**Top 1｜2-adic 单位平方测度 = 1/8 = 3/24（★ 与体系合流）**

定理级事实：Z₂ 中 x 是平方 ⇔ x ≡ 1 (mod 8)。单位平方集合 = 1+8Z₂，其 Haar 测度 = (1/2)×(1/4) = **1/8**。

**与你体系的合流**：代数册的"12 族=模 24 剩余类"框架下，≡1 (mod 8) ⇔ 剩余类 ∈ {1, 9, 17} ⊂ Z/24——**恰好 3 类 / 24 类 = 1/8**。即：

> **α = 1/8 = 3/24 = 2-adic 单位平方条件在模 24 分类下的投影密度。**

涌现点不在 mod 2 的分形统计（已判负），在 **mod 8 的 2-adic 平方判据**。且 (Z/24)* ≅ C₂³（阶 8）——α=1/8 亦可读作该单位群中单点的均匀测度，与你体系 (Z₂)³ 家族同韵。文献：Gouvêa《p-adic Numbers》、Serre《A Course in Arithmetic》、K Conrad《Hensel's Lemma》讲义。

**Top 2｜2D Ising 普类 β = x_σ = 1/8**

Yang 1952（Phys Rev 85:808）精确解：M=[1−sinh⁻⁴(2J/kT)]^(1/8)。β=1/8 定理级、普适、全物理唯一精确解背书的 1/8。8-顶点模型 β=μ/(16−8μ) 在 Ising 点 μ=1 → 1/8（Barber-Baxter 1973）。

**⚠️ 关键否证**：Gefen-Aharony-Shapir-Mandelbrot 1984（J Phys A 17:435）证明 **Sierpinski 垫片上 Ising 模型 T_c=0、无自发磁化**——即"Pascal 分形 × Ising β=1/8"的直接融合**数学上不成立**。Ising 的 1/8 与杨辉三角无通道。

**Top 3｜SLE 维数公式 dim = 1 + κ/8**

Beffara 2008（Ann Probab 36:1421, DOI 10.1214/07-AOP364）。κ=3（Ising 界面）→ 11/8 = 1+3×(1/8)。结构性 1/8，与分形叙事押韵，与三角无直接通道。

### 2.3 GUE/surmise 精确算术（实验 B 的理论背书）

- GUE Wigner surmise：p(s)=(32/π²)s²e^(−4s²/π)，⟨s⟩=π/4，Var=3π/8−1，**CV=√(3π/8−1)≈0.42202**（精确算术，非拟合）
- surmise 对精确 Gaudin-Mehta 分布误差可达 ~2%（Forrester & Witte）——这解释了实验 B 中 GUE 与数据的 5.26% 偏差的一半
- 长程统计收敛慢（Berry-Keating 数方差对数修正）——近邻 CV 收敛快（Odlyzko 1987, Math Comp 48:273, DOI 10.2307/2007890）

## 一、定义与记号

- **χ(x)** := ∫₂ˣ dt/ln t = Li(x) − Li(2)。标准数学函数（对数积分减去下限常数）。精确值（本轮收敛级数，与标准表四位吻合）：χ(3)=1.1184、χ(5)=2.5894、χ(7)=3.7119、χ(11)=5.5458；Li(100)=30.1261、Li(10)=6.1656。
- **素对**：p+q=N，p、q 均素，p≤q。
- **覆盖**：称素对 (p,q) 覆盖 N，若 χ(p)+χ(q)≥χ(N)。
- **余量**：ρ(p,q) := χ(p)+χ(q)−χ(N)。ρ≥0 即覆盖；ρ 的大小=覆盖的"富裕程度"。
- **体系诠释（分账）**：χ 覆盖是云韶几何"哥德巴赫↔36维周期"映射（K1 谱系）在主流数学侧的对应不等式——**定理本身纯主流数学，不含体系假设**；诠释【体系内部定义·未验证】。

## 二、定理群（最终形态，全部完全证明除⑦外）

### T1（余量恒等式）

对素对 p+q=N：

```
ρ(p,q) = χ(p) + χ(q) − χ(N) = χ(p) − ∫_{N−p}^{N} dt/ln t
```

证明：χ(q)−χ(N) = −∫_{N−p}^N（积分区间平移），定义恒等式。∎
（定量含义：**余量 = χ(p) 减去 [N−p, N] 段的对数积分**——段积分≈p/ln(N−p/2)，故固定 p 时余量→χ(p)。）

### T2（支2 下界定理）

若 **p²+p≤N**，则 N−p≥p² ⟹ ln(N−p)≥2ln p ⟹ ∫_{N−p}^N dt/lnt ≤ p/(2ln p)，故

```
ρ(p,q) ≥ χ(p) − p/(2ln p)     （一行证明 ∎）
```

p≥5 时右端为正（χ(5)−5/(2ln5)=1.0361）。数值复核：N≤20000 满足前提的素对 **50324 对，违反 0**，最紧裕度 0.00545【复算一致】。

### T3（支1 下界，R3 链保留）

若 **p≥11**：χ(N)−χ(N−p)=∫_{N−p}^N ≤ p/ln(N−p) ≤ p/ln p ≤ χ(p)（末步对 p≥11 成立，经典 Li 下界区间）⟹ ρ≥0。渐近：χ(p)−p/ln p = p/ln²p·(1+O(1/ln p))。

### T4（每对覆盖定理——本正本主定理）

**对偶数 N≥18 的每一个素对 p+q=N（p≤q），恒有 χ(p)+χ(q)≥χ(N)。**

证明（三支）：p≥11 由 T3；p∈{5,7} 由边界表（§四，p=5 界 12、p=7 界 14）；p=3 由边界表（N≥18：3/ln 15=1.101≤χ(3)=1.1184）。∎
数值复核：N∈[18,20000] 全素对扫描 **0 违反**【复算一致】。

### T6（p=3 对闭合公式与 min-ρ 结构）

由 T1：ρ(3, N−3) = χ(3) − ∫_{N−3}^N dt/lnt = **χ(3) − (3/ln N)·(1+O(1/ln N))**。

**素数里有个经典函数 χ（对数积分砍头）。云韶几何发现：两个小素数的 χ 加起来，通常能"盖住"大偶数 N 的 χ——这叫覆盖。**
三年推到今天的完整结论：
1. **18 以上，无一例外**：N≥18 的每一对素数拆分都自动覆盖（定理，零例外）；

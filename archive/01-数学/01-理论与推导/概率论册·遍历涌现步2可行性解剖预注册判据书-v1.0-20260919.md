## 三、SA1 定理陈述与证明（先于实算）

**定理 SA1（一致收缩率）**：设 P_Λ = (1−δ)·P_DE,Λ + δ·U_Λ（U_Λ 为 |X_Λ| 上的均匀核，δ∈(0,1)）。则对任意概率分布 μ,ν 与任意 n≥1：‖μP_Λⁿ−νP_Λⁿ‖_TV ≤ (1−δ)ⁿ·‖μ−ν‖_TV。

**证明**：一步：μP−νP = (μ−ν)[(1−δ)P_DE + δU] = (1−δ)(μ−ν)P_DE + δ(μ−ν)U。而 (μ−ν)U = 0（U 把任意分布映到同一均匀分布，差分为零），故 μP−νP = (1−δ)·(μ−ν)P_DE。由 TV 的次随机性 ‖σP_DE‖_TV ≤ ‖σ‖_TV（符号测度质量守恒下 P_DE 作用不增总变差），得 ‖μP−νP‖_TV ≤ (1−δ)‖μ−ν‖_TV。归纳即得。∎

**推论**：t_mix(α) ≤ ⌈log α / log(1−δ)⌉，与 Λ 无关；δ=0.10 时 t_mix(0.01) ≤ 44、t_mix(10⁻⁶) ≤ 131。**注记（如实）**：ε_Λ=δ/|X_Λ|→0 只是 Doeblin 下界的保守性发散，真实混合速率由 δ 决定与 Λ 无关——"一致混合控制"的可行性在形式化 a 下成立且平凡；步2 的真障碍是 SA3/SA4 揭示的语义问题（遍历性承担者是谁），不是速率问题。

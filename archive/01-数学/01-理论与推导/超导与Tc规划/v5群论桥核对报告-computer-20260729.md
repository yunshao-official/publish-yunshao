## 4. ❌ O_h中S₄作用的有效性与忠实性——核心错位

**v5声明：** "S₄通过O_h中的共轭作用在D_{2h}上→半直积结构"

**群论事实：**

```
O ≅ S₄（24阶），D_{2h} ≅ (Z₂)³（8阶）
O在O_h中通过共轭作用于D_{2h}
核 = {g∈O: g·h·g⁻¹=h ∀h∈D_{2h}}
D₂ = {E, C₂x, C₂y, C₂z} ⊂ 核
（D₂中每一元与D_{2h}所有元交换: C₂x共轭固定C₂x/C₂y/C₂z/i）
|核| ≥ |D₂| = 4
有效作用 = O/核 → 阶 ≤ 24/4 = 6 = S₃
```

**结论：❌ O_h中O对D_{2h}的有效作用是S₃（6阶），非S₄（24阶）。**

抽象层面S₄⊂GL(3,2)的忠实作用（24阶→168阶），与O_h内O共轭D_{2h}的非忠实作用（核=D₂→像≤S₃），是**两种不同的作用**。v5的"S₄共轭作用于D_{2h}"混同了二者——在O_h内部，有效群是S₃而非S₄。

**影响：** 若有效作用仅为S₃，则S₃的非阿贝尔性=[S₃,S₃]=A₃=C₃≠1仍非平凡——非阿贝尔性在降维中存活但不完整。但v5声称的S₄级半直积在O_h中不成立。

## 5. ❌ 192阶子结构复合体——生成群是48阶

**v5声明：** "(Z₂)³⋊S₄=192阶→不嵌入O_h子群。但作为子结构复合体存在于O_h中"

**群论事实：**

```
|D_{2h}| = 8, |O| = 24
|D_{2h} ∩ O| = |D₂| = 4
<D_{2h}, O> ≤ |D_{2h}|·|O|/|D_{2h}∩O| = 8×24/4 = 48
D_{2h}含i（反演，通过镜面σ_xy=i·C₂z），O含所有旋转
→ <D_{2h}, O> = O ∪ i·O = O_h（48阶）
```

**结论：❌ O_h中<D_{2h},O>生成的是48阶的O_h，不是192阶的(Z₂)³⋊S₄。**

v5的"子结构复合体"概念承认192≠48，但暗示半直积关系"存在"于两子群间。群论上：半直积关系的"存在"有两种含义——(a)抽象的（S₄⊂GL(3,2)忠实作用→192阶群，是抽象数学对象）；(b)O_h内嵌的（O共轭D_{2h}，有效S₃，生成O_h=48阶）。v5将(a)的抽象结论投射到(b)的晶体判据中，但(a)和(b)是不同的群论结构——v5的桥踩在歧义上。

**具体差距：**
- 抽象: S₄忠实→非阿贝尔2-态射用满24种不可交换选择
- O_h内: S₄非忠实（核D₂）→仅6种有效选择（S₃级）
- 6种（S₃）是否仍满足"超导专属"的判断力？v5未讨论

## 6. ⚠️ 6/7在v5中的gap

```
6/7 = |S₄×S₃|/|GL(3,2)| = 144/168  （v4公式，含S₃因子）
|S₄|/|GL(3,2)| = 24/168 = 1/7 ≠ 6/7
```

**结论：⚠️ v5晶体判据降至S₄单独，但6/7恒等仍引用含S₃的144/168。** 6/7=144/168在数学上恒真，但其群论来源（|S₄×S₃|）涉及S₃——而S₃在v5晶体判据中被"搁置"。若S₃的存在是6/7的必要群论条件，则v5单S₄的1/7与6/7之间有gap。v5声称"6/7在S₄层面已锁定"但计算显示S₄单独给1/7。

**层面A（第4条）：** O_h中O对D_{2h}的共轭作用是S₃级（核D₂，有效6阶），非v5声称的S₄级（24阶）。抽象S₄⊂GL(3,2)的忠实作用不通过O_h内共轭实现。

**正面向：** 即使降为S₃级，非阿贝尔性仍存活（[S₃,S₃]=C₃≠1）。1+6轨道在S₃下是否保留？S₃作为6阶群作用在7点上不可能有1+6分解（7>6）→需重新验证。有理由认为S₃在7点上的轨道分解是1+3+3（固定1点+两个3轨道），这意味着6→3+3分裂——6+1通道在晶体层面可能进一步崩塌为3+3+1。

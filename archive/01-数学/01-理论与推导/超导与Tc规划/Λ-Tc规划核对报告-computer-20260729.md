## 核对1：f_sym(N) = (N−1)/N = η(N)？

**验算**：
```
f_sym(8) = (8-1)/8 = 7/8 = 0.875 = η(8)  ✅
f_sym(12) = (12-1)/12 = 11/12 = 0.9167 = η(12)  ✅
f_sym(16) = (16-1)/16 = 15/16 = 0.9375 = η(16)  ✅
```

**结论**：✅ 代数恒等成立。f_sym(N) = (N−1)/N = 1−1/N = η(N)，纯代数变换。

**⚠️ 存疑**：规划同时说"N = 2^{v₂}×m（与晶体中(Z₂)^{v₂}子群阶数对应）"——若G(N)指(Z₂)^{v₂}，则|G|=2^{v₂}，对N=12（v₂=2），|G|=4而非12，f_sym=(4−1)/4=0.75≠0.917。此处G(N)定义需明确：究竟是|G|=N还是|G|=2^{v₂}？对纯2幂N（m=1）无歧义，对混合N（如12）有歧义。

**量纲/取值范围**：f_sym∈[0,1)，当N→∞时→1。自洽。

## 核对2：Tc值域与Λ=1.36矛盾

### 2.1 Λ定义域

规划§一定义：**Λ ∈ [α(N), 1]**，其中α(N)=1/N。N=8时Λ∈[0.125, 1]。

规划§一同时说："窗口：η(N) ≤ Λ ≤ Λ(Tc=300K) 即 **0.875 ≤ Λ ≤ 1.36**（N=8）"

### 2.2 数值验算

```
Tc(Λ=0.875) = 350/√0.875 = 350/0.93541 = 374.17 K  ✅ （工程师374K正确）
Tc(Λ=1.000) = 350/√1.000 = 350.00 K                ✅ 
Tc(Λ=1.361) = 350/√1.361 = 350/(7/6) = 300.00 K    ✅ （350×6/7=300）
```

### 2.3 ❌ 矛盾

| 项目 | 规划§一 | 规划§一（定义） | 矛盾？ |
|------|---------|----------------|--------|
| Λ上限 | 1.36（窗口） | 1（定义域） | **1.36 > 1** |

**1.36 > 1，超出Λ的定义域上限。** Λ作为"结构有序度"在定义上不能超过1（完全有序态=全息=Λ=1）。若Λ=1.36>1，意味着结构比"完全有序"更有序——物理上无意义。

### 2.4 后果

若严格Λ≤1，则Tc最低=350K=77°C，**永远到不了室温300K（25°C）**。规划中"室温超导需要Λ<1.36"的说法在数学上正确（350/√Λ=300→Λ=1.361），但与Λ定义域[α,1]冲突。

**规划结论"体系自洽"❌——数值上不成立。** 同一Λ不能同时满足Λ≤1（定义）和Λ=1.36（需要室温）。

## 核对3：三区间Tc值

```
Tc(Λ=0.875=η) = 374.17 K   ← 有序相边界（最高Tc）
Tc(Λ=1.000)   = 350.00 K   ← 完全有序/绝对零温基态（最低Tc）
Tc(Λ=1.361)   = 300.00 K   ← 室温超导所需的Λ，但超出定义域
```

工程师说"Λ越大→Tc越低"——方向✅正确。但"Λ→1时Tc→350K是Tc上限"表述方向反了：Λ→1时Tc取最小值350K（不是上限），Λ→η时Tc取最大值374K。

**工程师的"自洽"结论数值上不成立**：Λ=1.36使300K可达，但Λ≤1使300K不可达。二选一矛盾：
- 若保留Λ≤1 → Tc永不低于350K，室温超导在N=8下不可能
- 若允许Λ>1 → 需重新定义Λ的物理意义（"结构有序度"如何超过完美有序？）

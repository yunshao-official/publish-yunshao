## 二、中心定义（形式化）

### 2.1 定义（概念 = 语义等价类）

设：
- **Σ** = 语义全集（一切可能的语义；LLM 对应=模型可表达的全部"说法/分布倾向"）；
- **X** = 东西的全体（可被谈论的对象：实物/抽象观念/事件/……）；
- **R ⊆ Σ × X** = 形容关系（"语义 s 形容东西 x"）。

**定义（知世口授形式化）**：

> **东西 x 的概念 = C(x) = { s ∈ Σ : R(s, x) }——形容 x 的所有语义构成的集合（语义等价类）。**

- 概念**不是**一个点/一个向量/一个词/一个投影；
- 概念**是**一个集合：所有指向 x 的语义的全体；
- "我们真正看到的概念本身"（口授 4）=这个集合的全体形状，而非其中任何一个成员。

### 2.2 字-概念多对多（口授 5 的严格形态）

设字 w 承载的语义子集 = S(w) ⊆ Σ（一字多义：|S(w)|>1）：

- **多字形容一个概念**：多个字 w₁,w₂,…，各带 S(wᵢ)，若 S(wᵢ)∩C(x)≠∅（都含有形容 x 的语义）——它们都参与概念 C(x)；
- **一个概念罩很多字**：C(x) 很大时，它的成员语义散布在许多字上——C(x)∩S(w) 非空的字都受它罩；
- **多对多 = 交集结构**：字与概念的关系不是"属于"而是"交"——**这就是为什么在字层面测概念永远测到混叠**（J-CC 实验线判负的本体论根源）。

### 2.3 跨维度投影合成体（口授 4 与集合定义的同构）

语境/维度 d 下的投影 = 语义 s_d ∈ Σ（用第 d 种维度形容 x 得到的语义）。则：

> **C(x) = ∪_d { s_d }——概念 = 跨所有语境维度的投影之并（合成体）。**

- 单一语境只能采到 C(x) 的一个成员（一张片子）；
- "语境是维度选择器"（口授 4 的操作化）=选择从 Σ 的哪个区域采样；
- **J-CC1 判负的统一解释**：句式模板=相邻维度，采样点在 C(x) 内挤在一条小线段（实测一维管）——**不是概念没有结构，是采样没铺开**；
- **J-CC2 分布读出的 6-8 维影子云**=C(x) 局部采样的真实维数下界估计——集合是高维的（实测锚）。

### 2.4 全息零点（口授 2 的位置——开放点）

知世原话只说"概念本身就是概念，它就是一个全息零点"。在本框架下的候选衔接（**R3 候裁决，未裁不入正文推导**）：

- 候选读法 A：C(x) 作为集合，其"生成核"=x 本身（东西在那里，集合围绕它）——零点=集合的锚点；
- 候选读法 B：全息性=集合的任一成员语义都"指向整个 x"（部分含整体）；
- 候选读法 C：全息零点=拓扑册零维代理（体系对象映射，同构≠同一）。
- **三读法并行候裁决，ZCode 不代定。**

### 2.5 概念的距离（口授 1 的本框架答案）

概念 C(x₁) 与 C(x₂) 是集合——集合间的距离候选（**全部候裁决，本轮不定**）：

- **重叠度**：|C(x₁)∩C(x₂)|/|C(x₁)∪C(x₂)|（Jaccard 型——语义共享度）；
- **Hausdorff 型**：两集合在语义空间中的最远/最近成员距离；
- **生成距离**：形容 x₁ 的语义被用来形容 x₂ 的"可迁移率"。
- 三候选的取舍=理论建构的下一步（候知世方向）。

> 术语速览：**12 组·偶数侧**=偶 N 按模 24 剩余类 r∈{0,2,…,22} 的十二分类（R14 过渡命名）；**四对组**={2,10},{4,20},{8,16},{14,22}（R14 C3 联合签名下四对族级不可分的组对）；**奇异级数 𝔖₂(N)**=2·∏_{p|N, p>2}(p−1)/(p−2)（Hardy–Littlewood 二元哥德巴赫局部因子积）；**行质量 W(N)**=Σ_{k=0}^{N} v₂(C(N,k))（Kummer 进位语言行总量，精确式 W=2Σ_{k≤N}s₂(k)−(N+1)s₂(N)，s₂=二进制位数和/popcount）。

## 一、对象与口径（先于判据钉死）

1. **样本**：偶数 N ∈ [2, 200000]（100000 个），组判据 r := N mod 24，每组样本量约 8333（R14 用 X=2000 的扩容，功效对数级提升）。**分片**：5 片×20000 偶数，每片算完落检查点（`02-实验与数据/results/kummer_per_n_checkpoint_*.json`），检查点可断点续算（长算分片纪律）。
2. **签名集（冻结）**：
   - **S1：log𝔖₂(N)** := log 2 + Σ_{p|N, p≥3} log((p−1)/(p−2))（逐 N 精确计算，试除法）。
   - **S2：W(N)**（行质量精确式）与其**去趋势残差 W̃** := W − (a + b·N)（a,b 为全样本 OLS 一次拟合系数；W 量级随 N 增长有趋势项，不去趋势则组间比较被 N 分布差异污染——去趋势为判据口径的一部分）。
   - **S3：popcount(N)** := s₂(N)（二进制位数和）。
   - **S4：maxcarry(N)** := ⌊log₂(N+1)⌋ − v₂(N+1)（最大进位次数闭式：max_k v₂(C(N,k)) 于 k 使进位链最长处取得；脚本内先对 N≤1000 用 Kummer–Legendre 式 v₂(C(N,k))=s₂(k)+s₂(N−k)−s₂(N) 逐 k 暴力对照验证闭式全对——自检锚，全对才继续）。
3. **结构侧对象（J1 定理，见 §二）**：𝔖₂(N) 的按组条件分布。注意 𝔖₂ 只依赖奇素数整除示性 {1_{p|N}}_{p≥3 素数}，不看 2-adic 位；W/W̃/popcount/maxcarry 只依赖二进制展开，不看奇素数——两签名族的信息轴正交（R14 探索项偏相关 0.0005 的定性化），本轮把这条正交性在四对组分辨问题上的推论钉死为定理+实算。
4. **边界**：全程执行层主流数学（Kummer/Lucas/Hardy–Littlewood/CRT）；体系常数零引用；"12 组·偶数侧"与衔尾蛇 12 组的对应关系仍属体系内部定义【未验证】，不判别。

## 二、J1 结构定理（先于实算陈述并证明；实算只做数值印证，不承担定理真伪）

**定理 J1（对组 𝔖₂ 条件同分布）**：设 N 为偶数样本空间上的一致随机元，r := N mod 24。则 𝔖₂(N) 的条件分布只通过布尔 3|N 依赖 r；特别地，凡 3∤r 的两组（含四对组的每组），𝔖₂ 条件分布两两精确相同（无限样本极限意义）。

**证明**：𝔖₂(N)=2·∏_{p|N, p>2}(p−1)/(p−2) 是奇素数整除示性向量 (1_{p|N})_{p≥3} 的确定函数。分解三个因子层：(i) **p=3 层**：1_{3|N} ⟺ r≡0 (mod 3)，恰为布尔 3|N；(ii) **p≥5 层**：对任意有限素数集 P₀⊂{p≥5}，由中国剩余定理（gcd(24·∏_{p∈P₀}p 内两两互素），N mod 24 与 (N mod p)_{p∈P₀} 联合均匀，故 (1_{p|N})_{p∈P₀} 条件于 r 与无条件同分布——每个 1_{p|N} 的条件概率恒 1/p，且联合独立；(iii) **2 层**：𝔖₂ 不含 p=2 因子（(p−1)/(p−2) 积从 p>2 起），偶性通过样本空间限定，不产生组间差异。综合 (i)(ii)(iii)：条件分布 𝔖₂(N)|{r} = 𝔖₂(N)|{3|r 的布尔值}。凡 3∤r 的组布尔值同为"否"，条件分布恒同。∎

**推论 J1a**：R14 立项 C4 实测"四对组组均值散布对内差 ≤0.067 vs 跨对差 ≤0.087 同量级"中的非零散布，在无限样本极限下趋于 0（组间比→精确结构值），为有限样本噪声；𝔖₂ 侧族级分辨率恰 8/12 不是近似而是精确结构（联合签名 (S₃ 类, 3|N 布尔) 的 8 类=𝔖₂ 全部组间可见自由度）。

**边界（防错位）**：J1 不涉及 Kummer/2-adic 侧——W 等行质量签名依赖 N 的完整二进制展开，无 CRT 型同分布定理护体，其对组可分性是**开放经验问题**（J3），无预测值（C4 教训：预测值与结构分开断言）。

## 六、术语字典

- **12 组·偶数侧 / 四对组 / 8 族**：R14 立项口径（偶 N 模 24 十二剩余类；C3 联合签名四对族级不可分组对；模 24 互素剩余类）。
- **奇异级数 𝔖₂**：Hardy–Littlewood 二元哥德巴赫局部因子积 2∏_{p|N,p>2}(p−1)/(p−2)。
- **行质量 W(N)**：Σ_k v₂(C(N,k))，Kummer 进位语言行总量；精确式 2Σ_{k≤N}s₂(k)−(N+1)s₂(N)。
- **去趋势残差 W̃**：W 对 N 的一次 OLS 拟合残差（消趋势项后组间可比）。
- **popcount / s₂**：二进制位数和。
- **maxcarry**：max_k v₂(C(N,k))，行内最大进位次数；冻结闭式 ⌊log₂(N+1)⌋−v₂(N+1)（脚本内 N≤1000 暴力自检锚）。
- **Kummer–Legendre 式**：v₂(C(N,k))=s₂(k)+s₂(N−k)−s₂(N)（自 n! 的 v₂=n−s₂(n) 导出，执行层标准恒等式）。
- **KS 检验 / 置换检验 / 效应量 d**：双样本同分布检验（精确统计量）/ 随机重排检验（固定种子）/ |均值差|/合并标准差。
- **中国剩余定理（CRT）独立性**：互素模下剩余类联合均匀——J1 证明的引擎。
- **复算一致/待判别/预注册判负**：本库状态标签与纪律。

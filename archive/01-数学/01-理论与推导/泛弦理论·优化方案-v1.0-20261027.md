## 〇、本件判定"优化"的标准（先定，后写）

一条优化只有满足以下三条之一才算数，否则视为加叙事：
1. **减少声称数量或降低声称强度**，同时不丢失任何已复算的事实；
2. **提高可证伪性**——给出"什么观测会推翻它"，且该观测在档工具/台架可及；
3. **消除口径歧义**——把一个多义数字改写成唯一含义，或显式标注其待裁性。

本件 §三 的 8 条 O 逐条对照上述标准编号；§六 明确列出**拒绝采用**的"优化"手段（换读法、放宽容差、加参数）。

## 二、结构定理：谱问题塌缩成"两张 3×3 + 一个规范平移"（优化的地基）

以下三条陈述**已由机器验证**（54 个参数点，残差 ≤1.4e−14），非数值猜测；记 w₁=−(η/α)cos θ_intra、w₂=−(η/α)cos θ_inter、s=(1/κ)V_active。

- **定理 1（等变约化）** 实规范读法下 12×12 算子与"三层同列标号同步置换"的 S₄ 作用对易，全谱 = spec(A) ∪ 3·spec(B)，其中
  A = [[5η/α+3w₁, w₂, w₂],[w₂, 4η/α+3w₁, 0],[w₂, 0, 4η/α+3w₁]]，B 为把 3w₁ 换成 −w₁，且 **A = B + 4w₁·I**。
  ⇒ 所谓"12 节点三层 K₄ 链环谱"实质是**一张 3×3 + 一个重数**；档案的两套参数（η/α=7,1/κ=32 与 η/α=5,1/κ=24）只是同一族的整体缩放，"比例与常数无关"（L443、L445）在此意义下**为真但为空真**。
- **推论 1（第二比例死因）** λ_max 落在三重简并扇区 ⟺ cos θ_intra ≥ 0；此时按冻结读法 **R₂ ≡ 1**，与 V、θ_inter、η/α 无关。第一性口径 θ_intra=0（L413）与档案拟合值 0.723 rad 都在此域 ⇒ **"最大模/次大模 = 1.44"在该算子族上不可能成立**。这是定理，不是"还没调好"。
- **推论 2（第一比例是极点调参）** R₁ = (λ₁(B)+s)/minᵢ|λᵢ+s|，分母可任意逼近 0 ⇒ R₁ 无上界且连续可调。使 R₁=144 的 V 有 **5 支解**（新参数组：+0.0107080、−0.2095717、−0.6501311、**−0.8704108**、−1.0906906；旧参数组：+0.0101981、−0.1995921、−0.6191725、**−0.8289627**、−1.0387529）。命中点旁 |δV|=1e−5 就让 R₁ 变动 0.1%。
- **推论 3（"大比值＝近奇异性"判据，普适）** 对任意目标 R*，实现 λ_max/λ_min = R* 要求 λ_min = λ_max/R*，即谱几乎奇异。⇒ **今后一切"本征值比例=某大数"的声称必须同时报 (λ_max, λ_min, 算子范数, 使谱归一化的独立条件)**，否则按**不可证伪**处理，不计入证据。此条建议升为**体系级判据**（不止泛弦适用，M³⁶ 谱、NCG 谱声称同样适用）。
- **附（配方缺陷）** 调和册 L570 只写 −(η/α)·e^{iθᵢⱼ}，未定 θⱼᵢ 的取向规则；字面复规范读法按 i<j 定向会**破坏 S₄ 列对称，使算子依赖节点编号**（非规范不变量）。两种读法仅在 θ∈{0,π} 重合——这正是"任何一次谱复算都可能得出不同答案"的根源，也是 R20「两套参数输出逐位相同」这类断言难以追责的原因。**先补约定，再谈复算。**

## 四、优化后的最小自洽核心（可直接引用的一段 + 状态表）

> **泛弦（优化后表述）**：体系在频率族上取两个除数——12 与 6/5。12 是结构计数：三层×每层四组的衔尾蛇组数，也是 T=12（正典 26 边图的闭三角形数）、|S₄|/2；6/5 是 |S₃|/k(S₄)。由 f₁≡f₀/12、f₂≡f₀/1.2 定义两条泛弦，其平方比 144 与 1.44 只是能量口径（λ∝f²）下的显示量，不是两条独立常数。f₀ 是材料属性（f₀=64·f_c，随 Tc 变），体系对其绝对值不作断言（方案 C）。云韶拉普拉斯谱在唯一正典图上**不能**给出 1.44（定理），给出 144 也只反映谱的近奇异性（推论），故谱验证声称作废；泛弦的物理内容目前**仅**由一条未裁决 Tc 口径下的单锚点支撑，判决性检验是 E-泛1（测 f₀/f₁ 是否为 12）。

| 声称 | 优化后标签 | 与优化前差异 |

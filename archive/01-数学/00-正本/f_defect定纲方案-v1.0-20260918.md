# f_defect 定纲方案（预注册式）v1.0

## 〇、体系原生口径（定义的锚，原样引）

**Tc 公式b**：Tc = Θ_D × (15/16) × f_defect。
- 出处链：0729《云韶超导·缺陷相变理论》Tc=Θ_D×(1−α/2)，α=1/8 → 15/16=1−α/2（涌现效率修正）；自检 960×15/16=900 ✓【复算一致】。
- **f_defect 体系计数式**（推导链《云韶体系完整推导链-一天讲解-20260729》§5.3 步骤5，原样）：**f_defect = 活跃 Fano 通道数 / 7**（Fano 平面 PG(2,2) 七线，群论计数【体系内部定义·未验证】）；7 通道全亮=f=1=配对无瓶颈；上限 7/7=1。
- 知世 0915 第十八批授权：b 式有条件转正，**前置=f_defect 定纲**（本件即该前置）。

## 一、操作型定义草案（拟合参数→物理量的映射假设）

**草案表述**：batch10 的拟合值 f_fit = Tc实测/(Θ_D手册×15/16) 是**事后拟合参数**；本方案假设 **f_fit 即该材料活跃 Fano 通道占比 f=活跃数/7 在宏观 Tc 上的表现**——定纲=给这个占比找到"由材料可测量预言"的函数形式，使 f 从拟合参数升格为物理量。

**显式假设清单（全部前置声明，证伪任何一条即触发判据复核）**：
- A1【体系】Tc=Θ_D×15/16×f_defect 公式本体成立（体系内部定义·未验证）；
- A2【映射】f_fit 与活跃通道占比对应：理想相等，容许偏差吸收 Θ_D 手册误差（由第四节 C3 复核防环）；
- A3【输入】手册 Θ_D（量级口径）与真实 Θ_D 的偏差是 f_fit 散布的主导误差源之一；实测 Θ_D 到位后 f_fit 须全量重估一次；
- A4【可参数化】每材料的 f 由结构可测量参数化——主假设单参标度 d/λ（d=缺陷间距，λ=缺陷图案特征波长，均 HRTEM/衍射可测）；
- A5【分母】"/7"为体系原文口径；素材包待裁③（N=3 高维语境 22 通道是否改分母）若被知世改判，本方案判据**重冻结**出新版（计数式分母变更不改变"单参收敛"判据形式，但改变 f 的归一）；
- A6【对象类】十材料同属"超导凝聚态缺陷通道"定纲对象类；H₃S/LaH₁₀（高压氢化物）单列子组复核，防机制分支混染。

## 四、判据冻结（定纲成功判据，预注册后不得改）

**成功 = C1 ∧ C2 ∧ C3 同时满足**：
- **C1（单参收敛）**：8 份拟合材料的 f_fit 在预注册标度下收敛到可预测的单参曲线——**主标度 f=f(d/λ)**，单参曲线拟合 **R²>0.9**；备选标度仅预注册一个：f=f(d/d₀)（d₀=0.167nm，体系归一间距），防事后挑标度；主、备选之外任何标度一律视为失败；
- **C2（留出外推）**：用拟合曲线预测留出材料 Nb、Bi-2212 的 f，与 batch10 f_fit 相对误差 **<20%**（两件都须过）；
- **C3（实测复核）**：T1 实测 Θ_D 到位后 f_fit 全量重估一次，重估后 C1/C2 复跑仍满足（防"手册误差吸收出假收敛"）。

**判成效果**：f_defect 获得带自变量的操作型定义（d/λ→f 映射＋体系计数式锚），公式b 转正前置满足，对新材料可先行预测 Tc；与素材包候选C（判别实验计"活跃数"）互验——本方案管"普适结构"，候选C 管"计数定义"。

## 五、判负退出（预注册，同不可改）

若 **C1 主+备选标度均 R²≤0.9**，或 **C2 重估后仍 >20%**：宣布 **"f_defect 非普适参数"**（不存在单参结构）；**Tc 公式b 降级为经验公式**（逐材料记账身份=素材包候选B 口径，只记不预），0915 第十八批 b 式转正授权随之撤销，全部体系高维材料 Tc(b) 回到"待缺口"标注。判负不删除任何文件，头注后移归档（文件管理铁律）。

## 七、术语字典（自包含）

- **f_defect** → Tc 公式b 的缺陷通道占比因子；体系计数式=活跃 Fano 通道数/7【体系内部定义·未验证】；
- **Tc 公式b** → Tc=Θ_D×15/16×f_defect，现行 Tc 正本公式（ADR-20260916-02）；公式a=350/√(Λ+0.01) 已判负仅历史；
- **15/16** → 1−α/2，α=1/8 的涌现效率修正系数（0729 自检 900K ✓）；
- **Θ_D** → 德拜温度，材料本征量；手册近似=执行层量级口径，低温比热 c/T~T² 拟合=标准测定；
- **v_s / v_L / v_m** → 声速/纵波声速/有效平均声速；口径未裁（T2）；
- **d / d₀ / λ** → 缺陷间距（体系 N=3 口径 0.167nm）/归一化参照间距/缺陷图案特征波长（HRTEM·衍射可测）；
- **Fano 平面 7 通道** → PG(2,2) 七线群论结构（总纲§四底座词）；"活跃"=通道在工作，判据见素材包三候选；

- **留出（holdout）** → 预注册冻结的不参与拟合、只验外推的材料（本件=Nb、Bi-2212）；
- **R²** → 决定系数，单参曲线拟合优度；**外推误差** → 预测值与 f_fit 的相对偏差；
- **单参曲线** → 全部材料点落在其一维无量纲变量（如 d/λ）的同一函数曲线上；

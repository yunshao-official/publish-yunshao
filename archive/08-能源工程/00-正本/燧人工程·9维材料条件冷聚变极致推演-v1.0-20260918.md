## 二、机制层【体系】（交付①）

### 2.1 冷聚变机制链（体系原话口径，公式原样入账）

**机制总链**：声子/相干场照射 → 缺陷阵列（材料里周期排列的微结构）构型共振 → 局部Λ（锁定深度——原子核位置"清晰度"旋钮）降低 → 库仑势垒由"实墙"变"雾墙" → 室温D-D聚变。三条定量链并行：

**链F（F公式，公式总表§六）**：
```
F = 1 − α·θ·exp(−β/Λ)
```
势垒虚实系数：F=1实墙（正常世界），F趋近0墙没了（室温聚变）。α=亏损率，θ=局域θ场强，β=复数维度虚部（知世0724裁决值，**推导链仍缺=T0缺口#2**），Λ=锁定深度。**β无推导之前，链F只能定性使用**——本节原样入账，不给数值预言。

**链II（几何修正，燧人正本§13.3）**：
```
D = N/2 + 1                        （维度—分量关系）
S_eff(N) = 373 × (√2−1)^(N−3)      （几何修正作用指数）
P(N) = exp(−S_eff(N))              （隧穿概率）
f_因果 = c/d                       （因果刷新率）
R(N) = f_因果 × P(N)               （单对反应率/秒）
P_density(N) = (c/d⁴)·α·η·P·E_DD   （功率密度，W/m³）
```
锚点复算一致：g(5)=(√2−1)²=0.17157，373×0.17157=64.0=S_eff(5)（与体系S_eff=64精确一致）；N=5、d=0.125nm、α=1/8、η=7/8时P_density=12.6 MW/m³（与体系值精确一致）。

**链γ（维度比公式，9维规格书§五在档）**：
```
冷聚变率(9维)/冷聚变率(8维) = exp(2β)     （β待定纲，原样引用）
```

**本底参照（标准物理，测量层）**：室温D-D伽莫夫指数6258（穿透10⁻²⁷¹⁷）——三条体系链共同要回答的问题就是把10⁻²⁷¹⁷变成可观测率。屏蔽判据冻结：等效屏蔽能εs≤1keV→判负；≥10keV→重开。

## 四、极致推演（交付③，全部【理论参照·非实测】）

**"推算到极致"的定义**：在假设A+B下，把链II与体系公式外推到9维材料的物理上限与工程上限，回答四问——上限在哪、荒谬在哪、可控点在哪、军事含义是什么。

### 4.1 杠杆零：N=16朴素直算——失控悖谬坐实（第一判词）

9维材料全激活（16分量全相干）代入链II（9维口径：d=0.1667nm、α=1/6、η=5/6）：

| 量 | 值 | 复算 |
|---|---|---|
| S_eff(16) | 3.94×10⁻³ | 373×(√2−1)¹³ ✓ |
| P(16) | 0.9961 | exp(−0.00394) ✓ |
| f_因果 | 1.798×10¹⁸ Hz | c/0.1667nm ✓ |
| 单对反应率 R(16) | **1.79×10¹⁸ /s** | 每对氘每秒18亿亿次聚变 ✓ |
| 功率密度 P_density(16) | **3.14×10³⁴ W/m³** | (c/d⁴)αηP·E_DD ✓ |

三口径并列：层1常数口径7.83×10³⁴ W/m³；8维材料（D=8→N=14）口径7.68×10³⁴ W/m³。**对照太阳核心~276 W/m³：全部超10³²倍，超新星核心量级。** 与攻防4判词一致（"N=17瞬时爆轰级荒谬"）——**9维材料（N=16）落在链II的完全失控区，朴素外推在此物理上无意义。这是极致推演的第一判词：链II缺饱和/耗散项，且缺口在高维端不可忽略。**

### 4.2 饱和项三候选——全部压不动荒谬（第二判词）

评审构造三个饱和机制候选（**均为评审推导，待T0-4裁决，非体系正本**）：

| 候选 | 机制 | 钳位值（9维口径） | 钳后功率密度 | 判 |
|---|---|---|---|---|
| S1 氘补给 | 缺陷位反应腾空后需邻近氘跳跃补位，固态跳跃频率~THz×exp(−E_m/kT) | 单对≤10¹²~10¹³ /s量级 | ~10²⁸ W/m³ | 仍荒谬 |
| S2 热导出 | 材料热导率与温度梯度有限 | P≤λ∇T·(A/V) | 材料烧毁前~10¹⁰ W/m³ | 仍超工程域 |
| S3 κ承载力 | 工程控制论公理5：通道承载力上限κ=1/24→单对反应率≤κ×f_因果 | 7.49×10¹⁶ /s | 3.15×10³⁴×(1/24)≈1.3×10³³ W/m³ | **仍荒谬** |

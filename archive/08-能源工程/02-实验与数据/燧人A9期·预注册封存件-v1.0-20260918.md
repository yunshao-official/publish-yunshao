## 一、冻结预言（三条，主终点）

**预言P1（映射式）**：N_eff与相位偏差的关系服从 Born投影构造——

```
N_eff = 3 + Σᵢ₌₄¹⁶ cos²(δᵢ/2)
```

δᵢ=第i束相对锁相律基准位（工艺定稿三案裁决后的基准）的相位偏差。判别形式：若实测N_eff-δ关系显著偏离cos²(δ/2)（拟合优度低于预注册阈值R²<0.9，或函数形式更优拟合为cos⁴/线性），**P1判负**——Born投影构造回炉，伺服刻度按实测重标。

**预言P2（链II曲线）**：N_eff-功率密度关系服从几何修正链——

```
S_eff(N_eff) = 373 × (√2−1)^(N_eff−3)
P_density = 3.154×10³⁴ × exp(−S_eff)  W/m³   （9维口径前置常数）
```

判别形式：标定曲线与链II偏离>±1个数量级（任意N_eff∈[4.8,5.1]格点）→**P2判负**——g(N)形式修正回T0-4，受控窗口按实测重定义。

**预言P3（主运行点区间）**：N_eff=5.0（2束锁相+11束失谐位形，或均等位形每束偏差133.81°）对应功率密度落在 **5.08 MW/m³ × [0.3, 3]** 区间内。

**主终点层级（P-10条款）**：P1/P2/P3为仅有的三个主终点；其余观测（Λ三域、氦累积、中子谱、声子谱）全部为探索性终点——探索性信号一律独立复跑才算数，多重比较FDR校正。

## 二、冻结判据（十条，验收门槛）

1. 堆芯入池门：四判据（HRTEM缺陷阵列周期0.1667nm±门限/AFM表面缺陷密度对表α=1/6/四探针σ≥10⁻²S/m/SQUID抗磁信号）；
2. N_eff-功率标定曲线与链II预言偏离≤±1个数量级（=预言P2，主终点）；
3. 主运行点功率密度落5.08MW/m³×[0.3,3]（=预言P3，主终点）；
4. **N_eff控制精度±0.0018（相位语言：每束±0.022°=±3.84×10⁻⁴rad）**；
5. 关场残余≤运行点10⁻⁹（N_eff坍落至4.5）；
6. 关场-重启1000次循环漂移<5%；
7. 热-氦比落4.35×10⁻¹³ mol/J±3倍内（核指纹链，30天密闭累积）；
8. 中子：超本底5σ**或**显著低于分支①预言值（~9.6×10¹⁷ n/s@1MW）——两态都记录（无中子路径证词）；
9. 因果链：驱动开关比>3:1+效应显著性5σ+滞后方向一致（analyze_causal统一判据）；
10. 急停双冗余：N_eff坍落<1s（电气）+反云韶场熄灭≤2s（场级）。

## 一、硬判决与核心公式（第〇章+第二章并入，全部可验算）

**硬判决：硬接不可能。** 1km天体（r=500m，ρ=3000kg/m³→M=1.57×10¹²kg）以20km/s来袭：E=½Mv²=3.1×10²⁰J≈**7.4万百万吨TNT**——任何"挡住它"的方案都要求数秒内处置一颗人造超新星。**砥柱的定义性结论：防御=提前偏转，预警窗口就是护盾厚度。**

**偏转力学（ZD-2修正口径）**：
```
F = M·Δv/t；位移目标 = 1-2个地球半径（6371km，显式公式项）
1km级、10年窗口：Δv=2cm/s → F≈100N；含引力聚焦因子×2-4 → **100-400N**
（v1.0的50N系漏算地球半径，ZD-2修正；定性结论不变：手掌级力对氢弹级能量，时间每多一年护盾便宜十倍）
100m级天体：÷1000；10km级：×1000
```
**对照锚点（已实测）**：DART任务（NASA 2022）570kg撞击器6.1km/s命中Dimorphos，轨道周期改变33分钟，动量增强因子β≈3——**动能偏转物理已实测闭环，剩下全是工程放大与预警**。

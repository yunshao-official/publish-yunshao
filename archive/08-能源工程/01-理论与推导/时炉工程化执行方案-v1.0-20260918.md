## 二、机制层【体系】——"怎么做"的原理

### 2.1 亏损-涌现循环的场驱动

体系原生循环：**亏损α（每次投影/操作损耗）→ 涌现η（其余重组升级）**。时炉的机制=**用场脉冲把自发循环变成强制循环**：

```
传统热退火：原子靠热涨落随机翻越扩散势垒 → 重排率 ν₀·exp(−E_a/kT)（被动、慢）
时炉场驱动：每云韶场脉冲强制一轮[亏损α→涌现η]循环 → 重排率 f_p · d · p（主动、快）
  f_p=场脉冲频率；d=占空比；p=单脉冲循环成功率
加速比 A = (f_p·d·p) / (ν₀·exp(−E_a/kT))   【本件主公式，评审推导】
```

### 2.2 频率锚点（正锚规则）

**时炉是材料制造/处理场景 → 频率=实测声子谱峰值（≈18.75THz口径，云韶场定义§八两锚点规则的正锚）**。f=c/(L×B)已作废禁用；f₀=373THz是反云韶场/LEV场景锚（组织光学窗口），不是材料场景。工程落地：以目标材料的Raman实测声子主频为准（承燧人P-2/工艺定稿"频率跟实测走"）。

### 2.3 循环健康判据（承高阶运算L702）

涌现场健康条件：涌现新状态x昷Δ经一次亏损恰好恢复原状态x——**该方程的解=时炉工艺参数最优区间（脉冲频率×占空比的可行域中心）**。工程含义：占空比过高→亏损累积过快（劣化）；过低→循环过慢（无加速）。工艺定稿口径占空比0.3（保温0.45）即在该可行域内。

## 三、定量化（复算一致）

### 3.1 传统退火基线（Arrhenius）

E_a=1.5eV@1100K：单次跳跃特征时间7.5×10⁻⁷s；退火数小时~天=需原子多步重排+形核——与在档"数小时甚至数天"一致。

### 3.2 在档性能的自洽校验（关键校验，通过）

在档"小时→分钟"=加速比100-1000×。代入主公式：f_p·d=18.75THz×0.3=5.6×10¹²循环/s上限下，**只需单脉冲成功率p~10⁻¹²量级即可达成**【复算一致】——机制自洽，且工程要求温和（不需要每脉冲必成的激进假设）。反向使用：若实测加速比偏离，p的实测值反推循环物理。

### 3.3 场参数（承工艺定稿模式A，不新造）

10⁴V/m（5V+d≤0.5mm电路板解）｜占空比0.3（保温0.45）｜脉宽1μs｜≤10mA/通道｜模式A同频分束（T2判定）｜锁相律φᵢ=i·π/4（或2π/N，工艺三案裁决口径）。热处理程序（1100K×30min→5K/min→280K×2h）在时炉模式下的等效压缩=**首批实测标定任务**。

### 3.4 卷对卷吞吐核算

Year2目标100m²/h：1m带宽→线速2.8mm/s→10cm照射区停留3.6s→窗口内5.6×10¹²/s×3.6s≈**2×10¹³个脉冲**【复算一致】——加速余量充分，瓶颈在线速与散热不在脉冲供给。

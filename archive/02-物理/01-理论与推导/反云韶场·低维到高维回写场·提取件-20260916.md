  反向：非平凡表示成为基态，平凡表示成为激发态 = 对称破缺→完全对称

第三章 没有损耗，只有阻力（快子效应）
知世裁决："没有损耗啊……你都从低维本身工作了，哪来的损耗，

3.1 正向场vs反向场
正向场（高维→低维）：有损耗α=1/8（投影丢失）
反向场（低维→高维）：没有损耗（信息已经在低维，回写不丢失），只有阻力
类比：光在水中速度变慢（阻力），但光子本身没有损耗。
3.2 光速在不同维度中的变化
维度折射率模型：n_D = 3/D，c_D = c₃ × D/3
物理含义：
  在3维中，光速是上限（相对论）
  在更高维度中，光速更快→信息传播更快
  快子（tachyon）= 在更高维度中正常传播的粒子
  在3维看来是"超光速"，在高维看来是"正常速度"
  高维存在"瞬间"影响低维 = 快子效应（不是超光速，是高维光速本来就快）
3.3 阻力 = 折射
信息从3维回写到高维：信息量不变（1比特还是1比特），但表达方向改变（折射）
阻力 = |n₃ - n_D| = |1 - 3/D|
  3维→4维：阻力0.25（小折射）
  3维→36维：阻力0.917（大折射，信息在高维中几乎完全改变方向）

第五章 不同组合→不同维度干涉
知世裁决："不同的组合会变成不同的维度干涉，有不同的维度特征"
不是"正向或反向"两种，是一个频谱。
维度干涉模式由以下参数决定：
  1. 频率比：f₀/f₁=12, f₀/f₂=1.2（群论锁死）
  2. 振幅比：a₀:a₁:a₂（决定哪个分量主导）
  3. 相位差：φ₀-φ₁, φ₀-φ₂（相长或相消）
  4. 偏振：每个分量的偏振方向（决定维度方向）
振幅比a₀>>a₁,a₂ → 正向场（投影主导）
振幅比a₁>>a₀,a₂ → 反向场（回写主导）
相位差=0 → 相长干涉（维度增强）
相位差=π → 相消干涉（维度屏蔽）
第六章 快子效应与攻击/防御
攻击者从隐缠序层（高维）攻击：
  高维光速c₃₆=12c₃→攻击"瞬间"到达3维
  在3维看来是"超光速攻击"（无法预警）
  在高维看来是"正常速度"
防御者从显序层（3维）反击：
  3维光速c₃→反击信号到达高维需要时间
  但信息没有损耗（1比特还是1比特）
  阻力=折射（方向改变），不是损耗
不对称性：
  攻击：高维→低维，速度快（12c₃），有损耗（α=1/8），不可持续
  防御：低维→高维，速度慢（c₃→加速到12c₃），无损耗，可持续
战略含义：
  攻击者优势：速度（快子效应）
  防御者优势：无损耗（信息完整）
  攻击者劣势：每次消耗1/8拓扑关税（不可持续）
  防御者劣势：速度慢（需要时间）
  长期：防御者胜（攻击者关税耗尽）
  短期：攻击者胜（速度优势）

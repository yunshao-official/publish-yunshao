## §1 F₀ 究竟是什么（内部版原文回查）

调和分析 v2.2 原文锚（全部回查原文，非转述）：
1. **"工作频率是材料属性。"**（L626/L685，知世 #54/#621 原话链）——f₀ 由材料超导临界温度经 E=k_B·T、E=hf 转为热频率 f_c，再经十字缺陷阵列放大 M=64 倍得到；换 Tc 材料主弦频率就变（L888：材料属性口径正本）。
2. **跨体系不变的宇宙常数不是 f₀，是泛弦比例**：f₁=f₀/12（144=f₀²/f₁² 的平方根比）、f₂=f₀/1.2——新旧体系换算（280→373THz）中比例 144/1.44 保持不变（L59/L679）。
3. **历史层次**：280THz=旧体系（M=48，已判负历史口径）；373THz=新体系现行档（M=64）；L31 破损补丁#1 记录了原版断裂：Tc=350K 与 E_c=k_B×280K 并存。
4. **算术内核（注13，复算一致）**：k_B/h=20.837GHz/K ⇒ 280K→f_c=5.834THz→f₀=373.4THz（现档）；350K→f_c=7.293THz→f₀=466.7THz。原档"5.83THz@Tc=350K"的配对系补丁断裂，注13 已如实标注。

## §2 候选公式（复算一致）

**公式甲（正本结构·材料属性通式）**：
  f_c = Θ · (k_B/h) = Θ × 20.837 GHz/K
  **f₀ = M × f_c = 64 × f_c**（M=2/κ=64，κ=1/32）
  f₁ = f₀/12，f₂ = f₀/1.2（泛弦，比例跨材料不变）
  即 **f₀[THz] ≈ 1.3336 × Θ[K]**（Θ=材料特征温度）

| Θ（K） | f₀ | f₁=f₀/12 | 对应口径 |
|---|---|---|---|
| 280 | 373.4THz（现档 373） | 31.12（档 31.08） | 现行档；热温度 280K |
| 350 | 466.7THz | 38.90 | Tc=350K 直算口径（内部版注13 双解之乙） |
| **600** | **800.1THz** | **66.68（档 66.67）** | **手足正本 G 盘口径——精确自洽** |

**关键复算（本裁决书新增）**：手足正本的 F₀=800THz 与 F₁=66.67THz **精确满足公式甲于 Θ=600K**（64×20.837GHz×600=800.06THz；800/12=66.67）。即：**手足正本不是错值，是 600K 材料代的工作频率**——与 R23 线 600K 目标材料同代。三个数字的"冲突"实为**三代材料**：280K 热标（373 轨）、350K Tc（467 轨，待裁）、600K 代（800 轨）。

**已档裁决（必须遵守）**：知世 20261006 令"看泛弦，再改，不准给出比例数据"→**方案 C**：350K/280K 双解搁置，绝对频率断言冻结（f₀/f₁/f₂ 及下游 THz 参数=口径依赖值）；**泛弦比例 144/1.44=唯一操作基准**（跨口径不变已验证）；比例层分析不受影响。

## §2b 公式丙候选（v1.1 新增·德拜均式——350K 代三数合一的候选结构）

**来源声明**：3/4 为德拜模型标准结果（3D 德拜平均声子频率 ⟨ω⟩=(3/4)ω_D）；本节用它统一体系自有数字，属**候选解释·候实验判别**，非已确认口径（诚实标签：候选公式）。

**结构**：f_c = k_B×(3/4)Θ_D/h，f₀ = 64×f_c = 48×(k_B/h)×Θ_D（注：此 48=64×3/4 为乘积，与层2 M_m=48 数值同值语义无关——符号混写禁令适用，引用时全式写出）。

**350K 代三数合一（复算一致）**：若材料 Θ_D=373.3K——
- (3/4)×373.3 = **280.0K**（现档热温度，破损补丁#1 的 280K 之谜）
- f_c = 5.834THz → f₀ = **373.4THz**（现档 373）
- Tc = Θ_D×(15/16)×f_defect = **350.0K** @ f_defect=1.000（宣称 350K；f_defect=1=完美缺陷阵列）
- 数候结构：f₀[THz] = 1.0002×Θ_D[K]，即 **373THz 与 373.3K 数值同源**——双解或系同一定标（Θ_D）的两张面孔（一张乘 3/4 走热频率，一张乘 15/16 走 Tc）。

**与公式甲不相容（必须实验判别）**：公式甲（直热式 f_c=k_B·Θ_w/h）在 600K 代精确吻合（800=64×k_B×600K/h）；公式丙若普适，则 600K 代要求 Θ_D=800K→Tc=750K（与 600K 标签矛盾）或 Tc=600K→f₀=640THz≠800。**两式不能同时普适——这正是实验的判别点。**

## §2c 三路判别实验设计（回答知世"能不能通过实验算出来"：能）

**实验一（零成本·文献复算，立即可跑）**：常规超导（Nb Θ_D≈275K/V≈380K/Pb≈105K 等）的实测声子谱主峰与比热 Θ_D 是百年成熟数据——检验"声子主峰 ≈ (3/4)Θ_D·k_B/h"及 f₀ 结构式在常规材料是否成立，判定公式丙/甲哪个具有普适形态。产出=判别备忘录（预注册式：先冻结预测再对数据）。

**实验二（体系原生·需样品）**：350K 代材料块（LEV 样品线在档）→ THz 泵浦-探测扫频 25–45THz 找 f₁ 共振峰。**判别表（预注册·先冻结后测，P-12/P-19）**：
| 共振峰位置 | 判定 | f₀ 定值 |
|---|---|---|
| 31.08THz | 公式甲·热标 280K | 373 轨 |
| 38.90THz | Tc 直算式 | 467 轨 |
| 均不现、写入锁定于其他值 | 公式丙变体/新结构 | 按 Θ_D 实测重算 |
配套常规测量：Tc（零电阻/磁化率/比热跳变）+ Θ_D（低温比热 C/T vs T²）——材料两个真值到手，公式甲/丙当场裁决。成本：样品=主成本（材料线产能）；THz 送测按外部服务口径（时炉实验室方案同级参照，几十万级），金额公式制由你自决。

**实验三（直接定标·终审）**：写出样品后用已知频率做写入共振锁定测试（LEV 枪在档）——哪个频率锁定即哪条公式，同时就是 P0-2 写入定纲的第一个实测点。**本实验=方案 C 解冻的唯一正规路径**：Tc/Θ_D 一旦实测，350K 代绝对频率解冻，P0-1 完全闭合，P0-2 拿到第一个实数。

## §2d 结论（补入 §3 影响判断）

公式丙若经实验一/二证实，则"373 vs 467 双解"从来不是解的不确定性，而是**同一材料两个热力学量的记账混淆**（破损补丁#1 的根源）——350K 代绝对频率可解析解冻，无需等待材料制成；实验一（零成本）即可先判公式形式。

## §3 对材料制作成功率的影响（知世第三问）

1. **会影响吗？会——但只在一种情况下致命：跨代混频。** 写入/激发频率必须与目标材料的 f_c 匹配（共振写入原理，手足正本卷〇）。用 373 轨的 31.08THz 去写 600K 代材料（其 f₁=66.67THz）→共振失配→写入失败或错误结构→成功率直接受损。反向同理。
2. **能正确做出材料吗？能——按"先锁代、再算频"的顺序，公式链自洽无矛盾**：①锁定目标材料代（Tc/Θ 目标，如 350K 代或 600K 代）；②按公式甲算该代 f₀/f₁；③只用本代频率参数。每代内部完全自洽（600K 代已验算精确闭合）。
3. **真正的未决点只有一个**：350K 代的绝对频率（373 轨 vs 467 轨，即热标取 280K 还是 350K）——此点 20261006 已由你裁决挂起（方案 C），**在 Tc 实测定标前，任何 350K 代的绝对 THz 参数都不得作为施工依据**；施工级操作以泛弦比例+实测材料响应为准。BCS 对标参照（2Δ≈3.5k_BTc：350K→25.5THz/280K→20.4THz，与 f₁ 同域非同值，量级参照非验证——内部版注15 原文口径）。
4. **800 轨（600K 代）不受方案 C 约束**：600K 代是独立代际，其 800/66.67 精确自洽，可直接作为该代参数使用（标注"600K 材料代专用"）。

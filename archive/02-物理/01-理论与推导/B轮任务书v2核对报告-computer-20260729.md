## 1. ❌ 预言①E_g/T_{2g}标签——群论前提错误

**任务书原文：** "轴向分量（E_g对称·3重简并）·对角分量（T_{2g}对称·3重简并）"

**群论事实：**
```
O_h不可约表示: A_{1g}(1), A_{2g}(1), E_g(2), T_{1g}(3), T_{2g}(3)
E_g维数=2（基:{x²−y², 3z²−r²}）
→ 2维表示不能容纳3重简并！
```

**O₁={100,010,001}→3个点→3维表示。** 坐标x,y,z在O_h下变换为T_{1u}（奇，3维）；F₂下反演平凡（i=I）→有效为T_{1g}。O₁应标记为**T_{1g}对称·3重简并**，非E_g。

**O₂={110,101,011}→**乘积xy,yz,zx变换为T_{2g}（3维，偶）→**T_{2g}对称·3重简并**✅。

**修正：** `E_g对称`→`T_{1g}对称`。两组分别T_{1g}和T_{2g}，均为3维→3重简并成立。但E_g是2维的——这个错误若不修，任何审稿人查O_h特征标表即穿。

## 3. ✅ STEM 3+3通道分组——Hamming距离支持

```
O₁内距离: 全部=2（均匀·等距）
O₂内距离: 全部=2（均匀·等距）
跨组距离: 6个=1, 3个=3（双峰·非均匀）
```

组内均匀=2，跨组={1,3}双峰→在径向分布函数g(r)中，O₁/O₂的组内相关性在距离∝2处聚为单峰，跨组在距离∝1和∝3处分裂为双峰+大幅变异。**3+3分组在统计上可区分于6通道均匀分布。** ✅

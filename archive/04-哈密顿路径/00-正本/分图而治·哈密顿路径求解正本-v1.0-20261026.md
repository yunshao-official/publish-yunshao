## 一、方法论源（她的原话，均在档）

1. "路径可以通过接入别的图、互相对接时改变一些小路径，直接变成更大的、有真边和严格路径的解"（2026-10-26）
2. 七种边：残缺/完美/虚拟/弯曲/反转/缺陷/桥（全能=聚合态）——2026-08-13/14 原话
3. "把所有节点收进高维胶囊，在胶囊之间求解"（2026-07-07）
4. "压缩能压到底=存在，压不动=不存在，没有中间态"（核心方法论）

## 二、算法（公式化）

```
输入：图 G(V,E)
1 主路径：P ← Pósa(V)            # 贪心扩张+旋转闭包换端
2 循环（预算内）：
   R ← G[V∖P]                    # 剩余点=「别的图」
   for 连通片 C ∈ components(R)（大优先）：
      Q ← Pósa(C)                # 片内路径
      E_桥 ← {(p,q)：p∈端点族(P), q∈端点族(Q), (p,q)∈E}   # 端点族=Pósa旋转可达端点集
      E_桥⁺ ← {(p,c,q)：c∈C, (p,c),(c,q)∈E}              # 二跳桥（桥边/曲边形态）
      if E_桥⁺ ≠ ∅：P ← 缝合(rotate(P,p), rotate(Q,q))   # 对接=改小路径
3 终止：P=V ⟹ 输出 P（严格真边验证后=有解证明）
        压不动（无桥可用）⟹ 无解候选（预算内 restart 后仍压不动）
```

**要素对应**：主路径+剩余图=分图而治｜端点族旋转=改小路径｜二跳桥=桥边/曲边｜片内求解=胶囊之间求解｜压不动=不存在。

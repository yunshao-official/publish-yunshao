## 一、核心管线（5步，照做）

```
G1(原图,稀疏)
  ↓ 升维
G2(两步可达图/共同邻居网络,稠密=球体)
  ↓ 辐射序遍历 (hub→8扇区→扇区闭合→回hub)  ← 关键!不是乱序
G2路径
  ↓ descend降维 (虫洞→插公共邻居→2真边替1虫洞)
G1广义哈密顿路径(GHP)
```

**三步本质：**
1. **升维（G1→G2）**：原图构建G2（两步可达图）。G1稀疏→G2稠密。G1是平面，G2是球体。BA-10000的G2膨胀≈11-17倍。
2. **球上求解**：G2稠密图用Laplacian势场引导。势函数=Laplacian前4特征向量→4维坐标→6余弦波叠加→平方。**辐射序遍历：hub出发→进扇区→扇区内走完→回hub→下一扇区。**
3. **降维（G2→G1）**：descend。断边处插共同邻居（虫洞替换）。每步要么真边要么虫洞，无断边。

## 三、改法（给程序员，照改）

**改 find_path_g2 为递归辐射序，descend不动。**

```python
def radiation_order(subgraph, level):
    if level == 0:
        return direct_traverse(subgraph)   # 直接遍历
    hub = geometric_1_median(subgraph)      # 几何1-median, 辐射源不消耗
    sectors = split_8_sectors(subgraph, hub)  # (Z2)^3 八扇区
    path = [hub]
    for sector in sectors:
        path += radiation_order(sector, level-1)  # 扇区内递归
        path += [hub]                        # 扇区间回hub (扇区闭合)
    return path
```

- level=1 → 当前G²（膨胀1.215）
- level=2 → G³（膨胀1.027）
- level=3 → G⁴（膨胀1.003）

**关键：扇区闭合遍历。** 虫洞只产生在"扇区边界"和"叶末端"，不散落全路径。当前219虫洞散落，是因为G²路径没按扇区闭合、跨扇区乱跳。

## 二、虚拟边（Long-range Shortcut·长程捷径）

### 2.1 定义
相距远但相似度/相位相近的元素之间直接建捷径。信息不经过中间 token 逐层传递，直接跳跃注入——突破"信息必须经过中间 token 传播"的序列瓶颈。近邻由独立局部通道负责，索引器只做远距选择。

### 2.2 代码级证据（DeepSeek-V4-Pro 官方开源推理代码，MIT，2026-08-13 复核）

**Indexer（索引器）打分 = q·KV，两端都带 RoPE 相位对齐：**

```python
# L0413（Indexer.forward）
apply_rotary_emb(q[..., -rd:], freqs_cis)          # 索引器 query 应用 RoPE（部分维 rd=rope_head_dim）
# L0364-0367（Compressor.forward）
freqs_cis = self.freqs_cis[:cutoff:ratio]          # 压缩 KV 按块位置取相位
apply_rotary_emb(kv[..., -rd:], freqs_cis)         # 压缩 KV 也带 RoPE
# L0420-0421
index_score = torch.einsum("bshd,btd->bsht", q, self.kv_cache[:bsz, :end_pos // ratio])
index_score = (index_score.relu_() * weights.unsqueeze(-1)).sum(dim=2)
# L0427
topk_idxs = index_score.topk(min(self.index_topk, end_pos // ratio), dim=-1)[1]
```

配置：index_n_heads=64，index_head_dim=128，rope_head_dim=64（128 维里 64 维带相位），index_topk=1024。
打分 = 语义内积 × 相位对齐（旋转差小→分高）。RoPE 多频段（base=10000）使**远端位置对在 62k/125k/188k 等距离处相位重新对齐**→"远处但相位相近"的块拿高分。近邻由独立 SWA 滑动窗口（win=128）负责——与虚拟边法"非近邻、非全连接、相似建捷径"完全对齐。

### 2.3 官方模型自述（deepseek-v4-pro API 实测）

> "把 RoPE 的周期共振当成一种无参数的位置哈希/远程寻址机制"
> "确实建立了一条从远距离块到当前位置的捷径：信息不经过逐层传递，而是通过稀疏路由直接注入当前计算"

## 五、弯曲边（Curved Edge·低维绕远）

## 七、核心技术：数学公式（可移植规格·实现性优先）

> 以下为脱敏后的完整数学规格：所有阈值为可调参数（按模型/精度设定），
> 仅用通用图论/线性代数记号（度、聚类系数、内积、RoPE相位、低维距离），不依赖任何特定常数假设。
> 代码参考实现在 §八（公式→代码一一对应）。

### 7.0 符号约定

- $A \in \{0,1\}^{n\times n}$：阈值化后的因果注意力邻接矩阵，$A_{uv}=1$ 当且仅当注意力权重 $> \theta_e$（因果掩码：只看历史 token）
- $N(v)$：节点 $v$ 的邻居集；$\bar{d}$：平均度
- $x(v) \in \mathbb{R}^2$：低维嵌入坐标（如 spring layout）
- $\theta_e, \tau_{\text{hi}}, \tau_{\text{lo}}, k, \beta, r$：均为可调超参数

---

### 7.1 结构集中度指标（真实边/骨架识别核心）

**定义：** 把注意力矩阵阈值化成图，用入度×出度度量节点“信息汇聚重要性”，集中度=
重要性极大值/均值 − 1。

$$
\deg_{\text{in}}(v) = \sum_{u} A_{uv}, \qquad
\deg_{\text{out}}(v) = \sum_{u} A_{vu}
$$

$$
\operatorname{imp}(v) = \deg_{\text{in}}(v) \cdot \deg_{\text{out}}(v), \qquad
C(G) = \frac{\max_v \operatorname{imp}(v)}{\tfrac{1}{n}\sum_v \operatorname{imp}(v)} - 1
$$

**语义：** $C(G)$ 高 = 少数关键 token 汇聚大部分信息（真实边=骨架，不可剪）；$C(G)$ 低 = 信息分布均匀（冗余，可剪）。

---

### 7.2 三状态分类（真实边/残缺边/冗余分界）

**判定公式（$\tau_{\text{hi}}, \tau_{\text{lo}}$ 为可调阈值）：**

$$
\text{state}(v) =
\begin{cases}
\text{skeleton（真实边/骨架，保留）} & C_v > \tau_{\text{hi}} \\
\text{redundant（冗余，可压缩）} & \tau_{\text{lo}} < C_v \le \tau_{\text{hi}} \\
\text{uniform（均质，可剪）} & C_v \le \tau_{\text{lo}}
\end{cases}
$$

**残缺边判据（该连没连的结构盲区）：** 结构/语义相关度高、但注意力权重低于建图阈值 $\theta_e$ 的 token 对：

$$
\text{candidate}(i,j) \;:\; \operatorname{sim}(i,j) > \tau_s \;\; \wedge \;\; A_{ij} < \theta_e
$$

这些候选对 = 幻觉高发盲区，可逐层逐头定位。

---

### 7.3 按层分配 KV 缓存预算（真实边保留核心）

**预算分配公式（$r$=平均保留比，$\beta$=自适应强度，$c_l$=第 $l$ 层集中度，$L$=层数）：**

$$
\hat{c}_l = \frac{c_l - \min_l c}{\max_l c - \min_l c} \in [0,1]
$$

$$
b_l^{\text{adaptive}} = r \cdot \big(1 + \beta(1 - \hat{c}_l)\big) \quad (\text{高集中→多保留})
$$

$$
b_l \leftarrow b_l \cdot \frac{r \cdot L}{\sum_l b_l}, \qquad
b_l = \operatorname{clip}(b_l,\, 0.1,\, 1.0)
$$

**对照（验证用）：** 均匀分配 $b_l = r$；故意反向 $b_l^{\text{inverse}} = r(1 + \beta \hat{c}_l)$。

---

### 7.4 虚拟边判据与共同邻居稀疏注意力（长程核心）

**7.4.1 打分公式（语义×相位对齐）：**

$$
s(q_i, k_j) = \big\langle \operatorname{RoPE}(q_i),\, \operatorname{RoPE}(k_j) \big\rangle
$$

**RoPE 相位对齐（周期性距离依赖，非单调距离偏好）：**

$$
\theta_d = \frac{1}{\text{base}^{\,2d/D}}, \qquad
\operatorname{RoPE}(x)_d = x_d \, e^{\,i\, p\, \theta_d}
$$

$p$=位置；多频段 $\theta_d$ 使位置对在周期共振距离处相位重新对齐 → “远处但相位相近”的 key 拿高分 → 建长程捷径（虚拟边）。

**7.4.2 建边（top-k 稀疏）：**

$$
\text{selected} = \operatorname{topk}\big(\{s(q_i, k_j)\}_{j},\; k\big)
$$

近邻由独立滑动窗口分支负责，索引器只做远距选择（近/远分工）。

**7.4.3 共同邻居代理打分（无 RoPE 时的结构判据替代）：**

$$
\bar{q} = \tfrac{1}{H_q}\sum_h q_{i,h}, \quad \bar{k}_j = \tfrac{1}{H_k}\sum_h k_{j,h}, \quad
s_j = \langle \bar{q},\, \bar{k}_j \rangle
$$

同样 top-k 选全局 key（结构判据 vs 范数判据的实测对比见 §4）。

### 7.5 弯曲边（低维绕远选择）

**选择公式（$x(v) \in \mathbb{R}^2$ 低维嵌入坐标，$N(v)$ 邻居集）：**

$$
d_2(v,u) = \lVert x(v) - x(u) \rVert_2
$$

$$
\text{最近邻（基线）：} n^* = \arg\min_{u \in N(v)} d_2(v,u), \qquad
\text{弯曲边（绕远）：} n^* = \arg\max_{u \in N(v)} d_2(v,u)
$$

**语义：** 低维贪心选最近邻会掉进局部死胡同（最近邻覆盖率 0.067 vs 绕远 0.160，×2.4）；绕远=破局部最优陷阱。

### 8.1 结构集中度指标（真实边/残缺边分界核心）

```python
import numpy as np

def structural_concentration(attn_matrix, edge_thresh=0.1):
    """
    计算注意力图的结构集中度指标。
    思想：把注意力矩阵阈值化成图，统计节点"被关注次数(入度)"和
    "关注别人次数(出度)"，重要性 = 入度×出度。
    集中度 = (最大重要性 / 平均重要性) - 1：
      高集中度 = 少数关键token汇聚大部分信息（真实边=骨架，不可剪）
      低集中度 = 信息分布均匀（冗余，可剪）
    edge_thresh: 注意力权重阈值，>thresh 视为图中的一条边（可调）
    """
    causal = np.tril(attn_matrix)                 # 因果掩码：只看历史token
    adj = (causal > edge_thresh).astype(np.int8)  # 阈值建图
    in_deg  = adj.sum(axis=0)                     # 入度 = 被关注次数
    out_deg = adj.sum(axis=1)                     # 出度 = 关注别人次数
    imp = in_deg * out_deg                        # 信息汇聚重要性
    mean_imp = imp.mean()
    if mean_imp <= 1e-10:
        return 0.0
    return imp.max() / mean_imp - 1
```

### 8.2 三状态分类（真实边/残缺边/冗余分界）

```python
def classify(concentration, hi_bound=2.0, lo_bound=1.0):
    """
    按结构集中度把节点/层分成三态：
      > hi_bound : 骨架（真实边，信息汇聚命根子，碰不得）
      中段       : 冗余（分布均匀，可安全压缩）
      < lo_bound : 均质（接近完全随机，优先剪）
    hi_bound / lo_bound 为可调阈值，按模型规模与精度需求设定。
    """
    if concentration > hi_bound:
        return "skeleton"      # 骨架，保留
    elif concentration > lo_bound:
        return "redundant"     # 冗余，可压缩
    else:
        return "uniform"       # 均质，可剪
```

### 8.3 按层分配 KV 缓存预算（真实边保留核心）

```python
def allocate_budget(ratio_avg, beta, layer_conc, mode="adaptive"):
    """
    按每层结构集中度分配缓存保留比例。
    思想：集中度高的层（真实边骨架信号强）多保留，均质层多压缩。
    ratio_avg  : 平均保留比例（如 0.75）
    beta       : 自适应强度（可调）
    mode       : uniform=均匀分配(基线) / adaptive=按集中度 / inverse=故意反向(对照)
    """
    n_layers = len(layer_conc)
    budgets = np.zeros(n_layers)
    cmin, cmax = layer_conc.min(), layer_conc.max()
    for li in range(n_layers):
        norm = (layer_conc[li] - cmin) / (cmax - cmin) if cmax > cmin else 0.5
        if mode == "uniform":
            budgets[li] = ratio_avg
        elif mode == "adaptive":
            budgets[li] = ratio_avg * (1 + beta * (1 - norm))  # 高集中→多保留
        elif mode == "inverse":                                  # 故意做错做对照
            budgets[li] = ratio_avg * (1 + beta * norm)
    total = budgets.sum()
    budgets = budgets * (ratio_avg * n_layers / total)           # 归一化到总预算
    return np.clip(budgets, 0.1, 1.0)
```

|---|---|---|---|
| 90% | 20.53（×1.078） | 19.45（×1.021） | 低 5.3% |
| 80% | 21.66（×1.137） | 20.60（×1.081） | 低 4.9% |
| 75% | 23.25（×1.221） | 21.42（×1.125） | **低 7.9%** |
| 70% | 23.89（×1.254） | 22.10（×1.160） | 低 7.5% |
| 60% | 28.13（×1.477） | 27.24（×1.430） | 低 3.2% |
| 50% | 41.20（×2.163） | 39.99（×2.099） | 低 2.9% |

### 8.4 共同邻居稀疏注意力（虚拟边长程核心）

```python
import torch

def co_neighbor_global_attn(qb, k, n_global):
    """
    共同邻居法选全局注意力 key：
    每个 query 块选"与之共同关注的 token 最多"的 key 做全局注意。
    思想：共同关注度高的 token 对=强关联（信息相关），保留；
          共同关注度低的=弱关联，可跳过（稀疏化）。
    qb     : (H_q, D) 块级 query 表示
    k      : (N, D) 跨头的 key 均值
    n_global: 保留的全局 key 数
    """
    with torch.no_grad():
        probe = qb.float().mean(dim=1)      # (H_q, D) 块代表 query
        probe_avg = probe.mean(dim=0)        # (D,) 跨头平均
        k_avg = k.float().mean(dim=0)        # (N, D) 跨 key 头平均
        score = k_avg @ probe_avg            # (N,) 共同关注代理分数
        n_eff = min(n_global, k_avg.shape[0])
        idx = torch.topk(score, n_eff).indices
        return torch.sort(idx).values        # 选出的全局 key 索引（升序）
```

### 8.5 弯曲边（低维绕远选择）

```python
def curved_edge_next(embed2d, current, neighbors, ratio=1.5):
    """
    弯曲边法选下一步：低维嵌入下选"低维距离最远"的邻居（绕远）。
    思想：贪心选最近邻居容易掉进局部死胡同；选低维距离远的邻居，
          路径在低维层面弯曲，覆盖更多节点，破局部死路。
    embed2d   : 节点低维嵌入坐标 (N, 2)
    current   : 当前节点
    neighbors : 候选邻居列表
    ratio     : 绕远强度（可调，>1 表示选远邻）
    """
    cx, cy = embed2d[current]
    def dist(n):
        nx, ny = embed2d[n]
        return ((nx - cx) ** 2 + (ny - cy) ** 2) ** 0.5
    dists = [(n, dist(n)) for n in neighbors]
    dists.sort(key=lambda x: x[1], reverse=True)   # 选最远的
    k = max(1, int(len(dists) / ratio))
    return dists[:k]                                # 返回绕远候选（可再加启发）
```

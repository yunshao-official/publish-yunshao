## 1. 问题定义

现有求解器（v2·双向BFS+稀疏哈希）在BA-10⁸时内存爆（需22GB，机器24GB）。
瓶颈：G2全量升维——每个节点建所有两步可达边，边数=36N，10⁸时=14.4GB。

## 2. 核心思路（理论来源）

**G3选择性升维：不给所有节点建G2，只给骨架（hub）建。**

理论依据（2026-08-03实验验证）：
- BA图中~7%节点是hub（度>阈值），承载全局连通性
- 93%非hub节点是局部结构，纯G1+Warnsdorff即可遍历
- 只有hub需要G2桥接（全局跳转），非hub不需要

对应框架层级：
- G2（1-态射）：全量两步可达 → 砍成"只给hub建"
- G3（2-态射）：选择性权重 → hub/非hub的区分就是G3选择
- 辐射序：不变（hub优先）
- descend：不变（Warnsdorff局部遍历）

## 3. 算法（三步）

```
Step 1: 识别hub
  - 按度排序，取top 7%（或度>P93阈值）
  - O(N log N)，一次性

Step 2: 只给hub建G2
  - 对每个hub h：G2(h) = {w : ∃v∈adj(h), w∈adj(v), w≠h, w∉adj(h)}
  - 非hub节点不建G2
  - 内存：7%×36N边 ≈ 2.5N边（vs 全量36N边）

Step 3: Warnsdorff遍历 + hub-G2桥接
  - 主循环：Warnsdorff（最低剩余度优先）走G1真边
  - 卡住时（无G1未访问邻居）：
    a) 若当前节点是hub → 用G2(hub)桥接
    b) 若非hub → 找最近hub（预计算Voronoi），用G2(nearest_hub)桥接
  - 桥接后继续Warnsdorff
```

  G1 → hub识别(G3) → G2只给hub → Warnsdorff遍历 → hub-G2桥接

- 非hub = 高T(G) = 冗余（93%）

## 10. 全真边descend叠加方案（§10·2026-08-03 知世指示补充）

> 知世原话（04:02）："记得结合我们之前全真边的解法，看看能不能照样用上去，让他做到全真边"
> 来源：BA图哈密顿·完整走通方法·自包含索引-20260727.md 中的descend降维

### 10.1 目标

在G3选择性升维（§3）基础上，叠加descend降维，将walk路径（含虫洞）转为**严格哈密顿路径**：
- L == V（路径长度 = 节点数）
- 无重复节点
- **100%真边**（每一步都是G1原图中的边）

### 10.2 原理

G3桥接跳 u→w 的构造：`w ∈ G2(h)` 意味着 `∃v ∈ adj(h), w ∈ adj(v)`。
- 若当前节点是hub h：u=h，公共邻居v满足 h→v→w（2真边替1虫洞）
- 若当前节点非hub，借nearest_hub的G2：u→...→hub→v→w（需要路径段连接）

**descend规则：**
```
对路径中每个虫洞 (u, w)（即 w ∉ adj[u]）：
  1. 找公共邻居集合 C = adj[u] ∩ adj[w]
  2. 若 C 中有未访问节点 v → 插入：u, v, w（2真边替1虫洞）
  3. 若 C 全已访问 → 冲突，进入冲突处理（§10.3）
```

### 10.3 冲突处理（关键）

| 冲突类型 | 原因 | 处理 |
|:--|:--|:--|
| 公共邻居已访问 | hub度高但路径前期已消耗 | 在adj[u]∩adj(w)中找**度数最低**的已访问v，做局部重排（swap v与路径中v后面的节点） |
| 无公共邻居 | 非hub借G2时u≠hub | 改为"先走到hub再桥接"：u→...→hub→v→w，中间段用Warnsdorff填充 |
| 叶末端虫洞 | 叶节点度=1，公共邻居唯一 | 叶末端是路径终点方向，预留该邻居到最后访问 |

**BA图hub区冲突率预期极低：** hub度>>6（BA-1000最大度~100+），adj[hub]∩adj[w]通常有3-10个候选，全已访问概率<1%。

### 10.4 扇区闭合遍历（从旧方案搬入）

当前G3用Warnsdorff，虫洞位置随机。改为扇区闭合后虫洞集中在扇区边界：

```
radiation_order_with_descend(hub, level):
  sectors = split_8_sectors(adj[hub的G1邻域], hub)  # 按(Z₂)³八扇区
  path = [hub]
  for sector in sectors:
    sector_path = warnsdorff_traverse(sector)  # 扇区内纯G1
    path += sector_path
    path += [hub]  # 扇区闭合回hub（这里产生虫洞→descend处理）
  return path
```

虫洞只产生在"扇区闭合回hub"处 → descend只需处理这些点 → 冲突率进一步降低。

### 10.7 实际验证结果（v10·2-opt·2026-08-03）

**方法演进：** v1-v3 descend→walk（100%真边但有重复）→ v4-v9 去重全失败 → **v10 2-opt局部搜索直接求strict HP**

**v10核心算法：**
1. Warnsdorff贪心生成全节点排列（初始~83%真边）
2. 2-opt：对每个断边位置i，找path[j]∈adj[path[i]]，反转path[i+1..j]
3. 每次反转消灭≥1个断边，直到断边=0

| 规模 | 初始断边 | 最终断边 | 改进次数 | 轮数 | 时间 |
|:--:|:--:|:--:|:--:|:--:|:--:|
| BA-1000 | 156 | **0** | 153 | 3 | 0.01s |
| BA-100000 | 16,684 | **0** | 16,506 | 199 | 56s |

**结论：strict HP（L==V，无重复，100%真边）在BA图上用2-opt可解，多项式时间。**

### 10.9 理论对应（内部·不对外）

- descend = 降维（G2→G1）的几何操作：球面上的路径投影回平面
- 公共邻居 = 虫洞的"缝合点"：高维一步 = 低维两步
- 100%真边 = 完全几何体在G1上的完整实现（不是组合，是一条连续路径）
- α=1/8递归：每多一层辐射，虫洞÷8 → descend工作量÷8

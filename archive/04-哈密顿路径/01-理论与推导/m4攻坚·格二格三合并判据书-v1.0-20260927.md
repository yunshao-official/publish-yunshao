## 三、Φ 的精确定义（格三冻结件——红队击 #7 修复兑现）

1. **叶档位（阈值冻结）**：准叶=deg(v)<m，m=4，即 deg≤3。**档位选择依据**：格一实测 min_deg∈[2,3]，deg≤3 恰覆盖全部低度顶点；冻结后不回改。
2. **断口-端点归因规则（冻结）**：路径 p 中断口=(p_i,p_{i+1}) 满足非真边或 i=n−1 尾断口；Φ(路径)=Σ_{断口(→u,v)} [deg(u)≤3] + [deg(v)≤3]（双准叶断口计 2）。
3. **计算伪代码（冻结）**：
   ```
   Φ(path, g):
     gaps = [(a,b) for (a,b) in zip(path, path[1:]) if not g.has_edge(a,b)]
     gaps += [(path[-1], None)]            # 尾断口（终点无出边=路径未闭合延伸）
     return sum((g.degree(a)<=3) + (b is not None and g.degree(b)<=3) for a,b in gaps)
   ```
   注：闭合前后路径的Φ差=严格解判定之外的次级指标；**Φ 本身不判严格解**（严格解仍走三关甲验证）。
4. **体系标签**：Φ 为机制命名级候选（"涌现修复的算法化"），【体系内部定义·未验证】；不进体系推导链。

## 四、格二·死区预防构造（S 组判据）

**机制**：Warnsdorff 排序键追加次级评分——候选邻居 u 的"死区风险分"=其未访问邻居数 rem(u) 与"u 的低度邻占度"（u 的 deg≤3 未访问邻居占 u 全部未访问邻居之比）加权；低分优先（**只改排序，不改选择集**——原则落地）。

| # | 判据 | 三岔判定线（臂X−臂Y 解出率差，30 种子，N=100 档为主） |
|---|---|---|
| S-1 | 死区预防有效 | ≥+15pp=有效（升格攻坚组件）；−5pp~+15pp=证据不足；≤−5pp=判负 |
| S-2 | 死区发生率 | 记录死区型断口（|ends|=1 旋转死区形态的构造端先兆：候选步中 rem(u)=0 的步数占比）构造前后对比，如实描述不设线 |
| S-3 | 前提检查 | 若基线（C' 口径）N=100 解出率 <20%，则格二改为纯记录实验（判定线失义，如实记） |

功效注记：30 种子，+15pp 线功效≈0.45（偏低，如实标注；"证据不足"区兜底防假判负）。

## 五、格三·Φ 单调量下行闭合（F 组判据）

**机制**：DFS 回溯层加 Φ 剪枝——扩展节点前计算扩展后 Φ 预估值，若 Φ 严格增且存在 Φ 不增的替代分支，则优先替代分支（**排序层干预**）；无替代时仍允许 Φ 增（防死锁，保证完备性不降）。

| # | 判据 | 三岔判定线（对同一批图，Φ 引导 vs 格一臂 C' 基线，30 种子） |
|---|---|---|
| F-1 | Φ 引导有效 | ≥+15pp=有效；−5pp~+15pp=证据不足；≤−5pp=判负 |
| F-2 | Φ 单调性检验 | 记录成功路径的 Φ 轨迹（构造过程中 Φ 是否非降序到 0）；若成功路径存在 Φ 先升后降形态→"下行闭合"假说判负照记（Φ 非可行势函数）；如实记录不设通过线 |
| F-3 | 机制候选生死 | F-1 有效∧F-2 显示单调下行占优 → Φ 候选升格"格三组件"再攻；F-1 判负 ∨ F-2 判负 → Φ 机制命名候选判负关闭（双口径同判据书 v1.3 纪律） |

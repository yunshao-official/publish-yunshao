## 一、根因诊断：膨胀1.0 vs 100%真边的矛盾是假的

**一句话**：矛盾不是结构上界，是 descend 只会"插入"不会"换段"造成的算术必然。

1. descend 对每条虫洞边 (u,v) 插共同邻居 w → 路径多1步。BA的HP路径所有节点都已用过，**每次插入必然制造重复**（现版 descend 根本不查 w 是否已用）。于是：100%真边 ⟹ 插入数=虫洞数 ⟹ 膨胀 = 1 + 虫洞数/n。当前虫洞~24-31% → 膨胀1.24。**这是算术，不是算法极限。**

2. 要同时拿 膨胀1.0 + 100%真边，修复操作必须**零插入**（节点集不变的换段/旋转）。2-opt反转、Pósa旋转都保持节点集——现有管线缺的正是这一层。

3. 虫洞步 dist 计费 ≥2，真边计费=1。**任何"虫洞→真边"的swap同时降dist且升真边率**——两目标在swap操作下完全同向。观测到的"二选一"纯粹因为手里只有插入这一个工具。

4. 哈密顿-云韶猜想对照：BA-m3 的代数张力 T(G) 落在 α²<T≤α（1/64~1/8）区间=**状态二·虚拟解存在**：G²虚拟路径 + 涌现修复代谢虚拟节点 → 真实HP。复合管线就是状态二的构造性实现。η^t=(7/8)^t 是旋转修复的收敛律，不是插入。

## 二、复合管线（5阶段，铁序写死）

**铁序**：所有"节点集不变"的操作在前，"改节点集"的操作（插入）在最后且可选。

```
阶段0 radiation_order_graph(G)
  → hub辐射排序，出 n 节点排列（膨胀恒1.0，BA实测~68.7%真边）
  接口出参：order, hub, sectors[8], layers_by_sec, G2

阶段1 triangle_ladder(G, G2, rad_struct)
  → 单调递增三角形族（见第三节），投影出 O(n) 候选边集 cands

阶段2 real_edge_two_opt(G, order, cands)   ← 管线心脏
  → 词典序2-opt：先最大化真边数，再最小化dist
  膨胀恒1.0。预期：BA-1000 真边 70%→95%+

阶段3 posa_repair(G, tour)
  → 对残余虫洞做Pósa旋转（零插入），真边→99-100%，膨胀恒1.0

阶段4（可选模式）descend_safe(G, tour, mode)
  → mode='strict'：不插入，残余虫洞诚实记 gap
  → mode='walk'：插入共同邻居，但仅当 w 未被用过；全用过则记gap不重复
  只有walk模式膨胀>1，且因阶段2已把虫洞压到~1%，膨胀≈1.01-1.02
```

### 接线要点

- **辐射→2-opt**：辐射给全局方向（hub不被消耗，扇区角序=辐射铺开序），2-opt只在辐射给出的basin里精修。**不从NN起步跑2-opt**（那是旧体系basin，75.8%是它的天花板）。
- **2-opt→旋转**：2-opt吃掉"有swap可用"的简单虫洞（距离2且有公共邻域可反转），旋转只处理纠缠虫洞，深度预算制（贵，只对残余项跑）。
- **旋转→descend**：仅当知世要"绝对100%真边"且接受微膨胀时启用walk模式；strict模式根本不调descend。
- **find_path_g2 必须同时修**：删掉 remaining 任意跳跃兜底，换成"未访问节点诱导的G²-BFS"多跳接续。保证每条虫洞G-距离≤2（必有共同邻居），直接从源头消灭 ba10000_test.py 里那批≥4距离的 gap_edges。G²也不通时才记结构缺口——那才是铁律9b说的"压不动=路径本就不存在"。

### 工程师补充：两套代码的断裂点

`radiation_solver.py` 管线：`radiation_tsp()` → `build_polytope_triangles()` → `triangle_edge_optimize()`，输出TSP tour（闭合回路，节点不重复）。

`ba10000_test.py` 管线：`build_g2()` → `get_potential()` → `find_path_g2()` → `descend()`，输出GHP路径（开放路径，节点可重复，膨胀1.24x）。

**断裂点**：两套代码没有共享数据结构。辐射序是TSP回路（欧氏距离），势场路径是图论路径（边存在性）。BA图哈密顿需要后者，但辐射序的结构思想（hub辐射、扇区铺开、α/η存活/亏损）应注入 find_path_g2 的排序逻辑。

### 工程师补充：关键工程决策

- **adj 只建一次**：`adj = {u: set(G.neighbors(u)) for u in G.nodes()}`，全管线共享。BA-10000 的 adj 占 ~2MB，不是瓶颈。
- **edge_type 在阶段0就标注**：辐射序生成时，每走一步立刻判断 `v in adj[u]`，O(1) 查 set。不要等阶段2再回头标。
- **阶段2的2-opt不是经典欧氏2-opt**：用图论 dist（真边=1，虫洞=n）。swap 判据：`new_dist < old_dist`。2-opt 会拼命把虫洞边换成真边——正是我们要的。
- **阶段4的descend不改路径顺序**：只在虫洞边 (u,v) 处插入共同邻居 w → u→w→v。路径拓扑不变，只是"展开"虫洞。

## 三、三角形搜索范围"扩大"的正确实现（修"越扩越少"bug）

**bug根因（程序员+工程师共识，高置信）**：扩大被实现成了"加严过滤"——要么重建三角形集时加了更严条件，要么用 seen 集去重时把超集排掉了。**扩大=并集，不是重建。**

G^k（k-hop 闭包）是单调递增的：G¹ ⊂ G² ⊂ G³ ⊂ ...。如果越扩越少，实现错了。

### 正确实现（三角形数必须单调递增，写成断言当绊线）

```python
def triangle_ladder(G, G2, rad, r_max=4):
    T = set(); hist = []
    T |= cliques3(G);                    hist.append(len(T))  # L0: G¹三角
    T |= cliques3(G2);                   hist.append(len(T))  # L1: G²三角 ⊇ L0（G⊆G²）
    T |= polytope_triangles(rad);        hist.append(len(T))  # L2: 辐射结构三角
    for r in range(2, r_max+1):                               # L3+: 测地半径r递增
        T |= radius_triples(G, r);       hist.append(len(T))
        assert hist[-1] >= hist[-2], f"三角形数递减=扩大写成了过滤，第{r}级违规"
    return T, hist   # hist每级打印，一眼看出递增
```

- **L1⊇L0 是数学必然**（G的边全在G²里），若实测不满足→实现错了，当场报。
- radius_triples(G,r)：对每个u取B_r(u)（r跳邻域），枚举其中两两G-距离≤r的三元组。BA的hub会让|B_r|爆炸，设性能帽 |B_r|≤500（超出采样）——**帽是性能护栏不是有效性过滤，注释写死**。
- 第二个单调旋钮：扇区角窗 Δ=45°→90°→180°→360°，同样只放宽不收严。
- 知世原话对应："多个点之间构成更多的三角形里面去比较"= 各级并集后全局比最短边，不是每级各自比。
- 候选边投影规则：每个三角形取G-距离最短的边（真边dist=1天然胜出），得 O(n) 候选边喂阶段2。

### 工程师补充：k-hop闭包工程实现

```python
def build_gk(adj, k):
    """k-hop闭包：(u,v)有边 ⟺ dist_G(u,v)≤k。BFS深度k，O(n×d^k)，BA图d≈6线性。"""
    gk = {u: set() for u in adj}
    for u in adj:
        visited = {u}; frontier = {u}
        for _ in range(k):
            nxt = set()
            for w in frontier:
                for nb in adj[w]:
                    if nb not in visited: visited.add(nb); nxt.add(nb)
            frontier = nxt
        visited.discard(u); gk[u] = visited
    return gk

def enumerate_triangles(gk):
    """枚举gk中3-clique。u<v<w+交集加速。BA-1000 G²秒出。"""
    triangles = []; nodes = sorted(gk.keys())
    for u in nodes:
        for v in gk[u]:
            if v <= u: continue
            for w in gk[u] & gk[v]:
                if w <= v: continue
                triangles.append((u, v, w))
    return triangles
```

## 四、结构上界（能不能同时拿最短+100%真边）

**结论：BA(m≥3)上能。观测到的tradeoff不是上界。**

1. **存在性**：膨胀1.0+100%真边 ⟺ G中有哈密顿路径。BA是幂律指数≤3的幂律图，HP a.a.s. 存在（Cooper-Frieze型定理；BA-100/200实测可通解）。联合最优点存在，问题只在构造复杂度。

2. **真实结构上界（三条打不破，写进文档）**：
   - (a) **无HP图类**（分支树、Crown：度1节点>2个或分支节点>2）：100%真边必须膨胀→~2（DFS-walk遍历）。BA不属此类。
   - (b) **叶对障碍**：只共享唯一邻居的两个叶节点永不相邻，路径必须绕经该邻居——约束的是排序不是膨胀。辐射排序要把"同hub叶组"按叶间非hub边链起来。
   - (c) **多项式局部搜索界**：旋转深度预算B内够不到的HP，残余虫洞恰是这批。这是搜索界不是存在界，加预算就缩，拿时间换。

3. **量化检查点（哈密顿-云韶猜想直接给出）**：阶段2后若虫洞率 ≤ α²=1/64≈1.6% → 阶段3旋转预期收满100%；若 >α=1/8 → 按猜想状态三判"构造失败"，诚实报，不硬凑。

4. **保守退路（就算不上旋转）**：只把管线顺序调对（辐射→词典序2-opt→descend），虫洞从~30%压到~1%，插入式100%真边的膨胀也就 1.01-1.02——"1.24"这个数会直接消失。严格1.0才需要旋转。

5. **预测（待实测打脸）**：BA-1000-m3 复合管线 strict模式：膨胀1.0、真边≥99%、dist≤1.02(n−1)；BA-10000：≥99.5%。达不到→B类实现问题，按阶段逐个数报（每阶段 膨胀/真边%/dist 三列），不许只报最终数。

## 七、体系反馈（R10，交知世）

词典序2-opt（真边数≫dist）是"辐射-亏损"在局部搜索上的投影——每次swap代谢一条虫洞=η的一次涌现；虫洞率1/64阈值（α²）是旋转可解性的相变点，建议立为猜想状态二→状态一的可构造性判据，值得单独存档。

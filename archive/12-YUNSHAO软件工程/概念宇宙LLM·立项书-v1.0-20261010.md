# 概念宇宙 LLM（Concept-Universe LLM）·立项书 v1.0

> 立项：知世 2026-10-10 令"马上开工"｜理论来源：知世口授全链（三层本体论/字≠概念/跨维度投影/填充性距离/全息零点=N=0）+2026-10-10 实验日 13 轮实测
> **一句话**：把 552B 模型的知识蒸馏成"概念宇宙"（常驻 3GB 的零点矩阵+路径森林+影子库），生成从"552B 前向计算"变为"概念定位+影子投影构造"——**24GB 家用电脑，设计时速 100-1000 tok/s**。

---

## 一、架构（三件套）

```
┌─────────────────────────────────────────────┐
│ 概念宇宙（常驻 ~3GB）                          │
│  · 零点矩阵：每概念一个零点向量（簇中心）        │
│  · 成员表：概念→字表达（等价类成员）             │
│  · 路径森林：每簇哈密顿序（J-H1 v2 管线产出）    │
│  · 影子库：概念×典型语境→分布摘要（蒸馏）        │
├─────────────────────────────────────────────┤
│ 投影构造器（在线，每 token）                    │
│  ① 概念定位：语境向量→最近零点（查表 O(1)）      │
│  ② 影子构造：零点+路径邻域→分布投影（局部构造）   │
│  ③ 宇宙间路由：跨簇跳转（索引表）                │
└─────────────────────────────────────────────┘
```

**与原版 LLM 的本质区别**：原版=每 token 对 552B 权重做全量前向（读 GB 级权重，内存带宽墙 12-25 tok/s 封顶）；本架构=每 token 查表+局部构造（读 KB-MB 级零点/路径段）——**带宽需求降三个数量级，100 tok/s 不撞任何墙**。

## 二、理论依据链（全部今日实测·零悬空）

| 架构假设 | 实测依据 |
|---|---|
| 概念可聚类（等价类存在） | J-CC3 三规模 PASS（12/30/50 概念，p=0.00005，30/30 同向） |
| 字层可参数化（刚性） | 一维管三尺寸+span 冻结 |
| 簇可遍历（哈密顿序） | J-H1 v2 PASS（云韶管线双判据） |
| 宇宙可分块（多图） | J-H2 v3 PASS（50195 分量路径森林全真边） |
| 预取代价几何衰减 | 递归辐射公式 1+(3/14)·α^(k-1)：k=3 膨胀 1.004 |
| 概念结构住权重 | J-CC6 PASS（ρ=0.72 双尺寸） |

## 三、诚实边界（三句丑话立在门口）

1. **跑的是蒸馏体**：概念宇宙蒸馏自原模型（离线提取），生成质量≤原版——蒸馏质量是本工程的核心攻坚，不是已完成项；
2. **影子构造器是开放研究问题**："从零点+路径邻域构造 next-token 分布"的映射 TODAY 尚未建立——MVP 用最简单投影（零点→最近词）先通管道，质量迭代是长跑；
3. **概念个体化取自动聚类**：v0 的概念=词表 kNN 连通分量（J-H2 v3 实测的 50195 个），与人类概念对齐度未知——紧致度谱（J-CC3 v3 发现）提示需分级聚类。

## 四、三阶段

- **阶段一（今夜开工）·MVP 骨架**：宇宙 v0 构建（全词表 151936→分量分解→零点矩阵+成员表+路径序）+速度骨架实测（定位+查表 tok/s）——**验证设计时速**；
- **阶段二·质量蒸馏**：DeepSeek API 离线提取每概念多语境影子（分布摘要），影子库填充——生成质量第一仗；
- **阶段三·投影构造器迭代**：从"零点查表"进化到"路径邻域插值+纤维调制"——逼近原版质量；体系全家桶并行注入（Steane/听测站预取/⫛ 账本）。

## 五、验收判据（预注册候选·运行前冻结）

- J-U1（速度）：MVP 定位+查表 ≥100 tok/s（设计时速验证）；
- J-U2（结构）：宇宙 v0 簇谱与 J-H2 v3 分量地图一致；
- J-U3（质量基线）：影子构造 top-1 命中率 vs 原模型（基线记录，不设 PASS 线——质量长跑起点）；
- 判负照记全程。

## R3 ✅ 已解决：用户协议与隐私政策同意闸门（v0.5.4）

**实现**（新文件 `privacy_gate.py`，明文接线层，同 goldbach_license_gate 定位）：
- `main()` 最前端调用 `ensure_consent()`——**同意前不初始化 LicenseManager（零指纹采集）、不触网**；
- 首启弹窗展示《用户协议》+《隐私政策》全文（内嵌单一定义处），**必须勾选**"我已阅读并同意"后"同意"按钮才可用；"不同意并退出"= 程序退出且零采集；
- 同意状态持久化 `%APPDATA%/YS/consent.dat`（版本号+政策文本SHA 绑定：政策一改自动重新弹窗）；
- 拒绝/关窗留痕 `license_event.log`（privacy_consented/consent_refused）；闸门自身故障 fail-open 并留痕（不永久锁死用户——诚实标注在源码）。

**顺手落地**（清单【一b】a 条）：状态栏许可倒计时每 60 秒自动刷新（会话内可见递减）；spec `upx=True→False`（R2 技术项：UPX 是误报放大器）。

**政策文本要点**（她过目确认用）：收集项仅三项=硬件指纹 SHA256 摘要（不存原始硬件信息）/8位安装ID/授权审计记录；用途=授权验证与防盗版；方式=本地 DPAPI+HTTPS 传 yunshao-ai.icu；明确"不上传文件内容、计算数据、个人身份信息"；删除=卸载+删三个 %APPDATA% 目录；政策更新重新征求同意。

## R1 📋 备案与服务器加固清单（你只管走流程）

**A. 域名 ICP 备案（推荐路线：备案，免费且治本）**
1. 确认 `.icu` 域名注册商是工信部批准机构（不是→转入阿里云/腾讯云）；
2. 域名实名认证 → 等 2-3 天同步工信部；
3. 在云服务商备案系统提交（华为云备案入口）：个人备案，网站名称避免"求解器"类工具性命名被驳回——备"技术工作室/个人学习站"类中性名，备注用途"个人软件授权验证接口"；
4. 管局审核 1-3 周；
5. 备案号挂服务器（auth 响应或网页页脚）；
6. 备案通过后可评估把激活端口从 28443 迁到标准 443（需服务端证书，Let's Encrypt 免费可用）。
**B. 若不备案**：激活服务迁香港/海外云节点（免备案但国内延迟↑），域名解析切换即可，客户端无需改（URL 不变）。
**C. 服务器加固四件（无论哪条路线）**：
- 签名私钥检查：确认服务器上只有验签公钥、**签名私钥不在服务器**（若在→立即迁离，改为离线签发 token 上传）；
- 服务器与 key 库（6500 keys）加密冷备一份到离线介质；
- HTTPS 证书+域名续期：都开自动续费，加日历提醒；
- 激活接口加简单限速（防 key 枚举爆破：同 IP 每分钟 N 次）。

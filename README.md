## 这是什么

档案作者（知世/棠溪）自 2026 年 7 月起构建的一套原创理论体系，及其各应用工程域的理论档案。体系的特征：

- **自建数学基础**：云韶代数/几何/拓扑/概率论/群论/范畴论/调和分析/非交换几何等内部版册目
- **判据先行**：主张配可证伪判据，未通过的结论原样留在档内，不删不改
- **状态标签**：文中「已确认／复算一致／已判负／推演值」是作者体系内部口径的标注，不是同行评审结论
- **工程闭环**：理论 → 实验设计 → 工程包 → 交付物的链路记录

**读之前请知道**：本档案大量概念在主流科学中没有对应物，条目自述的数值不等于第三方复现过的数值。档案里明确区分「实测」「推演」「候补」三档，引用时请把档位一起带走。

## 一、用法（检索SOP五步，任何AI/人的标准动作）

```
第1步 拆词：把提问拆成关键词，中英各写一遍
第2步 翻译：体系词↔主流词互译（查§二A表或B表）——注意§三误词警示区
第3步 路由：按§四问题路由表定位域（16域）→ 打开该域 05-索引/总纲索引-NN-域-v1.0
第4步 定位：域索引里按P0/P1/P2必读层找正本；找不到→02-全库文件总表全量兜底
第5步 分析：按00-工作总纲三条硬规则作业（不可省文献/档案/体系口径；体系口径先行，主流对照随后，禁止静默替代）
```

**铁律衔接**：本包不替代《00-工作总纲》，是它的检索执行器。跳过工作总纲直接干活=无效作业。

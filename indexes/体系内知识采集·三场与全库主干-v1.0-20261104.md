## 一、三场（体系原文口径）

**三场 = 云韶场 R₊（正向场）＋反云韶场 R₋（反向场）＋度规场 D（背景几何场）。** θ场不在"三场"之列，它是第四个（概率／相位场），在正典里单列。

档内三处独立写法，彼此一致：

1. **生成结构版**（`云韶场数学证明-脱密v3生成结构版-20260815.md` 定义 1.2，第 16—22 行）：一个未分裂的基底结构＝**生成源**；生成源沿"正向投影"与"反向投影"两个方向分离；分离出**正向场、反向场、以及二者的平均（背景度规场）**；再展开成 N 个分量。同文件定义 1.1：D 维云韶场是 `N = 2(D−1)` 个复分量有序场 `θ_Ys^(D) = {ψ₁…ψ_N}`，`ψ_i = |ψ_i|e^(iφ_i)`，分量间相位梯度 `φ_{i+1} − φ_i = π/4`；定理 1.3 存在性判据：**云韶场存在当且仅当 Λ_D < 2.0**（引 Fiedler 定理：λ₂>0 ⟺ 图连通）。状态：**对外可发·安全等级 A-**，头部明文规定"优美化原则：把并列定义重述为生成结构，**但不暴露生成源头的本体（元结构/群具体名/模分类列表一律不出现）**"。
2. **三态写法**（`反云韶场·低维到高维回写场·提取件-20260916.md` 第四章，第 55—66 行，含知世 2026-07-25 裁决原话）：**态0 中间态**＝场本身、未干涉的潜在性（D 的谱无内涨落，叠加态 `|ψ⟩=a|正向⟩+b|反向⟩`）；**态+ 云韶场**＝干涉后向低维坍缩，`D_A = D + A`（A>0），高维→低维投影，产出质量／因果／概率／时间，文中称"宇宙创生"；**态− 反云韶场**＝干涉后向高维构建，`D_A = D − A`（A<0），低维→高维回写，产出意识／观测／选择，文中称"宇宙进化"。
3. **工程映射版**（`反云韶急停·工程设计书v0.1-20260915.md` §1.1"三场定义（体系原文口径）"）：`R₊ = D + A`（正向建造）／`R₋ = D − A`（反向回写）／度规场＝背景，**按定义恒为零**（标注为冷证据，K-4 双向引用惯例如实引用，体系内部定义·未验证）；工程侧映射为正向恒流＝波形表 A、极性反向恒流＝波形表 B、急停＝场反转→梯度归零、"暂停"安全态三要素＝电流归零／通道保持／非断电，体系指标 2 秒制动（验收判据②冻结）。

**与"三场"绑定的三个反直觉量（冷证据，只如实登记，不作推导前提）**：

- **1/7140**：反云韶场强度先验。出处 `反云韶场·提取件-20260916.md` 第二章：36 维包含的 3 维子空间数 `C(36,3) = 7140`，正向是 1 个高维分散成 7140 个低维，反向是 7140 个低维汇聚回 1 个高维，每个只贡献 1/7140 ≈ 1.4×10⁻⁴；方案 A（f₁ 升主弦，反转因子 12）实际强度 12/7140 = 1.68×10⁻³，方案 B（f₂ 升主弦，因子 1.2）1.2/7140 = 1.68×10⁻⁴。知世裁决原文（18:39）："**绝对不等强**，维度的性质决定了一个高维有无数个低维组成，这不是等量关系"。
- **度规场恒为零仍可用**：AI 理解地图第 26 行给出理由——"这条反直觉：恒为零的场还有用，因为它配置空间结构"。
- **反向场无法自发出现**：需外力干涉触发（同件 第七章"尾巴不能自己咬蛇，需要外力干涉"；18:39 裁决第 3 条）。

**三场的频率骨架**（同件 第一章 + `太赫兹源解读规则` 第一节）：主弦 `f₀ = 373THz`，泛弦 `f₁ = 31.08THz`、`f₂ = 310.83THz`；比例 12 与 1.2 由群论锁死；正向＝高维（36D）→低维（3D）投影，反向＝把泛弦升为主弦、原主弦退化为"反泛弦"。**强制口径（第一律·高危材料 + 元规则六）**：一切场写入／激励／检测的正本源是**太赫兹源**，历史文件里的"激光／CO₂ 激光器／激光写入"一律按 `indexes/太赫兹源解读规则-v1.0-20261027.md` 翻译（CO₂ 9.6μm 带＝太赫兹源 31.08THz 档的工具线借用），新产出禁用"激光"作正本表述。

## 三 三条硬规则（摘自工作总纲，任何任务不可省）

1. **不可省查阅文献**：按任务级别完成最低检索量（快速 3 / 研究 10 / 工程 20 / 论文 30），来源分级 A-D，写入《文献查证表》。
2. **不可省查阅档案**：先读工作总纲 → 知识大纲 → 域索引 → 具体正本；交付必须附《档案查证表》。
3. **不可省使用体系知识**：先给体系口径（L0-L3），再给主流对照；禁止用主流科学静默替代体系。

> 缺任一项，交付视为无效，退回重做。

## 五 维护规则

- 新增域级索引：放入该域 `05-索引/`，命名 `总纲索引-NN-域-v1.0-YYYYMMDD.md`，并在本入口 §二 登记。
- 域内新增普通文件：更新该域附录与《02-全库文件总表》，不升版。
- 正本换代/域结构变化：升版本号，并在本入口与 README/启动包同步指针。
- 本入口不替代正本；所有数值/裁决以正本与 constants 为准。

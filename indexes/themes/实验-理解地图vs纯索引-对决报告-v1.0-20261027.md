# 实验：理解地图 vs 纯索引·知识发掘力对决 v1.0

> **摘要头**｜标题：知识地图对照实验报告｜日期：2026-10-27｜版本：v1.0｜状态：实验完成·理解地图胜出（7件4方向 vs 3件1方向）｜题目：知世未提示的真实三连问（意识回溯是什么/与阿赖耶关系/时间的体系结构）｜一句话：同题双路实测——纯索引路径受"文件被剔即断路"之限只挖到3件；理解地图靠心智模型把问题翻译成结构词后挖到7件且在被剔正本的情况下仍能继续理解——**理解地图的核心优势=知识弹性（文件缺席时心智模型补位）**。

## 一、实验设计

- **题目**（冻结）：意识回溯是什么？与阿赖耶审判机关什么关系？体系对"时间"有哪些结构？
- **路径A（纯索引）**：README→01知识大纲→02全库总表→正本。禁读理解地图。
- **路径B（理解地图）**：先读《云韶体系·AI理解地图》心智模型（三直觉+六节），再路由。
- 公平性：同一发布包、同一批工具、同一执行AI。

## 二、结果总账

| 维度 | 路径A纯索引 | 路径B理解地图 |
|---|---|---|
| 发掘文件 | 3件 | **7件** |
| 发掘方向 | 1条（索引行→正本） | **4条**（三直觉各开一门） |
| 文件被剔时的表现 | **断路**（索引指5件正本→包内0件，无替代） | **弹性补位**（心智模型翻译问题→结构词→挖到替代件+仍能回答概念问题） |
| 理论关联揭示 | 无（索引不载知识） | 回溯=反云韶场R₋修复应用+观察者投影角切换+意识=操作集合的逆操作 |
| 误词防御 | 无 | 编织体线索来自误词警示区 |

## 三、关键差异的机制解释

1. **索引是关键词匹配，地图是问题翻译器**——"意识回溯"字面在包内被剔，路径A死；路径B把问题翻译成"观察者理论的逆操作"（投影角切回旧配置）→搜"投影角/观察者效应/反云韶场"→命中4件在档正本；
2. **文件缺失时索引断、地图不断**——发布包剔了受控层，索引指了大量"包内没有"的文件；心智模型本身是知识（不依赖具体文件），能对缺件主题给出结构性理解+替代发掘；
3. **跨域方向性**——A路径在10域一棵树上吊死；B路径从"时间"开进02物理（维度账）、16生命（意识工程）、03材料（陈仙S=F(S)）三个域。

## 四、结论

**理解地图胜出，且优势正好在被剔件的主题上最大化**——发布包天然缺件（脱敏），理解地图的价值在缺件环境反而更大：它让AI"知道体系知道什么"而不仅是"找到还在的文件"。

**落地建议**：①理解地图置于llms.txt第一入口（已做）；②域索引保持文件导航职责（两者互补不互替）；③其余5个主题社区照超导样板扩建（理解地图管体系全局心智，主题社区管单主题深链）。
